Middle School

MS · Problem 1 · Easy Number Theory

For an odd positive integer \(n\), the double factorial \(n!!\) is the product of all the odd numbers from \(1\) to \(n\). For example, \(7!! = 1 \cdot 3 \cdot 5 \cdot 7 = 105\). What are the last two digits of \[ 1!! + 3!! + 5!! + 7!! + \cdots + 2025!! \, ? \] (Give your answer as a number from \(0\) to \(99\).)

The last two digits of a number are its remainder when divided by \(100\). The key fact is that remainders travel through sums and products: the last two digits of \(a + b\) and of \(a \cdot b\) depend only on the last two digits of \(a\) and of \(b\). So we never need the huge numbers themselves (\(2025!!\) has almost \(3000\) digits). Build each term from the one before it, \(n!! = (n-2)!! \cdot n\), keep only the remainder mod \(100\) of the term and of the running sum, and add up all \(1013\) terms. The answer is \(49\). A pattern helps check it: from \(15!!\) on every term contains the factors \(5\) and \(15\), so it is a multiple of \(25\); it is also odd, so it ends in \(25\) or \(75\). The code does the remainder method and also checks it once with Python’s exact big integers.
# MATH: last two digits = remainder mod 100, and remainders travel through
# + and *, so we keep only (term mod 100) and (sum mod 100) at every step.
# n!! = (n - 2)!! * n, so each term comes from the one before it.
N = 2025
term, total = 1, 0
for n in range(1, N + 1, 2):        # odd n = 1, 3, 5, ..., 2025 (1013 terms)
    term = term * n % 100           # n!! mod 100
    total = (total + term) % 100
print(total)                        # 49

# check once with Python's exact (big) integers
term, exact = 1, 0
for n in range(1, N + 1, 2):
    term *= n
    exact += term
assert exact % 100 == total

MS · Problem 2 · Easy Geometry

A regular polygon has all its sides equal and all its angles equal. For how many whole numbers \(n\) with \(3 \le n \le 1000\) does each interior angle of a regular polygon with \(n\) sides measure a whole number of degrees?

The interior angles of a polygon with \(n\) sides add up to \((n - 2) \cdot 180^\circ\) (cut it into \(n - 2\) triangles from one corner). In a regular polygon all \(n\) angles are equal, so each one is \[ \frac{(n-2) \cdot 180}{n} = 180 - \frac{360}{n} \ \text{degrees}. \] This is a whole number exactly when \(n\) divides \(360\). Now \(360 = 2^3 \cdot 3^2 \cdot 5\) has \((3+1)(2+1)(1+1) = 24\) divisors, and two of them (\(1\) and \(2\)) are too small to be a number of sides. So the answer is \(24 - 2 = 22\), from the triangle (\(60^\circ\)) up to the \(360\)-gon (\(179^\circ\)). Every \(n\) larger than \(360\) fails, because then \(0 < 360/n < 1\). The code tests every \(n\) up to \(1000\) and also checks the divisor count.
# MATH: each interior angle of a regular n-gon is (n - 2) * 180 / n
#       = 180 - 360 / n degrees -> a whole number exactly when n | 360.
good = [n for n in range(3, 1001) if (n - 2) * 180 % n == 0]
print(good)                          # 3, 4, 5, 6, 8, 9, 10, 12, ..., 360

divisors_360 = [d for d in range(1, 361) if 360 % d == 0]
assert good == [d for d in divisors_360 if d >= 3]   # 24 divisors minus 1 and 2
print(len(good))                     # 22

MS · Problem 3 · Medium Combinatorics

How many different arrangements of the nine letters of the word TENNESSEE have no two letters E next to each other? (For example, ENSETENSE is allowed, but EENSETNSE is not.)

TENNESSEE has \(4\) E’s and \(5\) other letters: T, N, N, S, S. Step 1: line up the \(5\) other letters. Because the two N’s look the same, and so do the two S’s, there are \(\dfrac{5!}{2! \cdot 2!} = 30\) different lines. Step 2: the E’s go into the gaps: before the first letter, between two letters, or after the last — \(6\) gaps in all. No two E’s are next to each other exactly when each gap gets at most one E, so we choose \(4\) of the \(6\) gaps: \(\binom{6}{4} = 15\) ways. Each arrangement comes from exactly one choice in step 1 and one in step 2, so there are \(30 \cdot 15 = 450\). (The word has \(\frac{9!}{4!\,2!\,2!} = 3780\) arrangements in all.) The code builds every different arrangement with a set, and checks the gap count.
# MATH ("gap method"): arrange T, N, N, S, S first: 5! / (2! 2!) = 30 ways.
# The 4 E's go into the 6 gaps around them, at most one per gap: C(6, 4) = 15.
# So 30 * 15 = 450.
from itertools import permutations
from math import comb, factorial

word = "TENNESSEE"
arrangements = set(permutations(word))      # a set: equal letters, counted once
print(len(arrangements))                    # 3780
good = [w for w in arrangements if "EE" not in "".join(w)]

by_gaps = factorial(5) // (factorial(2) * factorial(2)) * comb(6, 4)
assert len(good) == by_gaps
print(len(good))                            # 450

MS · Problem 4 · Medium Algebra

Eighteen integers \(a_1, a_2, a_3, \dots, a_{18}\) are equally spaced on the number line, in this order: \(a_2 - a_1 = a_3 - a_2 = \cdots = a_{18} - a_{17}\). We also know that \[ 1 \le a_1 \le 10, \qquad 20 \le a_2 \le 27, \qquad 400 \le a_{18} \le 409. \] What is \(a_{17}\)?

Call the common step \(d\), so \(a_k = a_1 + (k - 1)d\) and \(a_{18} = a_1 + 17d\). Bound the step: \(d = a_2 - a_1\) is a whole number, and \(a_{18} - a_1 = 17d\) lies between \(400 - 10 = 390\) and \(409 - 1 = 408\). The only multiples of \(17\) in that range are \(391 = 17 \cdot 23\) and \(408 = 17 \cdot 24\). If \(d = 23\): \(a_1 + 391 \ge 400\) forces \(a_1 \ge 9\), but then \(a_2 = a_1 + 23 \ge 32\), too big. If \(d = 24\): \(a_1 + 408 \le 409\) forces \(a_1 = 1\), and then \(a_2 = 25\) and \(a_{18} = 409\) both fit. So the sequence is \(1, 25, 49, \dots, 409\), and \(a_{17} = 1 + 16 \cdot 24 = 385\). The code tries every possible \(a_1\) and \(a_2\) and confirms that exactly one sequence fits.
# MATH: a_k = a_1 + (k - 1) d.  17d = a_18 - a_1 lies in [390, 408], so
# d = 23 or 24; d = 23 makes a_2 too big, d = 24 forces a_1 = 1.
# Complete search: a_1 and a_2 decide the whole sequence.
answers = []
for a1 in range(1, 11):
    for a2 in range(20, 28):
        d = a2 - a1
        seq = [a1 + k * d for k in range(18)]       # a_1 ... a_18
        if 400 <= seq[17] <= 409:
            answers.append(seq)
assert len(answers) == 1                            # exactly one sequence fits
seq = answers[0]
print(seq[:3], seq[-1])                             # [1, 25, 49] 409
print(seq[16])                                      # a_17 = 385

MS · Problem 5 · Hard Geometry

Consider the \(27\) points \((x, y, z)\) in space with each of \(x, y, z\) equal to \(0\), \(1\) or \(2\). (They are the corners, edge midpoints, face centres and centre of a \(2 \times 2 \times 2\) cube.) How many equilateral triangles have all three vertices among these \(27\) points?

There are \(\binom{27}{3} = 2925\) ways to choose three of the points — few enough to test them all. A triangle is equilateral when its three sides are equal, and it is safest to compare squared lengths: by Pythagoras in space, the squared distance between \((x_1, y_1, z_1)\) and \((x_2, y_2, z_2)\) is \((x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2\), a whole number, so the test is exact (no square roots, no rounding). Three equal side lengths can never lie on one line, so every match really is a triangle. There are \(80\) of them, with squared sides \(2\), \(6\) or \(8\). Picture them: \(64\) small ones (side \(\sqrt2\)) cut off corners of the eight unit cubes, \(8\) big ones (side \(\sqrt8\)) cut off corners of the whole cube, and \(8\) tilted ones of side \(\sqrt6\) through the centre. The code checks all \(2925\) triples and reports how many of each size it finds.
# MATH: test all C(27, 3) = 2925 triples. Compare SQUARED distances
# (integers, by Pythagoras in 3D), so "equal sides" is an exact test.
from itertools import combinations, product
from collections import Counter

points = list(product(range(3), repeat=3))          # 27 points

def sq_dist(P, Q):
    return sum((p - q) ** 2 for p, q in zip(P, Q))

sizes = Counter()
for A, B, C in combinations(points, 3):
    ab, bc, ca = sq_dist(A, B), sq_dist(B, C), sq_dist(C, A)
    if ab == bc == ca:                               # equilateral (never collinear)
        sizes[ab] += 1
print(sorted(sizes.items()))                         # [(2, 64), (6, 8), (8, 8)]
print(sum(sizes.values()))                           # 80

High School

HS · Problem 1 · Easy Algebra

For how many integers \(k\) does the equation \(x^2 + kx + 720 = 0\) have two different integer solutions?

If the solutions are the integers \(r \ne s\), then \(x^2 + kx + 720 = (x - r)(x - s) = x^2 - (r + s)x + rs\), so (Vieta) \(rs = 720\) and \(k = -(r + s)\). Conversely, every pair of different integers with product \(720\) gives such a \(k\). The product is positive, so \(r\) and \(s\) are both positive or both negative. \(720 = 2^4 \cdot 3^2 \cdot 5\) has \(5 \cdot 3 \cdot 2 = 30\) positive divisors, which pair up as \(\{d, 720/d\}\) into \(15\) pairs (never \(d = 720/d\), since \(720\) is not a perfect square). With the negative pairs that makes \(30\) pairs. Different pairs give different \(k\): two numbers are fixed by their sum and their product. So there are \(30\) values of \(k\). The code collects the values of \(k\) in a set and checks each equation.
# MATH (Vieta): roots r != s with r * s = 720 and k = -(r + s).
# 30 positive divisors -> 15 positive pairs, 15 negative pairs -> 30 values.
N = 720
ks = set()
for r in range(-N, N + 1):
    if r != 0 and N % r == 0:
        s = N // r
        if r != s:
            k = -(r + s)
            assert r * r + k * r + N == 0 and s * s + k * s + N == 0
            ks.add(k)
print(sorted(ks)[:4], "...")       # [-721, -362, -243, -184] ...
print(len(ks))                     # 30

HS · Problem 2 · Easy Geometry

How many points with integer coordinates lie on the circle \(x^2 + y^2 = 5525\)?

Every point on the circle has \(|x| \le \sqrt{5525} < 75\). So the whole search is: for each integer \(x\) from \(-74\) to \(74\), is \(5525 - x^2\) a perfect square? Use exact integer square roots (math.isqrt) rather than floating-point sqrt, and count both \(y\) and \(-y\) (only once when \(y = 0\)). There are \(48\) points. Number theory explains the count: \(5525 = 5^2 \cdot 13 \cdot 17\), and every prime factor leaves remainder \(1\) when divided by \(4\). For such a number the count of lattice points is \(4\) times its number of divisors, \(4 \cdot (3 \cdot 2 \cdot 2) = 48\). By symmetry each point \((a, b)\) with \(a, b > 0\) comes with seven partners, such as \((\pm a, \pm b)\) and \((\pm b, \pm a)\). The code does the search and checks the divisor formula.
# MATH: |x| <= sqrt(5525) < 75, so try every x and test whether 5525 - x^2
# is a perfect square (exact integer square root, no floating point).
from math import isqrt

R2 = 5525
points = []
for x in range(-isqrt(R2), isqrt(R2) + 1):
    rest = R2 - x * x
    y = isqrt(rest)
    if y * y == rest:
        points.append((x, y))
        if y != 0:
            points.append((x, -y))
print(len(points))                 # 48

# check: 5525 = 5^2 * 13 * 17, all primes 1 mod 4 -> 4 * (number of divisors)
divisors = sum(1 for d in range(1, R2 + 1) if R2 % d == 0)
assert len(points) == 4 * divisors

HS · Problem 3 · Medium Combinatorics

Mia rolls a fair six-sided die \(6\) times and keeps a running total of the numbers rolled. The probability that her running total equals exactly \(10\) at some point is \(\dfrac{m}{n}\), where \(m\) and \(n\) are relatively prime positive integers. Find \(m + n\).

Let \(p(k, t)\) be the probability of reaching total exactly \(10\) at some point when the running total is now \(t\) and \(k\) rolls have been used. Then \(p(k, 10) = 1\); \(p(k, t) = 0\) if \(t > 10\) (the total only grows, so it has jumped past \(10\)) or if all \(6\) rolls are used; and otherwise the next roll is \(1, \dots, 6\), each with probability \(\frac16\): \[ p(k, t) = \tfrac16 \sum_{i=1}^{6} p(k + 1, t + i). \] The answer is \(p(0, 0) = \dfrac{749}{2592}\) (exact fractions, no rounding), so \(m + n = 3341\). There are only \(6^6 = 46\,656\) possible roll sequences, so the code also checks the answer by trying every one of them.
# MATH: p(k, t) = chance of hitting total 10 from total t after k rolls.
# p = 1 at t == 10; p = 0 past 10 or with no rolls left; else average of
# the six next states. Exact fractions -> exact answer.
from fractions import Fraction
from functools import lru_cache
from itertools import product, accumulate

ROLLS, TARGET = 6, 10

@lru_cache(maxsize=None)
def p(k, t):
    if t == TARGET:
        return Fraction(1)
    if t > TARGET or k == ROLLS:
        return Fraction(0)
    return sum(p(k + 1, t + i) for i in range(1, 7)) / 6

ans = p(0, 0)
print(ans)                                   # 749/2592

# check by trying all 6^6 = 46656 roll sequences
hits = sum(1 for rolls in product(range(1, 7), repeat=ROLLS)
           if TARGET in accumulate(rolls))
assert Fraction(hits, 6 ** ROLLS) == ans
print(ans.numerator + ans.denominator)       # 3341

HS · Problem 4 · Medium Number Theory

Let \(L\) be the least common multiple of \(1, 2, 3, \dots, 19\). The positive integer \(h\) satisfies \[ \frac11 + \frac12 + \frac13 + \cdots + \frac1{19} = \frac{h}{L}. \] What is the remainder when \(h\) is divided by \(19\)?

Multiply both sides by \(L\): \(h = \dfrac{L}{1} + \dfrac{L}{2} + \cdots + \dfrac{L}{19}\), a sum of whole numbers because each \(k\) divides \(L\). The prime \(19\) appears in \(L\) exactly once (\(19^2 = 361 > 19\)), and \(19\) is the only multiple of \(19\) up to \(19\). So for \(k \ne 19\), \(L/k\) still contains the factor \(19\) and is divisible by \(19\). Only one term matters: \[ h \equiv \frac{L}{19} = \operatorname{lcm}(1, 2, \dots, 18) = 12\,252\,240 \pmod{19}, \] and \(12\,252\,240 = 19 \cdot 644\,854 + 14\). The remainder is \(14\). Python’s integers are exact, so the code can compute \(h\) itself and check the shortcut.
# MATH: h = sum of L / k. Every term with k != 19 still has the factor 19,
# so h = L / 19 = lcm(1, ..., 18)  (mod 19).
from math import lcm
from fractions import Fraction

N = 19
L = lcm(*range(1, N + 1))
h = sum(L // k for k in range(1, N + 1))
assert Fraction(h, L) == sum(Fraction(1, k) for k in range(1, N + 1))

shortcut = lcm(*range(1, N)) % N
assert h % N == shortcut
print(h % N)                       # 14

HS · Problem 5 · Hard Geometry

For each positive integer \(k\), let \(T_k\) be the transformation of the coordinate plane that first rotates the plane \(7k\) degrees counterclockwise about the origin and then reflects it across the line \(y = x\). What is the least positive integer \(n\) such that applying \(T_1\), then \(T_2\), then \(T_3\), …, then \(T_n\) returns the point \((1, 0)\) to itself?

Both moves keep the distance to the origin, so it is enough to follow the angle \(\theta\) of the point (in degrees, measured from the positive \(x\)-axis). Rotating adds \(7k\); reflecting across \(y = x\) sends \(\theta\) to \(90 - \theta\). So \[ T_k : \theta \mapsto 90 - (\theta + 7k). \] Pair the steps. Applying \(T_k\) and then \(T_{k+1}\) gives \(90 - \big(90 - \theta - 7k\big) - 7(k+1) = \theta - 7\): every pair of steps is just a rotation by \(-7^\circ\). Start at \(\theta = 0\). After \(n = 2m\) steps the angle is \(-7m\); after \(n = 2m + 1\) steps it is \(90 - (-7m) - 7(2m+1) = 83 - 7m\). We need the angle to be a multiple of \(360\). Even \(n\): \(7m \equiv 0\), so \(m = 360\) and \(n = 720\). Odd \(n\): \(7m \equiv 83 \pmod{360}\). Since \(7 \cdot 103 = 721 \equiv 1\), this means \(m \equiv 83 \cdot 103 \equiv 269\), so \(n = 2 \cdot 269 + 1 = 539\). The smaller is \(539\). The code follows the angle with exact integers, step by step, and checks the result with real coordinates.
# MATH: follow the angle theta (degrees). T_k: theta -> 90 - (theta + 7k).
# Two steps T_k then T_(k+1) = rotation by -7, so the angle is -7m after 2m
# steps and 83 - 7m after 2m + 1 steps -> first return at n = 539.
from math import cos, sin, radians, isclose

theta, n = 0, 0
while True:
    n += 1
    theta = (90 - (theta + 7 * n)) % 360          # exact integer degrees
    if theta == 0:
        break
print(n)                                          # 539

# check with real coordinates: rotate, then swap x and y (reflect in y = x)
x, y = 1.0, 0.0
for k in range(1, n + 1):
    a = radians(7 * k)
    x, y = x * cos(a) - y * sin(a), x * sin(a) + y * cos(a)
    x, y = y, x
assert isclose(x, 1, abs_tol=1e-9) and isclose(y, 0, abs_tol=1e-9)
