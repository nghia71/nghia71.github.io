1An exact answer m/n, and why the denominator is what it is
Find 1/(1·2·3) + 1/(2·3·4) + … + 1/(20·21·22) as m/n in lowest terms, then m + n. total adds the terms exactly, m_plus_n finishes the answer, and factorize shows where the denominator comes from.
Uses ALG.SUM.partial FIN.FRAC.tools NT.FAC.factorize
s = total(lambda k: F(1, k * (k + 1) * (k + 2)), 1, 20)
print(s)   # -> 115/462
print(m_plus_n(s))   # -> 577
m, n = mn(s)
print(show_factors(factorize(n)))   # -> 2 * 3 * 7 * 11
2Numbers with exactly 6 divisors
How many n from 1 to 500 have exactly 6 divisors, and which is the smallest odd one? Then look at the factorisations: every such n is p⁵ or p²·q. Write the property once; count and first do the searching; factorize explains the answer.
Uses NT.DIV.count FIN.SEARCH.first NT.FAC.factorize
def six_divisors(n):
    return divisor_count(n) == 6

print(count(six_divisors, 1, 500))   # -> 59
odd = first(lambda n: n % 2 == 1 and six_divisors(n))
print(odd, divisors(odd))   # -> 45 [1, 3, 5, 9, 15, 45]
print([show_factors(factorize(n)) for n in range(1, 60) if six_divisors(n)])
# -> ['2^2 * 3', '2 * 3^2', '2^2 * 5', '2^2 * 7', '2^5', '2^2 * 11', '3^2 * 5', '2 * 5^2', '2^2 * 13']
3Paths with a closed point: count, check, draw
Walk from (0, 0) to (5, 4) by steps right or up; the point (2, 2) is closed. grid_paths counts directly. The check: all paths minus the paths through (2, 2), using choose. The picture writes the number of paths at every point.

direct = grid_paths(5, 4, blocked={(2, 2)})
through = choose(4, 2) * choose(5, 2)

4A probability as m/n
Two fair dice are rolled. The probability that the product is a multiple of 6 is m/n in lowest terms; find m + n. combine and die build the distribution of the product, prob adds up the outcomes, m_plus_n finishes.
Uses PROB.DIST.finite FIN.FRAC.tools
product = combine(die(6), die(6), lambda a, b: a * b)
p = prob(product, lambda x: x % 6 == 0)
print(p, m_plus_n(p))   # -> 5/12 17
print(expect(product))   # -> 49/4

6Check your own formula with a slow count
Guess: an n × n board contains 1² + 2² + … + n² squares with sides along the grid. Test the guess against a direct count of squares on the dots for n = 1 to 7; compare stops at the first n where they differ.
Uses FIN.CHECK.compare COMB.FIG.count
def formula(n):
    return sum(k * k for k in range(1, n + 1))

def direct(n):
    return count_squares(grid_points(n, n), tilted=False)

print(compare(formula, direct, range(1, 8)), "values agree")   # -> 7 values agree
print(formula(8))   # -> 204
7Last two digits of a huge power
What are the last two digits of 3²⁰²⁶? The last two digits of the powers of 3 repeat. find_cycle finds the repeat, order gives the same period from number theory, nth_by_cycle jumps to step 2026.
Uses ALG.REC.iterate NT.MOD.order
step = lambda x: x * 3 % 100
print(find_cycle(step, 1))   # -> (0, 20)
print(order(3, 100))   # -> 20
print(nth_by_cycle(step, 1, 2026), pow(3, 2026, 100))   # -> 29 29

9Palindromic squares, and which of them come from primes
Which n below 1000 have a palindromic square (like 26² = 676)? Which of those n are prime, and what are the digit sums of their squares?
Uses NT.DIGIT.digits NT.PRIME.is_prime
found = [n for n in range(1, 1000) if is_palindrome(n * n)]
print(found)   # -> [1, 2, 3, 11, 22, 26, 101, 111, 121, 202, 212, 264, 307, 836]
print([n for n in found if is_prime(n)])   # -> [2, 3, 11, 101, 307]
print([digit_sum(n * n) for n in found])
# -> [1, 4, 9, 4, 16, 19, 4, 9, 16, 16, 25, 36, 28, 46]
