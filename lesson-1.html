MS · Purple Comet 2004, Problem 1 · Easy Number Theory

This year February 29 fell on a Sunday. In what year will February 29 next fall on a Sunday?

A leap year happens every 4 years, except a century year (divisible by 100) is not a leap year unless it’s also divisible by 400 — that exception rule is exactly the kind of thing that’s easy to misremember or miscount by hand over a 28-year search, but trivial to state as a precise boolean rule and let code apply faithfully, year after year, without ever slipping. Once the leap-year rule is nailed down exactly, the day-of-week question is just: which of those leap years lands Feb 29 on a Sunday?
# MATH: a year is a leap year iff divisible by 4, EXCEPT a century
# year (divisible by 100) is NOT a leap year, UNLESS it's also
# divisible by 400. That exact rule (not "every 4 years") is what
# fixes the actual day-of-week drift between leap years -- get it
# wrong and the count silently comes out off by a day every century.
import datetime

def is_leap(y):
    return y % 4 == 0 and (y % 100 != 0 or y % 400 == 0)

d0 = datetime.date(2004, 2, 29)
print(d0.strftime('%A'))   # Sunday -- confirms the given fact

y = 2004
while True:
    y += 1
    if is_leap(y):
        d = datetime.date(y, 2, 29)
        if d.weekday() == 6:   # Python: Monday=0 ... Sunday=6
            print(y)           # 2032
            break

MS · Purple Comet 2004, Problem 2 · Easy Algebra

If \(h(a,b,c) = \dfrac{abc}{a+b+c}\), find \(h(3\sqrt5,\ 6\sqrt5,\ 9\sqrt5)\).

Don’t substitute the surds and grind through the arithmetic — look at how \(h\) behaves under scaling instead. The numerator \(abc\) is degree 3 in \((a,b,c)\); the denominator \(a+b+c\) is degree 1. So replacing \((a,b,c)\) with \((ka,kb,kc)\) multiplies the numerator by \(k^3\) and the denominator by \(k^1\), which multiplies \(h\) itself by \(k^{3-1}=k^2\). (Functions that scale this cleanly — by a fixed power of \(k\) — come up often enough in later chapters to have a name, homogeneous, but the argument here stands on its own without it.) Here \(k=\sqrt5\), so \(h(3\sqrt5,6\sqrt5,9\sqrt5) = 5\cdot h(3,6,9)\), and \(h(3,6,9)\) is easy integer arithmetic.
# MATH: h(a,b,c) = abc/(a+b+c) is homogeneous of degree 2 -- scaling
# every input by k multiplies the numerator by k^3 and the denominator
# by k^1, so h itself scales by k^(3-1) = k^2. Prove that symbolically
# first (works for ANY a,b,c,k), then use k = sqrt(5) to avoid ever
# doing surd arithmetic by hand: h(3root5,6root5,9root5) = 5*h(3,6,9).
import sympy as sp

a, b, c, k = sp.symbols('a b c k', positive=True)
h = a*b*c / (a + b + c)
scale_factor = sp.simplify(h.subs({a: k*a, b: k*b, c: k*c}) / h)
print(scale_factor)                       # k**2

h39 = h.subs({a: 3, b: 6, c: 9})
answer = sp.simplify(sp.Integer(5) * h39)  # k=sqrt(5) -> k**2 = 5
print(h39, answer)                         # 9 45

MS · Purple Comet 2004, Problem 3 · Medium Geometry

In \(\triangle ABC\), three lines are drawn parallel to side \(BC\), dividing the altitude of the triangle into four equal parts. If the area of the second-largest part is 35, what is the area of the whole \(\triangle ABC\)?

Solution 1 — similar triangles.

Each line parallel to \(BC\) cuts off a smaller triangle, from the apex, that is similar to \(\triangle ABC\). A triangle similar with linear scale factor \(k\) has area \(k^2\) times the original. With the altitude split into quarters, the four nested triangles (from the apex down) scale as \(k = \tfrac14, \tfrac12, \tfrac34, 1\), so their areas are \(\tfrac{1}{16}, \tfrac{4}{16}, \tfrac{9}{16}, \tfrac{16}{16}\) of the whole. The four strips between them are the successive differences: \(\tfrac{1}{16}, \tfrac{3}{16}, \tfrac{5}{16}, \tfrac{7}{16}\) — a 1:3:5:7 split that holds for every triangle cut this way, regardless of size.
# MATH: the three lines parallel to BC cut off, from the apex, smaller
# triangles similar to the whole triangle with linear scale factors
# k = 1/4, 1/2, 3/4, 1. Similar triangles scale AREA by k^2, so those
# four nested triangles have areas (k^2)*A for each k -- true for the
# whole family of such triangles, not just one particular size. The
# four strips are the successive differences of those nested areas.
import sympy as sp

A, k = sp.symbols('A k', positive=True)
subtriangle_area = k**2 * A

strips, prev = [], sp.Integer(0)
for frac in (sp.Rational(1,4), sp.Rational(1,2), sp.Rational(3,4), sp.Rational(1,1)):
    area_k = subtriangle_area.subs(k, frac)
    strips.append(sp.simplify(area_k - prev))
    prev = area_k
print(strips)                        # [A/16, 3*A/16, 5*A/16, 7*A/16]

second_largest = sorted(strips, key=lambda e: e.subs(A, 1))[-2]   # 5A/16
print(sp.solve(sp.Eq(second_largest, 35), A))                     # [112]

Solution 2 — coordinates, as a cross-check.

The similar-triangles argument is the fast route, but it’s worth confirming with an independent method: place the triangle with apex \(A\) at height \(4h\) above a base of half-width \(b\). By similar triangles, the horizontal segment at height \(y\) has half-width \(b(1-\tfrac{y}{4h})\), so each strip between two heights is a trapezoid whose area is computable directly from its two parallel widths — no appeal to “similar triangles scale area by \(k^2\)” as a remembered fact, just the trapezoid area formula applied four times.
# MATH: build the triangle in coordinates -- apex at height 4h, base
# half-width b -- and compute each strip as an ordinary TRAPEZOID area
# (average of its two parallel widths, times its height), using only
# the trapezoid-area formula, not the "area scales as k^2" fact from
# Solution 1. An independent method landing on the same 1:3:5:7 ratio
# and the same final answer is strong confirmation neither has an error.
import sympy as sp

b, h = sp.symbols('b h', positive=True)

def half_width(y):
    return b*(1 - y/(4*h))

def strip_area(y_lo, y_hi):
    w_lo, w_hi = 2*half_width(y_lo), 2*half_width(y_hi)
    return sp.simplify((w_lo + w_hi)/2 * (y_hi - y_lo))

strips = [strip_area(3*h, 4*h), strip_area(2*h, 3*h), strip_area(1*h, 2*h), strip_area(0, 1*h)]
whole = sp.simplify(sp.Rational(1,2)*(2*b)*(4*h))
ratios = [sp.simplify(s/whole) for s in strips]
print(ratios)   # [1/16, 3/16, 5/16, 7/16] -- matches Solution 1 exactly

second_largest_ratio = sorted(ratios)[-2]     # 5/16
W = sp.symbols('W', positive=True)
print(sp.solve(sp.Eq(second_largest_ratio*W, 35), W))   # [112]

MS · Purple Comet 2004, Problem 4 · Easy Algebra

If the numbers \(2a+2\) and \(2b+2\) add up to 2004, find the sum of the numbers \(\dfrac{a}{2}-2\) and \(\dfrac{b}{2}-2\).

Never solve for \(a\) and \(b\) individually — the problem only ever asks about them through the combination \(a+b\), so work with that combination directly. The given equation \((2a+2)+(2b+2)=2004\) simplifies straight to \(a+b=1000\), and the target expression \(\left(\frac{a}{2}-2\right)+\left(\frac{b}{2}-2\right)\) is just \(\frac{a+b}{2}-4\) — substitute the single known value \(a+b=1000\) once, at the very end.
# MATH: never isolate a and b separately -- both the given equation and
# the target expression depend on them only through the SUM a+b, so
# solve for that one combined quantity and substitute it in once, at
# the end, rather than solving a 2-variable system that isn't actually
# determined (there are infinitely many valid (a,b) pairs).
import sympy as sp

apb = sp.symbols('apb')                     # apb stands for (a + b)
given = sp.Eq(2*apb + 4, 2004)                # (2a+2)+(2b+2) = 2004
apb_value = sp.solve(given, apb)[0]
print(apb_value)                              # 1000

target = apb_value / 2 - 4                    # (a/2-2)+(b/2-2) = (a+b)/2 - 4
print(target)                                 # 496

MS · Purple Comet 2004, Problem 5 · Easy Number Theory

Write the number \(2004_{(5)}\) — that is, 2004 read as a base-5 numeral — as a number in base 6.

A positional numeral system is itself a piece of math, not just notation: the digits \(d_k \ldots d_1 d_0\) of a base-\(b\) numeral stand for \(\sum_i d_i b^i\). Converting bases is two applications of that one idea — expand \(2004_{(5)}\) into a decimal value using powers of 5, then re-expand that same decimal value into base 6 using the standard repeated-division algorithm (which is just running the place-value expansion backwards, one remainder at a time).
# MATH: a base-b numeral d_k...d_1 d_0 means sum_i d_i * b^i -- that's
# the definition of positional notation, not a guess. Apply it once
# (base 5 -> decimal) and then run it backwards via repeated division
# (decimal -> base 6): dividing by 6 repeatedly and reading remainders
# is exactly how you invert the place-value sum one digit at a time.
digits_base5 = [2, 0, 0, 4]   # "2004" in base 5, most significant first
decimal = sum(d * 5**i for i, d in enumerate(reversed(digits_base5)))
print(decimal)                # 254

def to_base(n, b):
    digits = []
    while n:
        digits.append(n % b)
        n //= b
    return digits[::-1] or [0]

print(''.join(map(str, to_base(decimal, 6))))   # 1102

MS · Purple Comet 2004, Problem 6 · Easy Number Theory

How many different positive integers divide \(10!\)?

Solution 1 — unique factorization.

Every divisor of \(n\) is built by choosing, independently, how many copies of each prime in \(n\)’s factorization to include. If \(n = p_1^{e_1}p_2^{e_2}\cdots\), there are \(e_i+1\) choices for each prime’s exponent (0 through \(e_i\)), so the divisor count is \(\prod_i (e_i+1)\) — a direct consequence of unique prime factorization, not something to count one divisor at a time.
# MATH: unique factorization -- every divisor of n = p1^e1 * p2^e2 *...
# is p1^f1 * p2^f2 * ... with 0 <= fi <= ei, independently for each
# prime. That's (e1+1)(e2+1)... divisors total. Factor 10! completely,
# then apply that formula -- never list divisors one at a time.
import sympy as sp

n = sp.factorial(10)
factors = sp.factorint(n)          # {2: 8, 3: 4, 5: 2, 7: 1}
divisor_count = 1
for exponent in factors.values():
    divisor_count *= (exponent + 1)
print(factors, divisor_count)      # {2: 8, 3: 4, 5: 2, 7: 1} 270

Solution 2 — count divisors directly, in pairs.

Every divisor \(d\le\sqrt n\) of \(n\) pairs off with a partner divisor \(n/d\ge\sqrt n\), so trial-dividing only up to \(\sqrt n\) and counting each hit twice finds every divisor without ever factoring \(n\) — a direct headcount instead of a formula built from prime exponents. \(\sqrt{10!}\approx1905\), so this is a genuinely small, provably complete loop, not a guess at how far to search.
# MATH: divisors pair up as d and n/d, and every pair has one partner
# at or below sqrt(n) -- so trial-dividing only up to sqrt(n) and
# counting each hit twice (once for the perfect-square divisor, if any)
# finds every divisor of n WITHOUT ever factoring n. This is a direct
# headcount, a genuinely different technique from Solution 1's
# prime-exponent formula, even though it must agree with it.
import math

n = math.factorial(10)
count = 0
for d in range(1, math.isqrt(n) + 1):
    if n % d == 0:
        count += 2                  # d and its partner n // d
        if d * d == n:
            count -= 1               # perfect-square n: don't double-count d itself
print(n, count)                     # 3628800 270 -- matches Solution 1

MS · Purple Comet 2004, Problem 7 · Easy Algebra

A rectangle has area 1100. If the length is increased by ten percent and the width is decreased by ten percent, what is the area of the new rectangle?

Increasing one factor by 10% multiplies it by 1.1; decreasing the other by 10% multiplies it by 0.9. So the new area is always \((1+p)(1-p) = 1-p^2\) times the old area, for any starting area and any percent \(p\) — not just for 1100 and 10%. That identity is the whole problem; 1100 only tells you where to evaluate it.
# MATH: (1+p)(1-p) = 1 - p^2 is a fixed algebraic identity, true for
# ANY starting area A and ANY percent p. So a "+10%, then -10%" change
# always shrinks the area by exactly p^2 = 1% -- regardless of the 1100
# in this particular problem. Derive that identity symbolically first,
# then substitute this problem's numbers only at the very end.
import sympy as sp

A, p = sp.symbols('A p', positive=True)
new_area = sp.simplify(A * (1 + p) * (1 - p))
print(new_area)                                   # A*(1 - p**2)

print(new_area.subs({A: 1100, p: sp.Rational(1, 10)}))   # 1089

MS · Purple Comet 2004, Problem 8 · Medium Number Theory

The number \(2.5081081081081\ldots\) can be written as \(\dfrac{m}{n}\) where \(m\) and \(n\) are natural numbers with no common factors. Find \(m+n\).

Solution 1 — multiply and subtract.

A repeating decimal is rational by construction, and there’s a standard algebraic trick to extract the exact fraction: if a decimal has \(k\) non-repeating digits after the point followed by a block of \(r\) repeating digits, multiplying by \(10^{k+r}\) and by \(10^k\) and subtracting cancels the entire infinite tail, leaving one clean equation for the exact value — no rounding, no truncating the decimal anywhere.
# MATH: x = 2.5(081) has k=1 non-repeating digit ("5") then a repeating
# block of length r=3 ("081"). Multiplying by 10^(k+r) and by 10^k gives
# two decimals with IDENTICAL infinite tails; subtracting cancels that
# tail completely, leaving an exact integer equation for x -- the
# standard, fully rigorous way to turn a repeating decimal into a
# fraction, not an approximation.
import sympy as sp

k, r = 1, 3
whole_digits = 25081    # digits of 10^(k+r)*x, truncated at the point: "25081"
nonrep_digits = 25      # digits of 10^k*x, truncated at the point: "25"
x = sp.Rational(whole_digits - nonrep_digits, 10**(k+r) - 10**k)
print(x)                 # 464/185

m, n = sp.fraction(x)
print(m, n, m + n)       # 464 185 649

Solution 2 — sum the repeating block as a geometric series.

A repeating decimal is literally an infinite geometric series: \(0.\overline{081}=0.081+0.081\cdot10^{-3}+0.081\cdot10^{-6}+\cdots\), a block of value \(81/1000\) shrinking by a factor of \(1000\) each time. Summing that series in closed form (\(a/(1-r)\)) is calculus’ tool for the same fact Solution 1 reaches by algebraic cancellation — a genuinely different route to the identical exact value.
# MATH: 0.081081081... is an infinite geometric series with first term
# a = 81/1000 and common ratio r = 1/1000 -- sum it with the closed
# form a/(1-r) (equivalently, sympy's own infinite summation), a
# different tool (series summation) from Solution 1's algebraic
# multiply-and-subtract trick, reaching the same exact fraction.
import sympy as sp

n = sp.symbols('n', positive=True, integer=True)
repeating_part = sp.summation(81 * sp.Rational(1, 1000)**n, (n, 1, sp.oo))
print(repeating_part)              # 3/37 -- exact value of 0.081081081...

x = sp.Rational(5, 2) + repeating_part / 10   # 2.5 shifts the repeating block one place right
print(x)                                       # 464/185

m, n2 = sp.fraction(x)
print(m, n2, m + n2)                           # 464 185 649 -- matches Solution 1

MS · Purple Comet 2004, Problem 9 · Medium Number Theory

How many positive integers less than 200 are relatively prime to either 15 or 24?

Solution 1 — simplify the logic first, then count.

“Coprime to 15 or 24” is easiest to attack through its complement: a number fails to be coprime to either exactly when it shares a factor with 15 (i.e. is divisible by 3 or 5) and shares a factor with 24 (i.e. is divisible by 2 or 3). Walk through what “divisible by 3 or 5” and “divisible by 2 or 3” means for a number \(n\) by cases: if \(3\mid n\), both conditions are already satisfied by that one fact, regardless of 2 or 5. If \(3\nmid n\), the first condition forces \(5\mid n\) and the second forces \(2\mid n\) — together, \(10\mid n\). So the whole double condition collapses to one clean rule: divisible by 3, or divisible by 10 — which inclusion–exclusion counts exactly, no case-by-case checking of individual numbers required.
# MATH: work with the complement. n fails "coprime to 15 or 24" iff
# NOT coprime to 15 (i.e. 3|n or 5|n) AND NOT coprime to 24 (i.e. 2|n
# or 3|n). Case on whether 3|n: if it does, both conditions already
# hold; if it doesn't, the first condition forces 5|n and the second
# forces 2|n, i.e. 10|n. So the combined condition is just: 3|n or
# 10|n. Inclusion-exclusion counts that exactly.
N = 199

complement = (N // 3) + (N // 10) - (N // 30)   # divisible by 3 or 10
answer = N - complement
print(complement, answer)   # 79 120

Solution 2 — build the sets directly, skip the hand-simplification.

The truth-table collapse in Solution 1 is elegant but not strictly necessary: the complement condition is literally “shares a factor with 15” and “shares a factor with 24,” and both of those are themselves just unions of multiples — so build the actual sets of multiples and intersect them with Python’s own set operations. This is a more mechanical, less clever method, and that’s the point: it needs no logical simplification by hand at all, only a correct translation of the problem into set language, and it lands on the same answer as an independent check.
# MATH: "shares a factor with 15" = multiple of 3 OR multiple of 5;
# "shares a factor with 24" = multiple of 2 OR multiple of 3. Build
# those as actual sets and use set UNION and INTERSECTION directly --
# no need to simplify the logic into "div by 3 or 10" by hand first,
# since Python's set algebra does the equivalent work for us.
N = 199
multiples_of_2 = set(range(2, N+1, 2))
multiples_of_3 = set(range(3, N+1, 3))
multiples_of_5 = set(range(5, N+1, 5))

not_coprime_15 = multiples_of_3 | multiples_of_5    # shares a factor with 15
not_coprime_24 = multiples_of_2 | multiples_of_3    # shares a factor with 24

complement = not_coprime_15 & not_coprime_24         # fails BOTH conditions
print(len(complement), N - len(complement))          # 79 120 -- matches Solution 1

MS · Purple Comet 2004, Problem 10 · Hard Number Theory

One rainy afternoon you write the number 1 once, the number 2 twice, the number 3 three times, and so forth until you have written the number 99 ninety-nine times. What is the 2005th digit that you write?

Group the writing into two blocks by digit-length. Numbers 1–9 are single digits, and number \(n\) is written \(n\) times, so that block contributes \(\sum_{n=1}^{9}n\) (shorthand for the sum \(1+2+3+\cdots+9\)) \(=45\) digits total. From 10 onward, each number is two digits, so after finishing number \(m\) (for \(10\le m\le99\)), the running digit total is \(45+\sum_{k=10}^{m}2k\) (that is, \(45+2\cdot10+2\cdot11+\cdots+2m\)) \(= m(m+1)-45\) — a closed-form running total, not something to tally one number at a time. Solve \(m(m+1)-45\ge2005\) for the smallest \(m\), then locate the exact position inside that one number’s block of repeats.
# MATH: numbers 1-9 are 1 digit each, written n times -> sum_{n=1}^{9} n
# = 45 digits total. From 10 on, each number is 2 digits, so the
# running digit-count after finishing number m is 45 + sum_{k=10}^m 2k
# = m(m+1) - 45, a closed form (no loop needed to GET to the right
# number -- only to pinpoint the exact digit once we're there).
def cumulative(m):
    return m*(m+1) - 45

m = 10
while cumulative(m) < 2005:
    m += 1
print(m, cumulative(m))          # 45 2025 -- digit 2005 falls inside number 45's block

before = cumulative(m-1)         # digits written through the end of number 44
position_in_block = 2005 - before
digit_index = (position_in_block - 1) % 2   # 0 = tens digit of m, 1 = units digit
print(before, position_in_block, str(m)[digit_index])   # 1935 70 5

# Sanity check only -- actually build the whole string and index into it.
s = ''.join(str(n)*n for n in range(1, 100))
print(s[2004])   # 0-indexed -> the 2005th character. 5

MS · Purple Comet 2004, Problem 11 · Medium Algebra

Find the sum of all integers \(x\) satisfying \(1+8x \le 358-2x \le 6x+94\).

A compound inequality is really two separate inequalities sharing a variable, and each is linear — so each reduces to a single bound on \(x\) by straightforward rearrangement, no special technique needed beyond isolating \(x\) in each half separately, then intersecting the two resulting ranges before summing the integers inside.
# MATH: split the compound inequality into its two linear halves and
# solve each independently for a bound on x, then intersect the two
# ranges -- an arithmetic series sum over the integers that survive.
import sympy as sp

x = sp.symbols('x')
lower_bound = sp.solve(sp.Ge(358 - 2*x, 1 + 8*x), x)   # from 1+8x <= 358-2x
upper_bound = sp.solve(sp.Ge(6*x + 94, 358 - 2*x), x)  # from 358-2x <= 6x+94
print(lower_bound, upper_bound)   # x <= 357/10, x >= 33

integers = [i for i in range(33, 36)]   # 33 <= x <= 35.7, integers only
print(integers, sum(integers))          # [33, 34, 35] 102

MS · Purple Comet 2004, Problem 12 · Easy Algebra

If \(f(x,y)=xy+2x+y+1\), find \(f\bigl(f(2,f(3,4)),5\bigr)\).

Before grinding through three nested evaluations, notice that \(f(x,y)+1 = xy+2x+y+2 = (x+1)(y+2)\) — the messy expression factors completely. # MATH: multiplication principle. First digit: 9 choices (1-9). Given

MS · Purple Comet 2004, Problem 21 · Superhard Number Theory

Find the number of different quadruples \((a,b,c,d)\) of positive integers such that \(ab=cd=a+b+c+d-3\).

Let \(N\) be the common value \(ab=cd\), so \(a+b+c+d=N+3\). Divide that sum equation by \(N\): since \(N=ab\), \(\frac aN=\frac1b\) and \(\frac bN=\frac1a\) — and symmetrically \(\frac cN=\frac1d\), \(\frac dN=\frac1c\), since \(N=cd\) too. Adding all four fractions gives \(\frac1a+\frac1b+\frac1c+\frac1d=1+\frac3N>1\).

That one inequality does almost all the work. If every one of \(a,b,c,d\) were \(\ge4\), the left side could be at most \(4\times\frac14=1\) — too small to beat \(1+\frac3N\). So the smallest of the four numbers has to be \(1\), \(2\), or \(3\): just three cases to check, not an open-ended search over \(N\).

Swapping the two numbers inside either product, or swapping the whole pair \((a,b)\) with \((c,d)\), leaves the equation unchanged — so we're free to call whichever number is smallest \(a\), knowing the other three are then all \(\ge a\). Case on \(a\in\{1,2,3\}\):

\(a=1\): then \(N=b\), and the sum equation forces \(c+d=2\), so \(c=d=1\) and \(b=cd=1\). One solution: \((1,1,1,1)\).

\(a=2\): then \(N=2b\). Combining \(cd=N\) with the sum equation and eliminating \(b\) reduces everything to \((c-2)(d-2)=2\) — adding a constant to both sides of a quadratic so it factors into two simple pieces, the same shift-then-factor idea that turns many messy-looking equations into a short list of cases. Since \(2\) factors as \(1\times2\) in only one way, \((c,d)=(3,4)\) or \((4,3)\), giving \(b=6\).

\(a=3\): now \(b,c,d\ge3\), and the same elimination gives \((2c-3)(2d-3)=9\). Both factors must be odd and \(\ge3\), and \(9\)’s only such factorization is \(3\times3\) — forcing \(c=d=3\), \(b=3\).

Each case above is one base solution; counting every way to reorder it (swap within a pair, swap the pairs) totals \(1+8+1=10\) quadruples.
# MATH: dividing a+b+c+d=N+3 (N=ab=cd) by N gives the identity
# 1/a+1/b+1/c+1/d = 1+3/N > 1. If all four numbers were >=4, the left
# side could be at most 1 -- contradiction. So the SMALLEST of the four
# is 1, 2, or 3: a genuinely finite case split, not a guess at how far
# to search. Each case reduces algebraically (shift both sides of a
# quadratic by a constant so it factors) to a small, fully-factored
# equation, not a scan over N.
import sympy as sp

def orbit(a, b, c, d):
    # the equation is unchanged by swapping within a pair, or swapping
    # the two pairs -- expand one representative into its full orbit
    quads = set()
    for x, y in [(a, b), (b, a)]:
        for z, w in [(c, d), (d, c)]:
            quads.add((x, y, z, w))
            quads.add((z, w, x, y))
    return quads

solutions = set()

solutions |= orbit(1, 1, 1, 1)             # a=1: forces c=d=1, b=1

for e in sp.divisors(2):                   # a=2: (c-2)(d-2) = 2
    c, d = 2 + e, 2 + 2 // e
    solutions |= orbit(2, c + d - 1, c, d)

for e in sp.divisors(9):                   # a=3: (2c-3)(2d-3) = 9,
    if e >= 3 and 9 // e >= 3 and (e + 3) % 2 == 0:   # both factors odd, >=3
        c, d = (e + 3) // 2, (9 // e + 3) // 2
        solutions |= orbit(3, (c + d) // 2, c, d)

print(len(solutions))     # 10
print(sorted(solutions))  # matches an exhaustive brute-force check over N up to 1000

MS · Purple Comet 2004, Problem 25 · Superhard Number Theory

Solution 1 — every bijection, exhaustively.

Count the distinct letters first, before writing any code: \(W,H,I,T,E,A,R,P,C,N\) — exactly 10 letters, one for each digit \(0\)–\(9\). That single observation turns an apparently open-ended puzzle into a genuinely finite, fully enumerable search: every valid solution is some bijection from letters to digits, and there are exactly \(10!=3{,}628{,}800\) of those — small enough to check completely, with the only real logic needed being “no leading digit is 0” and “the arithmetic actually checks out.” This is exhaustive search over a search space proven small and complete — not guessing digits until something matches.
# MATH: exactly 10 distinct letters appear across WHITE + WATER =
# PICNIC, matching the 10 available digits 0-9 exactly -- so every
# candidate solution is a BIJECTION (permutation) of letters to digits,
# and there are only 10! = 3,628,800 of those. That is a small,
# provably complete search space, not an open-ended guess -- check
# every permutation, reject leading zeros, keep the ones where the sum
# actually holds.
from itertools import permutations

letters = ['W', 'H', 'I', 'T', 'E', 'A', 'R', 'P', 'C', 'N']

def to_num(word, assign):
    return int(''.join(str(assign[ch]) for ch in word))

found = []
for perm in permutations(range(10)):
    assign = dict(zip(letters, perm))
    if assign['W'] == 0 or assign['P'] == 0:   # no leading zero
        continue
    if to_num('WHITE', assign) + to_num('WATER', assign) == to_num('PICNIC', assign):
        found.append(to_num('PICNIC', assign))

print(sorted(set(found)))   # [169069] -- unique answer despite two valid letter assignments

Only \(W,H,T,E,A,R\) need to be searched over — a genuinely smaller and differently-structured search (permutations of 6 digits out of 10, then checking whether the two places \(C\) and \(I\) each appear are consistent) rather than one big flat guess over all 10.
# MATH: standard column-addition logic. Adding column by column from
# the units digit, each column's sum determines that PICNIC digit AND a
# carry into the next column -- so C, I, N, P are all DERIVED from
# W,H,T,E,A,R (only 6 truly free letters), not chosen independently.
# C and I each appear in TWO columns, so both derivations must agree --
# that consistency check is what makes this a real constraint, not
# just relabeling the same search.
from itertools import permutations

count = 0
found = set()
for W, H, T, E, A, R in permutations(range(10), 6):
    if W == 0:
        continue

Three lines are drawn parallel to each of the three sides of \(\triangle ABC\) so that the three lines intersect in the interior of \(ABC\). The resulting three smaller triangles have areas 1, 4, and 9. Find the area of \(\triangle ABC\).

Solution 1 — set up and solve the ratio system.

Each of the three corner triangles is similar to \(\triangle ABC\) (its sides are parallel to \(ABC\)’s own sides), so if a corner triangle’s sides are a fraction \(k_i\) of \(ABC\)’s, its area is \(k_i^2\) times \(ABC\)’s area \(S\). The key extra fact — true because the three parallel lines all pass through one common interior point — is that the three ratios add to exactly 1: \(k_1+k_2+k_3=1\). With \(k_i=\sqrt{\text{area}_i/S}\), that one linear identity pins down \(S\) completely.
# MATH: each corner triangle is similar to ABC (parallel sides), so
# with side-ratio k_i, its area is k_i^2 * S where S = area(ABC). The
# three ratios satisfy k1+k2+k3=1 exactly, because the three lines
# meet at one common interior point -- a genuine geometric fact, not
# an assumption. Four unknowns (S,k1,k2,k3), four equations, solved
# symbolically.
import sympy as sp

S, k1, k2, k3 = sp.symbols('S k1 k2 k3', positive=True)
equations = [
    sp.Eq(k1**2 * S, 1),
    sp.Eq(k2**2 * S, 4),
    sp.Eq(k3**2 * S, 9),
    sp.Eq(k1 + k2 + k3, 1),
]
solution = sp.solve(equations, [S, k1, k2, k3], dict=True)
print(solution)   # [{S: 36, k1: 1/6, k2: 1/3, k3: 1/2}]

Solution 2 — linearize with a square-root substitution.

Solution 1’s system is only nonlinear because of the squares; substituting \(t_i=\sqrt{\text{area}_i}=k_i\sqrt S\) turns \(k_1+k_2+k_3=1\) directly into \(\frac{t_1+t_2+t_3}{\sqrt S}=1\), i.e. \(\sqrt S=t_1+t_2+t_3=\sqrt1+\sqrt4+\sqrt9\). No system to solve at all — just one substitution collapses four unknowns into a single square root, evaluated directly.
# MATH: substituting t_i = sqrt(area_i) turns the nonlinear system of
# Solution 1 into ONE linear identity: sqrt(S) = t1+t2+t3, since
# k_i = t_i/sqrt(S) and k1+k2+k3=1. A substitution that linearizes the
# problem, rather than solving four equations simultaneously.
import sympy as sp

sqrt_S = sp.sqrt(1) + sp.sqrt(4) + sp.sqrt(9)
S = sp.simplify(sqrt_S**2)
print(sqrt_S, S)   # 6 36 -- matches Solution 1

# MATH: a point and its reflection sit on opposite sides of the mirror

# distance from P to its reflection is exactly TWICE the straight-line
# distance from P to the line -- no need to find the reflected point.
# Distance from (x0,y0) to the line ax+by=c is |a*x0+b*y0-c|/sqrt(a^2+b^2).

The diagram shows a circle with radius 24 which contains two circles with radius 12 tangent to each other and the larger circle. The smallest circle is tangent to the three other circles. What is the radius of the smallest circle?

Solution 1 — Descartes’ Circle Theorem.

This is exactly the situation Descartes’ Circle Theorem was built for: four mutually tangent circles have curvatures (\(k=1/\text{radius}\), negative when a circle contains the others) related by \[k_4 = k_1+k_2+k_3 \pm 2\sqrt{k_1k_2+k_2k_3+k_3k_1}.\] Plugging in the big circle (curvature \(-1/24\)) and the two radius-12 circles gives the fourth curvature directly, with no coordinate geometry required.
# MATH: Descartes' Circle Theorem. For four mutually tangent circles
# with curvatures k1,k2,k3,k4 (k = 1/radius; NEGATIVE for a circle that
# the others sit inside of, since it curves the "other way"):
#   k4 = k1+k2+k3 +/- 2*sqrt(k1*k2 + k2*k3 + k3*k1)
# Here k1 is the big radius-24 circle (internally tangent -> negative),
# k2=k3 are the two radius-12 circles, and k4 is the unknown small
# circle tangent to all three.
from fractions import Fraction
import math

k1 = -Fraction(1, 24)
k2 = Fraction(1, 12)
k3 = Fraction(1, 12)

s = k1 + k2 + k3
p = k1*k2 + k2*k3 + k3*k1
k4 = float(s) + 2 * math.sqrt(float(p))
print(1 / k4)  # 8.0

Solution 2 — coordinates.

Not every reader has Descartes’ theorem memorized, and this configuration is symmetric enough to set up directly: by the left-right symmetry of the two radius-12 circles, the small circle’s center must lie on the vertical axis of symmetry, at some point \((0,y)\). Two tangency conditions — externally tangent to a radius-12 circle (distance between centers \(=12+r_4\)) and internally tangent to the big circle, sitting inside it (distance from the origin \(=24-r_4\)) — are two equations in the two unknowns \(y\) and \(r_4\), solved directly with no named theorem required.
# MATH: symmetry places the small circle's center at (0,y). It is
# externally tangent to the circle at (12,0) -- distance between
# centers equals the SUM of radii, 12+r4 -- and internally tangent to
# the big circle, sitting inside it -- distance from the origin equals
# the DIFFERENCE of radii, 24-r4. Two equations, two unknowns, solved
# directly with sympy -- no theorem needed, just tangency definitions.
import sympy as sp

y, r4 = sp.symbols('y r4', positive=True)
eq_tangent_to_r12 = sp.Eq(sp.sqrt(12**2 + y**2), 12 + r4)
eq_tangent_to_R24 = sp.Eq(y, 24 - r4)

solution = sp.solve([eq_tangent_to_r12, eq_tangent_to_R24], [y, r4], dict=True)
print(solution)   # [{r4: 8, y: 16}]

HS · Purple Comet 2004, Problem 14 · Medium Geometry

Two circles have radii 15 and 95. If the two external tangents to the circles intersect at 60 degrees, how far apart are the centers of the circles?

(This problem is also 2004 Purple Comet Middle School Problem 22, solved there with the plain 30-60-90 triangle ratio. The solutions here use trigonometric notation instead — the same underlying fact, written the way a high-school course would write it.)

Solution 1 — two right triangles, then subtract. [Official]

The two external tangent lines meet at the circles’ external center of similitude — the point from which both circles look tangent to the same pair of lines, which always lies on the line through both centers. From that point, each circle’s radius and its distance to that point form a right triangle with the tangent line, so \(\sin(\text{half the 60}^\circ\text{ angle}) = \frac{r}{\text{distance to that circle}}\) for both circles — the same half-angle, since it’s literally the same pair of lines. Subtracting the two distances (they’re collinear) gives the center-to-center distance directly, in one formula: \(d=\frac{R-r}{\sin(30^\circ)}\).
# MATH: both circles are tangent to the SAME two lines meeting at the
# external point P, at the SAME half-angle (30 degrees). In each
# tangent-radius right triangle, sin(half-angle) = radius / (distance
# from P to that circle's center) -- solve both distances, then
# subtract (P, and both centers, are collinear).
import sympy as sp

R, r = 95, 15
half_angle = sp.rad(30)
dist_to_R = R / sp.sin(half_angle)
dist_to_r = r / sp.sin(half_angle)
d = sp.simplify(dist_to_R - dist_to_r)
print(d)   # 160

Solution 2 — shrink the small circle to a point.

A classic trick for external tangents: shrink both circles’ radii by the same amount \(r\). Every external common tangent shifts inward by exactly \(r\), staying tangent to the (now radius-\((R-r)\)) big circle and passing through the (now radius-0) small circle’s center — which is exactly a tangent line from an external point to a single circle. So the whole two-circle configuration reduces to the single-circle right triangle \(\sin(30^\circ)=\frac{R-r}{d}\), one equation instead of two subtracted ones — a genuinely different (and shorter) route to the identical distance.
# MATH: shrinking both circles' radii by r turns the small circle into
# a single point (the tangent lines pass exactly through its center)
# and the big circle into radius R-r, WITHOUT moving either tangent
# line or the point P where they meet -- a standard reduction for
# external tangent problems. That collapses two right triangles into
# one: sin(half-angle) = (R-r)/d, solved directly for d.
import sympy as sp

R, r = 95, 15
half_angle = sp.rad(30)
d = sp.simplify((R - r) / sp.sin(half_angle))
print(d)   # 160 -- matches Solution 1

HS · Purple Comet 2004, Problem 17 · Hard Combinatorics

We want to paint some identically-sized cubes so that each face of each cube is painted a solid color and each cube is painted with six different colors. If we have seven different colors to choose from, how many distinguishable cubes can we produce?

Solution 1 — Burnside’s Lemma, no shortcuts assumed.

Two colorings that are rotations of each other are the same physical cube, so this is a counting-up-to-symmetry problem — exactly what Burnside’s Lemma is for: the number of genuinely distinct colorings equals the average, over every symmetry of the cube, of how many colorings that symmetry leaves unchanged. Since every face gets a different color, only the “do nothing” symmetry can ever leave a coloring unchanged, which collapses the count to \(6!/24=30\) arrangements per choice of 6 colors, times \(\binom{7}{6}=7\) ways to choose which 6 of the 7 colors to use.
# MATH: Burnside's Lemma (orbit-counting theorem). Two colorings of the
# cube's faces are "the same cube" if a rotation of the cube turns one
# into the other, so we are counting ORBITS of colorings under the
# rotation group G (the 24 rotations of a cube), not raw colorings.
# Burnside: #orbits = (1/|G|) * sum_{g in G} (# colorings fixed by g).
# Because all 6 colors here are required to be different, a nontrivial
# rotation (which always moves some face to another face) can never fix
# such a coloring -- only the identity does. The code below does not
# assume that shortcut, though: it checks every rotation directly.
from itertools import permutations, product
from math import comb

faces = ['U', 'D', 'F', 'B', 'L', 'R']
vec = {'U': (0,0,1), 'D': (0,0,-1), 'F': (0,-1,0),
       'B': (0,1,0), 'L': (-1,0,0), 'R': (1,0,0)}

def apply(M, v):
    return tuple(sum(M[i][j]*v[j] for j in range(3)) for i in range(3))

def det(M):
    return (M[0][0]*(M[1][1]*M[2][2]-M[1][2]*M[2][1])
          - M[0][1]*(M[1][0]*M[2][2]-M[1][2]*M[2][0])
          + M[0][2]*(M[1][0]*M[2][1]-M[1][1]*M[2][0]))

rotations = []
for perm in permutations(range(3)):
    for signs in product([1, -1], repeat=3):
        M = [[0]*3 for _ in range(3)]
        for i in range(3):
            M[i][perm[i]] = signs[i]
        if det(M) == 1:
            rotations.append(M)

face_perms = []
for M in rotations:
    p = {f: next(g for g in faces if vec[g] == apply(M, vec[f])) for f in faces}
    face_perms.append(p)

idx = {f: i for i, f in enumerate(faces)}
all_colorings = list(permutations(range(6)))   # the 6! all-distinct colorings

total_fixed = sum(
    1
    for p in face_perms
    for coloring in all_colorings
    if tuple(coloring[idx[p[f]]] for f in faces) == coloring
)
distinct_colorings = total_fixed // len(face_perms)          # -> 30
print(distinct_colorings, comb(7, 6) * distinct_colorings)   # 30 210

Solution 2 — the shortcut, taken at face value.

Solution 1 deliberately doesn’t assume the shortcut mentioned in the math note above — it checks every rotation directly. Solution 2 takes that shortcut at face value and just computes it: since every face is a different color, any rotation other than “do nothing” necessarily moves some face to a position with a different color, so it can never fix a coloring. Burnside’s average then collapses from “sum over 24 rotations” to a single term — a much shorter computation that trusts the geometric argument instead of re-deriving it in code.
# MATH: take the shortcut from the math note at face value -- with all
# 6 colors distinct, only the identity rotation can ever fix a
# coloring, so Burnside's average is just (all 6! colorings) / 24
# rotations, with no need to enumerate the rotation group at all.
import math

distinct_colorings = math.factorial(6) // 24
answer = math.comb(7, 6) * distinct_colorings
print(distinct_colorings, answer)   # 30 210 -- matches Solution 1

HS · Purple Comet 2004, Problem 18 · Hard Algebra

As \(x\) ranges over the interval \((0,\infty)\), the function \(\sqrt{9x^2+173x+900}-\sqrt{9x^2+77x+900}\) ranges over the interval \((0,M)\). Find \(M\).

Solution 1 — rationalize by the conjugate.

A difference of two square roots that both grow like \(3x\) is exactly the situation for rationalizing by the conjugate: multiplying and dividing by the sum of the two roots turns the difference into \(\frac{96x}{\sqrt{9x^2+173x+900}+\sqrt{9x^2+77x+900}}\), a single fraction whose behavior as \(x\to\infty\) is now visible directly — both square roots behave like \(3x\), so the denominator behaves like \(6x\), and the whole expression approaches \(\frac{96x}{6x}=16\). The function increases toward that limit but never reaches it (the interval is open at \(M\)), so \(M\) is exactly that limiting value.
# MATH: rationalize by the conjugate -- multiply and divide by the SUM
# of the two square roots. The numerator becomes the difference of the
# two expressions under the radicals (linear in x, no square roots
# left), turning an opaque difference of large roots into one clean
# fraction whose limit as x -> infinity can be read off directly.
import sympy as sp

x = sp.symbols('x', positive=True)
f = sp.sqrt(9*x**2 + 173*x + 900) - sp.sqrt(9*x**2 + 77*x + 900)

numerator = sp.simplify((9*x**2+173*x+900) - (9*x**2+77*x+900))
print(numerator)   # 96*x  -- exactly what the conjugate trick produces

M = sp.limit(f, x, sp.oo)
print(M)   # 16  -- f increases toward this but never reaches it

Solution 2 — substitute \(x=1/t\) and expand near \(t=0\).

“\(x\to\infty\)” is the same limit as “\(t\to0^+\)” after substituting \(x=1/t\), and near \(t=0\) sympy’s series expansion reads off the limiting value as the expansion’s constant term directly — a genuinely different tool (asymptotic series, the same idea behind Taylor’s theorem) from Solution 1’s algebraic conjugate trick, and one that also shows how fast \(f\) approaches \(M\) (the next term, \(-\frac{1000}{9}t\), says the approach is linear in \(1/x\)).
# MATH: substitute x = 1/t so x -> infinity becomes t -> 0+, then
# expand f as a series in t near 0. The CONSTANT term of that
# expansion is the limit -- an asymptotic-series approach, a different
# tool from Solution 1's conjugate rationalization, that also reveals
# the rate of approach (the next term) for free.
import sympy as sp

t = sp.symbols('t', positive=True)
x = 1/t
f = sp.sqrt(9*x**2 + 173*x + 900) - sp.sqrt(9*x**2 + 77*x + 900)

expansion = sp.series(f, t, 0, 2)
print(expansion)                              # 16 - 1000*t/9 + O(t**2)

M = expansion.removeO().subs(t, 0)
print(M)                                       # 16 -- matches Solution 1

HS · Purple Comet 2004, Problem 19 · Hard Combinatorics

There are three bags. One bag contains three green candies and one red candy. One bag contains two green candies and two red candies. One bag contains one green candy and three red candies. A child randomly selects one of the bags, randomly chooses a first candy from that bag, and eats the candy. If the first candy had been green, the child randomly chooses one of the other two bags and randomly selects a second candy from that bag. If the first candy had been red, the child randomly selects a second candy from the same bag as the first candy. If the probability that the second candy is green is \(\dfrac{m}{n}\) in lowest terms, find \(m+n\).

This is a small, fully enumerable probability tree, not a shortcut formula — the rule for the second draw genuinely depends on the outcome of the first (a different bag, untouched, if the first candy was green; the same bag with one candy already removed, if it was red), so every branch has to be walked through, weighted by its own probability, and summed. That case-dependence is the actual content of the problem; the arithmetic itself is elementary once every branch is accounted for.
# MATH: full probability tree, exhaustively enumerated -- the rule for
# the second draw is CASE-DEPENDENT on the first candy's color (fresh
# bag if green, same bag missing one candy if red), so every one of the
# 3 (bag) x 2 (first color) x (2 or 1) (second bag/same bag) branches
# must be weighted by its own probability and summed. No shortcut
# formula applies here -- exhausting the tree correctly IS the math.
from fractions import Fraction as F

bags = {1: {'G': 3, 'R': 1}, 2: {'G': 2, 'R': 2}, 3: {'G': 1, 'R': 3}}

total = F(0)
for first_bag in [1, 2, 3]:
    n = bags[first_bag]['G'] + bags[first_bag]['R']
    for first_color in ['G', 'R']:
        p_first = F(1,3) * F(bags[first_bag][first_color], n)
        if first_color == 'G':
            for second_bag in [b for b in [1,2,3] if b != first_bag]:
                n2 = bags[second_bag]['G'] + bags[second_bag]['R']
                p_second_green = F(bags[second_bag]['G'], n2)
                total += p_first * F(1,2) * p_second_green
        else:   # RED -> second draw from the SAME bag, one candy gone
            p_second_green = F(bags[first_bag]['G'], n - 1)
            total += p_first * p_second_green

print(total)                                  # 73/144
print(total.numerator + total.denominator)    # 217

HS · Purple Comet 2004, Problem 20 · Medium Geometry

A 70-foot pole stands vertically in a plane, supported by three 490-foot wires, all attached to the top of the pole, pulled taut, and anchored to three equally spaced points in the plane. How many feet apart are any two of those anchor points?

Each wire, the pole, and the ground form a right triangle, so every anchor point sits at the same horizontal distance \(R=\sqrt{490^2-70^2}\) from the base of the pole — all three anchors lie on one circle of radius \(R\). “Equally spaced” on that circle means they form an equilateral triangle inscribed in it, and the side length of an equilateral triangle inscribed in a circle of radius \(R\) is the standard \(R\sqrt3\) — a fact worth deriving symbolically (via the law of cosines on the \(120^\circ\) central angle between adjacent anchors) rather than just quoting.
# MATH: each wire+pole+ground is a right triangle, giving every anchor
# the SAME horizontal distance R = sqrt(490^2-70^2) from the pole's
# base -- all three anchors lie on one circle of radius R. Equally
# spaced on that circle means 120 degrees apart; the law of cosines on
# that 120-degree central angle gives the chord (anchor-to-anchor)
# length directly, which simplifies to the classic R*sqrt(3).
import sympy as sp

pole, wire = 70, 490
R = sp.sqrt(wire**2 - pole**2)
print(sp.simplify(R))                       # 280*sqrt(3)

central_angle = sp.rad(120)
chord = sp.sqrt(R**2 + R**2 - 2*R*R*sp.cos(central_angle))   # law of cosines
print(sp.simplify(chord))                   # 840
print(sp.simplify(R * sp.sqrt(3)))          # 840 -- matches the general R*sqrt(3) fact

HS · Purple Comet 2004, Problem 21 · Hard Algebra

Define \(a_k=(k^2+1)k!\) and \(b_k=a_1+a_2+a_3+\cdots+a_k\). Let \(\dfrac{a_{100}}{b_{100}}=\dfrac{m}{n}\) where \(m\) and \(n\) are relatively prime natural numbers. Find \(n-m\).

Computing \(b_{100}\) by literally adding 100 huge factorials would work, but it hides the real structure: \(b_k\) is a partial sum, so guess that it has a clean closed form and prove the guess symbolically rather than trusting a numeric coincidence. Trying \(b_k=k(k+1)!\) and checking \(b_k-b_{k-1}=a_k\) algebraically confirms it exactly. Once \(b_k=k(k+1)!\) is established, \(\frac{a_k}{b_k}=\frac{(k^2+1)k!}{k(k+1)!}\) has the entire \(k!\) cancel, collapsing to the simple rational function \(\frac{k^2+1}{k(k+1)}\) — no giant numbers anywhere in the final computation.
# MATH: guess a closed form for the partial sum b_k -- try b_k=k*(k+1)!
# and PROVE it by checking that consecutive differences reproduce a_k
# exactly (b_k - b_(k-1) = a_k), symbolically, for general k. Once
# proven, a_k/b_k simplifies algebraically: the k! cancels completely,
# leaving a small rational function with no huge factorials left in it
# at all.
import sympy as sp

k = sp.symbols('k', positive=True, integer=True)
b_k, b_km1 = k*sp.factorial(k+1), (k-1)*sp.factorial(k)
a_k = (k**2 + 1)*sp.factorial(k)
print(sp.simplify(b_k - b_km1 - a_k))       # 0 -- confirms b_k = k*(k+1)! exactly

ratio = sp.simplify(a_k / b_k)
print(ratio)                                 # (k**2 + 1)/(k*(k + 1))

value = ratio.subs(k, 100)
print(value)                                 # 10001/10100
m, n = sp.fraction(value)
print(m, n, n - m)                           # 10001 10100 99

HS · Purple Comet 2004, Problem 22 · Superhard Geometry

How many non-overlapping \(2\times2\) squares fit into a circle with radius 8?

[Official]

This is a packing problem, and packing problems have a built-in asymmetry: a lower bound is a construction you can check square by square, while the matching upper bound (that no arrangement does better) generally has no such short certificate — it is a genuinely hard claim, and the source itself calls a full optimality proof “extremely difficult.” What is checkable is a specific 40-square packing: seven vertical strips of width 2, offset from the circle’s center rather than centered on it, with lengths chosen so each strip still fits entirely inside the circle. For each strip, only its two farthest corners (at the strip’s outer edge, at the top or bottom) can leave the circle, so checking those two points against the Pythagorean bound \(x^2+y^2\le8^2\) is enough to certify the whole strip — and each strip length divides evenly by 2 into whole \(2\times2\) squares.
# MATH: verify a specific 40-square packing (not a proof that 40 is
# optimal -- packing upper bounds don't reduce to a simple check).
# Seven width-2 vertical strips, offset from center, with lengths
# chosen so each strip's two farthest corners still satisfy the
# circle's bound x^2+y^2 <= 8^2. Each strip's length divides evenly by
# 2 into whole 2x2 squares.
import sympy as sp

R = 8
strips = [
    (sp.Rational(-608, 100), 6),
    (sp.Rational(-408, 100), 12),
    (sp.Rational(-208, 100), 14),
    (sp.Rational(-8, 100), 14),
    (sp.Rational(192, 100), 14),
    (sp.Rational(392, 100), 12),
    (sp.Rational(592, 100), 8),
]

total = 0
for xc, L in strips:
    far_x = max(abs(xc - 1), abs(xc + 1))   # strip has half-width 1
    far_y = sp.Rational(L, 2)               # strip's half-length
    fits = (far_x**2 + far_y**2) <= R**2    # farthest-corner check
    assert fits, (xc, L)                    # every strip must fit -- no exceptions
    assert L % 2 == 0                       # length divides evenly into 2x2 squares
    total += L // 2

print(total)   # 40

HS · Purple Comet 2004, Problem 23 · Hard Algebra

Let \(a\) and \(b\) be real numbers satisfying \(a^4+8b=4(a^3-1)-16\sqrt3\) and \(b^4+8a=4(b^3-1)+16\sqrt3\). Find \(a^4+b^4\).

Adding the two equations kills the \(\sqrt3\) terms entirely, leaving a single symmetric relation in \(a\) and \(b\) — a strong hint that the intended solution is symmetric too. The \(\pm16\sqrt3\) is the other hint: it suggests \(a\) and \(b\) sit equal distances on either side of some center, i.e. \(a=c+t\), \(b=c-t\) for constants \(c,t\). Testing the simplest case \(c=1\) (matching the \(4(a^3-1)\) and \(4(b^3-1)\) shift already in the equations) turns each quartic into a single-variable equation in \(t\); \(t=\sqrt3\) solves it exactly, which sympy confirms symbolically rather than approximately — an exact check, not a numeric coincidence.
# MATH: adding the two equations cancels the +-16*sqrt(3) terms,
# hinting at a symmetric solution a = 1+t, b = 1-t (the "1" matches
# the 4(a^3-1)/4(b^3-1) shift already built into the equations).
# Substituting collapses each quartic-in-two-variables into a single
# quartic in t; solving (or, as here, verifying the natural candidate
# t = sqrt(3)) closes it out. sympy checks the candidate EXACTLY --
# simplify() reducing the residual to 0 is a real proof, not a
# numerical near-miss.
import sympy as sp

a, b = sp.symbols('a b')
sqrt3 = sp.sqrt(3)
candidate_a, candidate_b = 1 + sqrt3, 1 - sqrt3     # a = 1+t, b = 1-t, t = sqrt(3)

eq1_residual = sp.simplify((candidate_a**4 + 8*candidate_b) - (4*(candidate_a**3 - 1) - 16*sqrt3))
eq2_residual = sp.simplify((candidate_b**4 + 8*candidate_a) - (4*(candidate_b**3 - 1) + 16*sqrt3))
print(eq1_residual, eq2_residual)                    # 0 0 -- both equations hold exactly

answer = sp.simplify(candidate_a**4 + candidate_b**4)
print(answer)                                        # 56

HS · Purple Comet 2004, Problem 24 · Medium Algebra

The determinant \(\begin{vmatrix}3&-2&5\\7&1&-4\\5&2&3\end{vmatrix}\) has the same value as the determinant \(\begin{vmatrix}x&1+x&2+x\\3&0&1\\1&1&0\end{vmatrix}\). Find \(x\).

Both sides are just numbers once expanded — the left determinant is a fixed constant, and the right one is linear in \(x\) (cofactor-expand along the bottom row, which has two zeros, to see it collapses to a first-degree polynomial). Setting the two equal is then a one-line linear equation. Hand-expanding a \(3\times3\) determinant is exactly the kind of mechanical, sign-error-prone step that’s worth handing to code — the real math is recognizing both sides are just numbers to be equated, not carrying nine products by hand.
# MATH: expand both 3x3 determinants symbolically -- the left one is a
# fixed constant, the right one is linear in x (cofactor expansion
# along the bottom row, which has two zeros, makes this visible by
# hand too). Equate them and solve the resulting linear equation.
import sympy as sp

x = sp.symbols('x')
M1 = sp.Matrix([[3, -2, 5], [7, 1, -4], [5, 2, 3]])
M2 = sp.Matrix([[x, 1 + x, 2 + x], [3, 0, 1], [1, 1, 0]])

d1 = M1.det()
d2 = sp.expand(M2.det())
print(d1, d2)                          # 160 3*x + 7

sol = sp.solve(sp.Eq(d1, d2), x)
print(sol)                             # [51]
