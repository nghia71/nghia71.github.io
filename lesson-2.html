MS · Purple Comet 2010, Problem 1 · Easy Algebra

If \(125 + n + 135 + 2n + 145 = 900\), find \(n\).

This is a one-step “collect and solve” equation — the only thing to be careful about is combining the constant terms (\(125+135+145\)) and the \(n\)-terms (\(n+2n\)) correctly before isolating \(n\). Rather than trust hand arithmetic on three-digit sums, let symbolic algebra do the collecting and the solving in one pass, so there’s no place for an arithmetic slip to hide.
# MATH: this is a linear equation in one unknown -- gather the constant
# terms and the n-terms, then isolate n. Doing that symbolically removes
# any risk of a slipped digit when adding 125+135+145 by hand.
import sympy as sp

n = sp.symbols('n')
equation = sp.Eq(125 + n + 135 + 2*n + 145, 900)
print(sp.solve(equation, n))   # [165]

MS · Purple Comet 2010, Problem 2 · Easy Algebra

Three boxes each contain four bags. Each bag contains five marbles. How many marbles are there altogether in the three boxes?

This is nested multiplication — three levels of grouping (boxes, then bags, then marbles) multiply together, they don’t add. Writing it as a single product \(3 \times 4 \times 5\) makes the structure explicit instead of relying on a mental shortcut like “count by fives twelve times.”
# MATH: three nested levels of grouping (boxes -> bags -> marbles)
# combine by multiplication, not addition -- the total is the product
# of the counts at each level.
boxes, bags_per_box, marbles_per_bag = 3, 4, 5
total = boxes * bags_per_box * marbles_per_bag
print(total)   # 60

MS · Purple Comet 2010, Problem 3 · Easy Number Theory

The sum \(\dfrac{1}{1}+\dfrac{1}{2}+\dfrac{1}{3}+\dfrac{1}{4}+\dfrac{1}{5}+\dfrac{1}{6} = \dfrac{m}{n}\) where \(m\) and \(n\) are relatively prime positive integers. Find \(m+n\).

Adding six unit fractions by hand over a common denominator (their least common multiple is 60) is exactly the kind of bookkeeping where a single wrong numerator ruins the answer. A computer’s built-in rational-number type never approximates and never needs a chosen common denominator — it keeps every fraction exact and automatically reduces the final sum to lowest terms, which is precisely the \(m/n\) the problem wants.
# MATH: Python's Fraction type does EXACT rational arithmetic -- no
# floating-point rounding, and every sum is automatically reduced to
# lowest terms. That means the m/n the problem describes (relatively
# prime by construction) falls straight out of Fraction's own
# .numerator / .denominator, with no separate gcd-reduction step needed.
from fractions import Fraction

total = sum(Fraction(1, k) for k in range(1, 7))
print(total)                              # 49/20
print(total.numerator + total.denominator)  # 69

MS · Purple Comet 2010, Problem 4 · Medium Geometry

A grid has five rows with six points in each row; adjacent points (horizontally or vertically) are a distance one apart. Find the area of the pentagon shown.

The pentagon’s vertices, read off the grid (using \(x=0,\ldots,5\) for columns left-to-right and \(y=0,\ldots,4\) for rows bottom-to-top), are \((1,4),\,(4,4),\,(5,2),\,(3,0),\,(0,1)\). For any polygon whose vertices are known coordinates, in order, the Shoelace Formula gives the exact area with no need to decompose it by eye into triangles and rectangles: \(\text{Area} = \tfrac12\left|\sum (x_iy_{i+1} - x_{i+1}y_i)\right|\). It’s mechanical, it works for any simple polygon, and it’s far less error-prone here than trying to subtract corner triangles from a bounding box by hand.
# MATH: the Shoelace Formula computes the area of ANY simple polygon
# directly from its ordered vertex coordinates:
#   Area = (1/2) * | sum_i (x_i * y_{i+1} - x_{i+1} * y_i) |
# It needs no case-by-case decomposition into triangles/rectangles --
# it works identically whether the polygon is convex, concave, or an
# odd irregular shape, as long as the vertices are listed in order
# around the boundary (clockwise or counterclockwise, doesn't matter).
def shoelace_area(points):
    n = len(points)
    total = 0
    for i in range(n):
        x1, y1 = points[i]
        x2, y2 = points[(i + 1) % n]
        total += x1 * y2 - x2 * y1
    return abs(total) / 2

pentagon = [(1, 4), (4, 4), (5, 2), (3, 0), (0, 1)]
print(shoelace_area(pentagon))   # 14.0

MS · Purple Comet 2010, Problem 5 · Easy Number Theory

Find the least positive integer \(k\) so that \(k + 25973\) is a palindrome (a number which reads the same forward and backwards).

“Least \(k\) such that some property holds” is a search problem, and a palindrome check is trivial to state precisely: a number is a palindrome exactly when its digit string equals its own reversal. There’s no shortcut worth deriving by hand here — just try \(k=1,2,3,\ldots\) in order and stop at the first hit, which is exactly what a computer is for.
# MATH: "least k with a property" is answered by an exhaustive search
# starting from the smallest candidate -- correct as long as the
# property test itself is exact. A palindrome test is exact and cheap:
# convert to a string and compare it against its own reversal.
def is_palindrome(x):
    s = str(x)
    return s == s[::-1]

k = 0
while not is_palindrome(25973 + k):
    k += 1
print(k, 25973 + k)   # 89 26062

MS · Purple Comet 2010, Problem 6 · Easy Number Theory

Find the sum of the prime factors of \(777\).

Factoring a three-digit number by hand means testing small primes one at a time and hoping you don’t miss one or misdivide along the way. SymPy’s factorint runs trial division (and smarter methods for larger numbers) internally and hands back the exact prime factorization as a dictionary — the sum of its keys is exactly “the sum of the prime factors” the problem asks for.
# MATH: every positive integer has a unique prime factorization
# (the Fundamental Theorem of Arithmetic). factorint returns that
# factorization as {prime: exponent, ...}; the problem only wants
# the DISTINCT prime factors, so sum the dictionary's keys.
import sympy as sp

factors = sp.factorint(777)
print(factors)                 # {3: 1, 7: 1, 37: 1}
print(sum(factors.keys()))     # 47

MS · Purple Comet 2010, Problem 7 · Medium Algebra

\(x\) and \(y\) are positive real numbers where \(x\) is \(p\) percent of \(y\), and \(y\) is \(4p\) percent of \(x\). What is \(p\)?

Translate each sentence into an equation exactly as it’s spoken — “\(x\) is \(p\) percent of \(y\)” becomes \(x = \frac{p}{100}y\), and “\(y\) is \(4p\) percent of \(x\)” becomes \(y = \frac{4p}{100}x\). Substituting the first into the second eliminates \(y\) entirely and leaves a single equation in \(x\) and \(p\) alone, which (since \(x\) is a positive real, so it’s safe to divide by it) solves cleanly for \(p\).
# MATH: translate each percent-statement literally into an equation
# ("A is q percent of B" means A = (q/100)*B), then substitute one
# into the other to eliminate y. Solving the resulting equation in x
# and p, with x positive and nonzero, isolates p on its own.
import sympy as sp

x, y, p = sp.symbols('x y p', positive=True)
eq1 = sp.Eq(x, (p/100) * y)         # x is p percent of y
eq2 = sp.Eq(y, (4*p/100) * x)       # y is 4p percent of x

solution = sp.solve([eq1, eq2], [x, p], dict=True)
print(solution)   # [{p: 50, x: y/2}]

MS · Purple Comet 2010, Problem 8 · Medium Number Theory

There are exactly two four-digit numbers that are multiples of three where their first digit is double their second digit, their third digit is three more than their fourth digit, and their second digit is 2 less than their fourth digit. Find the difference of these two numbers.

Each condition is a simple equation relating the four digits \(a,b,c,d\) (the number is \(\overline{abcd}\)): \(a=2b\), \(c=d+3\), \(b=d-2\), plus \(a\ge1\) since it’s a four-digit number, plus “divisible by 3.” With only four digits, each ranging over 0–9, there are at most \(10^4\) combinations to check — brute force is not just acceptable here, it’s the cleanest way to be certain no valid number is missed and that the problem’s claim of “exactly two” is actually true.
# MATH: with only 4 digits, each ranging 0-9, there are at most 10^4
# combinations -- small enough that an exhaustive search is both fast
# and provably complete (no risk of missing a case the way hand-listing
# might). Filter the search by each stated digit relation in turn,
# then by divisibility by 3, and let the count itself confirm the
# problem's claim that exactly two numbers survive.
candidates = []
for a in range(1, 10):        # a >= 1: four-digit number
    for b in range(0, 10):
        for c in range(0, 10):
            for d in range(0, 10):
                if a == 2*b and c == d + 3 and b == d - 2:
                    n = 1000*a + 100*b + 10*c + d
                    if n % 3 == 0:
                        candidates.append(n)

print(candidates)                                # [2163, 8496]
print(max(candidates) - min(candidates))         # 6333

MS · Purple Comet 2010, Problem 9 · Medium Number Theory

What percent of the numbers \(1, 2, 3, \ldots, 1000\) are divisible by exactly one of the numbers \(4\) and \(5\)?

Solution 1 — direct count.

“Exactly one of two conditions” means “one is true and the other is false” — not “at least one.” That distinction (which trips people up more than the arithmetic does) is trivial to state correctly in code as a boolean XOR, and then it’s just a matter of counting how many of the 1000 numbers satisfy it.
# MATH: "exactly one of two conditions" is logical XOR -- true when the
# two booleans differ. Looping over every number and testing that
# directly sidesteps any inclusion-exclusion bookkeeping, at the cost
# of nothing since checking 1000 numbers is instant.
count = 0
for i in range(1, 1001):
    div4 = (i % 4 == 0)
    div5 = (i % 5 == 0)
    if div4 != div5:     # exactly one is true (XOR)
        count += 1

print(count, count / 1000 * 100)   # 350 35.0

Solution 2 — inclusion-exclusion, as a cross-check.

The count of numbers divisible by exactly one of 4 and 5 equals (multiples of 4) plus (multiples of 5) minus twice the multiples of both — you subtract the overlap twice because it was counted once in each of the first two totals and it belongs in neither the “exactly one” group. Multiples of both 4 and 5 are exactly multiples of \(\mathrm{lcm}(4,5)=20\). This closed-form count should land on exactly the same number as the direct loop above — if it doesn’t, one of the two methods has a bug.
# MATH: |divisible by exactly one of 4,5| = |mult of 4| + |mult of 5|
# - 2*|mult of both|, where "mult of both" = multiples of lcm(4,5)=20
# (the overlap is subtracted TWICE, not once, because ordinary
# inclusion-exclusion for "at least one" already subtracts it once --
# to exclude it entirely we need to remove it a second time).
import math

N = 1000
mult4 = N // 4
mult5 = N // 5
mult_both = N // math.lcm(4, 5)   # multiples of 20

exactly_one = mult4 + mult5 - 2*mult_both
print(exactly_one, exactly_one / N * 100)   # 350 35.0 -- matches Solution 1

MS · Purple Comet 2010, Problem 10 · Medium Algebra

A baker uses \(6\frac23\) cups of flour when she prepares \(\frac53\) recipes of rolls. She will use \(9\frac34\) cups of flour when she prepares \(\dfrac{m}{n}\) recipes of rolls where \(m\) and \(n\) are relatively prime positive integers. Find \(m+n\).

The two quantities — cups of flour and number of recipes — are directly proportional, so the ratio “flour per recipe” is a fixed constant you can compute once from the first sentence and then reuse to answer the second. Keeping every number as an exact fraction (never a decimal) throughout is what guarantees the final \(m/n\) comes out already in lowest terms, ready to read off \(m+n\).
# MATH: flour and recipes scale proportionally, so
# (flour per recipe) = total_flour / total_recipes is a fixed rate.
# Given that rate, recipes = flour / rate for ANY amount of flour --
# in particular for the 9 3/4 cups asked about. Exact Fractions keep
# the whole computation rational, so the final answer is automatically
# in lowest terms.
from fractions import Fraction as F

flour_1 = F(20, 3)     # 6 2/3 cups
recipes_1 = F(5, 3)    # 5/3 recipes
rate = flour_1 / recipes_1               # cups of flour per recipe

flour_2 = F(39, 4)     # 9 3/4 cups
recipes_2 = flour_2 / rate               # m/n recipes

print(recipes_2)                                        # 39/16
print(recipes_2.numerator + recipes_2.denominator)      # 55

MS · Purple Comet 2010, Problem 11 · Hard Combinatorics

There are two rows of seats with three side-by-side seats in each row. Two little boys, two little girls, and two adults sit in the six seats so that neither little boy sits to the side of either little girl. In how many different ways can these six people be seated?

All six people are distinct individuals, so this is a full seating count out of \(6! = 720\) arrangements, with one restriction: in each row, no boy may sit directly next to (“to the side of”) a girl. That restriction is local — it only depends on who sits in adjacent seats within the same row — which makes it easy to state as a boolean test on any given seating but genuinely awkward to count by a clever combinatorial shortcut without risking a double-count or a missed case. With only 720 permutations total, checking every single one directly is both fast and unimpeachable: nothing is assumed about the structure of valid arrangements, they’re simply all found and counted.
# MATH: 6 distinct people in 6 distinct seats gives 6! = 720 total
# arrangements. The constraint ("no boy adjacent to a girl within a
# row") is purely local to each row's three seats, so it's checked
# directly on every permutation rather than derived by a combinatorial
# formula -- with only 720 cases, brute force is exact and effortless,
# and avoids the classic seating-problem trap of over- or under-
# counting a clever case-split by hand.
from itertools import permutations

people = ['boy1', 'boy2', 'girl1', 'girl2', 'adult1', 'adult2']
row1, row2 = [0, 1, 2], [3, 4, 5]   # seat indices, left to right, per row

def is_boy(p):  return p.startswith('boy')
def is_girl(p): return p.startswith('girl')

valid = 0
for seating in permutations(people):
    ok = True
    for row in (row1, row2):
        for i in range(3):
            if is_boy(seating[row[i]]):
                neighbors = [seating[row[i-1]]] if i > 0 else []
                if i < 2:
                    neighbors.append(seating[row[i+1]])
                if any(is_girl(nb) for nb in neighbors):
                    ok = False
    if ok:
        valid += 1

print(valid)   # 176

MS · Purple Comet 2010, Problem 12 · Hard Geometry

Twelve 30-60-90 triangles are placed in a circle so that the hypotenuse of each triangle coincides with the longer leg of the next triangle. The fourth and last triangle in the diagram are shaded. The ratio of the perimeters of these two triangles can be written as \(\dfrac{m}{n}\) where \(m\) and \(n\) are relatively prime positive integers. Find \(m+n\).

Solution 1 — similarity and scaling, the fast route.

Every one of the twelve triangles has vertex \(O\) at the center, and each occupies exactly \(30°\) at \(O\) (that’s what “twelve triangles placed in a circle” with a right-angle-free vertex at the center forces, since \(12\times30°=360°\)). Calling the twelve center-to-corner distances \(r_0, r_1, \ldots, r_{12}\), the “hypotenuse becomes the next longer leg” rule means each triangle is a scaled copy of the last with the same fixed ratio \(r_{i+1}/r_i\) — so every one of the twelve triangles is similar to every other one, all with the same shape, just different sizes. For similar triangles, the perimeter scales exactly like any one linear length, so \(\dfrac{\text{perimeter}_4}{\text{perimeter}_{12}} = \dfrac{r_3}{r_{11}} = \left(\dfrac{r_1}{r_0}\right)^{3-11}\). All that remains is pinning down the fixed ratio \(r_1/r_0\) from the 30-60-90 triangle’s own side ratios.
# MATH: all twelve triangles are similar to each other (same 30-60-90
# shape, common ratio r between consecutive center-distances r_i),
# because each is built from the last by the SAME rule (hypotenuse ->
# next longer leg) at the SAME 30-degree angle at center O. For similar
# figures, perimeter scales exactly like any single linear length, so
# perimeter_i / perimeter_j = (r_i / r_j) = ratio**(i-j) -- no need to
# ever compute an actual perimeter number.
import sympy as sp

# In triangle O-P_i-P_{i+1}: side O-P_i is a leg (length r_i), the
# 30-degree angle at O is between that leg and the hypotenuse O-P_{i+1}.
# A 30-60-90 triangle has legs in ratio 1 : sqrt(3), hypotenuse = 2*(short leg).
# Here O-P_i (=r_i) is the SHORTER leg opposite the 30-degree angle at
# P_{i+1}... working through the 30-60-90 ratios, the growth factor from
# one center-distance to the next is exactly 2/sqrt(3):
ratio = 2 / sp.sqrt(3)

# perimeter_4 corresponds to triangle index 3 (0-indexed: O,P3,P4);
# perimeter_last (12th) corresponds to index 11 (O,P11,P12).
perim_ratio = sp.simplify(ratio**(3 - 11))   # ratio**(-8) = (sqrt(3)/2)**8
perim_ratio = sp.nsimplify(sp.radsimp(perim_ratio))
print(perim_ratio)                # 81/256

m, n = sp.fraction(perim_ratio)
print(m + n)                      # 337

Solution 2 — direct coordinates and the Law of Cosines, as a cross-check.

Solution 1’s scaling argument is elegant but relies on trusting the abstract similarity claim. To confirm it independently, build the twelve triangles as actual coordinates: place \(P_i\) at distance \(r_i = r_0(2/\sqrt3)^i\) from \(O\), at angle \(30i°\), then compute each triangle’s three side lengths directly — two are just \(r_i\) and \(r_{i+1}\), and the third (the “short leg,” side \(P_iP_{i+1}\)) comes from the Law of Cosines using the known \(30°\) angle at \(O\). Summing three real side lengths for the 4th and 12th triangles and dividing should reproduce exactly \(81/256\) — a genuinely different computational path (trigonometry instead of an abstract scaling ratio) landing on the same fraction is strong evidence neither has an error.
# MATH: build each triangle O-P_i-P_{i+1} from explicit polar
# coordinates and get its third side via the LAW OF COSINES:
#   |P_i P_{i+1}|^2 = r_i^2 + r_{i+1}^2 - 2 r_i r_{i+1} cos(30 deg)
# This never assumes the similarity argument from Solution 1 -- it
# recomputes each perimeter as a genuine sum of three side lengths.
import sympy as sp

r0 = sp.Integer(1)
growth = 2 / sp.sqrt(3)

def perimeter(i):
    r_i = r0 * growth**i
    r_i1 = r0 * growth**(i + 1)
    third_side = sp.sqrt(r_i**2 + r_i1**2 - 2*r_i*r_i1*sp.cos(sp.pi/6))
    return sp.simplify(r_i + r_i1 + third_side)

p4 = perimeter(3)     # triangle O,P3,P4 -- the 4th triangle
p12 = perimeter(11)   # triangle O,P11,P12 -- the 12th (last) triangle

ratio_check = sp.nsimplify(sp.radsimp(sp.simplify(p4 / p12)))
print(ratio_check)    # 81/256 -- matches Solution 1 exactly

MS · Purple Comet 2010, Problem 13 · Medium Number Theory

Find the number of sets \(A\) that satisfy the three conditions: \(A\) is a set of two positive integers; each of the numbers in \(A\) is at least 22 percent the size of the other number; \(A\) contains the number 30.

A set \(\{30, x\}\) is valid exactly when the smaller of the two numbers is at least 22% of the larger — the condition is automatically true in the other direction, since a bigger number is always at least 22% of a smaller one. That single inequality, \(\min(30,x) \ge 0.22\max(30,x)\), splits into a bounded range of small \(x\) below 30 and a bounded range of larger \(x\) above 30; rather than solving that inequality by hand in two cases, just test every candidate \(x\) in a generous range and count how many pass.
# MATH: for a two-element set {30, x}, "each number is at least 22% of
# the other" reduces to ONE inequality (the reverse direction is
# automatic for positive integers): min(30, x) >= 0.22 * max(30, x).
# Using exact fractions instead of the decimal 0.22 avoids any
# rounding at the boundary of the inequality, where an off-by-one
# error in the count would otherwise be easy to introduce.
from fractions import Fraction as F

threshold = F(22, 100)
count = 0
for x in range(1, 10000):        # generous upper bound, x != 30
    if x == 30:
        continue
    lo, hi = min(30, x), max(30, x)
    if F(lo) >= threshold * F(hi):
        count += 1

print(count)   # 129

MS · Purple Comet 2010, Problem 14 · Hard Geometry

Let \(ABCD\) be a trapezoid where \(\overline{AB}\) is parallel to \(\overline{CD}\). Let \(P\) be the intersection of diagonal \(\overline{AC}\) and diagonal \(\overline{BD}\). If the area of triangle \(PAB\) is 16, and the area of triangle \(PCD\) is 25, find the area of the trapezoid.

Solution 1 — similar triangles and the four-region relations.

Because \(AB \parallel CD\), triangles \(PAB\) and \(PCD\) are similar (equal angles at \(P\) from vertical angles, equal alternate-interior angles from the parallel sides). Their area ratio is the square of their linear scale factor, so the ratio \(AB/CD\) equals \(\sqrt{16/25}=4/5\). The trapezoid’s diagonals also split it into two more triangles, \(PBC\) and \(PAD\), and a classic fact about this exact configuration is that these two “side” triangles are always equal in area to each other, and that shared area is the geometric mean \(\sqrt{[PAB]\cdot[PCD]}\). All four pieces then just add up.
# MATH: with AB || CD, triangles PAB and PCD are similar (vertical
# angles at P, alternate interior angles from the parallel sides), so
# their area ratio is the SQUARE of their side-length ratio. The other
# two pieces the diagonals create, triangle PBC and triangle PAD, are
# always equal to each other in this configuration, and each has area
# equal to the geometric mean sqrt([PAB] * [PCD]) -- a standard identity
# for a trapezoid split by its diagonals. Summing all four pieces gives
# the whole trapezoid.
import sympy as sp

area_PAB = 16
area_PCD = 25
area_side = sp.sqrt(area_PAB * area_PCD)   # geometric mean = each side triangle
total = area_PAB + area_PCD + 2*area_side
print(sp.simplify(total))   # 81

Solution 2 — explicit coordinates, as a cross-check.

Rather than trust the “side triangles are equal, and equal to \(\sqrt{[PAB][PCD]}\)” fact as a memorized identity, verify it by actually building a trapezoid with the right area ratio in coordinates and measuring every piece with the Shoelace Formula. Since \([PAB]/[PCD]=16/25\) forces \(AB/CD=4/5\), place \(D=(0,0)\), \(C=(5,0)\) (length 5), and \(A,B\) on a parallel line of length 4 at some height \(h\); scale \(h\) so \([PAB]=16\) exactly, then compute \(P\) as the actual intersection of the diagonals and sum all four triangle areas directly — no identity assumed, just coordinates and Shoelace.
# MATH: build one concrete trapezoid with AB || CD, sides in ratio
# 4:5 (forced by [PAB]:[PCD] = 16:25 = (4:5)^2), scale it so [PAB] is
# exactly 16, then find P as the literal intersection point of segments
# AC and BD and measure every one of the four triangles with the
# Shoelace Formula -- an entirely coordinate-based recomputation that
# assumes none of Solution 1's identities.
import sympy as sp

t = sp.symbols('t', positive=True)   # height scale factor, to be solved for
D = sp.Matrix([0, 0])

# MATH: similar cones have volume proportional to height^3 (any linear

# is the same for every pile (they're all "similarly shaped"). Each

# MATH: by Vieta, for roots r1,r2 of 2x^2+bx+c: r1+r2=-b/2, r1*r2=c/2.
# The SQUARED difference of the roots is a symmetric function of them:

# 30^2=900. Scan b upward, solve for c, and keep only positive integer
# c, tracking the minimum b+c found.
import sympy as sp

best = None
for b in range(1, 2000):

# MATH: this is a constraint-satisfaction search over the ten pairwise
# gcd conditions (4 required "not coprime", 6 required "coprime") --

# limit and check constraints as early as possible (pruning on a

# abandoned immediately rather than after a full 5-tuple is built.
from math import gcd

best = None
LIMIT = 60
for a in range(1, LIMIT):
    for b in range(1, LIMIT):
        if gcd(a, b) == 1:
            continue                          # need (a,b) NOT coprime

HS · Purple Comet 2010, Problem 16 · Hard Geometry

Triangle \(ABC\) has side lengths \(AB=39\), \(BC=57\), \(CA=70\) as shown. Median \(\overline{AD}\) is divided into three congruent segments by points \(E\) and \(F\). Lines \(BE\) and \(BF\) intersect side \(\overline{AC}\) at points \(G\) and \(H\), respectively. Find the distance from \(G\) to \(H\).

Solution 1 — coordinates.

With a triangle this specific (three concrete side lengths, cevians through a trisected median), coordinates turn every step into pure algebra: place \(B\) and \(C\) on the \(x\)-axis (so \(D\), their midpoint, is trivial), solve for \(A\) from the two distance constraints \(AB=39\), \(CA=70\), locate \(E\) and \(F\) by dividing segment \(AD\) into thirds, and find \(G,H\) as the intersections of lines \(BE\), \(BF\) with line \(AC\). No synthetic cleverness required — just solving linear systems sympy handles exactly.
# MATH: place B, C on the x-axis so their midpoint D is trivial; solve
# for A's exact coordinates from the two given side lengths AB=39,
# CA=70 (two circle equations, two unknowns). E, F trisect segment AD.
# G, H are found as literal line-line intersections of BE, BF with AC
# -- pure coordinate algebra, no synthetic argument needed, and sympy
# keeps every quantity exact (nested square roots) throughout.
import sympy as sp

B = sp.Matrix([0, 0])
C = sp.Matrix([57, 0])
Ax, Ay = sp.symbols('Ax Ay', real=True)
eqs = [sp.Eq(Ax**2 + Ay**2, 39**2), sp.Eq((Ax-57)**2 + Ay**2, 70**2)]
sol = [s for s in sp.solve(eqs, [Ax, Ay]) if s[1] > 0][0]
A = sp.Matrix(sol)

D = (B + C) / 2
E = A + sp.Rational(1, 3)*(D - A)     # trisection points of median AD
F = A + sp.Rational(2, 3)*(D - A)

def line_intersect(P1, P2, P3, P4):
    t, u = sp.symbols('t u', real=True)
    pt, pu = P1 + t*(P2-P1), P3 + u*(P4-P3)
    sol = sp.solve([sp.Eq(pt[0], pu[0]), sp.Eq(pt[1], pu[1])], [t, u])
    return P3 + sol[u]*(P4-P3)

G = line_intersect(B, E, A, C)     # line BE meets AC
H = line_intersect(B, F, A, C)     # line BF meets AC
GH = sp.sqrt((G[0]-H[0])**2 + (G[1]-H[1])**2)
print(sp.nsimplify(sp.simplify(GH)))   # 21

Solution 2 — mass points / area ratios, as a cross-check.

A synthetic route avoids coordinates entirely: apply mass points (or equivalently Menelaus’s theorem) to triangle \(ABD\) cut by cevian \(BE\) — with \(E\) one-third of the way from \(D\) to \(A\), balancing masses gives \(\frac{AG}{GC}\) directly. The same idea on triangle \(ABD\) with \(F\) two-thirds of the way from \(D\) to \(A\) gives \(\frac{AH}{HC}\). Converting both ratios into distances along \(AC=70\) and subtracting recovers \(GH\) — and should land on exactly the same 21 found by brute-force coordinates.
# MATH: Menelaus's theorem on triangle ADC with transversal line B-E-G
# (B off the triangle, E on AD, G on AC) gives
#   (AE/ED)*(DB/BC)*(CG/GA) = 1.
# With E splitting AD as AE:ED = 1:2 and D the midpoint of BC (so
# DB/BC = 1/2, with a sign convention baked into the ratio being
# treated as directed), this pins AG/GC exactly; the same theorem with
# F splitting AD as AF:FD = 2:1 pins AH/HC. Converting each ratio to a
# length along AC=70 and differencing gives GH independently of the
# coordinate computation above.
import sympy as sp

AC = 70
AE_ED = sp.Rational(1, 2)     # E is 1/3 of the way from A to D => AE:ED = 1:2
AF_FD = sp.Rational(2, 1)     # F is 2/3 of the way from A to D => AF:FD = 2:1
DB_BC = sp.Rational(1, 2)     # D is the midpoint of BC

# Menelaus (unsigned form, since G, H are known to lie strictly between A and C):
# (AE/ED)*(DB/BC)*(CG/GA) = 1  =>  CG/GA = 1/(AE_ED*DB_BC)
CG_GA = 1 / (AE_ED * DB_BC)
AG = AC / (1 + CG_GA)          # since AG + GC = AC and CG/GA known
CH_HA = 1 / (AF_FD * DB_BC)
AH = AC / (1 + CH_HA)

GH = abs(AH - AG)
print(sp.nsimplify(GH))        # 21 -- matches Solution 1

HS · Purple Comet 2010, Problem 22 · Medium Combinatorics

Ten distinct points are placed on a circle. All ten of the points are paired so that the line segments connecting the pairs do not intersect, as in the examples shown. In how many different ways can this pairing be done?

A pairing avoids crossings exactly when it has a recursive, “nested-or-side-by-side” structure: pick any one point (say the first) and pair it with some other point \(P\); every point strictly between them (going one way around the circle) must be paired only among themselves — otherwise a chord would have to cross the chord to \(P\) — and likewise for the points on the other side. This self-similar splitting is exactly the recurrence that defines the Catalan numbers: the number of non-crossing perfect matchings of \(2n\) points on a circle is \(C_n=\frac{1}{n+1}\binom{2n}{n}\). Here \(n=5\).

Solution 1 — the Catalan number formula.

# MATH: the number of non-crossing perfect matchings of 2n points on a
# circle is the Catalan number C_n = binom(2n,n)/(n+1). Here we have
# 10 points, so n=5. This closed form comes directly from the
# recursive "split into two independent sub-arcs" structure described
# above.
import sympy as sp

n = 5
C_n = sp.binomial(2*n, n) // (n + 1)
print(C_n)   # 42

Solution 2 — independent brute-force enumeration, as a genuine cross-check.

Trusting a formula is not the same as verifying it. As a real independent check, generate every perfect matching of the 10 labeled points (945 of them, since \(9\times7\times5\times3\times1=945\)) and test each one directly for crossings, using nothing but the definition: two chords \((a,b)\) and \((c,d)\) cross exactly when \(c\) and \(d\) fall on opposite arcs determined by \(a\) and \(b\). Counting how many of the 945 pass this direct geometric test should land on exactly the same 42.
# MATH: brute-force every perfect matching of 10 labeled points (there
# are 9*7*5*3*1 = 945 of them) and test each pairing directly against
# the DEFINITION of non-crossing: chord (a,b) and chord (c,d) cross
# iff exactly one of c,d lies on the arc strictly between a and b
# (going one fixed direction around the circle). This never assumes
# the Catalan formula -- it's a fully independent geometric check.
import itertools

def all_matchings(points):
    if not points:
        yield []
        return
    a = points[0]
    for i in range(1, len(points)):
        b = points[i]
        rest = points[1:i] + points[i+1:]
        for m in all_matchings(rest):
            yield [(a, b)] + m

def between(x, lo, hi, n=10):
    i, j = (x - lo) % n, (hi - lo) % n
    return 0 < i < j

def crosses(a, b, c, d):
    return between(c, a, b) != between(d, a, b)

def is_noncrossing(matching):
    return all(not crosses(a, b, c, d)
               for (a, b), (c, d) in itertools.combinations(matching, 2))

# MATH: with big circles at (0,0) r=10 and (3,0) r=8, top-bottom
# symmetry places the small circles' centers at (x0, r) and (x0, -r)
# for common radius r (their tangency to EACH OTHER, across the axis,

# sits INSIDE both big circles, so internal tangency gives distance-to-

HS · Purple Comet 2010, Problem 25 · Hard Algebra

Let \(x_1,x_2,x_3\) be the three roots of the polynomial \(x^3+3x+1\). There are relatively prime positive integers \(m,n\) so that \(\dfrac{m}{n} = \dfrac{x_1^2}{(5x_2+1)(5x_3+1)} + \dfrac{x_2^2}{(5x_1+1)(5x_3+1)} + \dfrac{x_3^2}{(5x_1+1)(5x_2+1)}\). Find \(m+n\).

Solution 1 — substitute the exact (radical) roots directly.

The cubic \(x^3+3x+1\) has no rational roots (its only candidates \(\pm1\) both fail), so its three roots involve nested cube roots — unpleasant to write by hand, but sympy can hold them exactly and symbolically. Substituting all three roots into the expression and simplifying should, despite the ugly intermediate radicals, collapse to a clean rational number: the expression is symmetric in a disguised way (built from the roots in a way that’s invariant under permuting them), so all the irrational parts are guaranteed to cancel.
# MATH: x^3+3x+1 has no rational roots (checking +-1 fails), so its
# roots are genuinely irrational (nested radicals). Even so, the target
# expression is a SYMMETRIC function of the three roots (permuting
# x1,x2,x3 leaves it unchanged), so it must simplify to a rational
# number even though each individual term is a mess of nested roots.
# Let sympy hold the exact roots symbolically -- no floating point --
# and simplify the full sum.
import sympy as sp

x = sp.symbols('x')
roots = sp.solve(x**3 + 3*x + 1, x)   # 3 exact (radical) roots

terms = []
for i in range(3):
    xi = roots[i]
    xj, xk = [roots[j] for j in range(3) if j != i]
    terms.append(xi**2 / ((5*xj + 1)*(5*xk + 1)))

total = sp.simplify(sum(terms))
print(total)                 # 3/7
m, n = sp.fraction(total)
print(m, n, m + n)           # 3 7 10

Solution 2 — Vieta’s formulas and Newton’s identities, no radicals at all.

There’s a cleaner route that never touches an explicit root. Writing \(D=(5x_1+1)(5x_2+1)(5x_3+1)\) for the common denominator, each term’s missing factor is exactly \(5x_i+1\), so the whole sum becomes \(\dfrac{\sum x_i^2(5x_i+1)}{D}=\dfrac{5\sum x_i^3+\sum x_i^2}{D}\). Every piece here — \(D\), \(\sum x_i^2\), \(\sum x_i^3\) — is a symmetric function of the roots, expressible purely through the elementary symmetric sums \(e_1=x_1+x_2+x_3=0\), \(e_2=x_1x_2+x_2x_3+x_3x_1=3\), \(e_3=x_1x_2x_3=-1\) (read straight off the polynomial’s coefficients via Vieta), with \(\sum x_i^2\) and \(\sum x_i^3\) obtained from Newton’s identities. Not one radical appears anywhere in this computation.
# MATH: with common denominator D=(5x1+1)(5x2+1)(5x3+1), each term's
# "missing" factor is exactly (5xi+1), so the sum equals
# [5*sum(xi^3) + sum(xi^2)] / D -- entirely in terms of power sums of
# the roots, which Newton's identities compute directly from the
# elementary symmetric sums e1,e2,e3 (read off the polynomial's
# coefficients via Vieta: e1=0, e2=3, e3=-1). No radical, floating
# point, or explicit root ever appears.
import sympy as sp

e1, e2, e3 = 0, 3, -1     # Vieta: x^3 - e1*x^2 + e2*x - e3 = x^3+3x+1

D = 125*e3 + 25*e2 + 5*e1 + 1        # (5x1+1)(5x2+1)(5x3+1), expanded
p2 = e1**2 - 2*e2                     # Newton: sum xi^2
p3 = e1*p2 - e2*e1 + 3*e3             # Newton: sum xi^3 (simplifies since e1=0)

numerator = 5*p3 + p2
total = sp.Rational(numerator, D)
print(D, p2, p3, total)      # -49 -6 -3 3/7 -- matches Solution 1 exactly

In the coordinate plane a parabola passes through the points \((7,6)\), \((7,12)\), \((18,19)\), and \((18,48)\). The axis of symmetry of the parabola is a line with slope \(\dfrac{r}{s}\) where \(r\) and \(s\) are relatively prime positive integers. Find \(r+s\).

This is not an upright parabola \(y=ax^2+bx+c\) — its axis is tilted, so it needs the general conic \(Ax^2+Bxy+Cy^2+Dx+Ey+F=0\) with the parabola condition \(B^2=4AC\). The key geometric fact is the diameter property of a parabola: the midpoints of any family of parallel chords all lie on a line parallel to the axis. The two vertical segments \((7,6)\)–\((7,12)\) and \((18,19)\)–\((18,48)\) are exactly such a pair of parallel chords (both vertical), so the line through their midpoints is parallel to the axis — and its slope is the axis’s slope.
# MATH: for a parabola, the DIAMETER property says the midpoints of any
# family of parallel chords lie on a line parallel to the axis of
# symmetry. The two given vertical chords -- (7,6)-(7,12) and
# (18,19)-(18,48) -- are parallel (both vertical), so the line joining
# their midpoints is parallel to the axis, and its slope IS the axis's
# slope. No need to fit the full conic at all.
import sympy as sp

mid1 = (7, sp.Rational(6+12, 2))
mid2 = (18, sp.Rational(19+48, 2))
slope = sp.Rational(mid2[1]-mid1[1], mid2[0]-mid1[0])
print(slope)                       # 49/22
r, s = sp.fraction(slope)
print(r, s, r+s)                   # 49 22 71

# independent cross-check: fit the full general conic Ax^2+Bxy+Cy^2+Dx+Ey+F=0
# through all 4 points with the parabola condition B^2=4AC, then find the
# axis direction as the null eigenvector of the quadratic-form matrix.
A, B, C, D, E, F = sp.symbols('A B C D E F')

Av = lin_sol[A].subs(F, Fscale)
Bv = lin_sol[B]
Cv = C
M = sp.Matrix([[Av, Bv/2], [Bv/2, Cv]]).subs(C, 484)
null_eigvec = [v for val, mult, v in M.eigenvects() if val == 0][0][0]
axis_slope = sp.simplify(1 / (null_eigvec[0]/null_eigvec[1]))
print(axis_slope)   # 49/22 -- matches

HS · Purple Comet 2010, Problem 27 · Hard Trigonometry

Let \(a\) and \(b\) be real numbers satisfying \(2(\sin a+\cos a)\sin b = 3-\cos b\). Find \(3\tan^2a + 4\tan^2b\).

Write \(\sin a+\cos a=\sqrt2\sin\!\left(a+\frac{\pi}{4}\right)\), so the equation becomes \(2\sqrt2\sin\!\left(a+\frac\pi4\right)\sin b = 3-\cos b\). The left side can never exceed \(2\sqrt2|\sin b|\) in magnitude (since \(|\sin(\cdot)|\le1\)), so for a real value of \(a\) to exist at all, we need \((3-\cos b)^2\le 8\sin^2b=8(1-\cos^2b)\). That inequality turns out to force equality — the only way a real \(a\) can exist is if the bound is met exactly — which does two things at once: it pins down \(\cos b\) to a single value, and it forces \(\sin\!\left(a+\frac\pi4\right)=\pm1\), which in turn forces \(\tan a=1\) exactly (since \(a=\frac\pi4+k\pi\)).
# MATH: sin(a)+cos(a) = sqrt(2)*sin(a+pi/4) has magnitude at most
# sqrt(2), so the LHS 2(sin a+cos a)sin b is bounded by 2*sqrt(2)*|sin
# b| in absolute value. For a real a to satisfy the given equation, the
# RHS 3-cos(b) must fit within that bound: (3-cos b)^2 <= 8*sin^2(b).
# Solving this as an EQUALITY (the boundary case, forced because it
# turns out to be the only case admitting a real a) pins down cos(b)
# exactly, and simultaneously forces sin(a+pi/4)=+-1, i.e. tan(a)=1.
import sympy as sp

cosb = sp.symbols('cosb', real=True)
boundary_expr = (3 - cosb)**2 - 8*(1 - cosb**2)
print(sp.factor(boundary_expr))          # (3*cosb - 1)**2  -- a perfect square!
cosb_val = sp.solve(sp.Eq(boundary_expr, 0), cosb)[0]
print(cosb_val)                          # 1/3 (the ONLY root -- a repeated root)

sinb2 = 1 - cosb_val**2
tan2b = sinb2 / cosb_val**2
tan2a = 1                                # forced: sin(a+pi/4) = +-1 => tan(a) = 1

answer = 3*tan2a + 4*tan2b
print(answer)   # 35

# MATH: the denominator factors as n(n-1)(n+1)(n-2)(n+2) -- five

HS · Purple Comet 2010, Problem 29 · Hard Geometry

Square \(ABCD\) is shown in the diagram below. Points \(E\), \(F\), \(G\) are on sides \(\overline{AB}\), \(\overline{BC}\), \(\overline{DA}\) respectively, so that lengths \(BE\), \(BF\), \(DG\) are equal. Points \(H\) and \(I\) are the midpoints of segments \(\overline{EF}\) and \(\overline{CG}\), respectively. Segment \(\overline{GJ}\) is the perpendicular bisector of segment \(\overline{HI}\). The ratio of the areas of pentagon \(AEHJG\) and quadrilateral \(CIHF\) can be written as \(\dfrac{m}{n}\) where \(m\) and \(n\) are relatively prime positive integers. Find \(m+n\).

The one length the problem never states outright — how big \(BE=BF=DG\) is relative to the square’s side — is exactly what the “\(GJ\) is the perpendicular bisector of \(HI\)” condition is there to pin down. So the real first task is not geometry but algebra: set the square’s side to \(S\) and the shared length to an unknown \(t\), write \(H\) and \(I\) in coordinates, and impose that the segment from \(G\) to the midpoint of \(HI\) is perpendicular to \(HI\) — a single equation in \(t\) and \(S\) whose non-degenerate solution is \(t=\frac{7S}{9}\). Only after that ratio is nailed down does computing the two polygon areas (again by the shoelace formula) and their ratio become routine.
# MATH: the ratio t/S (where t = BE = BF = DG) is NOT given directly --
# it's determined by the condition that GJ is THE perpendicular
# bisector of HI, i.e. the segment from G to HI's midpoint is
# perpendicular to HI. Set up coordinates with an unknown ratio t
# (relative to side S), impose that perpendicularity as one equation,
# solve for t/S, THEN compute both polygon areas by the shoelace
# formula and take their ratio -- getting the geometric constraint
# right comes before any area computation.
import sympy as sp

S, t = sp.symbols('S t', positive=True)
A = sp.Matrix([0, S]); B = sp.Matrix([0, 0])
C = sp.Matrix([S, 0]); D = sp.Matrix([S, S])
E = sp.Matrix([0, t]); F = sp.Matrix([t, 0]); G = sp.Matrix([S-t, S])
H = (E + F) / 2
I = (C + G) / 2
mid_HI = (H + I) / 2

# GJ perpendicular to HI, with J on segment HI (so J = mid_HI when the
# perpendicular from G meets HI exactly at its midpoint):
perpendicularity = sp.simplify((I - H).dot(mid_HI - G))
t_solutions = sp.solve(sp.Eq(perpendicularity, 0), t)
print(t_solutions)          # [7*S/9, S]  -- t=S is degenerate (E=B, F=C), discard

t_val = sp.Rational(7, 9) * S
Ev, Fv, Gv = E.subs(t, t_val), F.subs(t, t_val), G.subs(t, t_val)
Hv, Iv = (Ev+Fv)/2, (C+Gv)/2
Jv = (Hv + Iv) / 2

def shoelace(pts):
    n = len(pts)
    s = sum(pts[i][0]*pts[(i+1) % n][1] - pts[(i+1) % n][0]*pts[i][1] for i in range(n))
    return sp.simplify(sp.Abs(s) / 2)

pentagon_AEHJG = [tuple(A), tuple(Ev), tuple(Hv), tuple(Jv), tuple(Gv)]
quad_CIHF = [tuple(C), tuple(Iv), tuple(Hv), tuple(Fv)]
area1 = shoelace(pentagon_AEHJG)
area2 = shoelace(quad_CIHF)

ratio = sp.nsimplify(sp.simplify(area1 / area2))
print(area1, area2, ratio)   # 97*S**2/648 13*S**2/108 97/78
m, n = sp.fraction(ratio)
print(m, n, m + n)           # 97 78 175

HS · Purple Comet 2010, Problem 30 · Hard Algebra

Let \(x\) and \(y\) be real numbers satisfying \((x^2+x-1)(x^2-x+1) = 2(y^3-2\sqrt5-1)\) and \((y^2+y-1)(y^2-y+1) = 2(x^3+2\sqrt5-1)\). Find \(8x^2+4y^3\).

Expanding the left side of each equation, \((x^2+x-1)(x^2-x+1)=x^4-x^2+2x-1\), so each equation has the same underlying shape: \(f(x)=2(y^3-2\sqrt5-1)\) and \(f(y)=2(x^3+2\sqrt5-1)\) where \(f(t)=t^4-t^2+2t-1\). The appearance of \(\sqrt5\) is the giveaway: it strongly suggests the golden ratio \(\varphi=\frac{1+\sqrt5}2\) and its conjugate \(\psi=\frac{1-\sqrt5}2\) — the two roots of \(t^2-t-1=0\) — are secretly the answer. Testing the natural guess \(x=\psi,\ y=\varphi\) directly (rather than trying to solve the quartic system by brute algebra) confirms both equations hold exactly, and then \(8x^2+4y^3\) is just arithmetic with \(\varphi,\psi\).
# MATH: expanding, each equation has the shared shape f(t) = t^4-t^2+2t-1
# on one side. The sqrt(5) in the problem is a strong hint toward the
# golden ratio phi=(1+sqrt5)/2 and its conjugate psi=(1-sqrt5)/2, the
# two roots of t^2-t-1=0. Rather than grinding through the full quartic
# system, test the natural guess x=psi, y=phi directly -- substituting
# exact radicals and checking both equations simplify to EXACTLY 0
# confirms it's a genuine solution, not a numerical coincidence.
import sympy as sp

x, y = sp.symbols('x y', real=True)
eq1 = (x**2+x-1)*(x**2-x+1) - 2*(y**3 - 2*sp.sqrt(5) - 1)
eq2 = (y**2+y-1)*(y**2-y+1) - 2*(x**3 + 2*sp.sqrt(5) - 1)

phi = (1 + sp.sqrt(5)) / 2
psi = (1 - sp.sqrt(5)) / 2
x_val, y_val = psi, phi

residual1 = sp.simplify(eq1.subs({x: x_val, y: y_val}))
residual2 = sp.simplify(eq2.subs({x: x_val, y: y_val}))
print(residual1, residual2)     # 0 0 -- confirms this is an exact solution

answer = sp.simplify(8*x_val**2 + 4*y_val**3)
print(answer)                   # 20

# independent numeric cross-check: solve the system from scratch with
# a numerical solver (scipy), starting near the golden-ratio guess,
# with no reference to phi/psi at all.
import numpy as np
from scipy.optimize import fsolve

s5 = np.sqrt(5)
def system(v):
    xx, yy = v
    e1 = (xx**2+xx-1)*(xx**2-xx+1) - 2*(yy**3 - 2*s5 - 1)
    e2 = (yy**2+yy-1)*(yy**2-yy+1) - 2*(xx**3 + 2*s5 - 1)
    return [e1, e2]

root = fsolve(system, [-0.6, 1.6])
print(root, 8*root[0]**2 + 4*root[1]**3)   # [-0.618 1.618] 19.999999... -> 20
