What’s required and acceptable for a contest submission

A reminder of the rules every submission was scored against. Every worked example below is itself a submission that would pass all of these rules — that’s the point of reading them closely, not just the answer.

File format

  • One .py text file per problem you attempt. Plain Python source, nothing else.
  • Not accepted: a PDF, a Google Doc, a Jupyter notebook (.ipynb), a screenshot of code, a file renamed to end in .py that isn’t actually Python.

Your program must

  • Run in 30 seconds or less.
  • Run with no errors — no exceptions, no crash, nothing printed to the screen except your program’s own output.
  • Only import from the allowed list below.

Middle School

MS · Problem 1 · Easy Algebra

A bag holds only red, green, blue and yellow marbles. All but \(20\) of the marbles are red, all but \(22\) are green, all but \(25\) are blue, and all but \(23\) are yellow. How many marbles are in the bag?

Let \(T\) be the number of marbles. “All but \(20\) are red” means exactly \(20\) are not red, so there are \(T - 20\) red marbles; in the same way there are \(T - 22\) green, \(T - 25\) blue and \(T - 23\) yellow. Every marble has exactly one of the four colours, so the four counts add up to \(T\): \[ (T - 20) + (T - 22) + (T - 25) + (T - 23) = T \iff 4T - 90 = T \iff T = 30. \] Check: \(10\) red, \(8\) green, \(5\) blue and \(7\) yellow marbles add up to \(30\), and all but \(20\) of them are red, and so on. The code solves the equation and checks every count.
# MATH: with T marbles, "all but k are red" means T - k are red.
# The four colour counts add up to T:
#   (T - 20) + (T - 22) + (T - 25) + (T - 23) = T  ->  3T = 90  ->  T = 30
ALL_BUT = {"red": 20, "green": 22, "blue": 25, "yellow": 23}

k = len(ALL_BUT)                    # 4 colours
T = sum(ALL_BUT.values()) // (k - 1)
assert (k - 1) * T == sum(ALL_BUT.values())     # the division is exact

counts = {c: T - n for c, n in ALL_BUT.items()}
assert all(v > 0 for v in counts.values())       # every colour really appears
assert sum(counts.values()) == T
print(counts)                       # {'red': 10, 'green': 8, 'blue': 5, 'yellow': 7}
print(T)                            # 30

MS · Problem 2 · Easy Geometry

Each student in a class draws a rectangle with integer side lengths and a perimeter of \(74\) units, and then works out its area. What is the difference between the largest and the smallest possible areas of these rectangles?

If the sides are \(w\) and \(\ell\), then \(2(w + \ell) = 74\), so \(w + \ell = 37\) and the area is \(w(37 - w)\). Both sides are positive integers, so \(w\) runs from \(1\) to \(36\) — that is the whole list of possible rectangles, nothing is left out. The area \(w(37-w)\) is largest when the two sides are as close as possible (\(18 \times 19 = 342\)) and smallest when they are as far apart as possible (\(1 \times 36 = 36\)). The difference is \(342 - 36 = 306\). The code lists all \(36\) areas and checks both extremes.
# MATH: perimeter 74 -> w + l = 37, area = w * (37 - w), with 1 <= w <= 36.
# That list of w is complete: every rectangle in the problem is one of them.
P = 74
half = P // 2                          # w + l = 37
areas = [w * (half - w) for w in range(1, half)]
print(max(areas), min(areas))          # 342 36
assert max(areas) == 18 * 19 and min(areas) == 1 * 36   # sides close / far apart
print(max(areas) - min(areas))         # 306

MS · Problem 3 · Medium Combinatorics

Dana has \(32\) identical marbles. In how many ways can she share them among herself and her three friends Eli, Finn and Gia, so that each of the four children gets at least \(3\) marbles? (Only how many marbles each child gets matters.)

First give every child \(3\) marbles; that uses \(12\) and leaves \(20\). Now any way of handing out the remaining \(20\) marbles to the four children, with no further condition, gives exactly one sharing, and every sharing arises this way. Handing out \(20\) identical marbles to \(4\) children is the same as placing \(3\) dividers among \(20\) marbles in a row (stars and bars): choose the \(3\) divider positions among \(20 + 3 = 23\) places, so the answer is \(\binom{23}{3} = 1771\). The code computes this and checks it by listing every possible split.
# MATH: give each child 3 first (12 marbles), leaving 20 to share freely.
# Sharing 20 identical marbles among 4 children = placing 3 dividers among
# 20 marbles: choose 3 of the 23 places -> C(23, 3)   ("stars and bars").
from math import comb

N, KIDS, MIN = 32, 4, 3
free = N - KIDS * MIN                       # 20
by_formula = comb(free + KIDS - 1, KIDS - 1)

# check: Dana, Eli and Finn get a, b, c; Gia gets the rest (at least MIN)
by_listing = sum(1 for a in range(MIN, N + 1)
                   for b in range(MIN, N + 1)
                   for c in range(MIN, N + 1)
                   if N - a - b - c >= MIN)
assert by_formula == by_listing
print(by_formula)                           # 1771

MS · Problem 4 · Medium Number Theory

How many four-digit positive integers leave a remainder of \(3\) when divided by \(7\), a remainder of \(4\) when divided by \(8\), and a remainder of \(5\) when divided by \(9\)?

Look at what is missing instead of what is left over: each remainder is exactly \(4\) less than the divisor (\(3 = 7 - 4\), \(4 = 8 - 4\), \(5 = 9 - 4\)). So \(x + 4\) is divisible by \(7\), by \(8\) and by \(9\). These three numbers have no common factor pairwise, so \(x + 4\) is divisible by \(7 \cdot 8 \cdot 9 = 504\): \(x = 504t - 4\). For a four-digit \(x\) we need \(1000 \le 504t - 4 \le 9999\), i.e. \(2 \le t \le 19\) — that is \(18\) numbers, from \(1004\) to \(9572\). The code counts them from the formula and checks the three remainders of each.
# MATH: each remainder is 4 short of its divisor, so x + 4 is a multiple of
# 7, 8 and 9 (pairwise coprime) -> of 7*8*9 = 504.  x = 504t - 4.
from math import lcm

L = lcm(7, 8, 9)                                   # 504
xs = [L * t - 4 for t in range(1, 30) if 1000 <= L * t - 4 <= 9999]
assert all(x % 7 == 3 and x % 8 == 4 and x % 9 == 5 for x in xs)
print(xs[0], xs[-1])                               # 1004 9572
print(len(xs))                                     # 18

MS · Problem 5 · Hard Geometry

Twelve points are arranged in a rectangular array of \(3\) rows and \(4\) columns: they are the points \((x, y)\) with \(x \in \{0, 1, 2, 3\}\) and \(y \in \{0, 1, 2\}\). How many non-congruent triangles have their three vertices at three of these points?

There are only \(\binom{12}{3} = 220\) ways to choose three of the points, so we can look at every choice. Two things need care. Not every choice is a triangle: three points on one line give no triangle. Points \(A, B, C\) are on one line exactly when \((x_B - x_A)(y_C - y_A) - (y_B - y_A)(x_C - x_A) = 0\) (this number is twice the triangle’s area, up to sign). Counting each shape once: two triangles are congruent exactly when their three side lengths are the same (SSS). So describe each triangle by its three squared side lengths, sorted — squared, because those are whole numbers by Pythagoras, so the comparison is exact — and count the different descriptions. There are \(21\).
# MATH: 220 choices of 3 points -> check them all (a complete search).
#  * collinear (no triangle) <=> cross product (B-A) x (C-A) == 0
#  * congruent <=> same three side lengths (SSS); compare SQUARED lengths,
#    which are integers (Pythagoras), so the comparison is exact.
from itertools import combinations

points = [(x, y) for x in range(4) for y in range(3)]

def sq_dist(P, Q):
    return (P[0] - Q[0]) ** 2 + (P[1] - Q[1]) ** 2

shapes = set()
for A, B, C in combinations(points, 3):
    cross = (B[0] - A[0]) * (C[1] - A[1]) - (B[1] - A[1]) * (C[0] - A[0])
    if cross == 0:
        continue                                   # on one line: not a triangle
    shapes.add(tuple(sorted((sq_dist(A, B), sq_dist(B, C), sq_dist(A, C)))))

print(len(shapes))                                 # 21

High School

HS · Problem 1 · Easy Algebra

How many ordered pairs \((m, n)\) of positive integers with \(m > n\) satisfy \(m^2 - n^2 = 3600\)?

Factor: \((m - n)(m + n) = 3600\). The two factors \(m - n\) and \(m + n\) differ by \(2n\), an even number, so they have the same parity; since their product is even, both are even. Write \(m - n = 2a\) and \(m + n = 2b\): then \(ab = 900\), and \(m = a + b\), \(n = b - a\), so \(n > 0\) means \(a < b\). Conversely, every factorization \(900 = a \cdot b\) with \(a < b\) gives a solution. Since \(900 = 2^2 \cdot 3^2 \cdot 5^2\) has \(3 \cdot 3 \cdot 3 = 27\) divisors and is a perfect square, the pairs with \(a < b\) number \((27 - 1)/2 = 13\). The code walks through the divisors and checks each pair.
# MATH: (m - n)(m + n) = 3600, both factors even -> m - n = 2a, m + n = 2b,
# a * b = 900, a < b (so n > 0).  One solution per such factor pair of 900.
from math import isqrt

N = 3600
pairs = []
for a in range(1, isqrt(N // 4) + 1):       # a < b means a < 30 = sqrt(900)
    if (N // 4) % a == 0:
        b = (N // 4) // a
        if a < b:
            m, n = a + b, b - a
            assert m * m - n * n == N
            pairs.append((m, n))
print(pairs)
print(len(pairs))                           # 13

HS · Problem 2 · Easy Geometry

How many squares whose sides are parallel to the axes and whose vertices have integer coordinates lie entirely within the region bounded by the line \(y = \sqrt{3}\,x\), the line \(y = -0.1\) and the line \(x = 8.1\)?

Name a square by its lower-left corner \((a, b)\) and its side \(k \ge 1\). It lies in the region exactly when (1) \(b \ge 0\) (above \(y = -0.1\) with integer coordinates), (2) \(a + k \le 8\) (left of \(x = 8.1\)), and (3) its top-left corner \((a, b + k)\) is under the line: \(b + k \le \sqrt{3}\,a\). The top-left corner is the critical one, because the line rises to the right. Condition (3) involves an irrational number, so don’t compare with a decimal approximation of \(\sqrt3\): both sides are non-negative, so square them, \((b + k)^2 \le 3a^2\), and everything is an exact integer comparison. For fixed \(a\) and \(k\) the allowed \(b\) are \(0, 1, \dots, \lfloor \sqrt{3a^2} \rfloor - k\), and Python’s math.isqrt gives \(\lfloor \sqrt{3a^2} \rfloor\) exactly. Adding up gives \(92\).
# MATH: square = lower-left corner (a, b) and side k.  Inside the region iff
#   b >= 0,   a + k <= 8,   and the top-left corner (a, b + k) is under the
#   line: b + k <= sqrt(3)*a  <=>  (b + k)^2 <= 3a^2  (exact, integers only).
# For fixed a, k: b = 0 .. isqrt(3a^2) - k.
from math import isqrt

X = 8                                          # x <= 8.1 -> integer x <= 8
total = 0
for k in range(1, X + 1):
    for a in range(0, X - k + 1):
        top = isqrt(3 * a * a)                 # floor(sqrt(3) * a), exactly
        total += max(0, top - k + 1)           # b = 0 .. top - k

# check with the squared comparison, square by square
check = sum(1 for k in range(1, X + 1) for a in range(X - k + 1)
            for b in range(0, 2 * X) if (b + k) ** 2 <= 3 * a * a)
assert total == check
print(total)                                   # 92

HS · Problem 3 · Medium Combinatorics

Anna, Ben, Chloe, Dev, Ella and Finn sit in a row of six chairs. Anna refuses to sit next to Ben or to Chloe, and Dev refuses to sit next to Ella. In how many ways can the six of them be seated?

Count the bad seatings with inclusion–exclusion. Let \(X\), \(Y\), \(Z\) be the seatings where Anna–Ben, Anna–Chloe, Dev–Ella sit together. Gluing a pair into one block (in \(2\) orders) leaves \(5\) blocks: \(|X| = |Y| = |Z| = 2 \cdot 5! = 240\). Two at once: \(X \cap Y\) means Anna sits between Ben and Chloe (block BAC or CAB): \(2 \cdot 4! = 48\); \(X \cap Z\) and \(Y \cap Z\) are two separate pairs: \(2 \cdot 2 \cdot 4! = 96\) each. All three: the block BAC/CAB and the block Dev–Ella with Finn: \(2 \cdot 2 \cdot 3! = 24\). So the good seatings number \(720 - 3 \cdot 240 + (48 + 96 + 96) - 24 = 216\). The code computes the same terms and checks them against all \(6! = 720\) seatings.
# MATH: inclusion-exclusion over X = A~B adjacent, Y = A~C, Z = D~E.
#   |X| = |Y| = |Z| = 2 * 5!         (glue the pair, 2 orders)
#   |XY| = 2 * 4!  (A between B and C),   |XZ| = |YZ| = 2 * 2 * 4!
#   |XYZ| = 2 * 2 * 3!
# good = 6! - (|X|+|Y|+|Z|) + (|XY|+|XZ|+|YZ|) - |XYZ|
from math import factorial as f
from itertools import permutations

by_ie = f(6) - 3 * (2 * f(5)) + (2 * f(4) + 2 * (2 * 2 * f(4))) - 2 * 2 * f(3)

def ok(seats):
    pos = {p: i for i, p in enumerate(seats)}
    apart = lambda p, q: abs(pos[p] - pos[q]) != 1
    return apart("A", "B") and apart("A", "C") and apart("D", "E")

by_listing = sum(1 for s in permutations("ABCDEF") if ok(s))
assert by_ie == by_listing
print(by_ie)                                   # 216

HS · Problem 4 · Medium Number Theory

For how many positive integers \(n \le 500\) is \(n!\) divisible by \(1 + 2 + \cdots + n\)?

Since \(1 + 2 + \cdots + n = \tfrac{n(n+1)}{2}\), the question is whether \[ \frac{n!}{n(n+1)/2} = \frac{2\,(n-1)!}{n+1} \] is an integer. If \(n + 1\) is an odd prime \(p\): the numbers \(1, 2, \dots, n - 1\) are all less than \(p\), so \(p\) does not divide \((n-1)!\), nor \(2\); the fraction is not an integer. Otherwise it is: \(n = 1\) gives \(1\); if \(n + 1 = ab\) is composite with \(1 < a < b\), both \(a\) and \(b\) appear among \(1, \dots, n-1\), so \(ab \mid (n-1)!\); if \(n + 1 = a^2\) with \(a\) prime, then \(a\) and \(2a\) both appear when \(a > 2\) (so \(a^2 \mid (n-1)!\)), and \(n + 1 = 4\) gives \(2 \cdot 2!/4 = 1\). So \(n\) fails exactly when \(n + 1\) is an odd prime, i.e. \(n + 1 \in \{3, 5, 7, \dots, 499\}\). There are \(95\) primes up to \(501\) (the largest is \(499\)), \(94\) of them odd, so the answer is \(500 - 94 = 406\). The code counts the odd primes with a sieve and checks the divisibility directly for every \(n\), building \(n!\) step by step.
# MATH: n! / (n(n+1)/2) = 2(n-1)! / (n+1).  This fails to be an integer
# exactly when n + 1 is an odd prime p (p cannot divide 2 or any of 1..n-1);
# in every other case (n = 1, n + 1 composite) it is an integer.
LIMIT = 500

# sieve of Eratosthenes up to LIMIT + 1
is_prime = [False, False] + [True] * LIMIT
for p in range(2, int((LIMIT + 1) ** 0.5) + 1):
    if is_prime[p]:
        for q in range(p * p, LIMIT + 2, p):
            is_prime[q] = False
odd_primes = sum(1 for p in range(3, LIMIT + 2) if is_prime[p])
by_math = LIMIT - odd_primes

# direct check: build n! one factor at a time (exact big integers)
fact, by_definition = 1, 0
for n in range(1, LIMIT + 1):
    fact *= n
    if fact % (n * (n + 1) // 2) == 0:
        by_definition += 1
assert by_math == by_definition
print(odd_primes, by_math)          # 94 406

HS · Problem 5 · Hard Geometry

Call a positive integer \(x\) good if there is a triangle with side lengths \(13\), \(16\), \(x\), and a triangle with side lengths \(13\), \(16\), \(y\) for some integer \(y \ne x\), such that the two triangles have the same area. Find the sum of all good integers \(x\).

Both triangles have sides \(13\) and \(16\); let \(\theta\) be the angle between them. The area is \(\tfrac12 \cdot 13 \cdot 16 \cdot \sin\theta\), so equal areas means equal \(\sin\theta\). Different third sides means different angles, so the two angles are \(\theta\) and \(180^\circ - \theta\), i.e. \(\cos\) changes sign. By the law of cosines, \(x^2 = 13^2 + 16^2 - 2 \cdot 13 \cdot 16 \cos\theta\) and \(y^2 = 13^2 + 16^2 + 2 \cdot 13 \cdot 16 \cos\theta\); adding, \[ x^2 + y^2 = 2(13^2 + 16^2) = 850. \] The triangle inequality needs \(3 < x, y < 29\). The ways to write \(850\) as a sum of two squares with both numbers in that range are \(11^2 + 27^2\) and \(15^2 + 25^2\), so the good numbers are \(11, 27, 15, 25\), with sum \(78\). The code checks this independently with Heron’s formula in the exact integer form \(16\,[\text{area}]^2 = (a+b+c)(-a+b+c)(a-b+c)(a+b-c)\), comparing areas without any square roots.
# MATH: same two sides 13, 16 and equal areas -> sin of the included angle is
# equal -> the angles are t and 180 - t -> cos changes sign -> (law of cosines)
#   x^2 + y^2 = 2 * (13^2 + 16^2) = 850,   with 3 < x, y < 29 (triangle inequality)
from math import isqrt

A, B = 13, 16
lo, hi = abs(A - B) + 1, A + B - 1            # 4 .. 28
S = 2 * (A * A + B * B)                       # 850

by_math = set()
for x in range(lo, hi + 1):
    y2 = S - x * x
    y = isqrt(y2) if y2 > 0 else 0
    if y * y == y2 and lo <= y <= hi and y != x:
        by_math.add(x)

# independent check: 16 * area^2 by Heron, exact integers, every pair (x, y)
def area16(c):
    return (A + B + c) * (-A + B + c) * (A - B + c) * (A + B - c)

by_heron = {x for x in range(lo, hi + 1) for y in range(lo, hi + 1)
            if x != y and area16(x) == area16(y)}
assert by_math == by_heron
print(sorted(by_math))                        # [11, 15, 25, 27]
print(sum(by_math))                           # 78
