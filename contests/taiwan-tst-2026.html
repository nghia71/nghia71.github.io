Problem A

MAlgebra · LPS VII, Chapter 17: Sequences, Recurrences, and Discrete Dynamics · Nonlinear Recurrences

For any positive real $x$, set \[a_k=\left\lfloor x^{2^k}\right\rfloor\] for any non-negative integer $k$, in which $\lfloor z\rfloor$ is the largest integer not exceeding $z$. Show that, for any positive real $x$ and positive integer $n$, \[a_n\le a_0(a_0+2)(a_1+2)\cdots(a_{n-1}+2).\] Also, find all pairs $(x,n)$ such that the equality holds.

Show the answer

proof; equality holds exactly when $0<x<1$ (any $n$), or $x\ge1$ and $x^{2^n}\ge(\lfloor x\rfloor+1)^{2^n}-1$

Show solution 1 – One squaring step at a time

Write $y_k=x^{2^k}$, so that $y_{k+1}=y_k^2$ and $a_k=\lfloor y_k\rfloor$. Put $R_n=a_0(a_0+2)(a_1+2)\cdots(a_{n-1}+2)$.

The case $0<x<1$. Then $0<y_k<1$ and $a_k=0$ for every $k$, so both sides are $0$ and equality holds for every $n$.

The case $x\ge1$. Then $y_k\ge1$ and $a_k\ge1$ for all $k$. Since $y_k<a_k+1$, \[a_{k+1}=\lfloor y_k^2\rfloor\le y_k^2<(a_k+1)^2,\qquad\text{so}\qquad a_{k+1}\le(a_k+1)^2-1=a_k(a_k+2).\tag{1}\] We show $a_k\le R_k$ by induction on $k\ge1$. For $k=1$ this is (1) with $k=0$. If $a_k\le R_k$, then by (1) \[a_{k+1}\le a_k(a_k+2)\le R_k(a_k+2)=R_{k+1}.\] This proves the inequality.

Equality for $x\ge1$. In the chain $a_n\le a_{n-1}(a_{n-1}+2)\le R_{n-1}(a_{n-1}+2)=R_n$ all numbers are positive. So $a_n=R_n$ holds if and only if $a_n=a_{n-1}(a_{n-1}+2)$ and $a_{n-1}=R_{n-1}$. Repeating the argument, $a_n=R_n$ if and only if $a_{k+1}=(a_k+1)^2-1$ for $k=0,1,\ldots,n-1$, that is, \[a_k+1=(a_0+1)^{2^k}\qquad(0\le k\le n).\] Let $m=a_0=\lfloor x\rfloor$. Since $x<m+1$ we always have $y_k<(m+1)^{2^k}$, so $a_k=(m+1)^{2^k}-1$ means exactly $y_k\ge(m+1)^{2^k}-1$, i.e. $x\ge\bigl((m+1)^{2^k}-1\bigr)^{1/2^k}$. The function $k\mapsto\bigl((m+1)^{2^k}-1\bigr)^{1/2^k}$ is increasing: with $N=(m+1)^{2^k}>1$, raising both $(N-1)^{1/2^k}$ and $(N^2-1)^{1/2^{k+1}}$ to the power $2^{k+1}$ gives $(N-1)^2=N^2-2N+1<N^2-1$. So the condition for $k=n$ implies the conditions for all smaller $k$. Hence, for $x\ge1$, equality holds if and only if \[x^{2^n}\ge(\lfloor x\rfloor+1)^{2^n}-1.\] For example, $x$ an integer never gives equality, while $x\in[\sqrt3,2)$ gives equality for $n=1$.

Together with the first case: equality holds exactly for $0<x<1$ (any $n$) and for $x\ge1$ with $x^{2^n}\ge(\lfloor x\rfloor+1)^{2^n}-1$.

Show solution 2 – A telescoping product

Keep the notation $a_k=\lfloor x^{2^k}\rfloor$ and $R_n=a_0(a_0+2)\cdots(a_{n-1}+2)$. If $0<x<1$ all $a_k$ vanish and $R_n=a_n=0$; so let $x\ge1$.

Inequality. We use the identity \[(x-1)(x+1)(x^2+1)(x^4+1)\cdots(x^{2^{n-1}}+1)=x^{2^n}-1,\] which follows by multiplying out from the left: $(x-1)(x+1)=x^2-1$, then $(x^2-1)(x^2+1)=x^4-1$, and so on. Now $a_0>x-1\ge0$ and $a_k+2>x^{2^k}+1>0$ for every $k$, because $\lfloor z\rfloor>z-1$. Multiplying these inequalities between non-negative numbers (the first factor on the right may be $0$, but the left factors are positive), \[R_n>(x-1)(x+1)(x^2+1)\cdots(x^{2^{n-1}}+1)=x^{2^n}-1\ge a_n-1.\] Since $R_n$ and $a_n$ are integers, $R_n\ge a_n$.

Equality. Note $R_{k+1}=R_k(a_k+2)$ and, by the inequality just proved for smaller indices, $a_k\le R_k$ for every $k\ge1$ (and $R_0:=a_0$). Suppose $a_n=R_n$. Then \[a_n=R_{n-1}(a_{n-1}+2)\ge a_{n-1}(a_{n-1}+2)=(a_{n-1}+1)^2-1,\] while $a_n\le x^{2^n}=\bigl(x^{2^{n-1}}\bigr)^2<(a_{n-1}+1)^2$. Hence $a_n=(a_{n-1}+1)^2-1$, and then the displayed inequality is an equality, which forces $R_{n-1}=a_{n-1}$. Descending, $a_{k+1}+1=(a_k+1)^2$ for all $k<n$, so $a_n=(a_0+1)^{2^n}-1$. Conversely, if $a_n=(a_0+1)^{2^n}-1$, then since every $a_k\le(a_0+1)^{2^k}-1$ (because $x<a_0+1$), \[a_n\le R_n\le a_0\prod_{k=0}^{n-1}\bigl((a_0+1)^{2^k}+1\bigr)=(a_0+1)^{2^n}-1=a_n,\] by the same telescoping identity with $x$ replaced by $a_0+1$. So equality holds if and only if $\lfloor x^{2^n}\rfloor=(\lfloor x\rfloor+1)^{2^n}-1$, i.e. $x^{2^n}\ge(\lfloor x\rfloor+1)^{2^n}-1$ (the upper bound $x^{2^n}<(\lfloor x\rfloor+1)^{2^n}$ is automatic). With the case $0<x<1$ this is the complete list of equality cases.

Problem C

MCombinatorics · LPS VII, Chapter 39: Graph Theory and Structural Combinatorics · Paths, Cycles, and Connectivity

Let $a_1,a_2,\ldots,a_{2026}$ be a permutation of $1,2,\ldots,2026$. There are cities labeled $1$ to $2026$. There exists a one-way route from city $i$ to $j$ if and only if $i<j$ or $a_i<a_j$. It is known that we can go from any city to any other city through a sequence of routes. Find the minimum possible value of \[\sum_{i=1}^{2026}|a_i-i|.\]

Show the answer

$4050$

Show solution 1 – Counting crossings of each cut

Write $n=2026$.

Reformulation. For $i<j$ there is always a route $i\to j$. A route $j\to i$ with $i<j$ exists exactly when $a_j<a_i$. We claim: all cities are mutually reachable if and only if for every $k=1,\ldots,n-1$ there are $i\le k<j$ with $a_i>a_j$.

If for some $k$ no such pair exists, then no route leads from $\{k+1,\ldots,n\}$ to $\{1,\ldots,k\}$, so city $n$ cannot reach city $1$. Conversely, assume the condition and fix a city $v$. Let $S$ be the set of cities reachable from $v$ (including $v$) and $m=\min S$. Because of the forward routes, $S=\{m,m+1,\ldots,n\}$. If $m>1$, the condition for $k=m-1$ gives a route from some $j\ge m$ to some $i\le m-1$, contradicting the choice of $m$. So $S$ is everything.

For $1\le k\le n-1$ let $c_k$ be the number of indices $i\le k$ with $a_i>k$. Then $\{a_1,\ldots,a_k\}=\{1,\ldots,k\}$ exactly when $c_k=0$, and if $c_k\ge1$ there are $i\le k$ with $a_i>k$ and $j>k$ with $a_j\le k$, i.e. $a_i>a_j$. So the condition says: $c_k\ge1$ for every $k$.

A formula for the sum. The number $|a_i-i|$ counts the integers $k$ with $\min(i,a_i)\le k<\max(i,a_i)$. If $a_i>i$, these are the $k$ with $i\le k<a_i$, i.e. the cuts $k$ for which $i\le k<a_i$ ("$i$ crosses cut $k$ upwards"). If $a_i<i$, they are the $k$ with $a_i\le k<i$ ("downwards"). At each cut $k$ the number of upward crossings is $c_k$, and the number of downward crossings is the number of $j>k$ with $a_j\le k$, which is also $c_k$ (both equal the number of values $\le k$ that are not among $a_1,\ldots,a_k$). Therefore \[\sum_{i=1}^n|a_i-i|=2\sum_{k=1}^{n-1}c_k\ge2(n-1)=4050.\]

Equality. The permutation $(a_1,\ldots,a_n)=(2,3,\ldots,n,1)$ has $c_k=1$ for all $k$, so it is admissible, and its sum is $(n-1)\cdot1+(n-1)=2(n-1)$. The minimum is $\boxed{4050}$.

Show solution 2 – Cycles of the permutation

Write $n=2026$ and regard $\pi:i\mapsto a_i$ as a permutation of $\{1,\ldots,n\}$.

Admissibility. A route from $j$ to $i<j$ exists iff $a_j<a_i$, and routes $i\to j$ for $i<j$ always exist. If for some $k<n$ the permutation maps $\{1,\ldots,k\}$ onto itself, then $a_i\le k<a_j$ for all $i\le k<j$, so there is no route from a city $>k$ to a city $\le k$, and the cities are not mutually reachable. Hence in an admissible permutation no set $\{1,\ldots,k\}$ with $1\le k<n$ is mapped onto itself.

A bound for one cycle. Let $C$ be a cycle of $\pi$, with smallest element $s$ and largest element $t$. Following the cycle $c\to\pi(c)\to\pi^2(c)\to\cdots$ we walk on the number line from $s$ to $t$ and back to $s$, with steps of lengths $|\pi(c)-c|$, $c\in C$. So \[\sum_{c\in C}|a_c-c|\ge2(t-s).\]

The intervals cover $[1,n]$. Let $I_C=[s,t]$ for every cycle $C$. Suppose some unit interval $[k,k+1]$ ($1\le k<n$) is contained in no $I_C$. Then every cycle lies entirely in $\{1,\ldots,k\}$ or entirely in $\{k+1,\ldots,n\}$, so $\pi$ maps $\{1,\ldots,k\}$ onto itself, which is impossible. Hence the intervals $I_C$ cover each of the $n-1$ unit intervals $[k,k+1]$, and their total length is at least $n-1$.

Adding the bound over all cycles, \[\sum_{i=1}^n|a_i-i|\ge2\sum_C(t_C-s_C)\ge2(n-1)=4050.\] The single cycle $1\to2\to\cdots\to n\to1$, i.e. $(a_1,\ldots,a_n)=(2,3,\ldots,n,1)$, is admissible (from any city one can go forward to city $n$, then from $n$ to city $1$ because $a_n=1<a_1$, and from city $1$ forward to any city) and gives exactly $2(n-1)$. The minimum is $\boxed{4050}$.

Problem G

MGeometry · LPS VII, Chapter 19: Triangle Centers and Classical Triangle Geometry · Euler Line and Nine-Point Circle Structure

Let $ABC$ be a triangle with circumcenter $O$, centroid $G$ and orthocenter $H$. Let $M$ be the midpoint of $BC$, let $AH$ intersect the circumcircle of $\triangle ABC$ again at $S$, and let $AH$ intersect $BC$ at $T$. Show that $TGMO$ is concyclic if and only if $GS$ is tangent to the circumcircle of $\triangle TGA$.

Show solution 1 – Cartesian coordinates

We assume the configuration is non-degenerate: $AB\ne AC$ (so $T\ne M$ and $G\notin AT$; otherwise the circle $TGA$ does not exist), $\angle A\ne90^\circ$ (so $O\ne M$) and $\angle B,\angle C\ne90^\circ$.

Put $T$ at the origin, $BC$ on the $x$-axis and $A$ on the $y$-axis: \[A=(0,a),\quad B=(b,0),\quad C=(c,0),\qquad a>0,\ b\ne c,\ b+c\ne0 .\] Then $M=\bigl(\tfrac{b+c}2,0\bigr)$ and $G=\bigl(\tfrac{b+c}3,\tfrac a3\bigr)$. The circumcenter lies on $x=\tfrac{b+c}2$; equating its distances to $A$ and $B$ gives $O=\bigl(\tfrac{b+c}2,\tfrac{a^2+bc}{2a}\bigr)$. The line $AT$ is $x=0$; it meets the circumcircle at $A=(0,a)$ and $S=(0,s)$, and the power of $T$ gives $a\cdot s=b\cdot c$ (both products are the power of the origin), so $s=\tfrac{bc}a$.

Condition 1: $T,G,M,O$ concyclic. Since $TM$ is horizontal and $MO$ is vertical, $\angle TMO=90^\circ$, so the circle through $T,M,O$ is the circle with diameter $TO$. As $G\ne T$ and $G\ne O$ ($G=O$ only for an equilateral triangle), $G$ is on it if and only if $\angle TGO=90^\circ$, i.e. $(T-G)\cdot(O-G)=0$. Now \[T-G=\Bigl(-\frac{b+c}3,-\frac a3\Bigr),\qquad O-G=\Bigl(\frac{b+c}6,\frac{a^2+3bc}{6a}\Bigr),\] \[(T-G)\cdot(O-G)=-\frac{(b+c)^2+a^2+3bc}{18}.\]

Condition 2: $GS$ tangent to the circle $(TGA)$. The points $T,A,S$ lie on the line $x=0$, so the power of $S$ with respect to $(TGA)$ is the product of signed lengths $(0-s)(a-s)=s^2-as$. The line $SG$ meets the circle at $G$ and at a second point $G'$ (possibly $G'=G$), and $\overline{SG}\cdot\overline{SG'}=s^2-as$. Hence $SG$ is tangent (that is, $G'=G$) if and only if $SG^2=s^2-as$. We compute \[SG^2-(s^2-as)=\frac{(b+c)^2}9+\Bigl(\frac a3-s\Bigr)^2-s^2+as=\frac{(b+c)^2+a^2+3as}9=\frac{(b+c)^2+a^2+3bc}9,\] using $as=bc$.

Both conditions are therefore equivalent to $(b+c)^2+a^2+3bc=0$, which proves the claim. (This equation needs $bc<0$, so in the equality case $T$ lies strictly between $B$ and $C$.)

Show solution 2 – Two circles centred on the altitude

We assume the configuration is non-degenerate: $AB\ne AC$ (so that the circle $TGA$ exists and $T\ne M$), $\angle A\ne 90^\circ$, and $\angle B,\angle C\ne90^\circ$ (so $H\ne T$). Let $\ell$ be the line $AT$. Two standard facts are used.

  • $S$ is the reflection of $H$ in $BC$, i.e. $T$ is the midpoint of $HS$. (Indeed $\angle CBS=\angle CAS=90^\circ-\angle C=\angle CBH$, so $BC$ bisects $\angle HBS$ and the right triangles $HBT$, $SBT$ are congruent.)

  • $H$, $G$, $O$ lie on the Euler line with $HG=2\,GO$; in particular $G\ne H,O$ and the lines $GO$ and $GH$ coincide.

Translating the two conditions. As $\angle TMO=90^\circ$, the circle through $T,M,O$ has diameter $TO$, so $TGMO$ is concyclic iff $\angle TGO=90^\circ$, iff $\angle TGH=90^\circ$, iff $G$ lies on the circle $\omega_1$ with diameter $TH$. For the tangency, $T,A,S$ are collinear, so the power of $S$ with respect to $(TGA)$ is $\overline{ST}\cdot\overline{SA}$, and $SG$ is tangent iff $SG^2=\overline{ST}\cdot\overline{SA}$.

Define for every point $X$ of the plane \[p_1(X)=\text{power of }X\text{ w.r.t. }\omega_1,\qquad p_2(X)=XS^2-\overline{ST}\cdot\overline{SA}.\] Both have the form $|X-Z|^2-k$ with the centre $Z$ on $\ell$ (the midpoint of $TH$, resp. $S$). Hence $p_2-p_1$ is a linear function of $X$ which depends only on the orthogonal projection of $X$ onto $\ell$ (the quadratic terms cancel, and $|X-Z|^2=|X'-Z|^2+d(X,\ell)^2$ where $X'$ is the projection). So $p_2-p_1$ is constant on every line parallel to $BC$.

The key value. Measure signed positions on $\ell$ from $T$, positive towards $A$: $T=0$, $A=a$, $H=h$, $S=-h$. For a point $U=u$ on $\ell$, \[p_1(U)=(u-0)(u-h),\qquad p_2(U)=(u+h)^2-(0+h)(a+h),\] so $p_2(U)-p_1(U)=3uh-ah=h(3u-a)$. This vanishes at $u=a/3$. The centroid $G$ is at distance $\tfrac13AT$ from $BC$ on the same side as $A$, so its projection onto $\ell$ is exactly the point $u=a/3$. Therefore $p_1(G)=p_2(G)$, and \[TGMO\ \text{concyclic}\iff p_1(G)=0\iff p_2(G)=0\iff GS\ \text{tangent to }(TGA).\]

Problem N

MNumber Theory · LPS VII, Chapter 37: Diophantine Equations: Descent and Infinite Processes · Infinite Descent

Determine all positive integers $n$ for which there exists a pair of positive integers $(a,b)$ satisfying \[a^2+b^2+1=n(ab+2).\]

Show the answer

$n=3$ and $n=\dfrac{k^2+1}2$ for odd positive integers $k$ (i.e. $n=1,3,5,13,25,41,\ldots$)

Show the solution – Vieta jumping

These values work. For $n=3$ take $(a,b)=(1,4)$: $1+16+1=18=3\cdot6$. For an odd $k\ge1$ and $n=\tfrac{k^2+1}2$ take $(a,b)=(k,kn)$: \[a^2+b^2+1=k^2+1+k^2n^2=2n+k^2n^2=n(k^2n+2)=n(ab+2).\]

No other values work. Fix $n$ and suppose solutions exist. Among them choose $(a,b)$ with $a+b$ minimal and, by symmetry, $a\le b$. Viewed as a quadratic in $b$, \[b^2-na\,b+(a^2+1-2n)=0,\] so $b'=na-b=\dfrac{a^2+1-2n}{b}$ is an integer and $(a,b')$ satisfies the same quadratic.

  • If $a^2+1>2n$, then $b'$ is a positive integer with $b'=\frac{a^2+1-2n}{b}<\frac{a^2}{b}\le a\le b$. Then $(a,b')$ is a solution with $a+b'<a+b$, a contradiction.

  • If $a^2+1=2n$, then $a$ is odd and $n=\frac{a^2+1}2$ is of the second form.

  • If $a^2+1<2n$, then $b'<0$, i.e. $b\ge na+1$. The equation reads $b(b-na)=2n-a^2-1$ with $b-na\ge1$, so $na+1\le b\le 2n-a^2-1$, i.e. $n(a-2)+a^2+2\le0$. This forces $a=1$. Then with $t=b-n\ge1$ we get $(n+t)t=2n-2$; $t=1$ gives $n=3$, and $t\ge2$ gives $(n+t)t\ge2n+4>2n-2$, impossible.

So $n=3$ or $n=\frac{k^2+1}2$ with $k$ odd, and all these values occur.

Problem A

MAlgebra · LPS VII, Chapter 30: Functional Equations: Core Olympiad Methods · Substitution and Special Inputs

Determine all functions $f:\mathbb{R}\to\mathbb{R}$ such that \[f\bigl(x^2f(y)+f(x)\bigr)=xf(xy)+x+\max\bigl\{f(y^2)-y^2,\ y\bigl(f(x)-x\bigr)\bigr\}\] for all real numbers $x$ and $y$.

Show the answer

$f(x)=x$

Show the solution – Special inputs and the value at $-1$

The identity $f(x)=x$ works: both sides equal $x^2y+x$, because both entries of the maximum are $0$.

Conversely let $f$ satisfy the equation and write $P(x,y)$ for the assertion \[f\bigl(x^2f(y)+f(x)\bigr)=xf(xy)+x+\max\bigl\{f(y^2)-y^2,\ y\bigl(f(x)-x\bigr)\bigr\}.\]

Step 1: $f(0)=0$ and $f(t)\le t$ for $t\ge0$. Let $c=f(0)$. $P(0,y)$ gives $f(c)=\max\{f(y^2)-y^2,\ cy\}\ge cy$ for all $y$. If $c\ne0$, choosing $y=(|f(c)|+1)/c$ gives $cy>f(c)$, a contradiction. So $c=0$, and then $P(0,y)$ reads $0=\max\{f(y^2)-y^2,0\}$, i.e. $f(y^2)\le y^2$.

Step 2: $f$ is an involution. $P(x,0)$ gives $f(f(x))=x+\max\{0,0\}=x$. Hence $f$ is a bijection.

Step 3: $f(1)=1$. Let $k=f(1)$ and $m=f(-1)$; by Step 1, $k\le1$. Compare \[P(1,-1):\ f(m+k)=m+1+\max\{k-1,\,1-k\}=m+1+(1-k),\] \[P(-1,1):\ f(k+m)=-m-1+\max\{k-1,\,m+1\}.\] Suppose $k<1$. Then $\max\{k-1,m+1\}=2m+3-k$. If the maximum is $k-1$ we get $m=k-2$; if it is $m+1$ we get $m+1=2m+3-k$, again $m=k-2$. So $m=k-2$, and then both entries of the maximum equal $k-1$, and $P(-1,1)$ gives \[f(2k-2)=f(k+m)=-(k-2)-1+(k-1)=0=f(0).\] By injectivity $2k-2=0$, i.e. $k=1$, contradicting $k<1$. Hence $k=1$.

Step 4. $P(1,y)$ with $k=1$ reads \[f\bigl(f(y)+1\bigr)=f(y)+1+\max\{f(y^2)-y^2,\,0\}=f(y)+1,\] since $f(y^2)-y^2\le0$. As $f$ is surjective, $f(y)$ takes every real value $z$, so $f(z+1)=z+1$ for all real $z$. Thus $f(x)=x$ for all $x$, and the only solution is $\boxed{f(x)=x}$.

Problem C

HCombinatorics · LPS VII, Chapter 31: Extremal Principle and Bounding Arguments · Bounding and Limiting Arguments

We fill in $0$ or $1$ in each cell in a $2026\times2026$ grid. Let $a_{i,j}$ denote the number in the cell at the $i$-th row and $j$-th column. For all $1\le i\le 2026$, let $r_i=\overline{a_{i,1}a_{i,2}\cdots a_{i,2026}}$ be a string of $0$ and $1$ with length $2026$. Similarly define $c_i=\overline{a_{1,i}a_{2,i}\cdots a_{2026,i}}$. If no two strings among $r_1,\ldots,r_{2026},c_1,\ldots,c_{2026}$ are exactly the same, find the largest possible sum of all the numbers on the grid.

Show the answer

$2026^2-3038=4101638$

Show the solution – Count the zeros line by line

Let $n=2026$ and let $Z$ be the number of cells containing $0$; the sum of the grid is $n^2-Z$. Identify each of the $2n$ strings $r_1,\ldots,r_n,c_1,\ldots,c_n$ with the set of positions where it has a $0$ (a subset of $\{1,\ldots,n\}$); the strings are distinct exactly when these $2n$ sets are distinct.

Bound. Every zero lies in one row and one column, so the numbers of zeros in the $2n$ strings add up to $2Z$. Among $2n$ distinct subsets of $\{1,\ldots,n\}$ at most one is empty and at most $n$ have exactly one element; the remaining at least $n-1$ have at least two elements. Hence \[2Z\ge0\cdot1+1\cdot n+2(n-1)=3n-2,\qquad Z\ge\frac{3n-2}2=3038,\] and the sum is at most $n^2-3038$.

Construction with exactly $\frac{3n-2}2=3038$ zeros. Number rows and columns $1,\ldots,n$ and put zeros exactly in the cells \[(i,i+1),\ (i,i+2),\ (i+1,i+1)\quad\text{for odd } i\le n-5,\] \[(n-3,1),\ (n-3,n-2),\ (n-2,1),\ (n-2,n-1),\ (n-1,n).\] That is $3\cdot\frac{n-4}2+5=\frac{3n-2}2$ zeros. The zero sets are:

  • rows: $r_i=\{i+1,i+2\}$ and $r_{i+1}=\{i+1\}$ for odd $i\le n-5$; $r_{n-3}=\{1,n-2\}$, $r_{n-2}=\{1,n-1\}$, $r_{n-1}=\{n\}$, $r_n=\varnothing$;

  • columns: $c_1=\{n-3,n-2\}$; $c_{i+1}=\{i,i+1\}$ and $c_{i+2}=\{i\}$ for odd $i\le n-5$; $c_{n-2}=\{n-3\}$, $c_{n-1}=\{n-2\}$, $c_n=\{n-1\}$.

The one-element sets are $\{2\},\{4\},\ldots,\{n-4\},\{n\}$ (rows) and $\{1\},\{3\},\ldots,\{n-5\},\{n-3\},\{n-2\},\{n-1\}$ (columns): all $n$ singletons, each once. Where $E$ and $F$ are. In triangle $BI_BE$ the angle at $I_B$ is right, so the angle at $B$ is acute and $E$ lies on ray $BA$ (the ray making the angle $\frac\beta2$ with $BI_B$). Two pairs of similar triangles. Since $A$ lies between $B$ and $E$ and between $I_C$ and $I_B$, the angles $\angle BAI_C$ and $\angle EAI_B$ are vertical angles. A rotation by $90^\circ$. As $Y$ lies on segment $I_CC$, $X$ on segment $I_BB$, and $I_B,I_C$ lie on the same arc $BC$ of the circle with diameter $I_BI_C$, \[\angle BI_CY=\angle BI_CC=\angle BI_BC=\angle XI_BC .\] With (1), triangles $BI_CY$ and $XI_BC$ are similar (SAS), with $B\mapsto X$, $I_C\mapsto I_B$, $Y\mapsto C$. Small cases. If $a=1$ then $d(1^b)=1=b^2-b+1$ gives $b=1$, and $(1,1)$ is indeed a solution ($d(1)=1=1-1+1$). Similarly $b=1$ forces $a=1$. From now on $a,b\ge2$.

  • If $a=b$, then $a\mid a+\Omega(a)$, so $a\mid\Omega(a)$, impossible as $1\le\Omega(a)<a$.

  • If $a<b$: $b$ divides the positive number $a+\Omega(a)<2a<2b$, hence $a+\Omega(a)=b$. Then $a\mid b+\Omega(b)=a+\Omega(a)+\Omega(b)$ gives $a\mid\Omega(a)+\Omega(b)=\Omega(ab)$.   • The case $a>b$ is symmetric.

Let $n$ and $k$ be positive integers such that $n<k<2n$. Suppose $a_1,a_2,\ldots,a_k$ are positive integers such that $2^{a_1}+2^{a_2}+\cdots+2^{a_k}$ is divisible by $2^n-1$.

Show solution 1 – Reading off binary digits

Since $2^n\equiv1\pmod{2^n-1}$, the residue of $2^a$ modulo $2^n-1$ depends only on $a\bmod n$: if $a\equiv r\pmod n$ with $0\le r\le n-1$, then $2^a\equiv2^r$. For $0\le r\le n-1$ let $c_r$ be the number of indices $i$ with $a_i\equiv r\pmod n$. Then $\sum_r c_r=k$ and \[S:=\sum_{r=0}^{n-1}c_r2^r\equiv2^{a_1}+\cdots+2^{a_k}\equiv0\pmod{2^n-1}.\] Suppose, for contradiction, that every $c_r\le2$. Then $0<S\le2(2^0+\cdots+2^{n-1})=2(2^n-1)$, with equality only if all $c_r=2$, i.e. $k=2n$, which is excluded. So $S$ is a positive multiple of $2^n-1$ below $2(2^n-1)$, i.e. $S=2^n-1$.

Claim. If $c_0,\dots,c_{m-1}\in\{0,1,2\}$ and $\sum_{r<m}c_r2^r=2^m-1$, then all $c_r=1$. Induction on $m$; $m=1$ is clear. For $m\ge2$, the right side is odd, so $c_0$ is odd, $c_0=1$. Subtracting $1$ and halving gives $\sum_{r=1}^{m-1}c_r2^{r-1}=2^{m-1}-1$, and the induction hypothesis gives $c_1=\cdots=c_{m-1}=1$.

By the claim with $m=n$, every $c_r=1$, so $k=\sum c_r=n$, contradicting $k>n$. Hence some residue class contains at least three of the $a_i$.

Show solution 2 – A number and its complement

As $2^n\equiv1\pmod{2^n-1}$, replace each $a_i$ by its remainder $r_i\in\{0,\dots,n-1\}$ modulo $n$; this does not change the sum modulo $2^n-1$. Assume no remainder occurs three times. Let $U$ be the set of remainders that occur at least once and $W\subseteq U$ the set of those occurring twice, and put \[A=\sum_{r\in U}2^r,\qquad B=\sum_{r\in W}2^r .\] Then $k=|U|+|W|$ and $2^n-1\mid A+B$. Both $A$ and $B$ are at most $2^n-1$, and they are not both equal to $2^n-1$ (that would mean $k=2n$); also $A+B\ge k>0$. Hence $A+B=2^n-1$.

Now $2^n-1$ is the $n$-bit number $11\ldots1$ in binary, and $A$ is an $n$-bit number whose $1$-bits are the positions in $U$. So $B=(2^n-1)-A$ is the number whose $1$-bits are exactly the positions not in $U$ (subtracting from $11\ldots1$ produces no borrows). But the $1$-bits of $B$ are the positions in $W\subseteq U$. A set contained both in $U$ and in its complement is empty, so $W=\varnothing$, $B=0$ and $A=2^n-1$, i.e. $U$ is everything. Then $k=|U|=n$, contradicting $n<k$. So some remainder occurs at least three times.

Problem 2

MCombinatorics · LPS VII, Chapter 20: Parity, Coloring, and Process Termination · Process Termination and Reachability · also Germany TST 2026, VAIMO 2, Problem 2

There is a row of $n$ paddocks, labelled from left to right with the integers $1$ to $n$, where $n\geq 3$. Skippy the Kangaroo grazes in the paddock according to the following rule:

If Skippy is grazing in paddock $k$, then she makes a sequence of $k$ hops from a paddock to an adjacent paddock. The first of the $k$ hops is always to the right, unless Skippy is in paddock $n$, in which case it is to the left. Each of the following $k-1$ hops is in the same direction as the previous hop, unless Skippy is in paddock $1$ or $n$. Skippy grazes in the paddock that she is in after the $k^{\text{th}}$ hop.

For example, if $n=8$ and Skippy is grazing in paddock $3$, the next $4$ paddocks she will graze in are $6,4,8,2$, in this order. Skippy continues grazing in this way indefinitely. A paddock is overgrazed if Skippy eventually grazes in it, regardless of which paddock she starts in. Determine all $n\geq 3$ for which there exists exactly one overgrazed paddock.

Show the answer

$n=3\cdot2^a$ with $a\ge0$ (i.e. $n=3,6,12,24,\dots$)

Show solution 1 – Folding the doubling map

Let $f(k)$ be the paddock after grazing in paddock $k$.

The map $f$. If $2k\le n$, the $k$ hops go straight right and $f(k)=2k$. If $\frac n2<k\le n-1$, Skippy reaches $n$ after $n-k$ hops, turns, and makes $2k-n\le n-2$ more hops to the left, so $f(k)=2n-2k$. If $k=n$, she hops left $n-1$ times to paddock $1$ and then once to the right: $f(n)=2$. For an integer $x$ let $\|x\|$ be the distance from $x$ to the nearest multiple of $2n$. Then \[f(k)=\|2k\|\quad(1\le k\le n-1),\qquad f(n)=2 .\] Since $\|2\|y\|\|=\|2y\|$ for every integer $y$, induction gives: if none of $k,f(k),\dots,f^{j-1}(k)$ equals $n$, then $f^j(k)=\|2^jk\|$.

Reformulation. Every orbit of $f$ ends in a cycle. If there are two different cycles, a start on one never visits the other, so no paddock is overgrazed. If there is exactly one cycle, its paddocks are exactly the overgrazed ones (every orbit enters it and runs around it; a paddock off the cycle is missed by a start on the cycle). So there is exactly one overgrazed paddock if and only if $f$ has a fixed point and no other cycle.

Fixed points. $f(n)=2\ne n$. For $k\le n-1$, $\|2k\|=k$ means $2k\equiv\pm k\pmod{2n}$; $k\equiv0$ is impossible, and $3k\equiv0\pmod{2n}$ with $1\le k\le n-1$ means $3\mid n$ and $k=\frac{2n}3$. So we need $3\mid n$; write $n=3\cdot2^a\cdot b$ with $b$ odd, and $k^*=\frac{2n}3=2^{a+1}b$.

If $b>1$, there is a second cycle. Let $k=2^{a+1}<k^*$. As long as the orbit avoids $n$, \[f^j(k)=\|2^{a+1}\cdot2^j\|=2^{a+1}\cdot\|2^j\|_{3b},\] where $\|\cdot\|_{3b}$ is the distance to the nearest multiple of $3b$ (because $2n=2^{a+1}\cdot3b$). These values are multiples of $2^{a+1}$, while $n=2^a\cdot3b$ is not (as $3b$ is odd), so by induction the orbit indeed never meets $n$ and the formula stays valid. As $3b$ is odd, $2^r\equiv1\pmod{3b}$ for some $r\ge1$, and then $f^r(k)=2^{a+1}=k$. So $k$ lies on a cycle different from the fixed point $\{k^*\}$, and no paddock is overgrazed.

If $b=1$, every orbit reaches $k^*=2^{a+1}$. Now $2n=3\cdot2^{a+1}$.

  • If $3\nmid k$: the orbit never meets $n$ before step $a+1$, since $\|2^ik\|=n$ would mean $2^ik\equiv n\pmod{2n}$, forcing $3\mid 2^ik$. Hence $f^{a+1}(k)=\|2^{a+1}k\|$, and $2^{a+1}k\equiv2^{a+1}$ or $2\cdot2^{a+1}\pmod{3\cdot2^{a+1}}$, so in both cases $f^{a+1}(k)=2^{a+1}=k^*$.

  • If $3\mid k$: if the orbit avoided $n$ for $a+1$ steps we would get $f^{a+1}(k)=\|2^{a+1}k\|=0$, which is not a paddock. So the orbit reaches $n$, then $2$, and $3\nmid2$, so by the first case it reaches $k^*$.

So $\{k^*\}$ is the only cycle and $k^*$ is the unique overgrazed paddock.

Therefore exactly one paddock is overgrazed if and only if $\boxed{n=3\cdot2^a,\ a\ge0}$.

Show solution 2 – Halving the board

Let $f_n(k)$ be the paddock after paddock $k$ when there are $n$ paddocks. If $k\le\frac n2$, the $k$ hops go straight right and $f_n(k)=2k$. If $\frac n2<k\le n-1$, Skippy reaches $n$ after $n-k$ hops and makes the other $2k-n\le n-2$ hops to the left, so $f_n(k)=2n-2k$. From $n$ she hops left $n-1$ times and then once right, so $f_n(n)=2$. All values of $f_n$ are even.

Every orbit ends in a cycle. If $f_n$ has two different cycles, a start on one never visits the other, and no paddock is overgrazed; if it has exactly one cycle, the overgrazed paddocks are exactly its paddocks. Call $n$ good if exactly one paddock is overgrazed, i.e. $f_n$ has exactly one cycle and this cycle is a fixed point.

Fixed points. $f_n(n)=2\ne n$; for $k\le\frac n2$, $2k\ne k$; for $\frac n2<k<n$, $2n-2k=k$ means $k=\frac{2n}3$. So $f_n$ has a fixed point only if $3\mid n$. In particular no power of $2$ is good.

Odd $n$. Let $n\ge3$ be odd and $E=\{2,4,\dots,n-1\}$. Then $f_n$ maps $E$ onto $E$: for $2c\in E$, if $c$ is even then $c\in E$ and $f_n(c)=2c$; if $c$ is odd then $k=n-c$ is even with $\frac n2<k\le n-1$, so $k\in E$ and $f_n(k)=2c$. A map of a finite set onto itself is a bijection, so every point of $E$ lies on a cycle; since every orbit is in $E$ after one step, the cycle points are exactly the points of $E$. Hence an odd $n$ is good if and only if $|E|=\frac{n-1}2=1$, i.e. $n=3$ (and indeed $f_3(2)=2$).

Doubling. Let $m\ge3$. For $1\le k\le m-1$ we have $f_{2m}(2k)=2f_m(k)$: if $k\le\frac m2$ both sides equal $4k$, and if $\frac m2<k\le m-1$ both sides equal $4m-4k$. Also $f_{2m}(2m)=2$ and $f_m(m)=2$, $f_m(1)=2$. Every cycle of $f_{2m}$ consists of even numbers.

  • A cycle of $f_m$ not containing $m$ doubles to a cycle of $f_{2m}$ of the same length not containing $2m$, and conversely every cycle of $f_{2m}$ not containing $2m$ halves to such a cycle of $f_m$.

  • A cycle of $f_m$ through $m$ reads $m\to2\to f_m(2)\to\dots\to m$ and has length at least $2$. In $f_{2m}$ we get $2m\to2\to4\to2f_m(2)\to\dots\to2m$ (as $f_{2m}(2)=2f_m(1)=4$): the doubled cycle with an extra point $2$ inserted after $2m$. Conversely a cycle of $f_{2m}$ through $2m$ continues $2m\to2\to4$, and deleting the point $2$ and halving gives a cycle of $f_m$ through $m$.

These correspondences are inverse to each other, so $f_m$ and $f_{2m}$ have the same number of cycles, and the fixed points correspond (a fixed point of $f_m$ is never $m$, and cycles through $m$ correspond to cycles of length at least $3$). Hence, for $m\ge3$, $2m$ is good if and only if $m$ is good.

Conclusion. Write $n=2^a b$ with $b$ odd. If $b=1$, $n$ is a power of $2$ and is not good. If $b\ge3$, all the numbers $b,2b,\dots,2^{a-1}b$ are at least $3$, so by doubling $n$ is good if and only if $b$ is good, i.e. $b=3$. So exactly one paddock is overgrazed if and only if $\boxed{n=3\cdot2^a,\ a\ge0}$.

Find all functions $f,g:\mathbb{N}_{>1}\to\mathbb{N}$ such that \[f^{g(n)}(n)=g^{f(n)}(n)=1\] holds for all positive integers $n>1$.

Show the answer

$g=f$, where $f$ is any function with $f(f(n))=f(n)-1$ whenever $f(n)>1$; equivalently, the image of $f$ is $\{1,2,\ldots,K\}$ for some $K\in\{1,2,\ldots\}\cup\{\infty\}$, $f(m)=m-1$ for $2\le m\le K$, and $f(n)\in\{1,\ldots,K\}$ is arbitrary for $n>K$ (with the value $K$ attained when $K$ is finite)

Show the solution – Each function is the depth function of the other

Reformulation. Since $f$ is defined only on integers $>1$, $f^{g(n)}(n)=1$ means: starting from $n$ and applying $f$, we stay above $1$ for $g(n)-1$ steps and reach $1$ exactly at step $g(n)$ (if $\mathbb N$ contains $0$, the value $0$ is impossible because $f^0(n)=n\ne1$). Let $d_f(n)$ denote the number of applications of $f$ needed to reach $1$ from $n$. The conditions say exactly \[g(n)=d_f(n),\qquad f(n)=d_g(n)\qquad(n\ge2).\] In particular $f(n)=1\iff d_g(n)=1\iff g(n)=1$, and for $f(n)\ge2$ (equivalently $g(n)\ge2$): \[g(n)=1+g(f(n)),\qquad f(n)=1+f(g(n)).\tag{1}\]

Solutions. If $g=f$ and $f(f(n))=f(n)-1$ whenever $f(n)>1$, then the $f$-orbit of $n$ is $n,\ f(n),\ f(n)-1,\ \ldots,\ 1$, which reaches $1$ after exactly $f(n)$ steps; so $d_f=f=g$ and $d_g=d_f=f$, and both conditions hold. Such $f$ are described in the answer: the image $V$ of $f$ contains, with every $m\ge2$, also $f(m)=m-1$, so $V=\{1,\ldots,K\}$, and the only constraint is $f(m)=m-1$ for $2\le m\in V$.

The values of $g$ form an initial segment. If $g(n)=v\ge2$, the $f$-orbit $n=n_0,n_1,\ldots,n_v=1$ satisfies $g(n_i)=v-i$, so $1,\ldots,v$ are values of $g$. Hence the image $V_g$ of $g$ is $\{1,\ldots,K\}$ for some $K\le\infty$; likewise the image of $f$ is $V_f=\{1,\ldots,L\}$.

Level sets match. Let $v\in V_g$, $v\ge2$. By (1), every $n$ with $g(n)=v$ has $f(n)=1+f(v)$; call this number $\varphi(v)$, and put $\varphi(1)=1$. Symmetrically every $n$ with $f(n)=w\ge2$ has $g(n)=1+g(w)=:\psi(w)$, $\psi(1)=1$. Thus $\{g=v\}\subseteq\{f=\varphi(v)\}\subseteq\{g=\psi(\varphi(v))\}$, and since $\{g=v\}\ne\varnothing$ we get $\psi(\varphi(v))=v$; similarly $\varphi(\psi(w))=w$. So $\varphi:V_g\to V_f$ is a bijection with inverse $\psi$, $K=L$, and \[f=\varphi\circ g\quad\text{on }\{2,3,\ldots\}.\tag{2}\] Write $V=V_f=V_g=\{1,\ldots,K\}$.

A relation for $\varphi$. For $2\le x\in V$: from the definition of $\varphi$ and (2), $\varphi(x)=1+f(x)$, i.e. $f(x)=\varphi(x)-1$. From the definition of $\psi$ and $g=\psi\circ f$, $\psi(x)=1+g(x)=1+\psi(f(x))$, so $f(x)=\varphi(\psi(x)-1)$. Comparing, $\varphi(x)-1=\varphi(\psi(x)-1)$, and substituting $x=\varphi(u)$ ($u\in V$, $u\ge2$): \[\varphi(\varphi(u))=1+\varphi(u-1)\qquad(2\le u\in V).\tag{3}\]

$\varphi$ is the identity. We show $\varphi(u)=u$ by induction on $u\in V$; $\varphi(1)=1$. Let $u\ge2$ and $\varphi(j)=j$ for $j<u$. By (3), $\varphi(\varphi(u))=1+(u-1)=u$. Let $t=\varphi(u)$; since $\varphi$ is injective and fixes $1,\ldots,u-1$, $t\ge u$. Suppose $t>u$. Then $\varphi(t)=u$, and (3) at $t$ gives $t=\varphi(u)=\varphi(\varphi(t))=1+\varphi(t-1)$, so $\varphi(t-1)=t-1$; in particular $t-1\ne u$, so $t-1\ge u+1$. Now if $\varphi(x)=x$ for some $x\ge u+1$, then (3) at $x$ gives $x=1+\varphi(x-1)$, so $\varphi(x-1)=x-1$. Descending from $x=t-1$ we reach $\varphi(u+1)=u+1$, and (3) at $u+1$ gives $u+1=1+\varphi(u)=1+t$, i.e. $t=u$, a contradiction. Hence $\varphi(u)=u$.

So $\varphi=\mathrm{id}$, and (2) gives $f=g$. Then $f(x)=\varphi(x)-1=x-1$ for every $x\ge2$ in the image $V$ of $f$, which is the condition $f(f(n))=f(n)-1$ whenever $f(n)>1$. Together with the first part, the solutions are exactly the pairs described in the answer.

Reformulation. Put $c_i=a_i+i$ for $1\le i\le n$ and $c_0=+\infty$. The condition $a_{i-b}\ge a_i+b$ is equivalent to $c_{i-b}\ge c_i$. The two claims become \[c_i\le n+1\qquad\text{and}\qquad c_{c_i-1}=c_i\qquad(1\le i\le n).\]

Rectangles. Let $\Delta$ be the set of pairs $(j,k)$ of integers with $1\le j\le k\le n$; it has $\frac{n(n+1)}2$ elements. For each $i$ let \[R_i=\{(j,k):\ p_i<j\le i,\ \ i\le k\le c_i-1\},\] a set of $b_i\cdot a_i$ pairs.

First claim. The pair $(i,c_i-1)$ belongs to $R_i\subseteq\Delta$, so $c_i-1\le n$, i.e. $a_i+i-1\le n$.

Then $R_i$ and $R_q$ intersect, contradicting disjointness. Hence $c_m=c_i$, i.e. $a_m=c_m-m=1$, which is $a_{a_i+i-1}=1$.

Prove that the circumcircles of $\triangle ACD$ and $\triangle CSK$ are tangent at $C$.

Show solution 1 – Reduce to a collinearity and compare ratios

Let $\Gamma$ be the circumcircle of $ABC$ and let $X$ be the second intersection of line $AD$ with $\Gamma$. Angles are directed modulo $180^\circ$.

Step 1 (tangency criterion). Let $t$ be the tangent to $(ACD)$ at $C$. By the tangent-chord angle, $\angle(t,CD)=\angle CAD$. The circle $(CSK)$ is tangent to $t$ at $C$ if and only if $\angle(t,CK)=\angle CSK$. Since $CK$ and $CD$ are both the line $BC$, the two circles are tangent at $C$ if and only if \[\angle CSK=\angle CAD.\]

Step 2. If $S$, $K$, $X$ are collinear, then $\angle CSK=\angle CSX=\angle CAX=\angle CAD$, since $S,X,A,C$ lie on $\Gamma$ and $X$ lies on $AD$. So it suffices to prove that $K$ lies on line $SX$.

Step 3 (powers). Since $E$ lies on $(ABD)$ and $F$ on $(ACD)$, the powers of $C$ and $B$ give \[CE\cdot CA=CD\cdot CB,\qquad BF\cdot BA=BD\cdot BC.\tag{1}\]

Step 4 (three ratios). We treat the main configuration, in which $E$ and $F$ lie on the sides $AC$ and $AB$ (in the other configurations the same computation goes through with signed lengths). For a point $U\ne A$ on $\Gamma$, the law of sines in $\Gamma$ gives $\dfrac{UB}{UC}=\dfrac{\sin\angle UAB}{\sin\angle UAC}$.

  • In triangle $AEF$ the median $AM$ splits it into two triangles of equal area: $\tfrac12AF\cdot AM\sin\angle MAF=\tfrac12AE\cdot AM\sin\angle MAE$. As $S$ lies on ray $AM$, $\dfrac{SB}{SC}=\dfrac{\sin\angle MAF}{\sin\angle MAE}=\dfrac{AE}{AF}$.

  • Similarly, for the cevian $AD$ of triangle $ABC$, $\dfrac{BD}{DC}=\dfrac{AB\sin\angle BAD}{AC\sin\angle DAC}$, so $\dfrac{XB}{XC}=\dfrac{BD\cdot AC}{DC\cdot AB}$.

  • Menelaus for triangle $ABC$ and the line $EFK$ gives $\dfrac{KB}{KC}=\dfrac{AE\cdot BF}{EC\cdot FA}$.

Step 5 (the collinearity). Let line $SX$ meet line $BC$ at $K'$. Because $K'B\cdot K'C=K'S\cdot K'X$, triangles $K'BS\sim K'XC$ and $K'BX\sim K'SC$, so $\dfrac{SB}{XC}=\dfrac{K'B}{K'X}$ and $\dfrac{XB}{SC}=\dfrac{K'B}{K'S}$; multiplying, \[\frac{K'B}{K'C}=\frac{SB\cdot XB}{SC\cdot XC}=\frac{AE}{AF}\cdot\frac{BD\cdot AC}{DC\cdot AB}.\] By (1), $BF\cdot AB\cdot DC=BD\cdot BC\cdot DC=CE\cdot AC\cdot BD$, i.e. $\dfrac{BF}{CE}=\dfrac{BD\cdot AC}{DC\cdot AB}$. Hence \[\frac{K'B}{K'C}=\frac{AE}{AF}\cdot\frac{BF}{CE}=\frac{KB}{KC}.\] Both $K$ and $K'$ lie outside the segment $BC$: $K$ because line $EF$ cuts the sides $AB$, $AC$ internally; $K'$ because $S$ and $X$ lie on the same arc $BC$ (the one not containing $A$, as rays $AM$ and $AD$ lie inside angle $BAC$). A point of line $BC$ outside segment $BC$ is determined by the ratio of its distances to $B$ and $C$ (here different from $1$, since $EF\nparallel BC$). Therefore $K'=K$, and by Steps 1 and 2 the circles $(ACD)$ and $(CSK)$ are tangent at $C$.

Show solution 2 – Barycentric coordinates

Use barycentric coordinates with respect to $ABC$, with $a=BC$, $b=CA$, $c=AB$, and let $D=(0:1-t:t)$, i.e. $BD=ta$, $CD=(1-t)a$. The circumcircle $\Gamma$ is $a^2yz+b^2zx+c^2xy=0$.

Tangency criterion. Angles are directed modulo $180^\circ$. Let $t$ be the tangent to $(ACD)$ at $C$; by the tangent-chord angle, $\angle(t,CD)=\angle CAD$. The circle $(CSK)$ is tangent to $t$ at $C$ if and only if $\angle(t,CK)=\angle CSK$. As $CK$ and $CD$ are both the line $BC$, the circles $(ACD)$ and $(CSK)$ are tangent at $C$ if and only if $\angle CSK=\angle CAD$. If $X$ is the second intersection of $AD$ with $\Gamma$ and $S,K,X$ are collinear, then $\angle CSK=\angle CSX=\angle CAX=\angle CAD$ (as $S,X,A,C$ lie on $\Gamma$). So it suffices to show that $S$, $X$, $K$ are collinear.

Coordinates. By the powers of $C$ and $B$, $\overline{CE}\cdot\overline{CA}=CD\cdot CB$ and $\overline{BF}\cdot\overline{BA}=BD\cdot BC$, so \[\frac{\overline{CE}}{\overline{CA}}=\varepsilon:=\frac{(1-t)a^2}{b^2},\qquad\frac{\overline{BF}}{\overline{BA}}=\varphi:=\frac{ta^2}{c^2},\] \[E=(\varepsilon,0,1-\varepsilon),\qquad F=(\varphi,1-\varphi,0)\quad\text{(normalized)}.\] Put $\beta=1-\varphi$ and $\gamma=1-\varepsilon$. Then $M=\tfrac12(E+F)$ has $y:z=\beta:\gamma$, so the points of line $AM$ are $(x:\beta:\gamma)$, and the one on $\Gamma$ other than $A$ is \[S=\bigl(-a^2\beta\gamma:\ \beta(b^2\gamma+c^2\beta):\ \gamma(b^2\gamma+c^2\beta)\bigr).\] In the same way (line $AD$ consists of the points $(x:1-t:t)$), \[X=\bigl(-a^2t(1-t):\ (1-t)(b^2t+c^2(1-t)):\ t(b^2t+c^2(1-t))\bigr).\] The point of line $EF$ with $x=0$ is $K=\varepsilon F-\varphi E=(0:\varepsilon\beta:-\varphi\gamma)$.

Collinearity. The point of line $SX$ with $x=0$ is $K'=X_xS-S_xX$. Its coordinates are \[K'_y=-a^2t(1-t)\beta(b^2\gamma+c^2\beta)+a^2\beta\gamma(1-t)\bigl(b^2t+c^2(1-t)\bigr)=a^2c^2\beta(1-t)\bigl(\gamma(1-t)-t\beta\bigr),\] \[K'_z=-a^2t(1-t)\gamma(b^2\gamma+c^2\beta)+a^2\beta\gamma t\bigl(b^2t+c^2(1-t)\bigr)=-a^2b^2\gamma t\bigl(\gamma(1-t)-t\beta\bigr),\] so $K'=\bigl(0:c^2\beta(1-t):-b^2\gamma t\bigr)$ (in the non-degenerate case $\gamma(1-t)\ne t\beta$, i.e. $S\ne X$). On the other hand \[\frac{K_y}{K_z}=\frac{\varepsilon\beta}{-\varphi\gamma}=\frac{(1-t)a^2b^{-2}\beta}{-ta^2c^{-2}\gamma}=\frac{c^2\beta(1-t)}{-b^2\gamma t}=\frac{K'_y}{K'_z}.\] Hence $K=K'$ lies on line $SX$, and the circles $(ACD)$ and $(CSK)$ are tangent at $C$.

Problem N

HNumber Theory · LPS VII, Chapter 49: Combinatorial Number Theory and Structure · Hybrid Combinatorial-Arithmetic Arguments

Let $p,q>1$ be two distinct positive integers. Prove that there exists a sequence $a_1,\ldots,a_{2026}$ such that the sum of the digits of $a_1,\ldots,a_{2026}$ in base $p$ is strictly increasing, and the sum of the digits of $a_1,\ldots,a_{2026}$ in base $q$ is strictly decreasing.

Show the solution – Powers of $p$ and $q$, or digit blocks

The $a_i$ are positive integers. Write $s_m(N)$ for the sum of the base-$m$ digits of $N$. Multiplying by $m$ shifts the base-$m$ digits, so $s_m(m^kN)=s_m(N)$. We distinguish two cases.

Case 1: $p^b\ne q^a$ for all positive integers $a,b$.

Lemma. In this case the numbers $s_p(q^y)$, $y\ge0$, are unbounded.

Proof. Write $v_\ell$ for the exponent of the prime $\ell$. Among the primes $\ell\mid p$ choose $\ell_0$ for which $v_\ell(q)/v_\ell(p)$ is smallest, and let $a_0=v_{\ell_0}(p)\ge1$, $b_0=v_{\ell_0}(q)\ge0$. For every prime $\ell\mid p$ we have $a_0v_\ell(q)\ge b_0v_\ell(p)$, so $G=q^{a_0}/p^{b_0}$ is an integer, and $v_{\ell_0}(G)=a_0b_0-b_0a_0=0$. Also $G\ne1$, since $G=1$ would mean $q^{a_0}=p^{b_0}$ (with $b_0\ge1$ as $q>1$). Now $q^{ta_0}=p^{tb_0}G^t$, hence $s_p(q^{ta_0})=s_p(G^t)$.

Suppose $s_p(G^t)\le C$ for all $t$. Fix $m$. The residue of $G^t$ modulo $p^m$ is the number formed by its last $m$ base-$p$ digits, and these have sum at most $C$; there are at most $(C+1)\,m^C(p-1)^C$ such residues (choose at most $C$ nonzero positions and their digits). On the other hand $G$ is coprime to $\ell_0$ and $G^k\ne1$ for $k\ge1$, so by the lifting-the-exponent lemma, with $k=\operatorname{ord}_{\ell_0}(G)$ for odd $\ell_0$ and $k=2$ for $\ell_0=2$, we have $v_{\ell_0}(G^{kj}-1)=v_{\ell_0}(G^k-1)+v_{\ell_0}(j)$. Hence $G^d\equiv1\pmod{\ell_0^m}$ forces $\ell_0^{\,m-c}\mid d$ with the constant $c=v_{\ell_0}(G^k-1)$; i.e. the order of $G$ modulo $\ell_0^m$, and so the number of distinct residues of $G^t$ modulo $\ell_0^m$ (hence modulo $p^m$), is at least $\ell_0^{\,m-c}$. For large $m$ the exponential $\ell_0^{\,m-c}$ exceeds the polynomial $(C+1)m^C(p-1)^C$: a contradiction. $\square$

The hypothesis of Case 1 is symmetric in $p$ and $q$, so $s_q(p^x)$ is unbounded as well. Choose $y_1,\ldots,y_{2026}$ with $s_p(q^{y_1})<\cdots<s_p(q^{y_{2026}})$, and $x_1,\ldots,x_{2026}$ with $s_q(p^{x_1})>\cdots>s_q(p^{x_{2026}})$ (pick $2026$ exponents with increasing values and reverse their order). Put $a_i=p^{x_i}q^{y_i}$. By the shift rule, \[s_p(a_i)=s_p(q^{y_i})\ \text{is strictly increasing},\qquad s_q(a_i)=s_q(p^{x_i})\ \text{is strictly decreasing}.\]

Case 2: $p^b=q^a$ for some positive $a,b$. Dividing $a,b$ by their gcd we may assume $\gcd(a,b)=1$. For each prime $\ell$, $b\,v_\ell(p)=a\,v_\ell(q)$, so $a\mid v_\ell(p)$; hence $p=r^\alpha$ for an integer $r\ge2$ with $\alpha=a$, and then $q=r^\beta$ with $\beta=b$; $\alpha\ne\beta$ as $p\ne q$.

Let $R=r^{\alpha\beta}=p^\beta=q^\alpha$. A base-$R$ digit is a block of $\beta$ base-$p$ digits and also a block of $\alpha$ base-$q$ digits, so for a number with base-$R$ digits $D_j$ we have $s_p=\sum s_p(D_j)$ and $s_q=\sum s_q(D_j)$. The digit $1$ contributes $1$ to both; the digit $R-1$ contributes \[S_p=s_p(R-1)=\beta(r^\alpha-1),\qquad S_q=s_q(R-1)=\alpha(r^\beta-1).\] The function $g(t)=\frac{r^t-1}t$ is strictly increasing for $t\ge1$ (indeed $g(t+1)>g(t)\iff r^t\bigl(t(r-1)-1\bigr)+1>0$), and $S_p=\alpha\beta\,g(\alpha)$, $S_q=\alpha\beta\,g(\beta)$; so $S_p\ne S_q$. Let $N(u,v)$ be the number whose base-$R$ digits are $u$ ones followed by $v$ digits $R-1$; then $s_p=u+vS_p$ and $s_q=u+vS_q$.

  • If $S_p<S_q$, take $a_i=N\bigl((2S_p+1)i,\;2(2027-i)\bigr)$. From $a_i$ to $a_{i+1}$, $s_p$ changes by $(2S_p+1)-2S_p=1>0$ and $s_q$ by $(2S_p+1)-2S_q\le-1<0$.

  • If $S_p>S_q$, take $a_i=N\bigl((2S_q+1)(2027-i),\;2i\bigr)$. Now $s_p$ changes by $2S_p-(2S_q+1)\ge1$ and $s_q$ by $2S_q-(2S_q+1)=-1$.

In both cases $a_1,\ldots,a_{2026}$ have strictly increasing base-$p$ digit sums and strictly decreasing base-$q$ digit sums, which completes the proof.

Problem A

HAlgebra · LPS VII, Chapter 30: Functional Equations: Core Olympiad Methods · Injectivity and Surjectivity

Determine all functions $f:\mathbb{R}_{>0}\to\mathbb{R}_{>0}$ such that \[f\bigl(x+x^2f(y)\bigr)=yf(x)f(x+y)\] for all positive real numbers $x$ and $y$.

Show the answer

$f(x)=\dfrac1x$

Show the solution – Injectivity, a monotone product, and iteration

Write $P(x,y)$ for $f(x+x^2f(y))=yf(x)f(x+y)$. The function $f(x)=1/x$ works: both sides equal $\frac{y}{x(x+y)}$. We show it is the only solution.

Surjectivity. For $y>0$ put $x=\sqrt{y/f(y)}$; then $x^2f(y)=y$ and $P(x,y)$ gives $f(x+y)=yf(x)f(x+y)$, so \[f\bigl(\sqrt{y/f(y)}\bigr)=\frac1y\qquad(y>0).\tag{1}\]

Injectivity. Suppose $f(a)=f(b)$ with $0<a<b$ and put $d=b-a$. Comparing $P(x,a)$ and $P(x,b)$ gives $af(x+a)=bf(x+b)$, i.e. \[f(t+d)=\tfrac ab f(t)\qquad(t>a).\tag{2}\] Comparing $P(a,y)$ and $P(b,y)$ and using (2) at $t=a+y$ gives $f(a+a^2f(y))=\frac baf(b+b^2f(y))$. As $f$ is surjective, $u=a^2f(y)$ takes every positive value; with (2) at $t=a+u$ this yields $f(b+u)=f(b+\lambda u)$ for all $u>0$, where $\lambda=b^2/a^2$. Take $u=a^2/(a+b)$, so that $(\lambda-1)u=d$: then $f(a')=f(a'+d)$ with $a'=b+u$. Repeating the derivation of (2) for the pair $a'<a'+d$ gives $f(t+d)=\frac{a'}{a'+d}f(t)$ for $t>a'$. But $\frac{a'}{a'+d}>\frac a{a+d}=\frac ab$ since $a'>a$, which contradicts (2) for $t>a'$ because $f(t)>0$. So $f$ is injective.

$h(t)=tf(t)$ is nondecreasing. Fix $x>0$. If $y_1f(x+y_1)=y_2f(x+y_2)$, then $P(x,y_1)$ and $P(x,y_2)$ give $f(x+x^2f(y_1))=f(x+x^2f(y_2))$, so $f(y_1)=f(y_2)$ and $y_1=y_2$. Thus $y\mapsto yf(x+y)$ is injective for each $x>0$. Now suppose $0<a<b$ and $af(a)>bf(b)$. Then $f(a)>f(b)$, and \[x=\frac{af(a)-bf(b)}{f(a)-f(b)}>0,\qquad a-x=\frac{(b-a)f(b)}{f(a)-f(b)}>0,\] while $(a-x)f(a)-(b-x)f(b)=af(a)-bf(b)-x\bigl(f(a)-f(b)\bigr)=0$. So the distinct positive numbers $y_1=a-x$, $y_2=b-x$ satisfy $y_1f(x+y_1)=y_2f(x+y_2)$, a contradiction. Hence $h$ is nondecreasing, and in particular \[\tfrac12h(1)\le f(t)\le h(2)\qquad(1<t<2).\tag{3}\]

An orbit argument. Put $g=1/f$. Then (1) reads $g\bigl(\sqrt{yg(y)}\bigr)=y$; with $y=g(t)$ and injectivity, $\sqrt{g(t)g(g(t))}=t$, i.e. $g(t)\,g(g(t))=t^2$. Consequently $H(t)=t^2g(t)$ satisfies $H(g(t))=g(t)^2g(g(t))=t^2g(t)=H(t)$.

Suppose $g(t_0)\ne t_0$ for some $t_0$. Put $H=H(t_0)$, $c=H^{1/3}$ (so $t_0\ne c$) and $t_{n+1}=g(t_n)$. Then $H(t_n)=H$ for all $n$, so $t_{n+1}=g(t_n)=H/t_n^2$, i.e. $t_{n+1}/c=(t_n/c)^{-2}$ and $t_n/c=(t_0/c)^{(-2)^n}$. Along the even or the odd indices (depending on whether $t_0<c$ or $t_0>c$) we get $t_n\to0$, and then $f(t_n)=t_n^2/H\to0$ as well. For such $y=t_n$ small enough, $1+y$ and $1+f(y)$ lie in $(1,2)$, and $P(1,y)$ with (3) gives \[0<\tfrac12h(1)\le f\bigl(1+f(y)\bigr)=yf(1)f(1+y)\le yf(1)h(2)\longrightarrow0,\] a contradiction. Hence $g(t)=t$ for all $t$, that is $f(x)=\frac1x$.

Problem C

MCombinatorics · LPS VII, Chapter 39: Graph Theory and Structural Combinatorics · Extremal Graph Structure

The Olympiad legend Arctan is planning an $n$-day trip through the $n$ cities of Normieland. He wishes to visit exactly one city each day and every city exactly once.

However, the jealous Forever-Alone Cult, determined to punish those with fulfilling social lives, casts a spell that brings storms to certain cities on certain days. A city cannot be visited on a day when it is experiencing a storm. The spell is subject to the following loser-equilibrium restrictions:

  • On each day, at most $m$ cities experience a storm.

  • In each city, storms occur on at most $m$ days.

Fortunately, Arctan can perfectly predict the weather and knows, before the journey begins, exactly which cities will experience storms on which days.

Determine the greatest possible value of $m$ such that, regardless of how the storms are distributed, Arctan is guaranteed to be able to complete his journey.

Show the answer

$m=\left\lfloor \dfrac n2\right\rfloor$

Show solution 1 – Hall's marriage theorem

Consider the bipartite graph whose two sides are the $n$ days and the $n$ cities, with an edge between a day and a city when the city has no storm on that day. Arctan can complete the journey exactly when this graph has a perfect matching. Every day is joined to at least $\delta=n-m$ cities and every city to at least $\delta$ days.

$m\le\lfloor n/2\rfloor$ always works. Then $\delta\ge n/2$. We check Hall's condition: every set $S$ of days has at least $|S|$ neighbours. If $|S|\le\delta$, one day of $S$ alone has $\ge\delta\ge|S|$ neighbours. If $|S|>\delta$, then $|S|>n-\delta$ as well (because $\delta\ge n-\delta$), so every city, which is joined to at least $\delta$ days, is joined to some day of $S$ (as $\delta+|S|>n$); thus $S$ has all $n$ cities as neighbours. By Hall's theorem a perfect matching exists.

$m=\lfloor n/2\rfloor+1$ can fail (and then every larger $m$ fails too). Now $\delta=n-m$ satisfies $2\delta+1\le n$. Let the days $1,\ldots,\delta+1$ be stormy in all cities except $1,\ldots,\delta$, and let the remaining days be stormy exactly in the cities $1,\ldots,\delta$. Each of the first $\delta+1$ days has $n-\delta=m$ storms and every other day has $\delta\le m$ storms; each city $1,\ldots,\delta$ has storms on $n-\delta-1=m-1$ days, and each other city on $\delta+1\le m$ days. But the $\delta+1$ days $1,\ldots,\delta+1$ can only be spent in the $\delta$ cities $1,\ldots,\delta$, so no journey exists.

Hence the answer is $\boxed{\lfloor n/2\rfloor}$.

Show solution 2 – Exchanging along a maximal schedule

Call a set of pairs (day, city) a partial schedule if the days are distinct, the cities are distinct, and no chosen city has a storm on its day. Let $\delta=n-m$.

$m\le\lfloor n/2\rfloor$ works, i.e. $2\delta\ge n$. Take a partial schedule $\mathcal P$ of maximal size and suppose it has fewer than $n$ pairs. Then some day $d$ and some city $c$ are unused. Every city available on day $d$ (at least $\delta$ of them) is used in $\mathcal P$, otherwise we could add it; likewise every day on which $c$ is available (at least $\delta$ of them) is used. Let $A$ be the set of pairs $(d',c')\in\mathcal P$ such that $c'$ is available on day $d$, and $B$ the set of pairs $(d',c')\in\mathcal P$ such that $c$ is available on day $d'$. Then $|A|,|B|\ge\delta$, while $|\mathcal P|\le n-1<2\delta$. So some pair $(d',c')$ lies in $A\cap B$. Replacing it by the two pairs $(d,c')$ and $(d',c)$ gives a larger partial schedule, a contradiction. So a full schedule exists.

$m=\lfloor n/2\rfloor+1$ fails. Then $2\delta+1\le n$. Make the days $1,\ldots,\delta+1$ stormy everywhere except in cities $1,\ldots,\delta$, and the other days stormy exactly in cities $1,\ldots,\delta$. The storm counts are at most $m$ per day and per city (days: $n-\delta=m$ or $\delta$; cities: $n-\delta-1$ or $\delta+1\le n-\delta=m$). The first $\delta+1$ days would need $\delta+1$ distinct cities among only $\delta$, so there is no journey. For larger $m$ the same storms are allowed.

So the greatest value is $\boxed{\lfloor n/2\rfloor}$.

MGeometry · LPS VII, Chapter 15: Circles, Power, and Radical Structure · Power of a Point

Let $P$ be a point lying on the side $CD$ of a rectangle $ABCD$. Let $E,F$ be the intersections of $PA,PB$ with $BD,AC$, respectively. Line $EF$ meets the sides $AD,BC$ at $M,N$, respectively. Show solution 1 – Power of a point and an altitude in a right triangle

Only the facts $M\in AD$, $N\in BC$ are used; the point $P$ plays no further role. We assume $MN\nparallel AB$ (this happens exactly when $P$ is not the midpoint of $CD$; if $MN\parallel AB$ then $L=Q$ and the statement degenerates).

The point $Y$. Let $Y$ be the intersection of line $QL$ (the horizontal line $y=k$) with line $MN$. Solving $m+\frac{n-m}wx=k$ gives \[x_Y=\frac{w(k-m)}{n-m}=\frac{wm^2}{(m+n)(m-n)}.\] Since $KL\perp MN$ and $Y\in MN$, triangle $YKL$ has a right angle at $K$; since $KQ\perp QL$ and $Q$ lies on $YL$, the point $Q$ is the foot of the altitude from $K$. The power of $Y$ with respect to $M,N$. Along line $MN$, signed distances are proportional to differences of $x$-coordinates, with the same factor for all pairs. Therefore $\overline{YM}\cdot\overline{YN}=YK^2$ is equivalent to \[(x_M-x_Y)(x_N-x_Y)=(x_K-x_Y)^2\iff -x_Y(w-x_Y)=(q-x_Y)^2\iff q^2=x_Y(2q-w).\] Here $2q-w=\frac{w(m-n)}{m+n}$, so $x_Y(2q-w)=\frac{wm^2}{(m+n)(m-n)}\cdot\frac{w(m-n)}{m+n}=\frac{w^2m^2}{(m+n)^2}=q^2$. Thus \[\overline{YM}\cdot\overline{YN}=YK^2=YQ\cdot YL.\] (In particular $M$ and $N$ lie on the same side of $Y$, as do $Q$ and $L$.) By the converse of the power of a point, $Q$, $L$, $M$, $N$ are concyclic.

Show solution 2 – The circle through $M$, $N$, $Q$

Only the facts $M\in AD$ and $N\in BC$ are used. We assume $MN\nparallel AB$ (this happens exactly when $P$ is not the midpoint of $CD$; if $MN\parallel AB$ then $L=Q$ and the statement degenerates). Since $Q$ and $L$ have the same $y$-coordinate, the difference of the left-hand side of the equation of $\omega$ at $L$ and at $Q$ is \[(x_L-q)(x_L+q+\mathcal D),\qquad x_L+q=\frac{2wm}{m+n}+\frac{mn(n-m)}{w(m+n)}=\frac{m(2w^2+n^2-mn)}{w(m+n)}=-\mathcal D.\] So this difference is $0$, and $L$ lies on $\omega$ as well: $L$ is the mirror image of $Q$ in the vertical line through the centre of $\omega$. HNumber Theory · LPS VII, Chapter 49: Combinatorial Number Theory and Structure · Counting Integer Configurations

For any prime $p$ and integer $r$, let $f(r,p)$ be the minimum positive integer $M$ so that the following is true: for any integer $k$, there exist integers $0\le a,b\le M$ so that \[a+rb\equiv k\pmod p.\] Show that there exists some positive real number $C$ so that \[f(1,p)+\cdots+f(p-1,p)\le Cp^{3/2}\] holds for all primes $p$.

Show the answer

proof (for example $C=32$ works)

Show the solution – A short lattice vector controls $f(r,p)$

Fix a prime $p$ and $1\le r\le p-1$, and let \[\Lambda=\{(x,y)\in\mathbb Z^2:\ x+ry\equiv0\pmod p\}.\] This is a subgroup of $\mathbb Z^2$ of index $p$; the cosets of $\Lambda$ correspond to residues $k\bmod p$ via $(a,b)\mapsto a+rb$. So $f(r,p)\le M$ as soon as every coset of $\Lambda$ contains a point of the square $\{0,\ldots,M\}^2$.

A short vector. Let $\lambda=\lambda(r)$ be the least value of $\max(|u|,|v|)$ over nonzero $(u,v)\in\Lambda$. With $T=\lfloor\sqrt p\rfloor$, the $(T+1)^2>p$ pairs $(a,b)\in\{0,\ldots,T\}^2$ give two pairs with the same $a+rb\bmod p$; their difference is a nonzero vector of $\Lambda$ with both coordinates at most $T$ in absolute value. Hence $1\le\lambda\le T\le\sqrt p$.

Lemma: $f(r,p)\le4p/\lambda$. Let $e_1\in\Lambda$ attain $\lambda$. It is primitive in $\Lambda$ (if $e_1=jw$ with $w\in\Lambda$, $|j|\ge2$, then $w$ would be shorter), so it extends to a basis $e_1,e_2$ of $\Lambda$, and $|\det(e_1,e_2)|=p$. All vectors $e_2+je_1$ lie on a line parallel to $e_1$ at Euclidean distance $p/|e_1|$ from the origin, and consecutive ones are $|e_1|$ apart; choosing $j$ suitably we may assume $|e_2|\le p/|e_1|+|e_1|/2$. With $\lambda\le|e_1|\le\sqrt2\lambda$ and $\lambda\le p/\lambda$ this gives $|e_2|\le p/\lambda+\lambda\le2p/\lambda$. Let $\Pi=\{se_1+te_2:\ 0\le s,t<1\}$. For any point $z\in\mathbb R^2$, every coset of $\Lambda$ meets $z+\Pi$: for $w$ in the coset write $w-z=\alpha e_1+\beta e_2$ and subtract $\lfloor\alpha\rfloor e_1+\lfloor\beta\rfloor e_2\in\Lambda$. Each coordinate of a point of $\Pi$ varies in an interval of length at most $\|e_1\|_\infty+\|e_2\|_\infty\le\lambda+2p/\lambda\le3p/\lambda$. Choose $z$ so that $z+\Pi\subseteq[0,M]^2$ with $M=\lceil3p/\lambda\rceil\le4p/\lambda$. Then every coset has a point in $\{0,\ldots,M\}^2$, so $f(r,p)\le4p/\lambda$.

Counting. If $\lambda(r)\le t$, there is $(u,v)\ne0$ in $\Lambda$ with $|u|,|v|\le t$. Here $v\ne0$ (otherwise $p\mid u$ with $|u|<p$, so $u=0$), and $v\not\equiv0\pmod p$, so $r\equiv-uv^{-1}\pmod p$. Hence the number $N(t)$ of $r$ with $\lambda(r)\le t$ satisfies $N(t)\le(2t+1)\cdot2t\le6t^2$, and $N(T)=p-1$. By summation by parts, \[\sum_{r=1}^{p-1}\frac1{\lambda(r)}=\sum_{t=1}^{T}\frac{N(t)-N(t-1)}t=\sum_{t=1}^{T-1}N(t)\Bigl(\frac1t-\frac1{t+1}\Bigr)+\frac{N(T)}T\le\sum_{t=1}^{T-1}\frac{6t^2}{t(t+1)}+\frac{p-1}{T}\le6T+\frac{p-1}T.\] Since $T\le\sqrt p$ and $T\ge\sqrt p/2$ (as $T+1>\sqrt p$), this is at most $6\sqrt p+2\sqrt p\cdot\frac{p-1}{p}\le8\sqrt p$. Therefore \[f(1,p)+\cdots+f(p-1,p)\le4p\sum_{r=1}^{p-1}\frac1{\lambda(r)}\le32\,p^{3/2},\] and $C=32$ works. (The statement only asks for some constant.)

MCombinatorics · LPS VII, Chapter 31: Extremal Principle and Bounding Arguments · Bounding and Limiting Arguments · also Germany TST 2026, AIMO 1, Problem 2

A balanced removal is the operation of selecting a balanced segment $S$, removing all the balls in $S$, and shifting left the balls that were to the right of $S$ so that the remaining balls form a contiguous row. Determine the smallest positive integer $N$ satisfying the following property: for every configuration of balls and for every integer $k$ satisfying $0\leq k\leq 2025$, there exists a sequence of at most $N$ balanced removals after which there are exactly $2k$ remaining balls.

Show the answer

$N=2$

Show the solution – Cut along the zero-level walk

Let $n=2025$. Number the gaps between balls $0,1,\dots,2n$ (gap $t$ is just after the $t$-th ball) and let $P_t$ be the number of white minus the number of black balls among the first $t$ balls. So $P_0=P_{2n}=0$, consecutive values differ by $1$, and the segment of balls between gaps $i<j$ is balanced exactly when $P_i=P_j$.

$N\ge2$. Take the row $BB\,\underbrace{W\cdots W}_{n}\,\underbrace{B\cdots B}_{n-2}$ and $k=1$. One balanced removal leaving $2$ balls would remove all balls except either the first two, or the last two, or the first and the last. These pairs are $BB$, $BB$ and $BB$ (as $n-2\ge2$), never one white and one black, while the removed segment, and hence the remaining pair, would have to be balanced. So one removal is not enough.

$N\le2$. Fix a row and $k$, and put $L=2n-2k$, the number of balls to remove. If $L=0$ do nothing. Otherwise let $z$ be the last gap with $z<L$ and $P_z=0$ (it exists, since $P_0=0$), and let $z'$ be the first gap with $z'\ge L$ and $P_{z'}=0$ (it exists, since $P_{2n}=0$). Between $z$ and $z'$ the walk does not return to $0$, so $P_t$ has constant sign for $z<t<z'$; say $P_t\ge0$ on $[z,z']$ (the other case is symmetric).

Put $\ell=L-z$; it is even and $0<\ell\le z'-z$. For $z\le i\le z'-\ell$ consider $g(i)=P_{i+\ell}-P_i$. Then \[g(z)=P_{z+\ell}\ge0,\qquad g(z'-\ell)=-P_{z'-\ell}\le0,\] all values of $g$ are even (since $\ell$ is even), and $g(i+1)-g(i)\in\{-2,0,2\}$. Hence $g(i)=0$ for some $i$: the balls between gaps $i$ and $i+\ell$ form a balanced segment of length $\ell$ lying between gaps $z$ and $z'$.

Now remove this segment, and then (if $z>0$) the first $z$ balls, which form a balanced segment because $P_z=P_0$ and are still contiguous at the start of the row. Altogether $\ell+z=L$ balls are removed in at most two balanced removals, leaving $2k$ balls.

Hence the smallest $N$ is $\boxed{2}$.

Problem 3

HAlgebra · LPS VII, Chapter 5: Polynomial Structure and Algebraic Identities · Factorization by Structure · also Germany TST 2026, AIMO 4, Problem 2

Determine all integers $n\geqslant 2$ such that the polynomial \[P_n(x,y,z)=x^n+y^n+z^n-xyz^{n-2}-xy^{n-2}z-x^{n-2}yz\] can be written as $P_n(x,y,z)=Q_n(x,y,z)\cdot R_n(x,y,z)$, where $Q_n(x,y,z)$ and $R_n(x,y,z)$ are non-constant polynomials with integer coefficients.

$n=3$ only

Show solution 1 – Specialisations and Eisenstein

$n=3$ works: $P_3=x^3+y^3+z^3-3xyz=(x+y+z)(x^2+y^2+z^2-xy-yz-zx)$.

From now on $n\ne3$ and suppose $P_n=QR$ with non-constant $Q,R\in\mathbb Z[x,y,z]$. Since $P_n$ is homogeneous of degree $n$, so are $Q$ and $R$ (the products of the lowest-degree parts and of the highest-degree parts of $Q,R$ are the lowest- and highest-degree parts of $P_n$); let their degrees be $d$ and $n-d$, with $1\le d\le n-1$.

Pure powers occur in $Q$ and $R$. Let $\alpha,\beta$ be the degrees of $Q,R$ in $x$ alone. Then $\alpha\le d$, $\beta\le n-d$, and $\alpha+\beta=n$ because $P_n$ contains $x^n$. Consequently every specialisation used below has the full degree: $Q(x,y,0)$ is a binary form of degree $d$, and $Q(x,1,1)$ has degree exactly $d$ in $x$.

$n=2$ and $n=4$. $P_2(x,y,0)=x^2-xy+y^2$ and $P_4(x,y,0)=x^4+y^4$ are irreducible over $\mathbb Q$ (the first has discriminant $-3$; the second is $y^4\Phi_8(x/y)$). But $Q(x,y,0)R(x,y,0)$ would be a factorisation into forms of degrees $d,n-d\ge1$. Contradiction.

$n\ge5$. Then $P_n(x,y,0)=x^n+y^n$. Put $y=z=1$: \[P_n(x,1,1)=x^n-x^{n-2}-2x+2=(x-1)(x^{n-1}+x^{n-2}-2)=(x-1)^2h(x),\] \[h(x)=x^{n-2}+2x^{n-3}+2x^{n-4}+\cdots+2x+2 .\] By Eisenstein's criterion at $2$, $h$ is irreducible over $\mathbb Q$, of degree $n-2$, and $h(1)\ne0$. Now $Q(x,1,1)R(x,1,1)=(x-1)^2h(x)$, so $h$ divides one factor; renaming, $h\mid R(x,1,1)$, whence $n-d\ge n-2$, i.e. $d\le2<n-2$. Since $P_n$ is symmetric, the same argument (with $y$ or $z$ as the free variable; $h$ can only divide the factor of degree $n-d$) gives $Q(1,y,1)=c'(y-1)^d$ and $Q(1,1,z)=c''(z-1)^d$.

Also $Q(x,y,0)$ divides $x^n+y^n$, and its degree is $d$.

Case $d=1$. $Q=\alpha x+\beta y+\gamma z$ with $\alpha\beta\gamma\ne0$. The rational number $t=-\beta/\alpha$ satisfies $t^n=-1$ (as $\alpha x+\beta y$ divides $x^n+y^n$), so $t=-1$ and $\alpha=\beta$; similarly $\beta=\gamma$. But then $Q(x,1,1)=\alpha(x+2)$, not a multiple of $x-1$. Contradiction.

Case $d=2$. $x^n+y^n$ has at most one rational linear factor ($x+y$, when $n$ is odd, and only to the first power), so $Q(x,y,0)$ is a constant times an irreducible rational quadratic form dividing $x^n+y^n$. Order $3$ is impossible ($\zeta^n$ would be a cube root of unity), so the form is $x^2+y^2$ (needs $n\equiv2\pmod 4$) or $x^2-xy+y^2$ (needs $n\equiv3\pmod 6$); which one is decided by $n$. The same holds for $Q(x,0,z)$ and $Q(0,y,z)$, and comparing the coefficients of $x^2,y^2,z^2$ shows that \[Q=c\,(x^2+y^2+z^2)+u\,(xy+yz+zx),\qquad u\in\{0,-c\}.\] Then $Q(x,1,1)=cx^2+2ux+2c+u$ must equal $c(x-1)^2$, so $u=-c$, $n\equiv3\pmod6$, $n\ge9$ and $Q=c(x^2+y^2+z^2-xy-yz-zx)$. Substituting a root ($x^2=-3$, and $n-3$ is even) gives $-2(-3)^{(n-3)/2}+2=0$, i.e. $(-3)^{(n-3)/2}=1$, which forces $n=3$. Contradiction.

In an $n\times n$ board, for each $1\leq i\leq n$ and $1\leq j\leq n$, the cell in the $i$th row from the bottom and $j$th column from the left contains $\gcd(i,j)$ leaves. The koala eats the leaves in each cell it visits, including the bottom left and top right cells.

Determine the maximum number of leaves that the koala can eat.

Show the answer

$\dfrac{n^2+3n-2}{2}$

Show the solution – Pairing consecutive anti-diagonals

Write $(i,j)$ for the cell in row $i$ and column $j$ and $g(i,j)=\gcd(i,j)$. Every step increases $i+j$ by $1$, so the koala's path visits exactly one cell on each anti-diagonal $i+j=s$, $s=2,3,\dots,2n$.

Construction. The staircase $(1,1),(1,2),(2,2),(2,3),\dots,(n-1,n),(n,n)$ visits the diagonal cells $(m,m)$, worth $m$, and the cells $(m,m+1)$, worth $\gcd(m,m+1)=1$. It collects $1+2+\cdots+n+(n-1)=\frac{n^2+3n-2}{2}$ leaves.

Key lemma. Let $A$ be the visited cell with $i+j=2m$ $(1\le m\le n-1)$ and $B$ the next visited cell (with $i+j=2m+1$). Then $g(A)+g(B)\le m+1$.

Proof. $A$ and $B$ share a row or a column, so they share a coordinate $c$, and their other coordinates are consecutive integers. Hence $g(A)$ and $g(B)$ both divide $c$, and a common divisor of them divides two consecutive integers, so $\gcd(g(A),g(B))=1$ and $g(A)g(B)\mid c$.

  • If $g(A)=1$: $g(B)$ is at most the smaller coordinate of $B$, which is at most $m$ because the coordinates of $B$ add up to $2m+1$. So the sum is at most $m+1$.

  • If $g(B)=1$: similarly $g(A)\le m$, since the coordinates of $A$ add up to $2m$.

  • If $g(A),g(B)\ge2$: then $(g(A)-2)(g(B)-2)\ge0$ gives $g(A)+g(B)\le\frac{g(A)g(B)}2+2\le\frac c2+2$. The coordinate $c$ belongs to $A$, whose other coordinate is at least $1$, so $c\le2m-1$; and $c=2m-1$ would force the other coordinate of $A$ to be $1$ and $g(A)=1$. So $c\le2m-2$ and $g(A)+g(B)\le m+1$. $\square$

Upper bound. Group the anti-diagonals as $\{2,3\},\{4,5\},\dots,\{2n-2,2n-1\}$ and $\{2n\}$. By the lemma the cells on the pair $\{2m,2m+1\}$ contribute at most $m+1$, and the last cell $(n,n)$ contributes $n$. So the total is at most \[\sum_{m=1}^{n-1}(m+1)+n=\frac{(n-1)n}2+(n-1)+n=\frac{n^2+3n-2}{2}.\] Hence the maximum is $\boxed{\dfrac{n^2+3n-2}{2}}$.

Problem 5

HAlgebra · LPS VII, Chapter 46: Functional Equations: Iteration, Rigidity, and Deep Structure · Monotonicity, Boundedness, and Regularity

Let $\mathbb{Z}_{\geq 0}$ be the set of all nonnegative integers. Let $f:\mathbb{Z}_{\geq 0}\to\mathbb{Z}_{\geq 0}$ be an unbounded function such that, if $m$ and $n$ are nonnegative integers satisfying \[f(m+n)=\max\{f(0),f(1),\ldots,f(m+n)\},\] then \[f(m+n)=f(m)+f(n).\] Prove that there exist positive integers $A,B,C$ and $D$ such that for all nonnegative integers $n$, \[f(An+B)=Cn+D.\] We say that $f$ is unbounded if for each nonnegative integer $N$, there exists some nonnegative integer $n$ such that $f(n)\geq N$.

Show the solution – Gaps between records never shrink

Call $r\ge0$ a record if $f(r)=\max\{f(0),\dots,f(r)\}$. The hypothesis says: if $r$ is a record, then $f(m)+f(r-m)=f(r)$ for all $0\le m\le r$. Taking $r=m=0$ gives $f(0)=0$. Since $f$ is unbounded, $f$ attains new maxima infinitely often, so there are infinitely many records. List them as $r_0=0<r_1<r_2<\cdots$; between two consecutive records $r_i<n<r_{i+1}$ we have $f(n)<f(r_i)$, and the running maximum there equals $f(r_i)$.

Step 1 (shifted copies). Let $s<t$ be records and $e=t-s$, $E=f(t)-f(s)$. For $0\le m\le s$, \[f(t-m)=f(t)-f(m),\qquad f(s-m)=f(s)-f(m),\] and subtracting gives, with $j=s-m$, \[f(j+e)=f(j)+E\qquad(0\le j\le s). \tag{1}\] In particular ($j=0$) $E=f(e)$.

Step 2 (gaps grow, increments shrink). Let $r<s<t$ be consecutive records, $d=s-r$, $D=f(s)-f(r)=f(d)$, $e=t-s$, $E=f(t)-f(s)=f(e)$. By (1) with $j=r$, \[f(r+e)=f(r)+E\ge f(r).\] If $e<d$, then $r<r+e<s$, and $f(r+e)\ge f(r)$ would make $r+e$ a record strictly between $r$ and $s$, which is impossible. Hence $e\ge d$. If $e>d$, then $s<r+e<t$, so $r+e$ is not a record and $f(r+e)<f(s)=f(r)+D$; thus $E<D$. If $e=d$, then $E=f(e)=f(d)=D$.

So along consecutive records the gap $d_i=r_{i+1}-r_i$ never decreases, the increment $D_i=f(r_{i+1})-f(r_i)$ never increases, and $D_i$ strictly decreases whenever $d_i$ increases. Since the $D_i$ are nonnegative integers, the gap can increase only finitely many times. Hence there are $i_0$, $d\ge1$ and $D\ge0$ with $d_i=d$ and $D_i=D$ for all $i\ge i_0$.

Step 3 (conclusion). For $i\ge i_0$, (1) applied to the records $r_i<r_{i+1}$ gives $f(j+d)=f(j)+D$ for $0\le j\le r_i$. As $r_i\to\infty$, this holds for every $j\ge0$, so $f(j+kd)=f(j)+kD$ for all $j,k\ge0$. If $D=0$, then $f$ would be periodic, hence bounded; so $D\ge1$. Taking $j=d$ (note $f(d)=D$), \[f(dn+d)=f(d)+nD=Dn+D\qquad(n\ge0),\] so the statement holds with the positive integers $A=B=d$ and $C=D$, the constant term being this same $D$.

Let $m=100$ be the number of vertices of $P$ and $n=2025$ the number of points. Points that are not vertices of $P$ are inner points; edges of triangles that are not sides of $P$ are inner edges.

Counting. The angles of all triangles add up to $360^\circ$ at each of the $n-m$ inner points plus the angle sum $(m-2)180^\circ$ of $P$, so the number of triangles is $|T|=2(n-m)+m-2=2n-m-2=3948$. Each triangle has three sides; sides of $P$ are counted once and inner edges twice, so the number of inner edges is $e=\frac{3|T|-m}2=3n-2m-3=5872$.

Arrows. An inner edge $xy$ is a side of exactly two triangles $xyz$ and $xyw$, and $z,w$ lie on opposite sides of line $xy$.   • A vertex of $P$ is never a head: all triangle angles there add up to an angle of $P$, which is less than $180^\circ$.

  • If an inner point $y$ is the head of two edges $yu$, $yv$, these edges are neighbours in the cyclic order of edges around $y$: otherwise the two pairs of angles adjacent to $yu$ and to $yv$ would be disjoint, and together they would exceed $360^\circ$.

Problem A

SNumber Theory · LPS VII, Chapter 49: Combinatorial Number Theory and Structure · Sequences with Arithmetic Constraints · also Germany TST 2026, AIMO 2, Problem 3

Let $S$ be a set of positive integers, possibly infinite, such that no positive integer greater than $1$ divides all elements of $S$. Determine all non-periodic infinite sequences $a_1,a_2,a_3,\ldots$ of positive integers such that, for all positive integers $n$,

  • $a_n\leqslant|a_{n+\ell}-\ell|$ for all $\ell$ in $S$, and

  • $a_n=|a_{n+\ell}-\ell|$ for at least one $\ell$ in $S$.

We say that an infinite sequence $a_1,a_2,a_3,\ldots$ is periodic if there exists a positive integer $t$ such that $a_n=a_{n+t}$ for all positive integer $n$.

Show the answer

$a_n=n+c$ for all $n$, where $c\ge0$ is an integer

Show the solution – Unbounded, then eventually above every shift, then eventually linear

The answer works. For an integer $c\ge0$ let $a_n=n+c$. These are positive integers, the sequence is strictly increasing (so not periodic), and $|a_{n+\ell}-\ell|=|n+c|=a_n$ for every $\ell\in S$, so both conditions hold.

From now on let $(a_n)$ be a non-periodic sequence with the two properties. Together they say \[a_n=\min_{\ell\in S}\,|a_{n+\ell}-\ell|\qquad\text{for every }n\ge1, \tag{$*$}\] and the minimum is attained.

A finite part of $S$. The greatest common divisor of the first $j$ elements of $S$ (in increasing order) is a non-increasing sequence of positive integers, so it is eventually constant; its final value divides every element of $S$, hence equals $1$. So some finite set $T\subseteq S$ has $\gcd T=1$. Let $M=\max T$ and $K=\bigl(\sum_{t\in T}t\bigr)^2$.

Fact: every integer $k>K$ is a sum of elements of $T$ (repetitions allowed). By Bézout there are integers $w_t$ with $\sum_{t\in T}w_tt=k$. If some $w_j<0$, the positive terms satisfy $\sum_{w_t>0}w_tt\ge k>K$; if every positive coefficient were at most $j-1$, this sum would be at most $(j-1)\sum_{t\in T}t<K$. So some $w_i\ge j$, and we replace $w_i$ by $w_i-j$ and $w_j$ by $w_j+i$: the value $\sum w_tt$ is unchanged, $w_i$ stays nonnegative, and the total $\sum_{w_t<0}|w_t|$ of the negative coefficients strictly decreases. After finitely many such steps all coefficients are nonnegative.

Step 1: the sequence is unbounded. Suppose $a_n\le C$ for all $n$. If $\ell\in S$ and $\ell>2C$, then $|a_{n+\ell}-\ell|\ge\ell-C>C\ge a_n$, so the minimum in $(*)$ is attained at some $\ell\le2C$. Hence $a_n$ is determined by the block $W_n=(a_{n+1},a_{n+2},\dots,a_{n+2C})$: there is a fixed rule $F$ with $a_n=F(W_n)$, and therefore a fixed rule $G$ with $W_{n-1}=G(W_n)$ (compute $a_n=F(W_n)$ and drop the last entry). The blocks take only finitely many values, so some block value $W$ occurs as $W_N$ for infinitely many $N$. The sequence $W,G(W),G^2(W),\dots$ takes finitely many values, so there are $J\ge0$ and $P\ge1$ with $G^{j+P}(W)=G^{j}(W)$ for all $j\ge J$. For any $n\ge1$ choose such an $N$ with $N\ge n+P+J$; then $W_n=G^{N-n}(W)$ and $W_{n+P}=G^{N-n-P}(W)$ are equal, since both exponents are at least $J$ and differ by $P$. So $a_n=F(W_n)=F(W_{n+P})=a_{n+P}$ for all $n$, and the sequence is periodic, a contradiction.

Step 2: $a_n>M$ for all large $n$. If $a_p\le M$, $t\in T$ and $p-t\ge1$, then by the first condition $a_{p-t}\le|a_p-t|\le M-1$, because both $a_p$ and $t$ lie in $[1,M]$. Now suppose $a_n\le M$ for infinitely many $n$, and let $m\ge1$. Pick such an $n$ with $n-m>K$ and write $n-m=t_1+\dots+t_r$ with $t_i\in T$ (Fact). Going from index $n$ down to $n-t_1$, then to $n-t_1-t_2$, and so on, all indices stay $\ge m$ and the value stays at most $M$; so $a_m\le M$. Hence the sequence is bounded, contradicting Step 1. So there is $N$ with $a_n>M$ for all $n>N$.

Step 3: a monotonicity. Put $b_n=a_n-n$. Let $n>N$ and $t\in T$. If $a_{n+t}<t$, the first condition would give $a_n\le t-a_{n+t}<t\le M<a_n$, which is absurd. So $a_{n+t}\ge t$ and $a_n\le a_{n+t}-t$, that is, $b_n\le b_{n+t}$. Using the Fact, we get \[b_n\le b_{n+k}\qquad\text{for all }n>N\text{ and all }k>K. \tag{1}\]

Step 4: $(b_n)$ is eventually constant.

  • Some $B_0$ satisfies $b_m\le B_0$ for infinitely many $m$. Suppose instead that for every $B$ only finitely many $m$ have $b_m\le B$. Take $B\ge\max(0,b_1)$, and let $m^*$ be the largest $m$ with $b_m\le B$ (the set is finite and contains $1$). Choose $\ell\in S$ attaining the minimum in $(*)$ for $n=m^*$. Then $b_{m^*+\ell}>B\ge0$, so $a_{m^*+\ell}=b_{m^*+\ell}+m^*+\ell>\ell$ and $a_{m^*}=a_{m^*+\ell}-\ell$, i.e. $b_{m^*}=b_{m^*+\ell}>B$, a contradiction. So there is $B_0$ with $b_m\le B_0$ for infinitely many $m$.

  • Bounded. For $n>N$ pick such an $m$ with $m>n+K$; by (1), $b_n\le b_m\le B_0$. Also by (1), $b_n\ge b_{N+1}$ for $n>N+1+K$. So for large $n$ the integers $b_n$ lie in a fixed finite set.

  • Constant. Let $v$ be the largest value taken by $b_n$ for infinitely many $n$. For large $n$, $b_n\le v$ (larger values occur only finitely often). Also, choosing $j>N$ with $b_j=v$ and $n>j+K$, (1) gives $b_n\ge v$. Hence $b_n=v$ for all large $n$.

Step 5: going back to the start. Let $c=v$ and let $L$ be the least index with $b_n=c$ for all $n\ge L$. Suppose $L\ge2$. Choose $\ell\in S$ attaining the minimum in $(*)$ for $n=L-1$. Since $L-1+\ell\ge L$, we have $a_{L-1+\ell}=L-1+\ell+c$, so $a_{L-1}=|L-1+c|$. As $L+c=a_L\ge1$, the number $L-1+c$ is nonnegative, so $a_{L-1}=L-1+c$ and $b_{L-1}=c$, contradicting the choice of $L$. Hence $L=1$: $a_n=n+c$ for all $n$, and $c=a_1-1\ge0$.

Therefore the sequences are exactly \[\boxed{a_n=n+c\ \ (n\ge1),\quad c\ge0\text{ an integer}}.\]

Problem C

HCombinatorics · LPS VII, Chapter 31: Extremal Principle and Bounding Arguments · Forcing Structure via Extremes

Sunny keeps a Charmander in each cell on a $2026\times2026$ chessboard, each facing up, down, left or right. All Charmanders simultaneously shoot flames of infinite length forward, and then keep shooting while turning ninety degrees clockwise. Let $N$ be the number of Charmander pairs that will shoot each other, not necessarily at the same time. Prove that, if $N$ reaches its maximum value, then there exist two different directions $A$ and $B$ such that the number of Charmanders initially facing $A$ is at least two times the number of Charmanders initially facing $B$.

Show the solution – Diagonal pairs and a staircase

Reading of the statement. Each Charmander turns only through $90^\circ$ clockwise while shooting, so its flame sweeps the closed quarter-plane between its initial direction and the next direction clockwise: a Charmander facing up covers the north-east quadrant (including the two bounding half-lines), one facing right the south-east, one facing down the south-west and one facing left the north-west quadrant. (Flames are infinite and are not blocked.) Two Charmanders shoot each other if each lies in the quadrant of the other, possibly at different moments. (If the Charmanders kept turning through full circles, only opposite initial directions in a common row or column would matter, and the question would be trivial; so this is the sensible reading.) Let $n=2026$ and let $u,r,d,l$ be the numbers of Charmanders initially facing up, right, down, left; $u+r+d+l=n^2$.

Which pairs count. Take two Charmanders $X$, $Y$ in different rows and different columns, say $Y$ strictly north-east of $X$. Only the north-east quadrant contains $Y$ as seen from $X$, so $X$ faces up; only the south-west quadrant contains $X$ as seen from $Y$, so $Y$ faces down. Similarly, if $Y$ is strictly north-west of $X$, then $X$ faces left and $Y$ faces right. Thus every counted pair not in a common row or column is an (up, down) pair or a (left, right) pair, and there are at most $ud+lr$ of these. The pairs in a common row or column number $2n\binom n2=n^2(n-1)$. Hence for every arrangement \[N\le ud+lr+n^2(n-1).\tag{1}\]

A good arrangement. Number rows and columns $1,\ldots,n$ and let the Charmander in column $i$, row $j$ face up if $i+j\le n$ and down if $i+j\ge n+1$. Count only pairs (up at $(i,j)$, down at $(i',j')$) with $i'>i$, $j'>j$; such a pair shoots each other. For a fixed up cell $(i,j)$ there are $(n-i)(n-j)$ cells strictly north-east of it, of which those with $i'+j'\le n$ are not down cells; writing $i'=i+\alpha$, $j'=j+\beta$ with $\alpha,\beta\ge1$, $\alpha+\beta\le k:=n-i-j$, there are $\binom k2$ of them. So \[N_{\max}\ \ge\ \sum_{\substack{i,j\ge1\\ i+j\le n}}\Bigl[(n-i)(n-j)-\binom{n-i-j}2\Bigr]=\frac{n(n-1)^2(n+1)}6,\tag{2}\] the sum being a routine polynomial summation (equivalently, the identity can be checked by induction on $n$).

Balanced arrangements are not optimal. Suppose that no two directions $A\ne B$ satisfy (number facing $A$) $\ge2\cdot$(number facing $B$). Then all four numbers are positive and, with $m=\min(u,r,d,l)$, all are less than $2m$. Put $\sigma=u+d$, $t=l+r$ and say $\sigma\ge t$ (the other case is symmetric). Then $\sigma<4m\le2t$, so $\sigma<\frac23n^2$, and by AM-GM and convexity \[ud+lr\le\frac{\sigma^2+t^2}4<\frac14\Bigl(\bigl(\tfrac23\bigr)^2+\bigl(\tfrac13\bigr)^2\Bigr)n^4=\frac5{36}n^4,\] because $\sigma^2+(n^2-\sigma)^2$ increases with $\sigma$ on $[\frac{n^2}2,\frac23n^2]$. With (1), such an arrangement has $N<\frac5{36}n^4+n^2(n-1)$. Finally \[6n(n-1)^2(n+1)-\bigl(5n^4+36n^2(n-1)\bigr)=n\,(n^3-42n^2+30n+6)>0\qquad(n=2026),\] so by (2) the arrangement has $N<N_{\max}$.

Therefore, when $N$ reaches its maximum, some direction $A$ is used at least twice as often as some other direction $B$.

Problem G

HGeometry · LPS VII, Chapter 53: Barycentric and Projective-Flavored Geometry · Projective Incidence Structure

Let the incircle $\omega$ of triangle $ABC$ touch $BC,CA,AB$ at $D,E,F$, respectively. Let $P_1,P_2$, $Q_1,Q_2$, $R_1,R_2$ lie on the minor arcs $EF$, $FD$, $DE$ of $\omega$, respectively, such that $A,B,C$ lie on $R_1P_1$, $P_1Q_1$, $Q_1R_1$, respectively, and also lie on $P_2Q_2$, $Q_2R_2$, $R_2P_2$, respectively. Prove that $AD$, $Q_1Q_2$, $R_1R_2$ are concurrent.

Show the solution – Involutions of the incircle and a symmetric model

Put $\omega$ in the complex plane as the unit circle. For a point $X$ not on $\omega$ let $\iota_X$ be the map of $\omega$ to itself that sends $U$ to the second intersection of the line $XU$ with $\omega$ (to $U$ itself if $XU$ is tangent). If $u,v\in\omega$, the chord $uv$ passes through $X$ exactly when $X+uv\overline X=u+v$; solving for $v$, \[\iota_X(u)=\frac{X-u}{1-\overline Xu},\] a Möbius map (its determinant $|X|^2-1$ is nonzero). We use three standard facts about Möbius maps $z\mapsto\frac{\alpha z+\beta}{\gamma z+\delta}$.

  • (F1) A Möbius map other than the identity has at most two fixed points.

  • (F2) A Möbius map is determined by the images of three points, and a Möbius map that swaps two points is an involution. (Move the two points to $0,\infty$: the map becomes $z\mapsto k/z$.)

  • (F3) For distinct $u,v$ there is exactly one Möbius involution with fixed points $u,v$. (Move $u,v$ to $0,\infty$: a map fixing both is $z\mapsto kz$, and $k^2=1$, $k\ne1$ forces $k=-1$.)

Consequently: $\iota_A$ is the Möbius involution fixing $E,F$ (the tangency points from $A$), $\iota_B$ the one fixing $F,D$, $\iota_C$ the one fixing $D,E$; and if $X=Q_1Q_2\cap R_1R_2$, then $\iota_X$ is the Möbius map swapping $Q_1\leftrightarrow Q_2$ and $R_1\leftrightarrow R_2$. Finally, $X$ lies on $AD$ if and only if $\iota_X(D)=\iota_A(D)$, because both sides are the second point of the line through $D$ and $X$, resp. $A$, and $\iota_A(D)\ne D$.

The hypotheses. They say $Q_1=\iota_B(P_1)$, $R_1=\iota_C(Q_1)$, $P_1=\iota_A(R_1)$ and $Q_2=\iota_A(P_2)$, $R_2=\iota_B(Q_2)$, $P_2=\iota_C(R_2)$. Let $\tau=\iota_A\iota_C\iota_B$. Then $\tau(P_1)=\iota_A\iota_C(Q_1)=\iota_A(R_1)=P_1$ and $\tau(Q_2)=\iota_A\iota_C(R_2)=\iota_A(P_2)=Q_2$. Also $\tau(D)=\iota_A(D)\ne D$, so $\tau\ne\mathrm{id}$ and, by (F1), $P_1$ and $Q_2$ (distinct, as they lie on different arcs) are the only fixed points of $\tau$. Note also that the second triple is determined by $Q_2$: $P_2=\iota_A(Q_2)$, $R_2=\iota_B(Q_2)$.

Normalisation. Everything above is expressed through Möbius maps and their fixed points, so it is unchanged if we apply a Möbius map $\mu$ to all points and conjugate all maps by $\mu$ (by (F2) and (F3) the conjugated maps are again the involutions with the image fixed points or image swapped pairs). Choose $\mu$ with $\mu(D)=1$, $\mu(E)=\varepsilon$, $\mu(F)=\varepsilon^2$, where $\varepsilon=e^{2\pi i/3}$. It maps the circle through $D,E,F$ to the circle through $1,\varepsilon,\varepsilon^2$, i.e. $\omega$ to itself. So we may assume $D=1$, $E=\varepsilon$, $F=\varepsilon^2$: the triangle is equilateral, $A=-2$, and \[\iota_A(z)=\frac{-2-z}{1+2z},\qquad \iota_A(1)=-1.\] We must show $\iota_X(1)=-1$.

The symmetry. Let $s(z)=1/z$; on $\omega$ this is the reflection in the real axis (the line $AD$). It is a Möbius involution fixing $1$ and swapping $\varepsilon\leftrightarrow\varepsilon^2$; by (F3), $s\iota_As=\iota_A$, $s\iota_Bs=\iota_C$, $s\iota_Cs=\iota_B$. Put $P_2^*=s(P_1)$, $Q_2^*=s(R_1)$, $R_2^*=s(Q_1)$. Then \[\iota_A(P_2^*)=s\iota_A(P_1)=s(R_1)=Q_2^*,\quad \iota_B(Q_2^*)=s\iota_C(R_1)=s(Q_1)=R_2^*,\quad \iota_C(R_2^*)=s\iota_B(Q_1)=s(P_1)=P_2^*,\] so the triple $(P_2^*,Q_2^*,R_2^*)$ satisfies the same relations as $(P_2,Q_2,R_2)$; as computed above, $Q_2^*$ is then a fixed point of $\tau$. Moreover $Q_2^*\ne P_1$: otherwise $s(R_1)=\iota_A(R_1)$, i.e. $R_1$ is a fixed point of $s\iota_A(z)=\frac{1+2z}{-2-z}$, whose fixed points are the roots of $z^2+4z+1=0$, namely $-2\pm\sqrt3$, not on $\omega$. Hence $Q_2^*=Q_2$, and then $P_2^*=P_2$, $R_2^*=R_2$. So \[s(Q_1)=R_2,\qquad s(R_1)=Q_2 .\]

Conclusion. The map $s\iota_Xs$ swaps $s(Q_1)=R_2\leftrightarrow s(Q_2)=R_1$ and $s(R_1)=Q_2\leftrightarrow s(R_2)=Q_1$; by (F2) it equals $\iota_X$. Hence $s(\iota_X(1))=\iota_X(s(1))=\iota_X(1)$, so $\iota_X(1)$ is a fixed point of $s$ on $\omega$: $\iota_X(1)=\pm1$. If $\iota_X(1)=1$, let $u$ be the other fixed point of the involution $\iota_X$ (a Möbius involution has exactly two fixed points on the Riemann sphere). Since $\iota_X$ commutes with $s$, $s(u)$ is also a fixed point of $\iota_X$, and $s(u)\ne1=s(1)$; so $s(u)=u$, i.e. $u=-1$. By (F3), $\iota_X=s$; then $R_2=s(Q_1)=\iota_X(Q_1)=Q_2$, which is false ($R_2=\iota_B(Q_2)\ne Q_2$ because $Q_2\ne D,F$). Therefore $\iota_X(1)=-1=\iota_A(1)$, which, as noted at the start, means that $X$ lies on $AD$. So $AD$, $Q_1Q_2$, $R_1R_2$ are concurrent.

The sequence of triples of positive integers $(a_0,b_0,c_0)$, $(a_1,b_1,c_1)$, $\ldots$, $(a_{2025},b_{2025},c_{2025})$ satisfies \[(a_{i+1},b_{i+1},c_{i+1})=\bigl(a_i+\gcd(b_i,c_i),\,b_i+\gcd(c_i,a_i),\,c_i+\gcd(a_i,b_i)\bigr)\] for $0\leqslant i\leqslant 2024$. Determine the smallest possible value of $a_{2025}$.

Here $\gcd(x,y)$ denotes the greatest common divisor of integers $x$ and $y$.

Show the answer

$3\cdot2^{675}$

Show the solution – Halving the triple and counting the halvings

Write $T_t=(a_t,b_t,c_t)$ and $\Phi(a,b,c)=\bigl(a+\gcd(b,c),\,b+\gcd(c,a),\,c+\gcd(a,b)\bigr)$, so $T_{t+1}=\Phi(T_t)$. Note $\Phi(2a,2b,2c)=2\Phi(a,b,c)$. Let $N=2025$.

Construction. Start with $T_0=(1,5,14)$. Then $T_1=(2,6,15)$, $T_2=(5,7,17)$, $T_3=(6,8,18)$, $T_4=(8,14,20)$, $T_5=(10,18,22)$, $T_6=(12,20,24)=4\cdot(3,5,6)$. For any $g$, \[g(3,5,6)\ \mapsto\ g(4,8,7)\ \mapsto\ g(5,9,11)\ \mapsto\ g(6,10,12)=2g\,(3,5,6),\] so $T_{3m}=2^m(3,5,6)$ for all $m\ge2$, and $a_{2025}=a_{3\cdot675}=3\cdot2^{675}$.

Parity lemma. Call a triple reduced if not all its entries are even. For a reduced triple $r$: if $r$ has exactly one even entry, $\Phi(r)$ has exactly two; if $r$ has exactly two even entries, $\Phi(r)$ is all odd; if $r$ is all odd, $\Phi(r)$ is all even. (A gcd is even only if both arguments are even; e.g. for $a$ even and $b,c$ odd all three gcds are odd, so $\Phi$ gives odd, even, even.) In particular $\Phi(r)$ is all even if and only if $r$ is all odd.

Reduced sequence. Let $2^{e_t}$ be the largest power of $2$ dividing all of $a_t,b_t,c_t$, $r_t=T_t/2^{e_t}$ (reduced) and $x_t=a_t/2^{e_t}\ge1$, so $a_t=2^{e_t}x_t$. Since $T_{t+1}=2^{e_t}\Phi(r_t)$, the parity lemma gives: if $r_t$ is not all odd then $e_{t+1}=e_t$ and $x_{t+1}=x_t+g\ge x_t+1$ ($g$ a gcd); if $r_t$ is all odd then $e_{t+1}=e_t+\delta$ with $\delta\ge1$ and $x_{t+1}=(x_t+g)/2^\delta$.

Let $t_1<\dots<t_K$ be the times $t\in\{0,\dots,N-1\}$ with $r_t$ all odd, $\delta_i$ the corresponding increments, $d_i=t_{i+1}-t_i$, $s=N-1-t_K$ and $y_i=x_{t_i+1}$. By the parity lemma (one even entry $\to$ two $\to$ none) we have $t_1\le2$, $d_i\le3$ and $s\le2$. Hence $2024=t_1+\sum d_i+s\le2+3(K-1)+2$, so $K\ge675$, and $e_N=e_0+\sum\delta_i\ge K\ge675$. Put \[D=(2-t_1)+\sum_{i<K}(3-d_i)=3K-2025+s\ \ (\ge0).\] Also $x_N\ge y_K+s$, $y_1\ge\frac{x_{t_1}+1}{2^{\delta_1}}\ge\frac{t_1+2}{2^{\delta_1}}$ (as $x_{t_1}\ge x_0+t_1$), and \[y_{i+1}\ge\frac{x_{t_{i+1}}+1}{2^{\delta_{i+1}}}\ge\frac{y_i+d_i}{2^{\delta_{i+1}}}. \tag{1}\] If $\delta_{j+1}=\dots=\delta_i=1$, the shortfalls $z_i=3-y_i$ satisfy $z_{i+1}\le\frac{z_i+(3-d_i)}{2}$, hence \[z_i\le\frac{z_j}{2^{\,i-j}}+\frac12\sum_{j\le l<i}(3-d_l). \tag{2}\] Since $a_N=2^{e_N}x_N$, it suffices to exclude $e_N=675$ with $x_N\le2$ and $e_N=676$ with $x_N=1$. If $e_N=675$, then $K=675$, $e_0=0$ and all $\delta_i=1$. If $e_N=676$, then either $e_0=1$, $K=675$ and all $\delta_i=1$, or $e_0=0$ and one of the two cases below occurs.

$K=675$, all $\delta_i=1$. Then $D=s$. By (2) with $j=1$ and $z_1\le2-\frac{t_1}2\le2$: $z_K\le2^{-673}+\frac12\sum_{i<K}(3-d_i)\le2^{-673}+\frac s2$. So $x_N\ge y_K+s=3-z_K+s\ge3-2^{-673}+\frac s2>2$, i.e. $x_N\ge3$.

$e_0=0$, $K=676$, all $\delta_i=1$. Now $D=3+s$ and (2) gives $z_K\le2^{-674}+\frac{3+s}2$, so $x_N\ge y_K+s\ge\frac32-2^{-674}+\frac s2>1$, i.e. $x_N\ge2$.

$e_0=0$, $K=675$, one $\delta_j=2$. Here $D=s$. If $j<K$: $y_j\ge1$, so $z_j\le2$ and (2) from $j$ gives $z_K\le1+\frac s2$, hence $x_N\ge y_K+s\ge2+\frac s2\ge2$. If $j=K$ and $s\ge1$: $x_N\ge y_K+s\ge1+1=2$. If $j=K$ and $s=0$: then $D=0$, so $t_1=2$ and all $d_i=3$; by (2) (all earlier $\delta=1$) $z_{K-1}<1$, so $y_{K-1}\ge3$, $x_{t_K}\ge y_{K-1}+2\ge5$ and $x_N=y_K\ge\frac{5+1}{4}>1$, i.e. $x_N\ge2$.

In every case $a_N=2^{e_N}x_N\ge3\cdot2^{675}$. Hence the smallest possible value of $a_{2025}$ is $\boxed{3\cdot2^{675}}$.

Problem A

HAlgebra · LPS VII, Chapter 1: Inequalities: Core Classical Methods · Cauchy-Schwarz and Titu's Lemma

Let $n$ be a positive integer, and $x_1,x_2,\ldots,x_n$ be non-negative real numbers such that $x_1+\cdots+x_n=1$. Find the smallest possible value of \[\sum_{i=1}^n\sum_{j=1}^n\frac{x_ix_j}{2^{|i-j|}}.\]

Show the answer

$\dfrac{3}{n+2}$

Show solution 1 – A sum of squares, then Cauchy–Schwarz

Let $Q=\sum_{i,j}x_ix_j2^{-|i-j|}$. For $n=1$, $Q=x_1^2=1=\frac3{1+2}$; let $n\ge2$.

A sum of squares. Define $u_k=\sum_{i=k}^nx_i2^{k-i}$ for $1\le k\le n$ (so $u_n=x_n$ and $u_k=x_k+\tfrac12u_{k+1}$). We claim \[Q=u_1^2+\frac34\sum_{k=2}^nu_k^2.\tag{1}\] Indeed, the coefficient of $x_ix_j$ ($i\le j$) on the right is computed from the terms $k\le i$: $u_k^2$ contains $x_ix_j$ with coefficient $2^{2k-i-j}$ (times $2$ if $i<j$). Summing, $2^{2-i-j}\bigl(1+\frac34\sum_{k=2}^{i}4^{k-1}\bigr)=2^{2-i-j}\cdot4^{i-1}=2^{i-j}$, which is the coefficient $2^{-(j-i)}$ in $Q$ (with the same factor $2$ for $i<j$).

The constraint. Since $x_k=u_k-\frac12u_{k+1}$ (with $u_{n+1}=0$), \[1=\sum_{k=1}^nx_k=u_1+\frac12\sum_{k=2}^nu_k.\]

Cauchy–Schwarz. \[1=\Bigl(1\cdot u_1+\sum_{k=2}^n\tfrac12u_k\Bigr)^2\le\Bigl(1+\sum_{k=2}^n\frac{(1/2)^2}{3/4}\Bigr)\Bigl(u_1^2+\frac34\sum_{k=2}^nu_k^2\Bigr)=\frac{n+2}3\,Q.\] So $Q\ge\frac3{n+2}$. Equality needs $u_1:u_k=1:\frac23$ for all $k\ge2$, which gives $x_1=x_n=\frac2{n+2}$ and $x_2=\cdots=x_{n-1}=\frac1{n+2}$; these are non-negative with sum $1$, and then $Q=\frac3{n+2}$. The minimum is $\boxed{\dfrac3{n+2}}$.

Show solution 2 – A magic vector

Let $A$ be the $n\times n$ matrix with entries $A_{ij}=2^{-|i-j|}$, so the quantity is $Q(x)=x^{\mathsf T}Ax$. For $n=1$ the answer is $1$; let $n\ge2$.

$A$ is positive semidefinite. Let $e_1,\ldots,e_n$ be the standard basis of $\mathbb R^n$ and $\rho=\frac12$. Put $v_i=\rho^{i-1}e_1+\sqrt{1-\rho^2}\sum_{k=2}^i\rho^{i-k}e_k$. For $i\le j$, \[v_i\cdot v_j=\rho^{j-i}\Bigl(\rho^{2(i-1)}+(1-\rho^2)\sum_{k=2}^i\rho^{2(i-k)}\Bigr)=\rho^{j-i}\bigl(\rho^{2(i-1)}+1-\rho^{2(i-1)}\bigr)=\rho^{j-i}.\] So $Q(x)=\bigl|\sum_ix_iv_i\bigr|^2\ge0$, and the bilinear form $\langle x,y\rangle=x^{\mathsf T}Ay$ satisfies the Cauchy–Schwarz inequality.

The vector $c=(2,1,\ldots,1,2)$. For each $i$, \[(Ac)_i=\sum_{j=1}^n2^{-|i-j|}+2^{-(i-1)}+2^{-(n-i)}=\Bigl(1+\sum_{k=1}^{i-1}2^{-k}+\sum_{k=1}^{n-i}2^{-k}\Bigr)+2^{1-i}+2^{i-n}=3.\] Hence, for $x\ge0$ with $\sum x_i=1$: $\langle x,c\rangle=3\sum x_i=3$ and $\langle c,c\rangle=3\sum c_i=3(n+2)$. By Cauchy–Schwarz, \[9=\langle x,c\rangle^2\le\langle x,x\rangle\langle c,c\rangle=3(n+2)\,Q(x),\qquad Q(x)\ge\frac3{n+2},\] with equality for $x=c/(n+2)$, which is admissible. So the minimum is $\boxed{\dfrac3{n+2}}$.

Problem C

HCombinatorics · LPS VII, Chapter 10: Double Counting and Counting Identities · Weighted Counting

Prove that if a positive integer $n$ has the following property: the cells of an infinite chessboard can be colored using $n$ colors so that, in every square sub-board, the numbers of cells of any two colors differ by at most $1$, then $n\le 7$.

Show the solution – Three counting arguments: a lonely centre, corner weights, and paired corners

Suppose that an $n$-colouring with the property exists and that $n\ge8$; we derive a contradiction. In a $k\times k$ square the $k^2$ cells are shared among the $n$ colours with counts differing by at most $1$, so \[\text{every colour occurs }\Bigl\lfloor\frac{k^2}{n}\Bigr\rfloor\text{ or }\Bigl\lceil\frac{k^2}{n}\Bigr\rceil\text{ times in every }k\times k\text{ square.}\tag{1}\] Two tools are used.

  • (T1) If $k^2\le n$, then by (1) each colour occurs at most once in a $k\times k$ square. Two cells whose rows differ by at most $k-1$ and whose columns differ by at most $k-1$ lie in a common $k\times k$ square, so they have different colours.

  • (T2) Weights. Let $F$ be an $(m+1)\times(m+1)$ square, rows and columns numbered $0,\dots,m$, and let $Q_1,\dots,Q_4$ be its four $m\times m$ corner sub-squares. The cell in row $i$, column $j$ lies in exactly $a_ia_j$ of them, where $a_0=a_m=1$ and $a_i=2$ for $0<i<m$. Call $a_ia_j$ the weight of the cell: it is $1$ at the four corners of $F$, $2$ at the other boundary cells and $4$ at the interior cells. Counting pairs (cell of colour $c$, sub-square containing it) in two ways, \[\sum_{t=1}^{4}\#\{\text{cells of colour }c\text{ in }Q_t\}=\sum_{\text{cells of }F\text{ of colour }c}\text{weight}.\tag{2}\]

Case 1: $9\le n\le12$ or $n\ge16$. Let $k=\lfloor\sqrt n\rfloor$, so $k^2\le n<(k+1)^2$. Then $(2k-1)^2\ge2n$: for $k=3$ this is $25\ge2n$, true for $n\le12$; for $k\ge4$ it follows from $n\le(k+1)^2-1$ and $(2k-1)^2-2\bigl((k+1)^2-1\bigr)=2k^2-8k+1>0$. Take a $(2k-1)\times(2k-1)$ square $S$. By (1) every colour occurs at least $\lfloor(2k-1)^2/n\rfloor\ge2$ times in $S$. But every cell of $S$ differs from the centre of $S$ by at most $k-1$ in row and in column, so by (T1) no cell of $S$ other than the centre has the centre's colour. So that colour occurs only once in $S$: a contradiction.

Case 2: $n=8$. Take a $5\times5$ square $F$. Each of its four $4\times4$ sub-squares has $16=2\cdot8$ cells, so by (1) it contains every colour exactly twice, and by (2) every colour has total weight exactly $8$ in $F$. By (1) every colour occurs $3$ or $4$ times in $F$, and since $25=3\cdot8+1$, exactly one colour $s$ occurs $4$ times. A colour occurring $3$ times has three weights from $\{1,2,4\}$ with sum $8$; the only possibility is $4+2+2$, so such a colour never occupies a corner of $F$. Hence all four corners of $F$ have colour $s$, and since $s$ occurs exactly $4$ times, these are all its cells: its total weight is $4\ne8$. A contradiction.

Case 3: $13\le n\le15$. Now $\lfloor16/n\rfloor=\lfloor25/n\rfloor=1$ and $\lceil16/n\rceil=\lceil25/n\rceil=2$: every colour occurs once or twice in every $4\times4$ square and in every $5\times5$ square.

Corner lemma. If $\kappa$ is a corner cell of a $5\times5$ square $F$, then the colour of $\kappa$ occurs exactly once more in $F$, at one of the nine interior cells of $F$. Indeed, this colour occurs in each of the four $4\times4$ sub-squares of $F$, so by (2) its total weight in $F$ is at least $4$. The corner $\kappa$ has weight $1$ and the colour has at most two cells in $F$; so there is exactly one other cell, of weight at least $3$, i.e. of weight $4$: an interior cell.

Now take a $6\times6$ square $W$ with rows and columns $0,\dots,5$, and let $R$ be its central $4\times4$ square (rows and columns $1,\dots,4$). The cell $(1,1)$ is a corner of the $5\times5$ square with rows and columns $1,\dots,5$, whose interior is the $3\times3$ square with rows and columns $2,3,4$; this lies inside $R$ and contains exactly one corner of $R$, namely the opposite corner $(4,4)$. The same holds for every corner of $R$ (use the $5\times5$ square of $W$ having that corner as a corner). So, by the corner lemma, each corner of $R$ has a partner: a second cell of $R$ of the same colour; and a corner can be the partner of another corner only if the two are opposite.

The $4\times4$ square $R$ contains every colour once or twice; as it has $16$ cells, exactly $16-n\le3$ colours occur twice in $R$. Each of the four corners of $R$ has one of these colours. If no such colour occupied two corners, the four corners would need four different colours occurring twice in $R$, which is impossible. So some colour $d$ occupies two corners of $R$, necessarily opposite ones.

  • If $d$ is the colour of $(1,1)$ and $(4,4)$, let $G$ be the $5\times5$ square with rows $0$–$4$ and columns $1$–$5$, and $X$ the $4\times4$ square with rows $0$–$3$ and columns $2$–$5$. Both cells of colour $d$ lie in $G$, so $d$ occurs nowhere else in $G$; and $X\subset G$ contains neither $(1,1)$ (column $1$) nor $(4,4)$ (row $4$).

  • If $d$ is the colour of $(1,4)$ and $(4,1)$, take $G$ with rows and columns $0$–$4$ and $X$ with rows and columns $0$–$3$; again both $d$-cells lie in $G$ and neither lies in $X\subset G$.

In both cases the colour $d$ does not occur in the $4\times4$ square $X$, contradicting the fact that every colour occurs in every $4\times4$ square.

The three cases cover all $n\ge8$. Therefore a colouring with the required property can exist only for $n\le7$.

Problem G

SGeometry · LPS VII, Chapter 11: Similarity, Homothety, and Ratio Geometry · Homothety Centers and Image Tracking · also Germany TST 2026, AIMO 4, Problem 3

Let $ABCD$ be a cyclic quadrilateral with circumcircle $\Omega$ such that $CD>BD>BC$. The tangents to $\Omega$ at $B$ and $C$ meet at a point $S$. A line $\ell$ is called coastal if:

  • $\ell$ does not pass through $A$,

  • $\ell$ intersects ray $SD$ at a point $X_\ell$ beyond $D$, and

  • there is a circle tangent to line $\ell$, line $X_\ell A$, segment $SB$ and segment $SC$.

Prove that there is a circle that is tangent to $\Omega$ and all coastal lines.

Show the solution – Pole of $SD$, a homothety from $S$, and a homothety from $U$

Let $O$ be the centre of $\Omega$. For a point $P\ne O$, its polar is taken with respect to $\Omega$; we use La Hire's principle ($P$ lies on the polar of $Q$ iff $Q$ lies on the polar of $P$) and Brocard's theorem: for four distinct points of $\Omega$, the three intersection points of opposite sides of the complete quadrangle form a self-polar triangle (with points at infinity allowed). Directed lengths are written with a bar.

The configuration. If $D$ were on the minor arc $BC$ we would have $BD<BC$; so the minor arc $BC$, which is the part of $\Omega$ seen from $S$, contains neither $D$ nor (by the order $A,B,C,D$) $A$. Hence line $SD$ meets $\Omega$ at $D$ and at a point of the minor arc $BC$, so $A\notin SD$, and the points of ray $SD$ beyond $D$ lie outside $\Omega$. Moreover $O\notin SD$: otherwise $D$ would be on the symmetry axis $SO$ of $B$ and $C$, and $BD=CD$.

The circle $\Gamma$. Let $K$ be the pole of line $SD$; it lies outside $\Omega$ because $SD$ is a secant. Line $KA$ is not tangent at $A$ (that would put $A$ on the polar $SD$ of $K$), so it meets $\Omega$ again at a point $U\ne A$. Let $\nu$ be the homothety with centre $U$ and ratio $\kappa=\overline{UA}/\overline{UK}$ (so $\nu(K)=A$; $\kappa\ne0,1$), and let $\Gamma=\nu(\Omega)$. Since $U\in\Omega$, $\Gamma$ is tangent to $\Omega$ at $U$. We show that every coastal line is tangent to $\Gamma$.

Setup for a coastal line. Let $\ell$ be coastal, $X=X_\ell$, and $\omega$ a circle tangent to $\ell$, to line $XA$ and to the segments $SB$, $SC$. Both $\omega$ and $\Omega$ are inscribed in angle $BSC$, so a homothety $\rho$ with centre $S$ and positive ratio maps $\omega$ to $\Omega$.

Case $\omega=\Omega$. Then line $XA$ is the tangent at $A$ and $\ell$ is the other tangent from $X$, touching at $T$. As $X$ lies on $SD$, the polar of $K$, the point $K$ lies on the polar $AT$ of $X$; so $T$ is the second point of $KA$ on $\Omega$, i.e. $T=U$. The homothety $\nu$ fixes $U$ and maps the tangent to $\Omega$ at $U$ to the parallel tangent of $\Gamma$ at $U$, i.e. to itself. So $\ell$ touches $\Gamma$ at $U$.

Case $\omega\ne\Omega$. Then the ratio of $\rho$ is not $1$. Put $Y=\rho(X)\in SD$. The lines $XA$ and $\ell$ (tangents to $\omega$ through $X$) are mapped to the two tangents from $Y$ to $\Omega$; let $E$ and $F$ be their points of contact, so $YE\parallel XA$ and $YF\parallel\ell$, and $E\ne F$.

  • $E\ne A$: $S\notin XA$ (else $XA=SD\ni A$), so $YE$ is a line parallel to and different from $XA$, and it cannot contain $A\in XA$.

  • $K\in EF$: $Y$ lies on $SD$, the polar of $K$, so $K$ lies on the polar of $Y$, which is $EF$.

  • Since $K\in AU$, $K\in EF$ and $K\notin\Omega$: if $F=A$ then $E=U$ (otherwise the lines $AU$, $AE$ meet only at $A$), and conversely if $E=U$ then $F=A$; and $F\ne U$ (otherwise $AU$, $EU$ would meet only at $U$, as $E\ne A$).

Main case: $A,E,U,F$ are four distinct points. By Brocard's theorem applied to them, the point $J=AE\cap UF$ lies on the polar of $AU\cap EF=K$, that is, on line $SD$ (if $AE\parallel UF$, this means that $AE$ and $UF$ are parallel to $SD$). Let $\tau$ be the homothety with centre $J$ (a translation along $SD$ in the parallel case) that maps $A$ to $E$. It fixes the lines $SD$ and $UF$ through $J$. It maps line $XA$ to the parallel line through $E$, which is $YE$; hence $\tau(X)=\tau(XA\cap SD)=YE\cap SD=Y$. Then $\tau(\ell)$ is the line through $Y$ parallel to $\ell$, namely $YF$. Line $\ell$ is not parallel to $UF$ (otherwise $YF=\tau(\ell)$ would be parallel to $UF$ and share the point $F$ with it, so $U$ would lie on the tangent at $F$, forcing $U=F$); so $L$ exists and $\tau(L)=YF\cap UF=F$. As $\tau$ maps $A\mapsto E$ and $L\mapsto F$, we get $AL\parallel EF$. Finally $A$ lies on line $UK$ with $\overline{UA}=\kappa\,\overline{UK}$, $L$ lies on line $UF$, and $AL\parallel KF$ (as $K\in EF$, $K\ne F$); by the intercept theorem $\overline{UL}=\kappa\,\overline{UF}$, i.e. $L=\nu(F)$.

Special case: $E=U$, $F=A$. Then $XA\parallel YE$ is parallel to the tangent at $U$, $\ell\parallel YF$ is parallel to the tangent at $A$, $Y$ is the intersection of these two tangents, and $L=\ell\cap UA$. Let $M=AU\cap SD$. The homothety with centre $M$ taking $Y$ to $X$ maps the tangent $YU$ to the parallel line through $X$, which is $XA$, so it maps $U\mapsto A$; and it maps the tangent $YA$ to $\ell$, so $A\mapsto L$. Since $M$ is on the polar of $K$ and $K\in AU$, the pair $K,M$ divides $AU$ harmonically, which gives $K=\frac{2au}{a+u}$. A direct computation now yields $(L-u)(K-u)=(a-u)^2$, i.e. $\overline{UL}=\kappa\,\overline{UA}$, so again $L=\nu(F)$. (If $AU\parallel SD$, the homothety is a translation, $K$ is the midpoint of $AU$, $L=2A-U$, and the same relation holds.)

The homothety $\nu$ maps $\Omega$ to $\Gamma$ and the tangent of $\Omega$ at $F$, which is the line $YF$, to the tangent of $\Gamma$ at $L$, a line through $L$ parallel to $YF$. Problem N

HNumber Theory · LPS VII, Chapter 29: Valuations and Lifting the Exponent · Lifting the Exponent (LTE)

Determine all pairs of positive integers $(a,b)$ satisfying $a<b$ and \[a^b-b^a=(b-a)!+1.\]

Show the answer

$(a,b)=(2,5)$

Show the solution – Parity, then a $2$-adic count against a size bound

Let $d=b-a\ge1$. The pair $(2,5)$ works: $32-25=7=3!+1$.

$a=1$ is impossible: $1-b<0$. Opposite parity. If $a,b$ have the same parity, then $d\ge2$ is even, $d!+1$ is odd, but $a^b-b^a$ is even. So $d$ is odd.

$a$ even (then $b$ odd). Here $8\mid a^b$ (as $b\ge3$) and $b^a\equiv1\pmod8$ ($b$ odd, $a$ even), so $a^b-b^a\equiv-1\pmod8$. If $d\ge4$ then $d!+1\equiv1\pmod8$, impossible. So $d\in\{1,3\}$. For $d=1$: $a^{a+1}-(a+1)^a=a^a\bigl(a-(1+\tfrac1a)^a\bigr)$, which is $-1$ for $a=2$ and $>a^a(a-e)>2$ for $a\ge4$; it never equals $2$. For $d=3$: $a^{a+3}-(a+3)^a=7$; $a=2$ gives $7$, and for $a\ge4$, $a^{a+3}-(a+3)^a=a^a\bigl(a^3-(1+\tfrac3a)^a\bigr)>a^a(a^3-e^3)>7$. So $(a,b)=(2,5)$.

Show the solution – Residues as a bijection, and two large primes

$f(n)=-n$ works: for $d\mid n$ take $e=d$; then $d+f(e)=0$.

Now let $f$ satisfy the condition; write $D(n)$ for the set of positive divisors of $n$ and $\tau(n)=|D(n)|$.

Step 1: a bijection. Fix $n$. The numbers $-d$ $(d\in D(n))$ are $\tau(n)$ different residues modulo $n$ (the divisors below $n$ are distinct and nonzero modulo $n$, and $-n\equiv0$). Each of them must be congruent to some $f(e)$ with $e\in D(n)$, and there are only $\tau(n)$ such values. Hence \[\{f(e)\bmod n:\ e\in D(n)\}=\{-d\bmod n:\ d\in D(n)\},\quad\text{and the }f(e)\ (e\in D(n))\text{ are pairwise incongruent mod }n. \tag{1}\]

By (1) for $n=mq$, $a\equiv-d\pmod{mq}$ for some $d\mid mq$, i.e. $d=d'$ or $d=d'q$ with $d'\mid m$. In the first case $mq\mid a+d'$ and $|a+d'|\le|a|+m<mq$, so $a=-d'$. In the second case $q\mid a$, so $a=0$ (as $q>|a|$).

Step 3: $f(m)=-m$ for all $m$, by strong induction. Let $m\ge1$ and assume $f(d)=-d$ for all $d<m$ (nothing is assumed for $m=1$). By (1) for $n=m$, the values $f(d)=-d$ $(d\in D(m),\ d<m)$ already occupy all the required residues except $0$, so $f(m)\equiv0\pmod m$, and by Step 2, $f(m)\in\{0,-m\}$.

It is not $f(d)=-d$ for $d<m$, $d\mid m$, nor $f(m)=0$. So $f(dq)\equiv-m\pmod{mq}$ for some $d\mid m$. By Step 2, $f(dq)$ is $0$ or $-c$ with $c\mid dq$, $0<c\le dq\le mq$; the congruence then forces $f(dq)=-m$ and $m\mid dq$, hence $m\mid d$ and $d=m$. Both $mq$ and $mr$ divide $N$ and $f(mq)=f(mr)=-m$, contradicting the incongruence in (1) for $N$. Hence $f(m)=-m$, completing the induction.

Let $m$ be the largest of $a,b,c,d$. Every $x^-\le m$, so $\sqrt{9-x^-}\ge\sqrt{9-m}$ and \[\Sigma\le\frac{\sum_xx\,x^-}{3+\sqrt{9-m}}=\frac{ab+bc+cd+da}{3+\sqrt{9-m}}=\frac{(a+c)(b+d)}{3+\sqrt{9-m}}.\] Let $p=a+c$, $q=b+d$, so $p+q=9$.

Case $m\ge\frac92$. The largest variable lies in $p$ or in $q$; say $q\ge m\ge\frac92$ (the other case is symmetric). Then $pq=q(9-q)\le m(9-m)$. With $s=\sqrt{9-m}\in[0,\frac3{\sqrt2}]$, so that $9-m=s^2$ and $m=(3-s)(3+s)$, \[\Sigma\le\frac{m\,s^2}{3+s}=(3-s)s^2\le4,\] because $4-(3-s)s^2=s^3-3s^2+4=(s+1)(s-2)^2\ge0$.

Case $m<\frac92$. Then $pq\le\frac{81}4$ and $\sqrt{9-m}>\sqrt{9/2}=\frac3{\sqrt2}$, so \[\Sigma<\frac{81/4}{3+3/\sqrt2}=\frac{27}{4}\cdot\frac{\sqrt2}{\sqrt2+1}=\frac{27}4\sqrt2(\sqrt2-1)=\frac{27}4(2-\sqrt2)<4,\] since $27(2-\sqrt2)<16\iff38<27\sqrt2\iff1444<1458$.

Strictness. In the first case equality would need $x^-\in\{0,m\}$ whenever $x>0$ (for the first estimate to be sharp); as all variables are positive, all of them would equal $m$, giving $m=\frac94<\frac92$, a contradiction. So $\Sigma<4$ always, and $L>23$. (Letting $(a,b,c,d)\to(4,0,0,5)$ shows that $23$ cannot be improved: then $L\to4\sqrt4+5\sqrt9=23$.)

Show solution 2 – Comparing each deficit with a chord

Since $a+b+c+d=9$, we have $a+b+c=9-d$, $b+c+d=9-a$, $c+d+a=9-b$ and $d+a+b=9-c$. For $0\le u\le 9$ put \[\varphi(u)=3-\sqrt{9-u}=\frac{u}{3+\sqrt{9-u}}.\] Using $a+b+c+d=9$ once more, the left side $L$ of the inequality equals \[L=a\sqrt{9-d}+b\sqrt{9-a}+c\sqrt{9-b}+d\sqrt{9-c}=3(a+b+c+d)-\Delta=27-\Delta,\] where \[\Delta=a\varphi(d)+b\varphi(a)+c\varphi(b)+d\varphi(c),\] so we must show $\Delta<4$.

Key fact. For $0<u\le9$ we have $\dfrac{\varphi(u)}{u}=\dfrac1{3+\sqrt{9-u}}$, which is strictly increasing in $u$. Hence \[\varphi(u)<\frac{u}{v}\,\varphi(v)\qquad\text{whenever }0<u<v\le9.\]

Grouping the variables. Let $A=a+c$ and $B=b+d$, so $A+B=9$ and $0<A,B<9$. All variables are positive, so $b,d<B$ and $a,c<A$. The key fact gives \[\varphi(d)<\frac dB\varphi(B),\quad \varphi(b)<\frac bB\varphi(B),\quad \varphi(a)<\frac aA\varphi(A),\quad \varphi(c)<\frac cA\varphi(A).\] Multiplying by $a$, $c$, $b$, $d$ respectively and adding, \[\Delta<(ad+bc)\frac{\varphi(B)}{B}+(ab+cd)\frac{\varphi(A)}{A}.\] Since $(ad+bc)+(ab+cd)=(a+c)(b+d)=AB$, the number $\lambda=\dfrac{ad+bc}{AB}$ lies in $(0,1)$ and the right side equals \[\lambda\cdot A\varphi(B)+(1-\lambda)\cdot B\varphi(A)\le\max\{A\varphi(B),\ B\varphi(A)\}.\]

The one-variable bound. Because $A=9-B$, writing $s=\sqrt A\in(0,3)$ gives $A\varphi(B)=A\bigl(3-\sqrt A\bigr)=3s^2-s^3$, and \[4-(3s^2-s^3)=s^3-3s^2+4=(s+1)(s-2)^2\ge0.\] So $A\varphi(B)\le4$, and in the same way (with $s=\sqrt B$) $B\varphi(A)\le4$.

Therefore $\Delta<4$, that is, \[a\sqrt{a+b+c}+b\sqrt{b+c+d}+c\sqrt{c+d+a}+d\sqrt{d+a+b}=27-\Delta>23.\] The constant $23$ cannot be improved: as $(a,b,c,d)\to(4,0,0,5)$ through positive values, the left side tends to $4\sqrt4+5\sqrt9=23$.

Problem 6

SAlgebra · LPS VII, Chapter 44: Combinatorial Games and Strategy · Invariant-Based Game Analysis

Tim and Tam play a game. To start the game, Tim writes some nonzero real numbers not necessarily distinct, on a blackboard. In each round, the following happens.

  • First, Tam chooses a polynomial $P_k(x)=a_kx^k+a_{k-1}x^{k-1}+\cdots+a_1x+a_0$ whose coefficients $a_k,a_{k-1},\ldots,a_1,a_0$ are all of the numbers currently written on the blackboard in some order. (For example, if the numbers on the blackboard are $4,-3,4$, then $k=2$ and Tam may choose the polynomial $4x^2-3x+4$ or $-3x^2+4x+4$ but not $4x-3$ or $-3x^2+4$.)

  • Then, if the equation $P_k(x)=0$ has no real solutions, the game is stopped. Otherwise, Tim chooses a real number $r$ such that $P_k(r)=0$ and writes it on the blackboard, so there is now one more number on the blackboard.

Determine whether Tim can ensure that the game is never stopped, no matter what Tam does.

Show the answer

No: Tam can always force the game to stop

Show the solution – Forcing positive roots, then a root-free polynomial

All numbers on the board are nonzero throughout: every polynomial Tam writes has a nonzero constant term, so $0$ is never a root.

A useful arrangement. Let $a_0,a_1,\dots,a_{2s}$ ($s\ge1$) be such that every even-indexed $a_i$ is positive and at least each of its odd-indexed neighbours. Put \[F(x)=\tfrac12a_0+\sum_{i=1}^{2s-1}a_ix^i+\tfrac12a_{2s}x^{2s}=\sum_{j=1}^{s}x^{2j-2}\Bigl(\tfrac12a_{2j-2}+a_{2j-1}x+\tfrac12a_{2j}x^2\Bigr).\] For $x\le0$ every bracket is nonnegative: if $a_{2j-1}\le0$, all three terms are $\ge0$; if $a_{2j-1}>0$, the bracket is at least $\tfrac12a_{2j-1}(1+2x+x^2)=\tfrac12a_{2j-1}(1+x)^2\ge0$. Hence $\sum a_ix^i=F(x)+\tfrac12a_0+\tfrac12a_{2s}x^{2s}>0$ for $x\le0$: all real roots are positive.

If a multiset of $2s+1$ numbers has a strict majority of positive numbers, put its $s+1$ largest elements (all positive) in the even positions and the others in the odd positions; this satisfies the condition. If the majority is negative, do this for the negated numbers and negate the polynomial: the roots do not change. (For a single number the polynomial is a nonzero constant.)

Step 1: Tam can force every new number to be positive. On a board with an odd number of entries and both signs, Tam uses the arrangement for the majority sign, so every real root is positive. On a board with an even number $2s+2$ of entries and both signs, let $\varepsilon$ be a sign occurring at least $s+1$ times and reserve one entry of the other sign as the leading coefficient (of $x^{2s+1}$); the other $2s+1$ entries have a strict majority of sign $\varepsilon$ and are arranged as above. After multiplying by $\varepsilon$, the lower part is positive for $x\le0$ and the leading term, with negative coefficient and odd exponent, is $\ge0$ there. So again every real root is positive.

On a board with all entries of one sign: if the number of entries is odd, the arrangement makes the polynomial nonzero for $x\le0$, and for $x>0$ all terms have the same sign, so there is no root and the game stops. If it is even, every polynomial has odd degree, its real roots are negative (all coefficients have one sign), and Tim adds a negative number. If all entries were negative, the next board is all negative of odd size and Tam stops the game; otherwise the board becomes mixed.

From a mixed board, every surviving round adds a positive number while the negative numbers stay fixed, say $q\ge1$ of them. So after finitely many rounds the board has an odd number of entries with a positive majority.

Step 2: the new numbers are bounded away from $0$. From now on Tam always uses the positive-sign arrangements (the positives keep the majority). Let $c>0$ be the largest positive entry at this moment and $B>0$ the largest absolute value of a negative entry. In every later round the constant term is the largest positive entry, so it is at least $c$, and every coefficient is at least $-B$. Put $\delta=\min\bigl(\tfrac12,\tfrac{c}{4B}\bigr)$. For $0\le x\le\delta$, \[P(x)\ge c-B\sum_{i\ge1}x^i=c-\frac{Bx}{1-x}\ge c-2B\delta\ge\frac c2>0,\] and there are no roots at $x\le0$. So every later number exceeds $\delta$.

Step 3: a polynomial without real roots. Choose an odd $h\ge1$ with $(2h-1)\delta\ge B$. After finitely many more rounds there is a board with an odd number of entries of which at least $q(2h-1)+1$ are $\ge\delta$. Tam writes the polynomial as a chain of blocks.

Take the $q(2h-1)+1$ largest positive entries. The $q+1$ largest of them are the endpoints; each of the $q$ blocks has degree $2h$, consists of positions $0,1,\dots,2h$, and consecutive blocks share an endpoint. In each block put a negative entry in the middle position $h$ (odd, as $h$ is odd) and $2h-2$ of the other selected positives in the remaining interior positions, the larger $h-1$ of them in the even positions and the smaller $h-1$ in the odd positions. Every even position then holds a positive number at least as large as its neighbours, so the half-weighted block polynomial $F_{\rm block}$ is $\ge0$ for $x\le0$. For $x>0$, by AM–GM, the two half-endpoints give $\tfrac12e_1+\tfrac12e_2x^{2h}\ge\sqrt{e_1e_2}\,x^h\ge\delta x^h$, each of the $h-1$ pairs of interior positives at exponents $j$ and $2h-j$ gives at least $2\delta x^h$, and the middle term is at least $-Bx^h$; so $F_{\rm block}(x)\ge\bigl((2h-1)\delta-B\bigr)x^h\ge0$.

These blocks use $2hq+1$ entries, an odd number; the rest of the board is an even number of positive entries. If any remain, add one last block, starting at the last endpoint, with the larger half of the remaining entries in the even positions and the smaller half in the odd positions; the endpoint is at least all of them, so this block also satisfies the arrangement condition, and its half-weighted polynomial is $\ge0$ for $x\le0$ and, having positive coefficients, for $x\ge0$.

Lay the blocks one after another, each starting at an even exponent (all blocks have even degree). The polynomial $P$ uses every entry of the board exactly once, and \[P(x)=\sum_{\text{blocks}}x^{d}F_{\rm block}(x)+\tfrac12a_0+\tfrac12a_{\rm top}x^{\deg P},\] since each shared endpoint appears with weight $\tfrac12$ in two blocks. Each summand $x^dF_{\rm block}(x)$ is $\ge0$ for all real $x$ ($d$ even), $a_0>0$, and $a_{\rm top}>0$ with $\deg P$ even. Hence $P(x)>0$ for all real $x$: $P$ has no real root and the game stops.

So Tim cannot ensure that the game never stops.
