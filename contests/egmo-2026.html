Problem 1

Combinatorics · LPS VII, Chapter 20: Parity, Coloring, and Process Termination

A $2026\times 2026$ board is said to be bordeaux if at least one of its $2026^2$ unit cells is coloured red. A rectangular region made of cells is oddly-rectangular if it contains an odd number of red cells. Determine the largest positive integer $M$ such that, in every possible $2026\times 2026$ bordeaux board, there exists an oddly-rectangular region of at least $M$ cells.

Note: A rectangular region has sides that are parallel to the sides of the board and contains all of its interior.

Show the answer

$M=1013^2=1026169$

Show the 3 solutions

Solution 1 (Corner parities)

Write $N=2026$ and $m=1013$, so $N=2m$. Number the rows and the columns $1,2,\dots,N$, and number the grid lines $0,1,\dots,N$, so that row $i$ lies between horizontal lines $i-1$ and $i$ (similarly for columns). A rectangular region is determined by two horizontal lines $x_1<x_2$ and two vertical lines $y_1<y_2$; its size is $(x_2-x_1)(y_2-y_1)$.

An example with no large odd region. Colour red only the four central cells in rows $m,m+1$ and columns $m,m+1$ (see the figure for the $6\times6$ analogue). A rectangular region meets this $2\times2$ block in a rectangle, that is, in $0$, $1$, $2$ or $4$ red cells, so it is oddly-rectangular exactly when it contains exactly one red cell. Then its rows contain exactly one of the rows $m,m+1$, so its rows lie inside rows $1,\dots,m$ or inside rows $m+1,\dots,N$: at most $m$ rows. The same holds for the columns, so it has at most $m^2$ cells. Hence $M\le m^2$.

Every bordeaux board has an odd region with at least $m^2$ cells. For grid lines $x,y$ let $g(x,y)\in\{0,1\}$ be the parity of the number of red cells in the region between lines $0,x$ and $0,y$ (put $g(x,y)=0$ if $x=0$ or $y=0$). By inclusion–exclusion, the number of red cells of the region between lines $x_1<x_2$ and $y_1<y_2$ has the parity of \[g(x_2,y_2)+g(x_1,y_2)+g(x_2,y_1)+g(x_1,y_1). \tag{1}\] In particular the single cell in row $i$, column $j$ is red if and only if $g(i,j)+g(i-1,j)+g(i,j-1)+g(i-1,j-1)$ is odd.

For a line number $x$ put $\bar x=N$ if $x<m$ and $\bar x=0$ if $x\ge m$; then $|x-\bar x|\ge m$. Suppose, for contradiction, that every region with both side lengths at least $m$ is even. Applying (1) to the region between lines $x,\bar x$ and $y,\bar y$ gives \[g(x,y)+g(\bar x,y)+g(x,\bar y)+g(\bar x,\bar y)\equiv 0\pmod 2\quad\text{for all }x,y. \tag{2}\]

  • If $x\ge m$ and $y\ge m$, then $\bar x=\bar y=0$ and (2) reads $g(x,y)\equiv 0$.

  • If $x\ge m>y$, then $\bar x=0$, $\bar y=N$, and (2) reads $g(x,y)\equiv g(x,N)$, which is $0$ by the first case. The case $y\ge m>x$ is symmetric.

  • If $x<m$ and $y<m$, then $\bar x=\bar y=N$, and (2) gives $g(x,y)\equiv g(N,y)+g(x,N)+g(N,N)\equiv0$ by the previous cases.

So $g\equiv 0$, and by the remark after (1) no cell is red, contradicting that the board is bordeaux. Hence some oddly-rectangular region has both sides at least $m$, so at least $m^2$ cells.

Therefore \[\boxed{M=m^2=1013^2=1026169}\]

Solution 2 (A bilinear form over $\mathbb{F}_2$)

Let $N=2026$, $m=1013$, and let $A$ be the $N\times N$ matrix with entries in $\mathbb{F}_2=\{0,1\}$ (arithmetic mod $2$) whose $(i,j)$ entry is $1$ exactly when the cell in row $i$, column $j$ is red. For a set $I$ of rows let $u_I\in\mathbb{F}_2^N$ be its indicator vector (a column vector). The rectangular region with row interval $I$ and column interval $J$ contains $\sum_{i\in I,\,j\in J}A_{ij}$ red cells, and modulo $2$ this is the number $u_I^{T}Au_J$. Note that $(u,v)\mapsto u^TAv$ is linear in each argument.

Upper bound. Colour red only the four central cells, in rows $m,m+1$ and columns $m,m+1$ (the example of Solution 1). A rectangular region meets this $2\times2$ block in $0$, $1$, $2$ or $4$ red cells, so it is oddly-rectangular exactly when it contains exactly one red cell. Then its rows contain exactly one of the rows $m,m+1$, so they lie within rows $1,\dots,m$ or within rows $m+1,\dots,N$: at most $m$ rows. Likewise it has at most $m$ columns, hence at most $m^2$ cells. So $M\le m^2$.

Lower bound. Let $\mathcal I$ be the family of the intervals $[1,k]$ with $m\le k\le N$ and $[k,N]$ with $1\le k\le m+1$; each has length at least $m$. Their indicator vectors span $\mathbb{F}_2^N$: if $e_i$ denotes the $i$-th unit vector, then \[e_{k+1}=u_{[1,k+1]}+u_{[1,k]}\ (m\le k\le N-1),\qquad e_k=u_{[k,N]}+u_{[k+1,N]}\ (1\le k\le m),\] which produces $e_{m+1},\dots,e_N$ and $e_1,\dots,e_m$.

Suppose every region $I\times J$ with $I,J\in\mathcal I$ is even, i.e. $u_I^TAu_J=0$ for all $I,J\in\mathcal I$. Every $e_i$ and every $e_j$ is a sum of such indicator vectors, so by bilinearity $A_{ij}=e_i^TAe_j=0$ for all $i,j$: no cell is red, a contradiction. Hence some oddly-rectangular region has both sides of length at least $m$, so at least $m^2$ cells.

So \[\boxed{M=1013^2=1026169}\]

Solution 3 (A largest odd region)

Write $N=2026$ and $m=1013$, so $N=2m$, and number the rows and the columns $1,2,\dots,N$.

An example with no large odd region. Colour red only the four central cells, in rows $m,m+1$ and columns $m,m+1$. A rectangular region meets this $2\times2$ block in a rectangle, that is, in $0$, $1$, $2$ or $4$ red cells, so it is oddly-rectangular exactly when it contains exactly one red cell. Then its rows contain exactly one of the rows $m,m+1$, so they lie within rows $1,\dots,m$ or within rows $m+1,\dots,N$: at most $m$ rows. Likewise it has at most $m$ columns, hence at most $m^2$ cells. So $M\le m^2$.

Every bordeaux board has an odd region with at least $m^2$ cells. A single red cell is an oddly-rectangular region, so there is an oddly-rectangular region $R$ with the largest possible number of cells. Let $R$ consist of rows $r_1,\dots,r_2$ and columns $c_1,\dots,c_2$; its height is $h=r_2-r_1+1$. We show $h\ge m$. Suppose instead $h<m$. Throughout we keep the columns $c_1,\dots,c_2$, and for a set $I$ of consecutive rows we write $n(I)$ for the number of red cells in the region formed by the rows of $I$ and the columns $c_1,\dots,c_2$. Such a region has more cells than $R$ as soon as $I$ has more than $h$ rows. Let $u=r_1-1$ and $v=N-r_2$ be the numbers of rows above and below $R$; then $u+v=2m-h>m$.

  • If $u\ge m$: the rows $1,\dots,r_2$ consist of the rows $1,\dots,u$ and the rows of $R$, so $n(\{1,\dots,r_2\})=n(\{1,\dots,u\})+n(R)$ with $n(R)$ odd. Hence one of the two regions with rows $1,\dots,u$ and rows $1,\dots,r_2$ is oddly-rectangular. Both have at least $u\ge m>h$ rows, so this region is larger than $R$.

  • If $v\ge m$: the same argument applies to the rows $r_2+1,\dots,N$ and $r_1,\dots,N$.

  • If $u<m$ and $v<m$: then $u=2m-h-v>m-h\ge1$ and likewise $v\ge1$. Consider the three regions with rows $1,\dots,N$, rows $r_1,\dots,N$ and rows $1,\dots,r_2$. Every red cell of $R$ is counted in all three, and every other red cell in the columns $c_1,\dots,c_2$ is counted in exactly two of them (a cell above $R$ in the first and third, a cell below $R$ in the first and second). So the sum of the three counts is congruent to $3n(R)$, which is odd, and one of the three regions is oddly-rectangular. Their numbers of rows are $N$, $h+v$ and $h+u$, all greater than $h$, so this region is larger than $R$.

Each case contradicts the choice of $R$, so $h\ge m$. The same argument with rows and columns exchanged shows that $R$ has at least $m$ columns. Hence $R$ has at least $m^2$ cells.

Therefore \[\boxed{M=m^2=1013^2=1026169}\]

Problem 2

Number Theory · LPS VII, Chapter 49: Combinatorial Number Theory and Structure

Given a positive integer $n$, Marie plays a game where she starts with the number $1$ on a blackboard. As many times as she wants, she can choose an integer $j$ such that $1\le j\le n$ and replace the number $V$ on the blackboard with the number $j\cdot R\left(\frac{V}{j}\right)$. Here $R(x)$ denotes the nearest integer to $x$; if $x$ is exactly halfway between two consecutive integers, it is rounded up. For example, $R(1.3)=1$ and $R(1.5)=R(1.8)=2$.

  • (a) Prove that for each given $n$, there is a positive integer $B$ such that Marie can never end up with a number larger than $B$ on the blackboard.

  • (b) For any given $n$, let $f(n)$ be the maximum number obtainable on the blackboard after finitely many replacements. Show that there exists a positive integer $N$ such that for all $n\ge N$, we have that $2026$ divides $f(n)$.

Show the answer

proof (one may take $N=1024\cdot1013$)

Show the solution

Solution (Monotone rounding and a doubling lemma)

For $1\le j\le n$ and an integer $V\ge0$ put $r_j(V)=j\,R(V/j)$; since $R(x)=\lfloor x+\tfrac12\rfloor$, this is the multiple of $j$ nearest to $V$ (rounding up at a tie). Starting from $1$, all numbers on the board are non-negative integers.

Monotonicity. If $V\le W$ then $r_j(V)\le r_j(W)$, because $x\mapsto\lfloor x+\frac12\rfloor$ is non-decreasing.

(a) Let $B=\operatorname{lcm}(1,2,\dots,n)$. Since $j\mid B$, $r_j(B)=B$ for every $j$. The first number is $1\le B$, and if the board shows $V\le B$, then after a move it shows $r_j(V)\le r_j(B)=B$. By induction Marie never exceeds $B$.

(b) By (a) only finitely many numbers are obtainable, so the maximum $f=f(n)\ge1$ exists. Since $f$ is obtainable, so is $r_j(f)$, hence $r_j(f)\le f$ for every $j\le n$. Write $f=qj+s$ with $0\le s<j$; then $r_j(f)=qj$ if $2s<j$ and $r_j(f)=qj+j>f$ if $2s\ge j$. Therefore \[2\,(f\bmod j)<j\qquad\text{for every }1\le j\le n. \tag{$*$}\]

Lemma. If $a\ge0$, $j\ge1$ and $2^aj\le n$, then $f\bmod 2^aj<j$.

Proof by induction on $a$; $a=0$ is clear. Let $a\ge1$ and $s=f\bmod 2^aj$. By $(*)$ for the number $2^aj$, $s<2^{a-1}j$. As $s\equiv f \pmod{2^{a-1}j}$ and $0\le s<2^{a-1}j$, also $s=f\bmod 2^{a-1}j$, which is less than $j$ by the induction hypothesis (as $2^{a-1}j\le n$). $\square$

Now let $n\ge N:=2^{10}\cdot1013=1037312$. The lemma with $j=1$, $a=10$ gives $f\bmod 1024<1$, so $f=1024u$ for an integer $u$. The lemma with $j=1013$, $a=10$ gives $f\bmod(1024\cdot1013)<1013$. But $f\bmod (1024\cdot 1013)=1024\,(u\bmod 1013)$, so $1024\,(u\bmod1013)<1013$, which forces $u\bmod 1013=0$. Hence $1024\cdot1013\mid f$, and in particular $2026=2\cdot1013$ divides $f(n)$ for every $n\ge N$.

Problem 3

Algebra · LPS VII, Chapter 30: Functional Equations: Core Olympiad Methods

Let $\mathbb{R}$ be the set of real numbers. Determine all functions $f:\mathbb{R}\to\mathbb{R}$ such that for all real numbers $x,y$, the following holds: \[f\left((f(x)+f(y))^2\right)=(x+y)f(x+y).\]

Show the answer

$f(x)=0$, $f(x)=x$ and $f(x)=-x$

Show the 2 solutions

Solution 1 (Zeros, injectivity, additivity)

All three functions work: for $f\equiv0$ both sides are $0$; for $f(x)=\varepsilon x$ with $\varepsilon=\pm1$ the left side is $\varepsilon(\varepsilon x+\varepsilon y)^2=\varepsilon(x+y)^2$ and so is the right side. Conversely let $f$ be a solution, write $P(x,y)$ for the equation, $c=f(0)$ and $g(t)=tf(t)$. Note that if $f$ is a solution, so is $-f$ (both sides change sign).

Step 1: $f(0)=0$. $P(0,0)$ gives $f(4c^2)=0$, and then $P(4c^2,0)$ gives $f(c^2)=4c^2f(4c^2)=0$. If $z_1,z_2$ are zeros of $f$, then $P(z_1,y)$ and $P(z_2,y)$ have the same left side $f(f(y)^2)$, so $g(z_1+y)=g(z_2+y)$ for all $y$: $z_1-z_2$ is a period of $g$. Thus $d=3c^2$ is a period of $g$. If $c\ne0$, then $d>0$ and $g(kd)=g(0)=0$, i.e. $f(kd)=0$ for every integer $k\ne0$; now $P(d,d)$ reads $f(0)=2d\,f(2d)=0$, a contradiction. So $c=0$.

Step 2: two identities. $P(x,0)$ gives \[f\bigl(f(x)^2\bigr)=xf(x)\quad\text{for all }x. \tag{1}\] If $z$ is a zero of $f$, $P(z,y)$ and (1) give \[(z+y)f(z+y)=yf(y)\quad\text{for all }y. \tag{2}\] Also, if $f(a)=f(b)\ne0$, then by (1) $af(a)=f(f(a)^2)=f(f(b)^2)=bf(b)$, so $a=b$. (3)

Step 3: either $f\equiv0$ or $0$ is the only zero. Suppose $f(z)=0$ with $z\ne0$, and $f(x_0)\ne0$ for some $x_0$ (so $x_0\ne0$). By (2) with $y=x_0$, $w:=z+x_0$ satisfies $wf(w)=x_0f(x_0)\ne0$. By (1), $f(f(w)^2)=wf(w)=x_0f(x_0)=f(f(x_0)^2)$, a non-zero value, so by (3) $f(w)^2=f(x_0)^2$. With $f(w)=x_0f(x_0)/w$ this gives $w^2=x_0^2$, and $w\ne x_0$, so $w=-x_0$, i.e. $z=-2x_0$. Thus every non-zero zero equals $-2x_0$. But (2) with $y=z$ gives $2zf(2z)=zf(z)=0$, so $2z$ is another non-zero zero, and $2z=-2x_0=z$ is impossible. Hence, if $f\not\equiv0$, then $f(x)=0\iff x=0$, and (3) shows that $f$ is injective. From now on assume this.

Step 4: $f$ is odd and additive. By (1) at $x+y$ and $P(x,y)$, $f\bigl(f(x+y)^2\bigr)=f\bigl((f(x)+f(y))^2\bigr)$, so by injectivity \[f(x+y)=\pm\bigl(f(x)+f(y)\bigr)\quad\text{for all }x,y. \tag{4}\] $P(x,-x)$ gives $f\bigl((f(x)+f(-x))^2\bigr)=0$, so $f(-x)=-f(x)$. Suppose $f(x+y)=-(f(x)+f(y))$ with $f(x)+f(y)\ne0$. Applying (4) to the numbers $x+y$ and $-y$: $f(x)=\pm(f(x+y)-f(y))=\pm(-f(x)-2f(y))$. The sign $+$ gives $f(x)+f(y)=0$; the sign $-$ gives $f(y)=0$, so $y=0$ and $f(x)=f(x+y)=-f(x)$, again $f(x)+f(y)=0$. Both contradict the assumption, so $f(x+y)=f(x)+f(y)$ for all $x,y$. In particular $f(qt)=qf(t)$ for rational $q$.

Step 5: $f(x)=\pm x$. Apply (1) to $x+y$ and expand with additivity: $f(f(x)^2)+f(f(y)^2)+2f(f(x)f(y))=xf(x)+yf(y)+xf(y)+yf(x)$, so by (1) \[2f\bigl(f(x)f(y)\bigr)=xf(y)+yf(x). \tag{5}\] Let $k=f(1)\ne0$. With $x=y=1$, (5) gives $f(k^2)=k$; with $y=1$, $2f(kf(x))=kx+f(x)$; and with $x=k^2$ in the latter, $2k=k^3+k$, so $k^2=1$. Replacing $f$ by $-f$ if necessary (also a non-zero solution), we may assume $k=1$, so \[2f(f(x))=x+f(x)\quad\text{for all }x. \tag{6}\] Fix $x$ and put $v=f(x)-x$. By (6), $f(v)=f(f(x))-f(x)=-v/2$. By (1) at $v$, $f(v^2/4)=v\cdot(-v/2)$, i.e. $f(w)=-2w$ for $w=v^2$. Then $f(f(w))=f(-2w)=4w$, while (6) gives $f(f(w))=(w+f(w))/2=-w/2$. So $w=0$, $v=0$ and $f(x)=x$.

Hence the solutions are \[\boxed{f\equiv0,\qquad f(x)=x,\qquad f(x)=-x}\]

Solution 2 (Infinitely many preimages, then a derivation)

All three functions work: for $f\equiv0$ both sides are $0$; for $f(x)=\varepsilon x$ with $\varepsilon=\pm1$ the left side is $\varepsilon(\varepsilon x+\varepsilon y)^2=\varepsilon(x+y)^2$ and so is the right side. Conversely, let $f$ be a solution that is not identically zero. Write $P(x,y)$ for the equation and $g(t)=tf(t)$.

Step 1: equal values are zero. If $f(a)=f(b)$, then $P(a,y)$ and $P(b,y)$ have the same left side, so $g(a+y)=g(b+y)$ for all $y$: the number $a-b$ is a period of $g$. With $y=0$ this gives $af(a)=bf(b)=bf(a)$, so $(a-b)f(a)=0$. Hence \[f(a)=f(b),\ a\ne b\ \Longrightarrow\ f(a)=f(b)=0. \tag{1}\]

Step 2: $f$ is injective. Suppose $f(a)=f(b)$ with $a\ne b$. By Step 1, $T=a-b\ne0$ is a period of $g$, so $Tf(T)=g(T)=g(0)=0$ and $f(T)=0$. Then $P(w,T)$ reads \[f\bigl(f(w)^2\bigr)=g(w+T)=g(w)\qquad\text{for all }w. \tag{2}\] The function $g$ is not identically zero: otherwise $f(x)=0$ for all $x\ne0$, and $P(1,-1)$ gives $f(0)=f\bigl((f(1)+f(-1))^2\bigr)=0\cdot f(0)=0$, so $f\equiv0$, which we excluded. Choose $x_0$ with $c_0=g(x_0)\ne0$. For every integer $k$ the number $w_k=x_0+kT$ satisfies $g(w_k)=c_0\ne0$, so $w_k\ne0$, $f(w_k)=c_0/w_k$, and by (2) \[f\Bigl(\frac{c_0^2}{w_k^2}\Bigr)=c_0.\] The numbers $w_k$ are pairwise distinct, and each value of $w_k^2$ occurs for at most two of them; so the arguments $c_0^2/w_k^2$ take infinitely many different values, all with the same non-zero image $c_0$. This contradicts (1). So $f$ is injective.

Step 3: $f$ is odd and additive. Let $c=f(0)$. $P(0,0)$ gives $f(4c^2)=0$, and then $P(4c^2,0)$ gives $f(c^2)=4c^2f(4c^2)=0$. By injectivity $4c^2=c^2$, so $c=0$. Now $P(x,-x)$ gives $f\bigl((f(x)+f(-x))^2\bigr)=0=f(0)$, so $f(-x)=-f(x)$. Comparing $P(x,y)$ with $P(x+y,0)$, whose right sides are both $(x+y)f(x+y)$, injectivity gives \[f(x+y)^2=\bigl(f(x)+f(y)\bigr)^2\qquad\text{for all }x,y. \tag{3}\] Fix $x,y$ and suppose $f(x+y)=-(f(x)+f(y))$. Applying (3) to the numbers $x+y$ and $-y$ and using oddness, $f(x)^2=\bigl(f(x+y)-f(y)\bigr)^2=\bigl(f(x)+2f(y)\bigr)^2$, so $4f(y)\bigl(f(x)+f(y)\bigr)=0$. If $f(y)=0$, then $y=0$ and $f(x+y)=f(x)=f(x)+f(y)$; if $f(x)+f(y)=0$, then $f(x+y)=0=f(x)+f(y)$. In every case $f(x+y)=f(x)+f(y)$: $f$ is additive. In particular $f(2t)=2f(t)$.

Step 4: a product identity. $P(x,0)$ gives $f\bigl(f(x)^2\bigr)=xf(x)$. Apply this to $x+y$ and expand with additivity: \[f\bigl(f(x)^2\bigr)+2f\bigl(f(x)f(y)\bigr)+f\bigl(f(y)^2\bigr)=(x+y)\bigl(f(x)+f(y)\bigr),\] and the two outer terms on the left are $xf(x)$ and $yf(y)$. Hence \[2f\bigl(f(x)f(y)\bigr)=xf(y)+yf(x)\qquad\text{for all }x,y. \tag{4}\]

Step 5: $f$ is bijective, and a formula for its inverse. Let $d=f(1)$; $d\ne0$ because $f(0)=0$ and $f$ is injective. Putting $y=1$ in (4) gives $dx=2f(df(x))-f(x)=f\bigl(2df(x)-x\bigr)$ by additivity. As $x$ runs over $\mathbb R$, so does $dx$; hence $f$ is surjective, so bijective. Let $F$ be its inverse function. For any reals $u,v$ put $x=F(u)$, $y=F(v)$ in (4): \[2f(uv)=F(u)\,v+F(v)\,u. \tag{5}\] With $u=v=1$ this gives $F(1)=f(1)=d$, and then $v=1$ gives $F(u)=2f(u)-du$. Substituting this into (5) and dividing by $2$, \[f(uv)=vf(u)+uf(v)-duv.\]

Step 6: $f(x)=\pm x$. Let $D(u)=f(u)-du$. Then $D$ is additive, and the last identity becomes \[D(uv)=uD(v)+vD(u)\qquad\text{for all }u,v. \tag{6}\] With $u=v=1$, $D(1)=2D(1)$, so $D(1)=0$. Also $F(u)=2f(u)-du=du+2D(u)$ and $f(w)=dw+D(w)$. Using additivity and (6) for $D(du)$, \[\begin{aligned}u=f\bigl(F(u)\bigr)&=d\bigl(du+2D(u)\bigr)+D(du)+2D\bigl(D(u)\bigr)\\&=d^2u+2dD(u)+uD(d)+dD(u)+2D\bigl(D(u)\bigr),\end{aligned}\] that is, \[\bigl(d^2+D(d)-1\bigr)u+3dD(u)+2D\bigl(D(u)\bigr)=0\qquad\text{for all }u.\] At $u=1$ (where $D(1)=0$ and $D(0)=0$) this gives $d^2+D(d)-1=0$, so \[E(u):=2D\bigl(D(u)\bigr)+3dD(u)=0\qquad\text{for all }u.\] By (6), $D(u^2)=2uD(u)$, and, using additivity and (6) again, $D\bigl(D(u^2)\bigr)=2D\bigl(uD(u)\bigr)=2uD\bigl(D(u)\bigr)+2D(u)^2$. Therefore \[0=E(u^2)=4uD\bigl(D(u)\bigr)+4D(u)^2+6duD(u)=2u\,E(u)+4D(u)^2=4D(u)^2.\] So $D\equiv0$ and $f(u)=du$. Then $D(d)=0$, and $d^2+D(d)-1=0$ gives $d^2=1$: $f(x)=x$ or $f(x)=-x$.

Hence the solutions are \[\boxed{f\equiv0,\qquad f(x)=x,\qquad f(x)=-x}\]

Day 2

Problem 4

Algebra · LPS VII, Chapter 17: Sequences, Recurrences, and Discrete Dynamics

Let $1=a_1\ge a_2\ge a_3\ge\dots$ be an infinite sequence of real numbers such that $a_n=a_{2n}+a_{2n+1}$ for all positive integers $n$. For $r=2026^{2026}$, prove that \[\frac{1}{r}\le a_r\le\frac{2}{r+1}.\]

Show the solution

Solution (A sliding window of total $1$)

We prove $\frac1r\le a_r\le\frac2{r+1}$ for every positive integer $r$; $r=2026^{2026}$ is a special case.

Claim. $S_r:=a_r+a_{r+1}+\dots+a_{2r-1}=1$ for every $r\ge1$.

Indeed $S_1=a_1=1$, and $S_{r+1}=S_r-a_r+a_{2r}+a_{2r+1}=S_r$ because $a_r=a_{2r}+a_{2r+1}$.

Lower bound. The sequence is non-increasing, so each of the $r$ terms of $S_r$ is at most $a_r$: $1=S_r\le ra_r$.

Upper bound. From $a_r=a_{2r}+a_{2r+1}\le 2a_{2r}$ we get $a_{2r}\ge a_r/2$. For $r\le i\le 2r-1$ we have $a_i\ge a_{2r-1}\ge a_{2r}\ge a_r/2$. Hence \[1=S_r\ge a_r+(r-1)\cdot\frac{a_r}{2}=\frac{r+1}{2}\,a_r,\] that is, $a_r\le\frac2{r+1}$. With $r=2026^{2026}$ this is the required inequality.

Remark (another view of the Claim). Regard the indices as a binary tree in which $i$ has the children $2i$ and $2i+1$; the relation $a_i=a_{2i}+a_{2i+1}$ splits the value at $i$ between its children. For an index $i\ge r$, exactly one of $i,\lfloor i/2\rfloor,\lfloor i/4\rfloor,\dots$ lies in $\{r,\dots,2r-1\}$: the first term below $2r$ is still at least $r$ (it is $i$ itself, or half of a number $\ge2r$), and the next one is below $r$. So the window $\{r,\dots,2r-1\}$ cuts every path from the root $1$ downwards exactly once, and the value $a_1=1$ is shared out exactly over it.

Problem 5

Geometry · LPS VII, Chapter 15: Circles, Power, and Radical Structure

Let $ABC$ be an acute triangle with $AC>AB$. Denote by $\omega$ its circumcircle and by $O$ its circumcentre. Let $K$ be the intersection of the tangents to $\omega$ at $B$ and $C$. Circle $ABK$ intersects line $BC$ again at $Z\ne B$. Let $L$ be the midpoint of $KZ$. Let $X$ be the intersection of the lines $KZ$ and $AB$. Let $V$ be the point on circle $ABL$ on the same side of $BC$ as $A$ such that $OV$ is perpendicular to $KZ$. Prove that $LV$ is perpendicular to $CX$.

Show the 3 solutions

Solution 1 ($L$ lies on $AC$, and $V$ is the antipode of $L$)

Let $\alpha,\beta,\gamma$ be the angles of $ABC$, let $\Gamma$ be the circle $ABL$, $N$ the midpoint of $BC$ and $S$ the midpoint of $BK$. We write $\measuredangle(p,q)$ for the directed angle between lines $p,q$ (modulo $180^\circ$). Recall $KB=KC$, $\angle KBC=\angle KCB=\alpha$, and $K$ lies on the other side of $BC$ from $A$, inside the angle $BAC$: since $\angle ABK=\alpha+\beta<180^\circ$ and $\angle ACK=\alpha+\gamma<180^\circ$, $K$ is on the same side of $AB$ as $C$ and on the same side of $AC$ as $B$ (indeed $AK$ is the $A$-symmedian).

Step 1: $Z$ lies beyond $C$. In triangle $ABK$, $\angle ABK=\beta+\alpha$, so $\angle AKB=\gamma-\angle BAK<\gamma=\angle ACB$. As $C$ and $K$ lie on the same side of $AB$, $C$ is inside the circle $ABK$; so line $BC$ leaves this circle at a point $Z$ on ray $BC$ beyond $C$. Hence $KZ>KC=KB$, and $A$, $Z$ lie on the same side of the tangent $BK$, so $\angle CZK=\angle BZK=\angle BAK$.

Step 2: $L\in AC$. Since $K$ and $B$ are on the same side of $AC$ and $Z,B$ on opposite sides, line $AC$ meets segment $KZ$ at a point $L'$; it lies on the other side of $BC$ from $A$, so on ray $AC$ beyond $C$. In triangle $KCZ$: $\angle KCZ=180^\circ-\alpha$, $\angle CZK=\angle BAK$, so $\angle ZKC=\alpha-\angle BAK=\angle KAC$; also $\angle KCL'=180^\circ-\angle KCA=180^\circ-(\alpha+\gamma)=\beta$ and $\angle L'CZ=\gamma$. By the law of sines in $KCL'$, $ZCL'$ and $KCZ$, \[\frac{KL'}{L'Z}=\frac{CK\sin\beta}{CZ\sin\gamma}=\frac{\sin\angle BAK}{\sin\angle KAC}\cdot\frac{\sin\beta}{\sin\gamma}.\] In triangles $ABK$, $ACK$ (with $KB=KC$) the law of sines gives $\frac{\sin\angle BAK}{\sin\angle KAC}=\frac{\sin\angle ABK}{\sin\angle ACK} =\frac{\sin(\alpha+\beta)}{\sin(\alpha+\gamma)}=\frac{\sin\gamma}{\sin\beta}$. So $KL'=L'Z$, i.e. $L'=L$: the midpoint $L$ of $KZ$ lies on $AC$.

Step 3: $S\in\Gamma$. $SL$ is a midline of triangle $KBZ$, so $SL\parallel BC$. Hence $\measuredangle(SB,SL)=\measuredangle(BK,BC) =\measuredangle(AB,AC)=\measuredangle(AB,AL)$ (tangent–chord angle), so $A,B,S,L$ are concyclic.

Step 4: the foot $H$ of the perpendicular from $O$ to $KZ$ lies on $\Gamma$. The circle $\kappa$ with diameter $OK$ passes through $B$, $C$ (right angles at $B$, $C$) and $H$. The power of $Z$ with respect to $\kappa$ gives $ZH\cdot ZK=ZB\cdot ZC=NZ^2-NB^2$, hence \[KH\cdot KZ=KZ^2-ZH\cdot ZK=(KN^2+NZ^2)-(NZ^2-NB^2)=KB^2.\] So $KH=KB^2/KZ<KB<KZ$: $H$ lies strictly between $K$ and $Z$, on the other side of $BC$ from $A$. Moreover $KH\cdot KL=\tfrac12KB^2=KS\cdot KB$, so $S,B,H,L$ are concyclic, i.e. $H\in\Gamma$.

Step 5: $V$ is the antipode $L^*$ of $L$ on $\Gamma$. The line through $O$ perpendicular to $KZ$ is the line $OH$. It meets $\Gamma$ at $H$ and at one more point $P$, and $\angle LHP=90^\circ$, so $LP$ is a diameter: $P=L^*$ (if $H=L$, the line is perpendicular to the tangent $KZ$ at $L$ and again passes through the antipode). Since $H$ is not on $A$'s side of $BC$, the point $V$ of the statement is $L^*$. Consequently $\angle LBV=90^\circ$.

Step 6: $LV\perp CX$. Let $Y$ be the second intersection of line $BL$ with $\omega$; $Y\ne B$, because $BL$ is not the tangent $BK$ ($L$ lies on line $KZ$, which meets line $BK$ only at $K\ne L$). Pascal's theorem for the hexagon $BBYCCA$ inscribed in $\omega$ says that $BB\cap CC=K$, $BY\cap CA=L$ and $YC\cap AB$ are collinear; so $YC\cap AB$ lies on $KL$ and on $AB$, i.e. it is $X$: the points $C,X,Y$ are collinear. Now, using $\Gamma$ (chord $VA$), then $\angle VBL=90^\circ$, then $\omega$ (chord $YA$): \[\measuredangle(LV,CX)=\measuredangle(LV,LA)+\measuredangle(CA,CY)=\measuredangle(BV,BA)-\measuredangle(CY,CA) =90^\circ+\measuredangle(BY,BA)-\measuredangle(BY,BA)=90^\circ.\] Hence $LV\perp CX$.

Solution 2 (Coordinates)

Put $B=(-1,0)$, $C=(1,0)$, $O=(0,t)$ with $t>0$ (the triangle is acute), so $\omega$ has equation $x^2+y^2-2ty=1$. Since $\overrightarrow{OB}\cdot\overrightarrow{BK}=0$ for $K=(0,-1/t)$, this is the point $K$. Let $s=\tan\angle ABC>0$; then $A=B+\lambda(1,s)$ with $\lambda=\frac{2(1+st)}{1+s^2}$ (the second intersection of the line $y=s(x+1)$ with $\omega$): \[A=\Bigl(\frac{1+2st-s^2}{1+s^2},\ \frac{2s(1+st)}{1+s^2}\Bigr).\] Abbreviate $P=3st^2+s+2t$, $Q=4st^3+2st+3t^2+1$ (both positive).

$Z$ and $L$. A circle through $B$ and $(z,0)$ has an equation $x^2+y^2-(z-1)x+ey-z=0$; passing through $K$ forces $e=\frac1t-zt$, and passing through $A$ then gives \[Z=(z,0),\quad z=\frac{2st^2+s+t}{t(st+1)},\qquad L=\Bigl(\frac z2,\,-\frac1{2t}\Bigr).\]

$X$. Intersecting line $KZ$ (direction $(z,\frac1t)$) with line $AB$ gives \[X=\Bigl(-\frac{(st+1)(2st^2+s+t)}{t(2s^2t^2+s^2-1)},\ -\frac{sP}{t(2s^2t^2+s^2-1)}\Bigr),\qquad X-C=\frac{-s}{t(2s^2t^2+s^2-1)}\,(Q,\ P).\]

$\Gamma$ and $V$. Solving for the circle through $A,B,L$ gives \[\Gamma:\ x^2+y^2-\frac{s(t^2+1)}{2t(st+1)}\,x-\frac{4st^3+3t^2-1}{2t(st+1)}\,y-\frac{P}{2t(st+1)}=0.\] Let $V_0=\bigl(-\tfrac12,\ \frac{4st^2+s+3t}{2(st+1)}\bigr)$. Then $V_0-O=\bigl(-\frac12,\frac{tz}2\bigr)$ is perpendicular to the direction $(z,\frac1t)$ of $KZ$, and substituting $V_0$ into the equation of $\Gamma$ gives $0$ (direct expansion), so $V_0\in\Gamma$; its $y$-coordinate is positive, so it is on $A$'s side of $BC$. The other point of $\Gamma$ on this line is the foot $H$ of the perpendicular from $O$ to $KZ$, whose $y$-coordinate $-\frac{sP}{t((2st+1)^2+s^2)}$ is negative. Hence $V=V_0$.

Conclusion. $V-L=\frac{1}{2t(st+1)}\,(-P,\ Q)$, so \[(V-L)\cdot(X-C)=\frac{-s}{2t^2(st+1)(2s^2t^2+s^2-1)}\bigl(-PQ+QP\bigr)=0,\] i.e. $LV\perp CX$. (The point $X$ exists, so $2s^2t^2+s^2-1\ne0$.)

Solution 3 (Powers of points along the line $KZ$)

Let $\alpha,\beta,\gamma$ be the angles of $ABC$, $R$ the radius of $\omega$, $N$ the midpoint of $BC$, $\Gamma$ the circle $ABL$, $Q$ the foot of the perpendicular from $O$ to line $KZ$, and $D$ the midpoint of $ZC$. Recall that $KB=KC$, $KN\perp BC$, $\angle KBC=\angle KCB=\alpha$ (tangent–chord angle), and, as the triangle is acute, $A$ and $K$ lie on opposite sides of $BC$. For a point $P$ and a circle we use the power of $P$: $PO_1^2-r^2$ for a circle with centre $O_1$ and radius $r$; if a line through $P$ meets the circle at $U,W$, it equals the signed product $PU\cdot PW$.

Step 1: $Z$ lies beyond $C$. Since $\angle ABC+\angle CBK=\beta+\alpha<180^\circ$, the ray $BC$ lies inside the angle $ABK$, so $C$ and $K$ are on the same side of $AB$. In triangle $ABK$, $\angle AKB=180^\circ-(\alpha+\beta)-\angle BAK=\gamma-\angle BAK<\gamma=\angle ACB$. So $C$ lies inside the circle $ABK$, and line $BC$ leaves this circle at a point $Z$ of ray $BC$ beyond $C$. In particular $Z\ne N$, so $KZ$ is not perpendicular to $BC$.

Step 2: coordinates on line $KZ$. Take $KZ$ as the unit of length, and give each point $P$ of line $KZ$ the coordinate $w$ with $\overrightarrow{ZP}=w\,\mathbf e$, where $\mathbf e$ is the unit vector from $Z$ towards $K$. So $Z$, $L$, $K$ have coordinates $0$, $\tfrac12$, $1$; let $q$ and $x$ be the coordinates of $Q$ and $X$.

The powers of $Z$ and $K$ with respect to $\omega$ are $ZB\cdot ZC=ZN^2-NB^2$ (as $B,C$ lie on the same side of $Z$) and $KB^2=KN^2+NB^2$; their sum is $ZN^2+KN^2=KZ^2=1$. For the point $P$ with coordinate $w$, $OP^2=(w-q)^2+OQ^2$, so its power is $w^2-2qw+\bigl(q^2+OQ^2-R^2\bigr)$, and the bracket is the power of $Z$. Adding the powers of $Z$ ($w=0$) and $K$ ($w=1$) gives $1=1-2q+2\,ZB\cdot ZC$, so \[q=ZB\cdot ZC,\qquad KB^2=KC^2=1-q,\qquad\text{power of }P\text{ w.r.t. }\omega=w^2-2qw+q.\] As both powers are positive, $0<q<1$: $Q$ lies strictly between $Z$ and $K$, on the same side of $BC$ as $K$.

Step 3: the point $X$. The circle $ABK$ passes through $Z$ and $K$, so the power of $P$ with respect to it is $PZ\cdot PK=w(w-1)$. The point $X$ lies on line $AB$, so its powers with respect to $\omega$ and to circle $ABK$ both equal $XA\cdot XB$. Hence $x^2-2qx+q=x^2-x$, that is, \[(2q-1)\,x=q.\] Since $X$ exists, $q\ne\tfrac12$. Also $x\ne\tfrac12$ (otherwise $q-\tfrac12=q$).

Step 4: $Q$ and $D$ lie on $\Gamma$. Line $KZ$ meets $\Gamma$ at $L$ and at a second point $W$ (with $W=L$ if the line is tangent); let $w_0$ be its coordinate. The power of $X$ with respect to $\Gamma$ is $(x-\tfrac12)(x-w_0)$, and also $XA\cdot XB=x(x-1)$. On the other hand, by Step 3, \[\bigl(x-\tfrac12\bigr)(x-q)=x^2-x-\bigl(q-\tfrac12\bigr)x+\tfrac q2=x^2-x.\] As $x\ne\tfrac12$, the equation $(x-\frac12)(x-w_0)=x(x-1)$ determines $w_0$, so $w_0=q$: the point $Q$ lies on $\Gamma$, and $Q\ne L$.

The power of $Z$ with respect to $\Gamma$ is $ZL\cdot ZQ=\tfrac q2>0$. Line $BC$ meets $\Gamma$ at $B$ and at a second point $D'$ with $ZB\cdot ZD'=\tfrac q2=\tfrac12\,ZB\cdot ZC$; so $D'$ lies on ray $ZB$ with $ZD'=\tfrac12ZC$, i.e. $D'=D$. Thus $D\in\Gamma$.

Step 5: $V$ is the antipode of $L$ on $\Gamma$. The line through $O$ perpendicular to $KZ$ is line $OQ$. It is not parallel to $BC$ (Step 1), so it meets $BC$ at a point $T$; in the right triangle $ZQT$, $ZT=ZQ/\cos\angle KZN=q\cdot\frac{ZK}{ZN}=\frac{ZN^2-NB^2}{ZN}$, with $T$ on ray $ZN$. Since $0<NB<ZN$, \[ZC=ZN-NB<ZN-\frac{NB^2}{ZN}=ZT<ZN+NB=ZB,\] so $T$ lies strictly between $C$ and $B$, hence strictly inside the chord $DB$ of $\Gamma$, i.e. inside $\Gamma$. Therefore line $OQ$ meets $\Gamma$ at $Q$ and at one more point, on the other side of $T$. As $Q$ is strictly on $K$'s side of $BC$, that point is strictly on $A$'s side, so it is $V$. Since $\angle LQV=90^\circ$ and $Q,L,V$ are distinct points of $\Gamma$, the segment $LV$ is a diameter of $\Gamma$. The point $D$ lies on $BC$ while $L$ and $V$ do not, so $D\ne L,V$ and $\angle LDV=90^\circ$.

Step 6: $LV\perp CX$. In triangle $ZKC$, $L$ and $D$ are the midpoints of $ZK$ and $ZC$, so $\overrightarrow{LD}=\tfrac12\overrightarrow{KC}$. Since $\overrightarrow{DV}\perp\overrightarrow{LD}$, we get $\overrightarrow{LV}\cdot\overrightarrow{LD}=LD^2$, and so \[\overrightarrow{LV}\cdot\overrightarrow{KC}=2\,\overrightarrow{LV}\cdot\overrightarrow{LD}=2LD^2=\tfrac12KC^2=\tfrac{1-q}2.\] The projection of $V$ onto line $KZ$ is $Q$, so $\overrightarrow{LV}\cdot\mathbf e=q-\tfrac12$, while $\overrightarrow{KX}=(x-1)\,\mathbf e$ with $x-1=\frac{q}{2q-1}-1=\frac{1-q}{2q-1}$. Hence \[\overrightarrow{LV}\cdot\overrightarrow{KX}=\frac{1-q}{2q-1}\Bigl(q-\frac12\Bigr)=\frac{1-q}2,\qquad \overrightarrow{LV}\cdot\overrightarrow{XC}=\overrightarrow{LV}\cdot\overrightarrow{KC}-\overrightarrow{LV}\cdot\overrightarrow{KX}=0.\] As $L\ne V$ and $X\ne C$ ($X$ lies on line $KZ$, which meets line $BC$ only at $Z\ne C$), this means $LV\perp CX$.

Problem 6

Number Theory · LPS VII, Chapter 21: Arithmetic Functions and Multiplicative Structure

Let $p$ be a prime number and let $n$ be a positive integer such that $p$ does not divide $n$. Denote by $k$ the number of positive divisors of $n$, and by $1=d_1<d_2<\cdots<d_k=n$ the positive divisors of $n$. For $i=1,2,\dots,k$, let $c_i$ be the number of positive divisors $\ell$ of $d_i^2$ such that $d_i-\ell$ is divisible by $p$. Prove that \[(p-1)(c_1+c_2+\cdots+c_k)\ge k^2.\]

Show the 2 solutions

Solution 1 (A bijection and Cauchy–Schwarz)

Let $D$ be the set of positive divisors of $n$, so $|D|=k$; all of them, and all divisors of $n^2$, are prime to $p$.

Claim. $c_1+\dots+c_k=T$, where $T$ is the number of ordered pairs $(u,v)\in D^2$ with $u\equiv v\pmod p$.

The left side counts pairs $(d,\ell)$ with $d\in D$, $\ell\mid d^2$, $\ell\equiv d\pmod p$. Map such a pair to \[(u,v)=\bigl(\gcd(\ell,d),\ \gcd(d^2/\ell,d)\bigr).\] Look at one prime $q\mid n$; let $q^j\,\|\,d$ and $q^t\,\|\,\ell$, $0\le t\le 2j$. The exponents of $q$ in $u,v$ are $\min(t,j)$ and $\min(2j-t,j)$: one of them equals $j$, and their difference is $t-j$. Hence $d=\operatorname{lcm}(u,v)$ and $\ell\,v=d\,u$. Conversely, for any $(u,v)\in D^2$ put $d=\operatorname{lcm}(u,v)\in D$ and $\ell=d\,u/v$: if $q$ has exponents $a,b$ in $u,v$, then $\ell$ has exponent $\max(a,b)+a-b\in[0,2\max(a,b)]$, so $\ell\mid d^2$, and the formulas above return $(u,v)$. So the map is a bijection between the pairs $(d,\ell)$ with $\ell\mid d^2$ and $D^2$. Finally, $\ell v=du$ and $d,v$ are invertible modulo $p$, so $\ell\equiv d\iff d\,u\equiv d\,v\iff u\equiv v\pmod p$. This proves the claim.

Conclusion. For a residue $r\in\{1,\dots,p-1\}$ let $m_r$ be the number of divisors of $n$ congruent to $r$; then $\sum_r m_r=k$ and $T=\sum_r m_r^2$. By the Cauchy–Schwarz inequality, \[k^2=\Bigl(\sum_{r=1}^{p-1}m_r\Bigr)^2\le(p-1)\sum_{r=1}^{p-1}m_r^2=(p-1)(c_1+\dots+c_k).\]

Solution 2 (Characters modulo $p$)

We use the $p-1$ Dirichlet characters $\chi$ modulo $p$ (the homomorphisms $(\mathbb Z/p)^\times\to\mathbb C^\times$, extended to integers prime to $p$). Their orthogonality relation states that for integers $a,b$ prime to $p$ \[\frac1{p-1}\sum_\chi\chi(a)\overline{\chi(b)}=\begin{cases}1,&a\equiv b\pmod p,\\0,&\text{otherwise.}\end{cases}\] Hence, writing $c(d)$ for the number of divisors $\ell$ of $d^2$ with $\ell\equiv d$, \[(p-1)\sum_{d\mid n}c(d)=\sum_\chi\ \sum_{d\mid n}\overline{\chi(d)}\sum_{\ell\mid d^2}\chi(\ell).\] Fix $\chi$. The inner function $d\mapsto\overline{\chi(d)}\sum_{\ell\mid d^2}\chi(\ell)$ is multiplicative (for coprime $d,d'$ the divisors of $(dd')^2$ are the products $\ell\ell'$ with $\ell\mid d^2$, $\ell'\mid d'^2$, and $\chi$ is multiplicative), so the sum over $d\mid n=\prod q^{e_q}$ factors over the primes. For one prime $q$, with $z=\chi(q)$ (a root of unity, so $\bar z=z^{-1}$), the factor is \[\sum_{j=0}^{e}z^{-j}\sum_{i=0}^{2j}z^{i}=\sum_{j=0}^{e}\ \sum_{i=-j}^{j}z^{i}=\sum_{i=-e}^{e}(e+1-|i|)\,z^i=\Bigl|\sum_{a=0}^{e}z^a\Bigr|^2,\] the last step because $\bigl|\sum_a z^a\bigr|^2=\sum_{a,b=0}^{e}z^{a-b}$ and exactly $e+1-|i|$ pairs $(a,b)$ have $a-b=i$. Multiplying over the primes and using multiplicativity of $\chi$, the contribution of $\chi$ is $\bigl|\sum_{d\mid n}\chi(d)\bigr|^2\ge0$. Keeping only the trivial character $\chi_0$ (with $\chi_0(d)=1$), whose contribution is $k^2$, \[(p-1)(c_1+\dots+c_k)=\sum_\chi\Bigl|\sum_{d\mid n}\chi(d)\Bigr|^2\ge k^2.\]
