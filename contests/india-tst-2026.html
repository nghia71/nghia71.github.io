Problem 1

Number Theory · LPS VII, Chapter 49: Combinatorial Number Theory and Structure

Let $a_1,a_2,a_3,\dots$ be a strictly increasing sequence of positive integers such that $a_ia_{i+1}-1$ is a perfect square for each positive integer $i$. Find the minimum possible value of $a_{46}$.

Show the answer

$2026$

Show the 2 solutions

Solution 1 (A jump lemma for consecutive terms)

Lemma. If $1\le a<b$ are integers and $ab-1=c^2$ for an integer $c\ge 0$, then \[\sqrt{b-1}\ \ge\ \sqrt{a-1}+1 .\]

Proof. Since $c^2=ab-1\ge a(a+1)-1\ge a^2$, we have $c\ge a$; write $c=a+t$ with an integer $t\ge 0$. Put $d=b-a\ge 1$. Then \[a(a+d)=ab=c^2+1=a^2+2at+t^2+1,\qquad\text{so}\qquad a(d-2t)=t^2+1 .\] Hence $s:=d-2t=\dfrac{t^2+1}{a}$ is a positive integer, so $s\ge 1$ and $t^2=as-1$. Therefore \[b-a=d=2t+s=2\sqrt{as-1}+s\ \ge\ 2\sqrt{a-1}+1,\] because the middle expression increases with $s$. Thus $b-1\ge (a-1)+2\sqrt{a-1}+1=\bigl(\sqrt{a-1}+1\bigr)^2$, which is the lemma. $\square$

Lower bound. Apply the lemma to each pair $a_i<a_{i+1}$ (here $a_ia_{i+1}-1$ is a square). We get $\sqrt{a_{i+1}-1}\ge\sqrt{a_i-1}+1$ for every $i$, and by induction \[\sqrt{a_n-1}\ \ge\ \sqrt{a_1-1}+(n-1)\ \ge\ n-1,\qquad\text{so}\qquad a_n\ge (n-1)^2+1 .\] In particular $a_{46}\ge 45^2+1=2026$.

Construction. Let $a_n=(n-1)^2+1$. This sequence is strictly increasing, and with $m=n-1$, \[a_na_{n+1}-1=(m^2+1)\bigl((m+1)^2+1\bigr)-1=\bigl(m(m+1)+1\bigr)^2,\] which one checks by expanding both sides (both equal $m^4+2m^3+3m^2+2m+1$). So the sequence is admissible and $a_{46}=2026$.

The minimum possible value of $a_{46}$ is $\boxed{2026}$.

Solution 2 (AM-GM bounds the square root)

Lemma. If $1\le a<b$ are integers and $ab-1=c^2$ with an integer $c\ge0$, then $\sqrt{b-1}\ge\sqrt{a-1}+1$.

Proof. By AM-GM, $c^2<ab\le\left(\frac{a+b}2\right)^2$, so $2c<a+b$, and as both sides are integers, $2c\le a+b-1$. Hence $(a+b-1)^2-4c^2\ge0$. Substituting $c^2=ab-1$ and expanding, \[(a+b-1)^2-4(ab-1)=(a-b)^2-2(a+b)+5=(a+b-3)^2-4(a-1)(b-1),\] so $(a+b-3)^2\ge4(a-1)(b-1)$. Since $b\ge2$, $a+b-3\ge0$, and taking square roots gives $a+b-3\ge2\sqrt{(a-1)(b-1)}$. Therefore \[\bigl(\sqrt{b-1}-\sqrt{a-1}\bigr)^2=a+b-2-2\sqrt{(a-1)(b-1)}\ge1,\] and as $b>a$ this means $\sqrt{b-1}\ge\sqrt{a-1}+1$. $\square$

Bound and example. Applying the lemma to each pair $a_i<a_{i+1}$ gives $\sqrt{a_n-1}\ge\sqrt{a_1-1}+(n-1)\ge n-1$, so $a_{46}\ge45^2+1=2026$. The sequence $a_n=(n-1)^2+1$ is strictly increasing and, with $m=n-1$, $a_na_{n+1}-1=(m^2+1)\bigl((m+1)^2+1\bigr)-1=\bigl(m^2+m+1\bigr)^2$ (both sides equal $m^4+2m^3+3m^2+2m+1$). Hence the minimum is $\boxed{2026}$.

Problem 2

Combinatorics · LPS VII, Chapter 52: Advanced Combinatorial Structure and Hybrid Methods

Let $k$ be a positive integer. Find the largest positive integer $n$ such that the cells of an $n\times n$ grid can be filled with positive integers satisfying:

  • Each row and column contains the numbers $1,2,3,\dots,n$ in some order, and

  • The sum of numbers in any two $k\times k$ sub-squares is the same.

Note: A $k\times k$ sub-square is a contiguous $k\times k$ subgrid of the grid consisting of $k^2$ cells that are in $k$ consecutive columns and $k$ consecutive rows.

Show the answer

$n=k^2$

Show the 2 solutions

Solution 1 (Rows k apart differ by a k-periodic vector)

Number the rows and columns $0,1,\dots,n-1$ and write $a(i,j)$ for the entry in row $i$, column $j$. A square with top-left cell $(i,j)$ has sum $W(i,j)=\sum_{x=0}^{k-1}\sum_{y=0}^{k-1}a(i+x,j+y)$, defined for $0\le i,j\le n-k$. Clearly $n\ge k$ is needed for any sub-square to exist. We show that the answer is $n=k^2$.

Construction for $n=k^2$. Write every index $i\in\{0,\dots,k^2-1\}$ in base $k$ as $i=k i_1+i_0$ with $0\le i_0,i_1\le k-1$, and similarly $j=kj_1+j_0$. Put \[a(i,j)=1+k\cdot\bigl((i_0+j_1)\bmod k\bigr)+\bigl((i_1+j_0)\bmod k\bigr).\] For fixed $i$ the map $(j_1,j_0)\mapsto\bigl((i_0+j_1)\bmod k,(i_1+j_0)\bmod k\bigr)$ is a bijection of $\{0,\dots,k-1\}^2$, so row $i$ contains each of $1,\dots,k^2$ exactly once; the same argument works for columns. Now take any $k\times k$ square. Its $k$ rows are consecutive, so their last digits $i_0$ run through all residues mod $k$ exactly once; hence in each column of the square (fixed $j_1$) the "high digit" $(i_0+j_1)\bmod k$ takes every value $0,\dots,k-1$ once. Likewise in each row of the square (fixed $i_1$) the "low digit" $(i_1+j_0)\bmod k$ takes every value once. So every $k\times k$ square has sum \[k^2+k\cdot k\cdot\tfrac{k(k-1)}2+k\cdot\tfrac{k(k-1)}2,\] the same for all squares.

Bound $n\le k^2$. Suppose a valid grid exists with $n\ge k^2+1$.

Step 1. For $0\le i\le n-k$ and $0\le j\le n-k-1$, comparing $W(i,j)$ with $W(i,j+1)$ gives \[\sum_{x=0}^{k-1}a(i+x,j)=\sum_{x=0}^{k-1}a(i+x,j+k).\] Subtracting this equation for $i$ and for $i+1$ (when $i+1\le n-k$) gives, for $0\le i\le n-k-1$ and $0\le j\le n-k-1$, \[a(i+k,j)-a(i,j)=a(i+k,j+k)-a(i,j+k).\] So for each $i\le n-k-1$ the difference $d_i(j)=a(i+k,j)-a(i,j)$ satisfies $d_i(j+k)=d_i(j)$: it depends only on $j\bmod k$.

Step 2. Because $n-1\ge k^2$, the rows $0,k,2k,\dots,k\cdot k$ all exist, and $uk\le (k-1)k\le n-k-1$ for $u\le k-1$. Adding the differences $d_0,d_k,\dots,d_{(t-1)k}$ we get, for $t=0,1,\dots,k$, \[a(tk,j)=a(0,j)+e_t(j\bmod k)\qquad\text{for all }j,\] for some function $e_t$ on the residues mod $k$, with $e_0\equiv 0$.

Step 3. Split the columns into the $k$ classes $C_\gamma=\{j: j\equiv\gamma \pmod k\}$; each class is non-empty because $n\ge k$. Row $tk$ restricted to $C_\gamma$ is row $0$ restricted to $C_\gamma$ shifted by the constant $e_t(\gamma)$, so \[\min_{j\in C_\gamma}a(tk,j)=\min_{j\in C_\gamma}a(0,j)+e_t(\gamma).\] Row $tk$ contains the number $1$, in some class $\gamma(t)$. There are $k+1$ rows $0,k,\dots,k^2$ and only $k$ classes, so two of them, say $t\ne t'$, have $\gamma(t)=\gamma(t')=\gamma$. The minimum over $C_\gamma$ equals $1$ in both rows, so $e_t(\gamma)=e_{t'}(\gamma)$, and then $a(tk,j)=a(t'k,j)$ for every $j\in C_\gamma$. This puts two equal numbers in one column, a contradiction.

Hence $n\le k^2$, and the largest $n$ is $\boxed{k^2}$.

Solution 2 (Where the largest number can sit)

Number the rows and columns $0,1,\dots,n-1$ and write $a(i,j)$ for the entry in row $i$, column $j$. We show that the answer is $n=k^2$.

Construction for $n=k^2$. Write each index in base $k$: $i=ki_1+i_0$ and $j=kj_1+j_0$ with digits $0\le i_0,i_1,j_0,j_1\le k-1$, and put \[a(i,j)=1+k\cdot\bigl((i_0+j_1)\bmod k\bigr)+\bigl((i_1+j_0)\bmod k\bigr).\] In a fixed row the two digits $(i_0+j_1)\bmod k$ and $(i_1+j_0)\bmod k$ determine $j_1$ and $j_0$, so the row contains each of $1,\dots,k^2$ exactly once; the same holds for every column. In any $k\times k$ square the $k$ consecutive rows have pairwise different last digits $i_0$, so in each column of the square the high digit $(i_0+j_1)\bmod k$ runs through $0,\dots,k-1$ once; likewise in each row of the square the low digit $(i_1+j_0)\bmod k$ runs through $0,\dots,k-1$ once. Hence every $k\times k$ square has the same sum $k^2+k\cdot k\cdot\frac{k(k-1)}2+k\cdot\frac{k(k-1)}2$.

Bound. Take a valid grid. If $n<k$ then $n<k^2$, so let $n\ge k$.

Step 1. For $0\le i\le n-k$ and $0\le j\le n-k-1$ the squares with top-left corners $(i,j)$ and $(i,j+1)$ have equal sums; cancelling their common cells gives $\sum_{x=0}^{k-1}a(i+x,j)=\sum_{x=0}^{k-1}a(i+x,j+k)$. Subtracting the same equation for $i+1$ (when $i+1\le n-k$) gives, for $0\le i,j\le n-k-1$, \[a(i,j)-a(i+k,j)=a(i,j+k)-a(i+k,j+k).\] So for each $i\le n-k-1$ the difference $D_i(j)=a(i,j)-a(i+k,j)$ satisfies $D_i(j)=D_i(j+k)$, and therefore $D_i(j)=D_i(j')$ whenever $j\equiv j'\pmod k$.

Step 2: a cross identity. Let $i<i'$ and $j,j'$ be indices with $i\equiv i'$ and $j\equiv j'\pmod k$. Writing $i'=i+uk$, \[a(i,j)-a(i',j)=\sum_{t=0}^{u-1}D_{i+tk}(j)=\sum_{t=0}^{u-1}D_{i+tk}(j')=a(i,j')-a(i',j'),\] where every $D_{i+tk}$ is defined because $i+tk\le i'-k\le n-1-k$. Hence \[a(i,j)+a(i',j')=a(i,j')+a(i',j).\]

Step 3. The number $n$ occurs once in each row; let it sit in column $c_i$ of row $i$. Suppose two rows $i\ne i'$ have $i\equiv i'$ and $c_i\equiv c_{i'}\pmod k$. Since a column contains $n$ only once, $c_i\ne c_{i'}$. Step 2 gives $2n=a(i,c_{i'})+a(i',c_i)$. But row $i$ contains $n$ only in column $c_i\ne c_{i'}$, so $a(i,c_{i'})\le n-1$, and likewise $a(i',c_i)\le n-1$; the right side is at most $2n-2$, a contradiction. Therefore the $n$ pairs $(i\bmod k,\ c_i\bmod k)$ are pairwise different. There are only $k^2$ such pairs, so $n\le k^2$.

Together with the construction, the largest $n$ is $\boxed{k^2}$.

Problem 3

Number Theory · LPS VII, Chapter 54: Advanced Number Theory Synthesis

For a polynomial $P$, a pair of integers $(x,y)$ is called $P$-good if there exists an integer $z$ such that $P(x)P(y)=P(z)$. Determine all monic polynomials $P$ with integer coefficients such that for all positive integers $n$ at least $n^{1.01}$ pairs from the set $\{(a,b)\mid 1\le a,b\le n,\ a,b\in\mathbb{Z}\}$ are $P$-good.

Show the answer

$P=1$ and $P(x)=(x+c)^d$ with $c\in\mathbb Z$ and an integer $d\ge1$

Show the solution

Solution (Approximate roots and few solutions on each line)

We show that the answer is $P=1$ and $P(x)=(x+c)^d$ with $c\in\mathbb Z$, $d\ge1$.

These work. For $P=1$ every pair is good ($1\cdot1=P(z)$ for any $z$). If $P=(x+c)^d$, then for all integers $x,y$ \[P(x)P(y)=\bigl((x+c)(y+c)\bigr)^d=P(z),\qquad z=(x+c)(y+c)-c\in\mathbb Z,\] so all $n^2\ge n^{1.01}$ pairs are good.

Set-up for the converse. Let $P(x)=x^d+a_{d-1}x^{d-1}+\dots$ be monic of degree $d\ge1$ with integer coefficients, put $h=a_{d-1}/d\in\mathbb Q$ and $F(T)=P(T-h)$, so that $P(x)=F(x+h)$ and \[F(T)=T^d+c_{d-2}T^{d-2}+\dots+c_1T+c_0\] has no $T^{d-1}$ term. If $F=T^d$, then $P=(x+h)^d$; here $h$ is a rational root of the monic integer polynomial $t^d-P(0)$, hence an integer, and $P$ is in our list. So assume $F\ne T^d$; then $d\ge2$ and some $c_j\ne0$ with $j\le d-2$. Let $D\ge1$ be an integer with $Dh\in\mathbb Z$, and $K=1+\sum_j|c_j|$. We show that the number of good pairs is at most $C\,n(1+\ln n)$ for a constant $C$ depending only on $P$; since $(1+\ln n)/n^{0.01}\to0$, this is less than $n^{1.01}$ for large $n$, so $P$ fails.

Step 1: size of $F$. Let $\rho(T)=|F(T)|^{1/d}$. For $|T|\ge\sqrt{2K}$ we have $|F(T)|=|T|^d(1+\varepsilon)$ with $|\varepsilon|\le\sum_j|c_j||T|^{j-d}\le K/T^2\le\frac12$. Then $(1+\varepsilon)^{1/d}$ lies between $1$ and $1+\varepsilon$, so \[\bigl|\rho(T)-|T|\bigr|\le|T|\,|\varepsilon|\le\frac{K}{|T|}\qquad(|T|\ge\sqrt{2K}).\tag{1}\] Also $|F(T)|\le M_0$ for $|T|<\sqrt{2K}$, for some constant $M_0$.

Step 2: $z$ lies close to one of two lines. Fix a constant $X_0\ge 2|h|+2+\sqrt{2K}$ so large that $(X_0-|h|)^{2d}>4M_0$. Pairs with $x<X_0$ or $y<X_0$ number at most $2X_0n$. By symmetry it suffices to count good pairs with $X_0\le x\le y\le n$ (and double). For such a pair put $X=x+h$, $Y=y+h$; then $\sqrt{2K}\le X\le Y$, $X\ge x/2$, $Y\le2y$, and $X\ge2$. Let $z$ be an integer with $P(z)=P(x)P(y)$ and $Z=z+h$, so $F(Z)=F(X)F(Y)$. By Step 1, $|F(X)|\ge X^d/2$ and $|F(Y)|\ge Y^d/2$, so $|F(Z)|\ge (X_0-|h|)^{2d}/4>M_0$ and therefore $|Z|\ge\sqrt{2K}$. Now $\rho(Z)=\rho(X)\rho(Y)$ and, by (1), $\rho(X)=X+e_1$, $\rho(Y)=Y+e_2$ with $|e_1|\le K/X\le K$, $|e_2|\le K/Y\le K/X$, and $|\rho(Z)-|Z||\le K$. Hence \[\bigl||Z|-XY\bigr|\le |e_1|Y+|e_2|X+|e_1e_2|+K\le K\frac YX+2K+K^2\le C_1\Bigl(\frac nx+1\Bigr),\] with $C_1=4K+2K+K^2$, using $Y/X\le4y/x\le4n/x$. So $Z=\varepsilon XY+b$ with $\varepsilon\in\{1,-1\}$ and $|b|\le C_1(\frac nx+1)$. Since $DZ$ and $D^2XY$ are integers, $D^2b$ is an integer. Thus, for a fixed $x$, the pair $(\varepsilon,b)$ takes at most $2\bigl(2D^2C_1(\frac nx+1)+1\bigr)\le C_2(\frac nx+1)$ values.

Step 3: each line carries at most $d$ solutions. Fix $x$, $\varepsilon$, $b$ and put $A=\varepsilon X$. Every $y$ counted with these data satisfies $G(Y)=0$, where \[G(T)=F(AT+b)-F(X)F(T).\] Suppose $G$ is the zero polynomial. The coefficient of $T^d$ gives $A^d=F(X)$. The coefficient of $T^{d-1}$ in $F(AT+b)$ is $dA^{d-1}b$ (only $(AT+b)^d$ contributes, as $F$ has no $T^{d-1}$ term), and in $F(X)F(T)$ it is $0$; as $A\ne0$, $b=0$. Then $F(AT)=A^dF(T)$, and comparing the coefficients of $T^j$ for a $j\le d-2$ with $c_j\ne0$ gives $A^j=A^d$, impossible because $|A|=X\ge2$. So $G$ is a non-zero polynomial of degree at most $d$, and it has at most $d$ roots; each root $Y$ gives at most one $y$.

Step 4: counting. The number of good pairs is at most \[2X_0n+2\sum_{x=1}^{n}d\,C_2\Bigl(\frac nx+1\Bigr)\le 2X_0n+2dC_2\bigl(n(1+\ln n)+n\bigr),\] using $\sum_{x\le n}\frac1x\le1+\ln n$. This is less than $n^{1.01}$ for all large $n$, so $P$ does not have the property.

Hence the polynomials are exactly $P=1$ and $P(x)=(x+c)^d$ with $c\in\mathbb Z$, $d\ge1$.

Problem 4

Algebra · LPS VII, Chapter 13: Systems, Symmetry, and Multi-Variable Algebra

Suppose $p$, $q$, and $r\in\mathbb{R}^+$ are pairwise distinct and are such that there is only one triple $(a,b,c)\in\mathbb{R}^3$ satisfying: \[a+b+c=1\] \[\frac{b^2+bc+c^2}{p}=\frac{c^2+ca+a^2}{q}=\frac{a^2+ab+b^2}{r}.\] Prove that for this triple $(a,b,c)$ we have $ab+bc+ca=0$.

Show the 2 solutions

Solution 1 (Differences of the quadratic forms are linear)

Write $s=a+b+c$, $Q_a=b^2+bc+c^2$, $Q_b=c^2+ca+a^2$, $Q_c=a^2+ab+b^2$, $\sigma=p+q+r$. The key identities are \[Q_b-Q_c=(c-b)s,\qquad Q_c-Q_a=(a-c)s,\qquad Q_a-Q_b=(b-a)s,\] for instance $Q_b-Q_c=c^2-b^2+a(c-b)=(c-b)(a+b+c)$.

All solutions. Let $(a,b,c)$ satisfy the system and let $\lambda$ be the common value of the three ratios, so $Q_a=\lambda p$, $Q_b=\lambda q$, $Q_c=\lambda r$. With $s=1$ the identities give $c-b=\lambda(q-r)$, $a-c=\lambda(r-p)$, $b-a=\lambda(p-q)$, hence \[(a,b,c)=(m-\lambda p,\ m-\lambda q,\ m-\lambda r)\quad\text{for some real }m,\qquad 3m-\lambda\sigma=1 .\tag{1}\] Conversely, if (1) holds and $Q_a=\lambda p$, then $s=1$ and the identities give $Q_b=Q_a-(b-a)=\lambda q$ and $Q_c=\lambda r$, so $(a,b,c)$ is a solution. Substituting $b=m-\lambda q$, $c=m-\lambda r$, $m=(1+\lambda\sigma)/3$ into $Q_a=\lambda p$ and simplifying gives the single equation \[F(\lambda):=A\lambda^2-\frac{\sigma}{3}\lambda+\frac13=0,\qquad A=\frac{p^2+q^2+r^2-pq-qr-rp}{3}.\tag{2}\] (Indeed $Q_a=3m^2-3m\lambda(q+r)+\lambda^2(q^2+qr+r^2)$; the $\lambda^2$-coefficient of $Q_a-\lambda p$ is $\sigma^2/3-(q+r)\sigma+q^2+qr+r^2=A$, the $\lambda$-coefficient is $2\sigma/3-(q+r)-p=-\sigma/3$, and the constant is $1/3$.)

So the solutions correspond to the real roots $\lambda$ of (2), and different roots give different triples, because $b-a=\lambda(p-q)$ and $p\ne q$. Since $p,q,r$ are distinct, $A=\frac16\bigl((p-q)^2+(q-r)^2+(r-p)^2\bigr)>0$, so (2) is a genuine quadratic.

Uniqueness forces a double root. There is exactly one triple, so (2) has exactly one real root $\lambda_0$, i.e. a double root. By Vieta, \[\lambda_0^2=\frac{1}{3A},\qquad 2\lambda_0=\frac{\sigma}{3A}.\] The second relation says $\sigma=6A\lambda_0$, so $\lambda_0\sigma=6A\lambda_0^2=2$ by the first.

Computing $ab+bc+ca$. Let $e=ab+bc+ca$. Adding $Q_a+Q_b+Q_c=\lambda\sigma$ gives $2(a^2+b^2+c^2)+e=\lambda_0\sigma=2$, while $1=s^2=a^2+b^2+c^2+2e$. Eliminating $a^2+b^2+c^2$: $2(1-2e)+e=2$, so $e=0$. Hence $ab+bc+ca=0$ for the unique triple.

Solution 2 (An inversion pairs the solutions)

Let $(a,b,c)$ be any real triple with $a+b+c=1$ and put $s=ab+bc+ca$. Since $b+c=1-a$ and $bc=s-a(b+c)=s-a+a^2$, \[b^2+bc+c^2=(b+c)^2-bc=(1-a)^2-(s-a+a^2)=1-a-s,\] and cyclically the other two numerators are $1-b-s$ and $1-c-s$.

Vector form. Let $\mathbf v=(a-\frac13,\ b-\frac13,\ c-\frac13)$; its coordinates add up to $0$, and \[|\mathbf v|^2=a^2+b^2+c^2-\tfrac23(a+b+c)+\tfrac13=(1-2s)-\tfrac13=\tfrac23-2s,\qquad\text{so}\qquad s=\tfrac13-\tfrac12|\mathbf v|^2 .\] Put $K=1+\frac32|\mathbf v|^2>0$. Then $1-a-s=\frac K3-v_1$, and similarly for $b,c$; in particular the three numerators add up to $3-1-3s=K$. Let $\sigma=p+q+r$ and $\mathbf w=\bigl(\frac13-\frac p\sigma,\ \frac13-\frac q\sigma,\ \frac13-\frac r\sigma\bigr)$.

Claim: $(a,b,c)$ (with $a+b+c=1$) solves the system if and only if $\mathbf v/K=\mathbf w$. If the three ratios equal $\lambda$, the numerators are $\lambda p,\lambda q,\lambda r$, and adding gives $\lambda\sigma=K$; so $\frac K3-v_1=\frac{Kp}{\sigma}$, i.e. $v_1/K=\frac13-\frac p\sigma$, and the same for the other coordinates. Conversely, if $\mathbf v/K=\mathbf w$, the numerators are $\frac{K}{\sigma}(p,q,r)$, so all three ratios equal $K/\sigma$.

Because $p,q,r$ are distinct, $\mathbf w\ne\mathbf 0$, so every solution has $\mathbf v\ne\mathbf 0$.

The pairing. For $\mathbf v\ne\mathbf 0$ with coordinate sum $0$ let $\mathbf v^*=\dfrac{2}{3|\mathbf v|^2}\,\mathbf v$. Its coordinates also add up to $0$, $|\mathbf v^*|^2=\dfrac{4}{9|\mathbf v|^2}$, hence $K^*=1+\frac32|\mathbf v^*|^2=\dfrac{3|\mathbf v|^2+2}{3|\mathbf v|^2}$ and \[\frac{\mathbf v^*}{K^*}=\frac{2}{3|\mathbf v|^2}\cdot\frac{3|\mathbf v|^2}{3|\mathbf v|^2+2}\,\mathbf v=\frac{2\mathbf v}{3|\mathbf v|^2+2}=\frac{\mathbf v}{K}.\] By the claim, if $(\frac13,\frac13,\frac13)+\mathbf v$ is a solution, so is $(\frac13,\frac13,\frac13)+\mathbf v^*$.

Conclusion. The solution is unique, so $\mathbf v^*=\mathbf v$, i.e. $\frac{2}{3|\mathbf v|^2}=1$ and $|\mathbf v|^2=\frac23$. Therefore $ab+bc+ca=s=\frac13-\frac12\cdot\frac23=0$.

Problem 5

Geometry · LPS VII, Chapter 45: Complex Numbers in Geometry

Given a triangle $\triangle ABC$ with circumcircle $\Omega$, suppose that the tangent to $\Omega$ at $C$ intersects the $B$-altitude at $B_C$. Similarly, suppose the tangent to $\Omega$ at $B$ intersects the $C$-altitude at $C_B$. Let $T_A$ denote the intersection point of tangents to $\Omega$ at $B$, $C$. Denote by $\omega_A$ the circumcircle of $\triangle T_AB_CC_B$. Define the points $T_B,T_C,A_C,C_A,B_A,A_B$ and the circles $\omega_B$ and $\omega_C$ analogously. Show that $\omega_A$, $\omega_B$ and $\omega_C$ concur at a point.

Show the solution

Solution (Complex numbers: a symmetric point on all three circles)

Take $\Omega$ as the unit circle and let $a,b,c$ be the complex coordinates of $A,B,C$, so $\bar a=1/a$, etc. We work in general position (all points below are distinct and finite); degenerate positions follow by continuity.

The points. The tangents at $B$ and $C$ meet at $T_A=\dfrac{2bc}{b+c}$. The tangent at $C$ is $z+c^2\bar z=2c$. The $B$-altitude is the line through $b$ perpendicular to $AC$: $\frac{z-b}{a-c}$ is purely imaginary, which (using $\bar a-\bar c=\frac{c-a}{ac}$) becomes $z-ac\,\bar z=b-\frac{ac}{b}$. Eliminating $\bar z=\frac{2c-z}{c^2}$ gives \[B_C=\frac{c\,(b^2+2ab-ac)}{b\,(a+c)},\qquad\text{and symmetrically}\qquad C_B=\frac{b\,(c^2+2ac-ab)}{c\,(a+b)} .\]

The common point. Let \[Q=a^2b^2+b^2c^2+c^2a^2+abc(a+b+c),\qquad X=\frac{2abc\,(ab+bc+ca)}{Q}.\] $X$ is symmetric in $a,b,c$, so it suffices to show that $X$ lies on $\omega_A=(T_AB_CC_B)$; the same computation with the letters permuted puts $X$ on $\omega_B$ and $\omega_C$.

$X\in\omega_A$. Put $Q'=Q-2a^2bc$. Direct simplification gives \[X-B_C=\frac{c\,(ac-b^2)\,Q'}{b\,(a+c)\,Q},\qquad X-C_B=\frac{b\,(ab-c^2)\,Q'}{c\,(a+b)\,Q},\] \[T_A-B_C=-\frac{c\,(b-c)(ac+b^2)}{b\,(a+c)(b+c)},\qquad T_A-C_B=\frac{b\,(b-c)(ab+c^2)}{c\,(a+b)(b+c)} .\] Hence the cross-ratio \[\rho=\frac{X-B_C}{X-C_B}\cdot\frac{T_A-C_B}{T_A-B_C}=-\frac{(ac-b^2)(ab+c^2)}{(ab-c^2)(ac+b^2)} .\] Using $\bar a=1/a$ etc.: $\overline{ac-b^2}=\dfrac{b^2-ac}{ab^2c}$, $\overline{ab+c^2}=\dfrac{c^2+ab}{abc^2}$, $\overline{ab-c^2}=\dfrac{c^2-ab}{abc^2}$, $\overline{ac+b^2}=\dfrac{b^2+ac}{ab^2c}$, so \[\bar\rho=-\frac{(b^2-ac)(c^2+ab)}{(c^2-ab)(b^2+ac)}=\rho .\] So $\rho$ is real, which means that $X,T_A,B_C,C_B$ lie on one circle or one line; since $T_A,B_C,C_B$ span the circle $\omega_A$, $X\in\omega_A$.

Therefore $\omega_A,\omega_B,\omega_C$ all pass through $X$.

Problem 6

Combinatorics · LPS VII, Chapter 39: Graph Theory and Structural Combinatorics

There are $n$ guests at a party, each pair of which is either friends or enemies (but not both). Akbar and Birbal are measuring the drama of this party.

For each non-empty subset $S$ of guests at the party, Akbar awards one point if all guests in $S$ have a common friend outside $S$ (i.e. a guest not in $S$ who is a friend of every guest in $S$). Similarly, Birbal awards one point if all guests in $S$ have a common enemy outside $S$.

The drama of a party is the sum of points given by Akbar and Birbal.

  • (a) For a fixed $n\ge 2$ find the maximum possible drama achievable.

  • (b) We say two parties are different if we cannot permute the guests in one so that a pair of guests in the first party is friends if and only if the corresponding permuted pair in the second party is friends. How many different parties achieve the maximum possible drama?

Note: If both Akbar and Birbal award a point to a subset, both points contribute to the drama of the party.

Show the answer

(a) $2^n-2$; (b) $2^{n-1}$

Show the 2 solutions

Solution 1 (Pair each set with its complement; threshold graphs)

Model the party as a graph $G$ on the set $V$ of guests, $|V|=n$, with edges for friendship. For $\emptyset\ne S\subseteq V$ let $\mathcal A(S)=1$ if some $v\notin S$ is adjacent to every vertex of $S$, and $\mathcal B(S)=1$ if some $v\notin S$ is adjacent to no vertex of $S$ (else $0$). The drama is $\sum_S(\mathcal A(S)+\mathcal B(S))$; the set $S=V$ scores $0$.

(a) Upper bound. Let $S\ne\emptyset,V$ and $T=V\setminus S$. We cannot have $\mathcal A(S)=\mathcal B(T)=1$: if $v\in T$ is adjacent to all of $S$ and $u\in S$ is adjacent to no vertex of $T$, then $u,v$ are both adjacent and non-adjacent. Likewise not $\mathcal B(S)=\mathcal A(T)=1$. Hence $\mathcal A(S)+\mathcal B(S)+\mathcal A(T)+\mathcal B(T)\le2$. The $2^n-2$ proper non-empty subsets split into $2^{n-1}-1$ complementary pairs, so the drama is at most $2^n-2$. The party with no friendships attains it: every proper non-empty $S$ has a common enemy outside, and no common friend. So the maximum is $\boxed{2^n-2}$.

(b) Equality. From the proof, the drama equals $2^n-2$ iff for every partition $V=S\sqcup T$ into non-empty parts both pairs above score exactly $1$, i.e. (applying it to $(S,T)$ and $(T,S)$): \[(\mathrm P)\qquad\text{for every such partition, some }t\in T\text{ is adjacent to all of }S,\ \text{or some }s\in S\text{ has no neighbour in }T .\] Call a partition violating if it fails (P): every $t\in T$ has a non-neighbour in $S$ and every $s\in S$ has a neighbour in $T$. Note that (P) is preserved when we pass to the complement graph and swap the names $S,T$.

A threshold graph is one built from a single vertex by repeatedly adding either an isolated vertex or a dominating vertex (adjacent to all previous ones). We show: $G$ satisfies (P) iff $G$ is a threshold graph.

Threshold $\Rightarrow$ (P), by induction on $n$ ($n=1$: nothing to check). Let $v$ be the last vertex added and $(S,T)$ a partition. If $v\in T$ is dominating, $v$ is adjacent to all of $S$. If $v\in S$ is isolated, $v$ has no neighbour in $T$. If $v\in T$ is isolated: when $T=\{v\}$ any $s\in S$ has no neighbour in $T$; otherwise apply induction to $G-v$ with $(S,T\setminus\{v\})$; a vertex of $T\setminus\{v\}$ adjacent to all of $S$ works, and a vertex of $S$ with no neighbour in $T\setminus\{v\}$ has none in $T$ either. The case $v\in S$ dominating is symmetric.

Lemma 1. If $G$ has (P) and $v$ is isolated or dominating, then $G-v$ has (P). Given a partition $(S',T')$ of $V\setminus\{v\}$: if $v$ is isolated, apply (P) to $(S',T'\cup\{v\})$; the witness cannot be $v$ (it is adjacent to nothing in $S'\neq\emptyset$), so it is a witness for $(S',T')$. If $v$ is dominating, use $(S'\cup\{v\},T')$ similarly.

Lemma 2. If $G$ has (P) and $z$ has maximum degree, then $G-z$ has (P). Suppose $(S',T')$ is violating in $G-z$. In $G$ the partitions $(S'\cup\{z\},T')$ and $(S',T'\cup\{z\})$ are not violating, and since $(S',T')$ is violating in $G-z$ the only possible witnesses are: $z$ has no neighbour in $T'$, and $z$ is adjacent to all of $S'$. So $S'=N(z)$ and $T'=M(z)$, the set of non-neighbours of $z$ other than $z$. If some $w\in N(z)$ has a non-neighbour $w'\in N(z)$, the partition $S=(N(z)\setminus\{w\})\cup\{z\}$, $T=M(z)\cup\{w\}$ of $G$ is violating: $z\sim w$, each $s\in N(z)\setminus\{w\}$ has a neighbour in $M(z)$, each $m\in M(z)$ is a non-neighbour of $z$, and $w\not\sim w'$. This contradicts (P). Otherwise $N(z)$ is a clique, and any $s\in N(z)$ is adjacent to $z$, to the other $|N(z)|-1$ vertices of $N(z)$ and to some vertex of $M(z)$, so $\deg s>\deg z$, a contradiction.

(P) $\Rightarrow$ threshold, by induction on $n$; $n\le2$ is clear. Let $G$ have (P), $n\ge3$.

Claim: $G$ has an isolated or a dominating vertex. Suppose not. Let $z$ have maximum degree. By Lemma 2 and induction, $G-z$ is threshold, so it has a vertex $y$ that is isolated or dominating in $G-z$.

Case A: $y$ is isolated in $G-z$. As $y$ is not isolated in $G$, $N(y)=\{z\}$. As $z$ is not dominating, it has a non-neighbour $x\ne y$, and $x$ has a neighbour $w$ ($w\ne y,z$). Put $S=\{y,x\}\cup\{r: r\sim z\text{ or }r\sim w\}$ (other vertices) and $T=\{z,w\}\cup\{r: r\not\sim z,\ r\not\sim w\}$. Every vertex of $S$ has a neighbour in $\{z,w\}\subseteq T$ ($y\sim z$, $x\sim w$). Every vertex of $T$ has a non-neighbour in $S$: $z\not\sim x$, $w\not\sim y$, and the other vertices of $T$ are not adjacent to $y$. So $(S,T)$ is violating, a contradiction.

Case B: $y$ is dominating in $G-z$. Then $y\not\sim z$ and $\deg y=n-2\le\deg z\le n-2$, so $z$ is adjacent to all vertices except $y$. Let $W=V\setminus\{y,z\}$; each $w\in W$ is adjacent to $y$ and $z$ and is not dominating, so it has a non-neighbour in $W$; in particular $|W|\ge2$. The graph $G[W]$ is threshold (restrict the construction of $G-z$ to $W$), has at least two vertices and no dominating vertex, so its last-added vertex $a$ is isolated in $G[W]$. Take $b\in W\setminus\{a\}$ and set $S=\{a,y\}\cup(W\setminus\{a,b\})$, $T=\{z,b\}$. Then $a\sim z$, $y\sim b$, every $w\in W\setminus\{a,b\}$ satisfies $w\sim z$; and $z\not\sim y$, $b\not\sim a$. So $(S,T)$ is violating, a contradiction.

So $G$ has an isolated or dominating vertex $v$; by Lemma 1 and induction $G-v$ is threshold, hence so is $G$.

Counting. A threshold graph is described by the types (isolated $=0$, dominating $=1$) of the vertices added after the first: a word in $\{0,1\}^{n-1}$. The word is determined by the isomorphism class: for $n\ge2$ a graph cannot have both an isolated and a dominating vertex, so the last letter is read off from $G$; any two dominating (or two isolated) vertices are interchangeable by an automorphism, so $G-v$ is well defined up to isomorphism, and we recurse. Conversely different words give non-isomorphic graphs by the same reading. Hence there are exactly $\boxed{2^{n-1}}$ different parties with maximum drama.

Solution 2 (An alternating quadruple of guests)

Model the party as a graph $G$ on the set $V$ of guests, $|V|=n$, with an edge for each pair of friends. For $\emptyset\ne S\subseteq V$ let $\mathcal A(S)=1$ if some vertex outside $S$ is adjacent to all of $S$, and $\mathcal B(S)=1$ if some vertex outside $S$ is adjacent to none of $S$ (otherwise $0$). The set $S=V$ scores $0$.

(a) Let $V=S\sqcup T$ with $S,T\ne\emptyset$. If $\mathcal A(S)=\mathcal B(T)=1$, some $t\in T$ is adjacent to all of $S$ and some $s\in S$ is adjacent to no vertex of $T$; then $s,t$ are both adjacent and non-adjacent, which is absurd. So $\mathcal A(S)+\mathcal B(T)\le1$ and likewise $\mathcal A(T)+\mathcal B(S)\le1$. Summing over the $2^{n-1}-1$ unordered pairs $\{S,T\}$, the drama is at most $2^n-2$. With no friendships at all every proper non-empty $S$ has a common enemy outside it, so the drama is $2^n-2$. The maximum is $\boxed{2^n-2}$.

Call an ordered partition $(S,T)$ (both parts non-empty) bad if every $s\in S$ has a neighbour in $T$ and every $t\in T$ has a non-neighbour in $S$; this says exactly $\mathcal A(S)=\mathcal B(T)=0$. By the argument above, the drama is $2^n-2$ if and only if $G$ has no bad partition. Note that $(S,T)$ is bad in $G$ if and only if $(T,S)$ is bad in the complement graph $\overline G$.

(b) Lemma 1. Let $z$ be a dominating vertex of $G$ (adjacent to all others). Then $G$ has a bad partition if and only if $G-z$ has one. The same holds if $z$ is isolated.

Proof. If $(S',T')$ is bad in $G-z$, then $(S'\cup\{z\},T')$ is bad in $G$: $z$ has a neighbour in $T'\ne\emptyset$, and the other conditions are unchanged. Conversely let $(S,T)$ be bad in $G$. Then $z\notin T$, since $z$ has no non-neighbour; so $z\in S$. Also $S\ne\{z\}$, since a vertex of $T$ has no non-neighbour in $\{z\}$. Now $(S\setminus\{z\},T)$ is bad in $G-z$: neighbours in $T$ are unaffected, and a non-neighbour in $S$ of a vertex of $T$ is never $z$. For isolated $z$ apply this to $\overline G$, in which $z$ is dominating, and use the remark on complements. $\square$

Lemma 2. If $n\ge2$ and $G$ has neither an isolated nor a dominating vertex, then $G$ has a bad partition.

Proof. For distinct $u,v$ write $u\preceq v$ if every neighbour of $u$ other than $v$ is a neighbour of $v$.

There are $u,v$ with neither $u\preceq v$ nor $v\preceq u$. Otherwise let $v$ have maximum degree and let $x\ne v$. If $v\preceq x$, the set of neighbours of $v$ other than $x$ is contained in the set of neighbours of $x$ other than $v$; their sizes are $\deg v-\varepsilon$ and $\deg x-\varepsilon$ with the same $\varepsilon\in\{0,1\}$, and $\deg x\le\deg v$, so the sets are equal and $x\preceq v$. Hence $x\preceq v$ for every $x\ne v$. As $v$ is not dominating, some $w\ne v$ is not adjacent to $v$; as $w$ is not isolated, it has a neighbour $x$, and $x\ne v$. From $x\preceq v$ we get that $w$ is adjacent to $v$, a contradiction.

So take such $u,v$. Since $u\not\preceq v$ there is a neighbour $x\ne v$ of $u$ that is not adjacent to $v$; since $v\not\preceq u$ there is a neighbour $y\ne u$ of $v$ that is not adjacent to $u$. Then $u,v,x,y$ are distinct and \[u\sim x,\qquad v\sim y,\qquad u\not\sim y,\qquad v\not\sim x .\] We build the partition by placing vertices one at a time: a vertex may be put into $S$ if it already has a neighbour in $T$, and into $T$ if it already has a non-neighbour in $S$. These properties are kept when more vertices are added, so if every vertex is placed legally, the final partition is bad. Both starts $S=\{u,v\},T=\{x,y\}$ and $S=\{x,y\},T=\{u,v\}$ are legal (check the four relations above). Let \[\mathcal X=\{w:\ w\sim u,\ w\sim v,\ w\not\sim x,\ w\not\sim y\},\qquad \mathcal Y=\{w:\ w\not\sim u,\ w\not\sim v,\ w\sim x,\ w\sim y\}\] (among the other vertices). After the first start every vertex outside $\mathcal X$ can be placed at once, and after the second start every vertex outside $\mathcal Y$ can; $\mathcal X\cap\mathcal Y=\emptyset$.

  • If every vertex of $\mathcal X$ has a neighbour in $\mathcal Y$ (this includes $\mathcal X=\emptyset$): use the first start, put all of $\mathcal Y$ into $T$ (each is not adjacent to $u\in S$), then all of $\mathcal X$ into $S$ (each has a neighbour in $\mathcal Y\subseteq T$), then all remaining vertices.

  • Otherwise some $a\in\mathcal X$ has no neighbour in $\mathcal Y$: use the second start, put $a$ into $S$ ($a\sim u\in T$), then all of $\mathcal Y$ into $T$ (each is not adjacent to $a\in S$), then all remaining vertices.

In both cases we obtain a bad partition. $\square$

Characterisation. A threshold graph is one obtained from a single vertex by repeatedly adding an isolated or a dominating vertex. $G$ has no bad partition if and only if $G$ is a threshold graph, by induction on $n$ (for $n=1$ there are no partitions). If $G$ is threshold with last added vertex $z$, then $G-z$ is threshold, has no bad partition by induction, and Lemma 1 gives the same for $G$. If $G$ ($n\ge2$) has no bad partition, Lemma 2 gives an isolated or dominating vertex $z$, Lemma 1 shows that $G-z$ has no bad partition, so $G-z$ is threshold by induction, and hence so is $G$.

Counting. A threshold graph is described by the word in $\{0,1\}^{n-1}$ recording the types (isolated $=0$, dominating $=1$) of the added vertices. For $n\ge2$ a graph cannot have both an isolated and a dominating vertex, so the last letter is read off from $G$; any two isolated (or two dominating) vertices are exchanged by an automorphism, so deleting one of them gives a well-defined graph up to isomorphism, and we continue. Thus the word is determined by the isomorphism class, and different words give non-isomorphic graphs. The number of different parties with maximum drama is $\boxed{2^{n-1}}$.

Problem 7

Geometry · LPS VII, Chapter 15: Circles, Power, and Radical Structure

Let $ABC$ be a triangle and let $K\,(\ne A)$ be a fixed point on the line through $A$ perpendicular to $BC$. Assume that $A$ and $K$ lie on the same side of $BC$. Let $w_B$, $w_C$ be the circles with diameters $AB$, $AC$ respectively. We call a point $X$ good if one can draw tangents $KP$ onto $w_B$ and $KQ$ onto $w_C$ (where $P$ and $Q$ are the tangency points) such that $P$, $Q$, and $X$ are collinear points. Prove that $B$ is good if and only if $C$ is good.

Show the solution

Solution (Power functions and a pencil of conics)

Let $D$ be the foot of the altitude from $A$. Since $\angle ADB=\angle ADC=90^\circ$, both $w_B$ and $w_C$ pass through $A$ and $D$, and $K$ lies on their common chord line $AD$. For a point $X$ write \[W_B(X)=\overrightarrow{XA}\cdot\overrightarrow{XB},\qquad W_C(X)=\overrightarrow{XA}\cdot\overrightarrow{XC}\] for the powers of $X$ with respect to $w_B$, $w_C$ (the power with respect to the circle on diameter $UV$ is $\overrightarrow{XU}\cdot\overrightarrow{XV}$). Then $W_B(K)=W_C(K)=\overrightarrow{KA}\cdot\overrightarrow{KD}=:p$.

If $K$ lies between $A$ and $D$, then $p<0$, $K$ is inside both circles, no tangents exist and neither $B$ nor $C$ is good. So assume $K$ is beyond $A$ (it is on $A$'s side of $BC$ and $K\ne A$); then $p=KA\cdot KD>0$. Let $\omega$ be the circle with centre $K$ and radius $\sqrt p$, and $\Omega(X)=KX^2-p$ its power function. A point $P$ of $w_B$ is a tangency point from $K$ iff $KP^2=p$, so the tangency points are $\{P_1,P_2\}=w_B\cap\omega$ and $\{Q_1,Q_2\}=w_C\cap\omega$. These four points are distinct: a common point of $w_B$ and $w_C$ is $A$ or $D$, and $\Omega(A)=-KA\cdot AD\ne0$, $\Omega(D)=KD\cdot AD\ne0$. Being on a circle, no three are collinear.

$W_B$, $W_C$, $\Omega$ all have the form $|X|^2+(\text{affine})$, so $\ell_B=W_B-\Omega$ and $\ell_C=W_C-\Omega$ are affine functions; $\ell_B=0$ is the line $P_1P_2$ and $\ell_C=0$ is the line $Q_1Q_2$. "$X$ is good" means that $X$ lies on one of the four lines $P_iQ_j$.

Step 1: a symmetric identity. We claim $\ell_C(B)=\ell_B(C)$. Indeed \[\ell_C(B)-\ell_B(C)=\bigl(W_C(B)-W_B(C)\bigr)+\bigl(\Omega(C)-\Omega(B)\bigr),\] where, treating points as vectors, $W_C(B)-W_B(C)=(B-A)\cdot(B-C)-(C-A)\cdot(C-B)=(B-C)\cdot(B+C-2A)$, and $\Omega(C)-\Omega(B)=|C-K|^2-|B-K|^2=-(B-C)\cdot(B+C-2K)$. Adding, $\ell_C(B)-\ell_B(C)=2(B-C)\cdot(K-A)=0$, because $KA\perp BC$.

Step 2: every line pair through the four points lies in the pencil. Let $\Lambda$ be the product of the affine functions of the lines $P_1Q_j$ and $P_2Q_{j'}$ ($\{j,j'\}=\{1,2\}$). We show $\Lambda=t\,\Omega+u\,\ell_B\ell_C$ for constants $t,u$. Choose a point $Y\ne P_1,P_2$ on line $P_1P_2$; it is not on $\omega$, so $\Omega(Y)\ne0$, and we can choose $t$ with $(\Lambda-t\Omega)(Y)=0$. The function $\Lambda-t\Omega$ (a polynomial of degree at most $2$) vanishes at the three points $P_1,P_2,Y$ of the line $\ell_B=0$, so its restriction to that line, a polynomial of degree at most $2$ in one variable, vanishes identically, and therefore $\Lambda-t\Omega=\ell_B\cdot m$ for an affine $m$. Now $\Lambda-t\Omega$ vanishes at $Q_1,Q_2$, where $\ell_B\ne0$ (they are not $P_1,P_2$); hence $m(Q_1)=m(Q_2)=0$, and $m=u\,\ell_C$ for a constant $u$.

Step 3: $B$ good $\Rightarrow$ $C$ good. Suppose $B$ lies on the line $P_1Q_j$, and let $\Lambda$ be as in Step 2, so $\Lambda(B)=0$. Note $W_B(B)=0$, so $\ell_B(B)=-\Omega(B)$, and $\Omega(B)=KB^2-KA\cdot KD=DB^2+KD\cdot AD>0$. Hence \[0=\Lambda(B)=t\,\Omega(B)-u\,\Omega(B)\ell_C(B)\quad\Longrightarrow\quad t=u\,\ell_C(B).\] Similarly $\ell_C(C)=-\Omega(C)$, and using Step 1, \[\Lambda(C)=t\,\Omega(C)+u\,\ell_B(C)\ell_C(C)=u\,\Omega(C)\bigl(\ell_C(B)-\ell_B(C)\bigr)=0 .\] So $C$ lies on line $P_1Q_j$ or on line $P_2Q_{j'}$: $C$ is good. (If $B$ lies on a line $P_2Q_j$, rename $P_1,P_2$.)

The roles of $B$ and $C$ are symmetric (Step 1 is symmetric), so $C$ good $\Rightarrow$ $B$ good as well.

Problem 8

Combinatorics · LPS VII, Chapter 20: Parity, Coloring, and Process Termination

Let $n$ and $d$ be positive integers greater than $1$. The numbers $1,2,\dots,n$ are written on a blackboard. In a move, we may pick two numbers on the board that differ by at least $d$, erase them both, and write their average instead. For a fixed $d$, let $m$ be the smallest positive integer choice for $n>1$ such that it is possible to perform operations so that we end with exactly one number written on the board. Show that \[3d-2026<m<3d+2026.\]

Show the solution

Solution (A potential that averaging cannot decrease, and a merging schedule)

We prove the sharper bounds $3d-3\le m\le 3d+4$, which give $3d-2026<m<3d+2026$. Every number ever written is an average of numbers in $[1,n]$, so all numbers on the board always lie in $[1,n]$. Ending with one number from $n\ge2$ numbers takes $n-1$ moves.

Step 1: $n\le 2d-1$ is impossible. Let $2\le n\le 2d-1$ and $j=\min(d,n)$; then $n-d<j\le d$ and $1\le j\le n$. For every number $x\in[1,n]$ we have $x-j\le n-j<d$ and $j-x\le j-1<d$, so the original number $j$ can never be picked and stays on the board. The last move writes a new number, and then the board holds at least two numbers, a contradiction.

Step 2: $2d\le n\le 3d-4$ is impossible. Then $d\ge4$. Normalise a number $x$ to $u=\bigl(x-\frac{n+1}2\bigr)/d$. All numbers satisfy $|u|\le\frac{n-1}{2d}<\frac32$; a move takes two numbers whose normalised values $\alpha,\beta$ satisfy $|\alpha-\beta|\ge1$ and writes the number with normalised value $\frac{\alpha+\beta}2$. Define the even function \[F(u)=1-|u|-\varphi(|u|),\qquad \varphi(t)=\begin{cases}0,&0\le t\le\frac12,\\ t-\frac12,&\frac12\le t\le1,\\ \frac12,&1\le t\le\frac32,\end{cases}\] so $F(u)=1-|u|$ for $|u|\le\frac12$, $F(u)=\frac32-2|u|$ for $\frac12\le|u|\le1$ and $F(u)=\frac12-|u|$ for $1\le|u|\le\frac32$. The potential of a board is the sum of $F$ over its numbers.

Claim: if $\alpha,\beta\in[-\frac32,\frac32]$ and $|\alpha-\beta|\ge1$, then $F(\alpha)+F(\beta)\le F\bigl(\frac{\alpha+\beta}2\bigr)$. As $F$ is even we may replace $(\alpha,\beta)$ by $(-\alpha,-\beta)$, so let $\mu=\frac{\alpha+\beta}2\ge0$, and write $\alpha=\mu-\tau$, $\beta=\mu+\tau$ with $\tau\ge\frac12$. Then $\mu+\tau=\beta\le\frac32$, so $\mu\le1$. The claim reads \[1+\mu+\varphi(\mu)\le|\alpha|+|\beta|+\varphi(|\alpha|)+\varphi(|\beta|).\tag{1}\]

  • If $\mu\le\frac12$: then $\varphi(\mu)=0$ and $\alpha=\mu-\tau\le0$, so $|\alpha|+|\beta|=2\tau$. If $\mu+\tau\le1$, then $\varphi(\beta)=\mu+\tau-\frac12$ and the right side of (1) is at least $3\tau+\mu-\frac12\ge1+\mu$. If $\mu+\tau>1$, then $\varphi(\beta)=\frac12$ and the right side is at least $2\tau+\frac12>2(1-\mu)+\frac12\ge1+\mu$, because $\mu\le\frac12$.

  • If $\frac12\le\mu\le1$: then $\varphi(\mu)=\mu-\frac12$; also $\beta\ge\mu+\frac12\ge1$, so $\varphi(\beta)=\frac12$. The right side of (1) is at least $\alpha+\beta+\frac12=2\mu+\frac12$, which is the left side.

So a move never decreases the potential. At the end there is one number, of potential at most $\max F=1$.

The initial potential exceeds $1$. The original numbers have normalised values $u_x=\frac{2x-n-1}{2d}$, $x=1,\dots,n$; they are the midpoints of the intervals $I_x=[u_x-\frac1{2d},u_x+\frac1{2d}]$, which tile $[-w,w]$, $w=\frac n{2d}\in[1,\frac32)$. If $F$ is affine on $I_x$, then $F(u_x)=d\int_{I_x}F$. Otherwise, since $F$ is $2$-Lipschitz, \[\Bigl|F(u_x)-d\int_{I_x}F\Bigr|\le d\int_{I_x}2|t-u_x|\,dt=\frac1{2d}.\] $F$ is affine between consecutive points of $-\frac32,-1,-\frac12,0,\frac12,1,\frac32$, so at most five intervals $I_x$ contain a break point in their interior. Hence $\sum_xF(u_x)\ge d\int_{-w}^wF-\frac5{2d}$. Now $\int_0^{1/2}(1-t)\,dt=\frac38$, $\int_{1/2}^1(\frac32-2t)\,dt=0$, $\int_1^{3/2}(\frac12-t)\,dt=-\frac38$, so $\int_{-3/2}^{3/2}F=0$ and \[\int_{-w}^{w}F=-2\int_w^{3/2}\Bigl(\frac12-t\Bigr)dt\ge2\cdot\frac12\Bigl(\frac32-w\Bigr)=\frac{3d-n}{2d},\] since $\frac12-t\le-\frac12$ on $[w,\frac32]$. Therefore the initial potential is at least $\frac{3d-n}2-\frac5{2d}\ge2-\frac58>1$, using $3d-n\ge4$ and $d\ge4$. This contradicts the monotonicity.

By Steps 1 and 2, $m\ge3d-3>3d-2026$.

Step 3: a construction with $n\le3d+4$. Let $D$ be the least even integer with $D\ge d$ (so $D\le d+1$), $D=2q$, and $n=3D+1$. Every move below has gap at least $D\ge d$.

  • 1. For $i=1,\dots,D$ merge $i$ and $i+D$ (gap $D$; these use each of $1,\dots,2D$ once) to get $i+q$; then merge the new number $D+1$ (from $i=q+1$) with $2D+1$ (gap $D$) to get $D+q+1$. The board is now $\{q+1,\dots,D\}\cup\{D+2,\dots,D+q+1\}\cup\{2D+2,\dots,3D+1\}$.

  • 2. For $j=1,\dots,q-1$ merge $q+j$ with $D+q+j$ to get $D+j$, then merge $D+1+j$ with $2D+1+j$ to get $D+q+1+j$ (both gaps $D$). The number $D+q+j$ used here is $D+q+1$ from stage 1 when $j=1$, and was produced in the previous round when $j\ge2$. The board is now $\{D,\dots,D+q-1\}\cup\{2D\}\cup\{2D+q+1,\dots,3D+1\}$.

  • 3. Merge $2D$ and $3D+1$ (gap $D+1$) to get $v=2D+(q-1)+\frac32$. For $j=q-1,q-2,\dots,0$: if $v=2D+j+e$ with $\frac32\le e\le2$, merge $v$ with $D+j$ (gap $D+e$), and then the result $\frac{3D+2j+e}2$ with $2D+q+1+j$ (gap $D+1-\frac e2\ge D$). The new number is $2D+j+\frac12+\frac e4=2D+(j-1)+e'$ with $e'=\frac32+\frac e4\in[\frac32,2]$, so the invariant persists.

Stage 3 uses up $D,\dots,D+q-1$ and $2D+q+1,\dots,3D+1$, so one number remains. Hence $m\le3D+1\le3d+4<3d+2026$.

Combining, $3d-2026<m<3d+2026$. (For $d=2,3,4$ an exhaustive search gives $m=5,9,12$.)

Problem 9

Number Theory · LPS VII, Chapter 49: Combinatorial Number Theory and Structure

For a positive integer $n$, let $f(n)$ denote the number of subsets $S$ of $\{1,2,\dots,n\}$ so that the sum of 2026th powers of the elements of $S$ is itself a perfect 2026th power. Prove that there exist positive real constants $c_1,c_2$ and a fixed integer $N$, so that for all positive integers $n$ where $n>N$, we have \[\frac{1}{n^{c_1}}\leqslant\frac{f(n)}{2^n}\leqslant\frac{1}{n^{c_2}}.\]

Show the solution

Solution (Sperner for the upper bound, Thue-Morse gadgets for the lower bound)

Write $k=2026$ and $\Sigma(S)=\sum_{s\in S}s^k$ for a finite set $S$ of positive integers. Constants $C_1,C_2,\dots$ below depend only on $k$, and “$n$ large” means larger than a suitable constant depending only on $k$; this is allowed, since the statement only asks for $n>N$.

Upper bound. Let $m=\bigl\lfloor n^{(k-1)/k}/4\bigr\rfloor$; for $n$ large, $n^{(k-1)/k}/5\le m<n/2$. Write each subset as $S=T\cup U$ with $T\subseteq\{1,\dots,m\}$ and $U\subseteq\{m+1,\dots,n\}$. Let $H=\{\lceil n/2\rceil,\dots,n\}$; it has $h\ge n/2$ elements, all larger than $m$. Call $U$ good if $|U\cap H|\ge n/8$.

Few $U$ are bad. If $U$ is a uniformly random subset of $\{m+1,\dots,n\}$, then $|U\cap H|$ is a sum of $h$ independent fair $0/1$ variables, so by Hoeffding's inequality \[\Pr\Bigl(|U\cap H|<\tfrac n8\Bigr)\le\Pr\Bigl(|U\cap H|\le\tfrac h2-\tfrac h4\Bigr)\le e^{-2(h/4)^2/h}=e^{-h/8}\le e^{-n/16}.\] So at most $e^{-n/16}2^n$ subsets $S$ have a bad $U$.

Each good $U$ allows few $T$. Fix a good $U$ and put $L=\Sigma(U)$. It contains at least $n/8$ elements that are at least $n/2$, so $L\ge\frac n8\left(\frac n2\right)^k=\frac{n^{k+1}}{2^{k+3}}$. For every $T\subseteq\{1,\dots,m\}$ we have $0\le\Sigma(T)\le m\cdot m^k$, so $\Sigma(S)$ lies in the interval $[L,\,L+m^{k+1}]$. We claim this interval contains at most one perfect $k$-th power. Indeed, if $y^k\ge L$, then \[(y+1)^k-y^k\ \ge\ ky^{k-1}\ \ge\ L^{(k-1)/k}\ \ge\ \frac{n^{(k+1)(k-1)/k}}{2^{(k+3)(k-1)/k}}\ \ge\ \frac{n^{k-1/k}}{2^{k+3}},\] while \[m^{k+1}\ \le\ \frac{n^{(k-1)(k+1)/k}}{4^{k+1}}=\frac{n^{k-1/k}}{2^{2k+2}}\ <\ \frac{n^{k-1/k}}{2^{k+3}}.\] So two $k$-th powers in the interval would be more than its length apart, which is impossible. Hence there is a number $v$ (depending on $U$) such that $S=T\cup U$ is counted by $f(n)$ only if $\Sigma(T)=v-L$.

All weights $s^k$ are positive, so if $T\subsetneq T'$ then $\Sigma(T)<\Sigma(T')$. Thus the sets $T$ with a prescribed value of $\Sigma(T)$ form an antichain among the subsets of $\{1,\dots,m\}$, and by Sperner's theorem there are at most $\binom{m}{\lfloor m/2\rfloor}$ of them. We use $\binom{m}{\lfloor m/2\rfloor}\le\frac{2^m}{\sqrt m}$: for $m=2r$ this follows from the classical bound $\binom{2r}{r}\le\frac{4^r}{\sqrt{3r+1}}$, and for $m=2r+1$ from $\binom{2r+1}{r}=\frac12\binom{2r+2}{r+1}\le\frac{2^{2r+1}}{\sqrt{3r+4}}$.

Conclusion. There are $2^{n-m}$ sets $U$, so \[\frac{f(n)}{2^n}\ \le\ e^{-n/16}+\frac{2^{n-m}\cdot 2^m/\sqrt m}{2^n}\ =\ e^{-n/16}+\frac1{\sqrt m}\ \le\ e^{-n/16}+\sqrt5\,n^{-\frac{k-1}{2k}}\ \le\ \frac1{n^{1/3}}\] for $n$ large, because $\frac{k-1}{2k}=\frac{2025}{4052}>\frac13$. So $c_2=\frac13$ works.

A Thue-Morse identity. Let $s(j)$ be the binary digit sum of $j$ and $\tau(j)=(-1)^{s(j)}$. Every $j$ with $0\le j<2^k$ is a unique sum of distinct powers $2^i$, $0\le i<k$, so \[F(z):=\prod_{i=0}^{k-1}\bigl(1-z^{2^i}\bigr)=\sum_{j=0}^{2^k-1}\tau(j)z^j .\] Each factor is $1-z^{2^i}=(1-z)(1+z+\dots+z^{2^i-1})$, so $F(z)=(1-z)^kh(z)$ with $h(1)=\prod_{i<k}2^i=2^{k(k-1)/2}$. Hence $F^{(a)}(1)=0$ for $a<k$ and $F^{(k)}(1)=(-1)^kk!\,h(1)$. Let $D$ denote the operator $z\frac{d}{dz}$; then $D^i\sum_j\tau(j)z^j=\sum_j\tau(j)j^iz^j$. By induction on $i$, $D^iF$ is a combination of $z^aF^{(a)}(z)$ with $1\le a\le i$ (for $i\ge1$), and the coefficient of $z^iF^{(i)}$ is $1$. Putting $z=1$ gives \[\sum_{j=0}^{2^k-1}\tau(j)j^i=0\quad(0\le i<k),\qquad \sum_{j=0}^{2^k-1}\tau(j)j^k=(-1)^kk!\,2^{k(k-1)/2}.\] (For $i=0$ the first sum is $F(1)=0$.) Put $\Delta=k!\,2^{k(k-1)/2}$. Expanding by the binomial theorem, for all integers $x$ and $t\ge1$, \[\sum_{j=0}^{2^k-1}\tau(j)(x+tj)^k=\sum_{i=0}^{k}\binom ki x^{k-i}t^i\sum_j\tau(j)j^i=t^k\sum_j\tau(j)j^k=\pm\Delta t^k .\] So the block $\{x+tj:0\le j<2^k\}$ (with $x,t\ge1$) splits into two halves, $\{\tau(j)=1\}$ and $\{\tau(j)=-1\}$, whose sums of $k$-th powers differ by exactly $\Delta t^k$. Call the half with the larger sum the high half and the other the low half.

Lower bound. Let $W=\Delta\sum_{i=1}^{\Delta-1}(i\Delta+1)^k$ (a constant, and $W\ge\Delta$) and let $J\ge0$ be the least integer with \[\Delta\,2^{(J+1)k}\ \ge\ k2^{k+1}n^{k-1/k}+2W .\tag{1}\] If $J\ge1$, then (1) fails for $J-1$, so $\Delta 2^{Jk}<k2^{k+1}n^{k-1/k}+2W\le C_1n^{k-1/k}$; hence in all cases $2^J\le C_2n^{1-1/k^2}$, $J\le\log_2n+C_3$, and $\Delta2^{(J+1)k}\le C_4n^{k-1/k}$. Now fix the following pairwise disjoint sets of integers in $\{1,\dots,n\}$:

  • the adjusters $b_i=i\Delta+1$ for $1\le i\le\Delta-1$; they are less than $\Delta^2$, and $b_i^k\equiv1\pmod\Delta$;

  • for each $e=0,1,\dots,J$, exactly $2^k-1$ blocks with step $t=2^e$, all of whose elements exceed $\Delta^2$, placed one after another so that they do not overlap.

A block with step $2^e$ spans fewer than $2^k2^e$ consecutive integers, so all blocks together fit into fewer than $\sum_{e=0}^{J}(2^k-1)2^k2^e<4^k2^{J+1}\le C_5n^{1-1/k^2}$ consecutive integers above $\Delta^2$, which is possible inside $\{1,\dots,n\}$ for $n$ large. Let $G$ be the union of the adjusters and the blocks, and $g=|G|\le\Delta+(J+1)4^k\le C_6\log_2n$.

Call $A\subseteq G$ admissible if it contains, from each block, exactly one of its two halves, and from the adjusters an initial segment $\{b_1,\dots,b_r\}$ with $0\le r\le\Delta-1$. Let $\beta$ be $\Sigma$ of the union of all low halves and $V_r=\sum_{i\le r}b_i^k$; then $V_r\equiv r\pmod\Delta$ and $0\le V_r\le W$. If $A$ takes the high half in exactly $c_e$ of the blocks of step $2^e$ ($0\le c_e\le2^k-1$) and the adjusters $b_1,\dots,b_r$, then \[\Sigma(A)=\beta+V_r+\Delta N,\qquad N=\sum_{e=0}^{J}c_e\,2^{ek}.\] Reading $N$ in base $2^k$ (digits $c_e$), every integer $N$ with $0\le N<2^{(J+1)k}$ arises.

Now let $U\subseteq\{1,\dots,n\}\setminus G$ be arbitrary and put $\Sigma_0=\Sigma(U)+\beta$. Since $U$ and the low halves are disjoint, $\Sigma_0\le\sum_{s=1}^ns^k\le n^{k+1}$. Consider the interval \[I=\bigl[\Sigma_0+W,\ \Sigma_0+\Delta2^{(J+1)k}-\Delta\bigr].\] By (1) and $W\ge\Delta$, its length is at least $k2^{k+1}n^{k-1/k}$, and its right end is at most $n^{k+1}+C_4n^{k-1/k}\le2n^{k+1}$ for $n$ large. For an integer $y\ge1$ with $y^k\le2n^{k+1}$, \[(y+1)^k-y^k\le k(y+1)^{k-1}\le k(2y)^{k-1}\le k2^{k-1}\bigl(2n^{k+1}\bigr)^{(k-1)/k}\le k2^kn^{k-1/k}.\] Let $y$ be the largest integer with $y^k<\Sigma_0+W$ (so $y\ge1$, as $\Sigma_0+W>1$). Then $y^k\le2n^{k+1}$, so $(y+1)^k<\Sigma_0+W+k2^kn^{k-1/k}$, and $(y+1)^k\ge\Sigma_0+W$; thus $(y+1)^k\in I$. Let $r\in\{0,\dots,\Delta-1\}$ with $r\equiv(y+1)^k-\Sigma_0\pmod\Delta$. Then \[N=\frac{(y+1)^k-\Sigma_0-V_r}{\Delta}\] is an integer (the numerator is $\equiv r-r\pmod\Delta$), $N\ge\frac{W-V_r}{\Delta}\ge0$, and $N\le\frac{\Delta2^{(J+1)k}-\Delta}{\Delta}<2^{(J+1)k}$. So some admissible $A$ has $\Sigma(A)=\beta+V_r+\Delta N$, that is, $\Sigma(U\cup A)=(y+1)^k$.

Different sets $U$ give different sets $U\cup A$ (as $U=(U\cup A)\setminus G$), and there are $2^{n-g}$ choices of $U$. Hence \[\frac{f(n)}{2^n}\ \ge\ 2^{-g}\ \ge\ 2^{-C_6\log_2n}=\frac1{n^{C_6}},\] and $c_1=C_6$ works.

Together, for all $n$ larger than a suitable $N$, $\frac1{n^{c_1}}\le\frac{f(n)}{2^n}\le\frac1{n^{c_2}}$ with $c_2=\frac13$ and $c_1=C_6$ (the constants are not optimised).

Problem 10

Combinatorics · LPS VII, Chapter 44: Combinatorial Games and Strategy

Let $n$ be a fixed positive integer. Alice and Bob play the following game on the integer number line. Alice starts at $0$ and Bob starts at $n$. They take turns making moves. On the $i^{th}$ turn,

  • If $i$ is odd, Alice moves to an integer at most $2^i-1$ distance away from her current position.

  • If $i$ is even, Bob moves to an integer at most $2^i-1$ distance away from his current position.

Note that both players have the option to stay where they are on their turn. The game ends only when one player moves to the same position as the other player, in which case the player who moved wins. Find all positive integers $n$ for which Alice has a winning strategy, and find all positive integers $n$ for which Bob has a winning strategy.

Show the answer

Bob wins exactly for $\frac{4^{k+1}+2}{3}\le n\le\frac{2\cdot 4^{k+1}-2}{3}$ ($k\ge 0$), i.e. $n\in\{2\}\cup[6,10]\cup[22,42]\cup[86,170]\cup\dots$; Alice wins for all other $n$

Show the solution

Solution (Classify the distances turn by turn)

Reduction to the distance. Only the distance $x>0$ between the players matters. On turn $i$ the mover may change his position by at most $r_i=2^i-1$. If $x\le r_i$ he can land on the opponent and win at once. If $x>r_i$ he cannot reach the opponent and cannot jump over him either, so after the move the new distance $y$ is any integer with $x-r_i\le y\le x+r_i$ (and $y\ge 1$). Call the distance $x$ at the start of turn $i$ winning (W) if the player to move has a winning strategy and losing (L) if the other player has one.

Claim. Let $c_k=\frac{2\cdot 4^k+1}{3}$ and $d_k=\frac{4^{k+1}-1}{3}$ for $k\ge 0$ (so $(c_k,d_k)=(1,1),(3,5),(11,21),(43,85),\dots$; note $d_k=2c_k-1$ and $c_{k+1}=2d_k+1$). At the start of turn $i$, the distance $x$ is L if $c_k2^i\le x\le d_k2^i$ for some $k$, and W otherwise. Moreover the winner can force a win in finitely many moves.

Proof. We describe the play and check it is consistent; the claim then follows because every position is shown to be W or L with an explicit strategy. Write $L_i=\bigcup_k[c_k2^i,d_k2^i]$ and let $W_i$ be the rest of the positive integers.

(a) If $x\le 2^i-1$, the mover wins at once.

(b) If $d_k2^i+1\le x\le c_{k+1}2^i-1$ for some $k\ge0$, the mover can reach a distance in $[c_k2^{i+1},d_k2^{i+1}]\subseteq L_{i+1}$. Indeed this interval meets $[x-r_i,x+r_i]$ exactly when $x+2^i-1\ge 2c_k2^i$ and $x-2^i+1\le 2d_k2^i$, i.e. $x\ge(2c_k-1)2^i+1=d_k2^i+1$ and $x\le(2d_k+1)2^i-1=c_{k+1}2^i-1$.

(c) If $c_{k}2^i\le x\le d_{k}2^i$ ($k\ge 0$), then every move leads into $W_{i+1}$. For $k=0$ ($x=2^i$) the new distance lies in $[1,2^{i+1}-1]$, where the opponent wins at once. For $k\ge 1$ the new distance lies in \[[(c_k-1)2^i+1,\ (d_k+1)2^i-1]=[d_{k-1}2^{i+1}+1,\ c_k2^{i+1}-1],\] using $c_k-1=2d_{k-1}$ and $d_k+1=2c_k$; this is exactly a W-interval of type (b) for turn $i+1$.

These three cases cover all $x\ge1$, since the intervals $[1,2^i-1]$, $[c_k2^i,d_k2^i]$ and $[d_k2^i+1,c_{k+1}2^i-1]$ tile the positive integers. The strategy of the W-player is: win at once if possible, otherwise move into $L_{i+1}$. Then the opponent is in case (c) with some index $k$ and must move into a W-interval of index $k-1$ (or lose at once if $k=0$). So the index drops by one every two turns, and the W-player wins after finitely many turns. In particular no game is drawn when both play this way. $\square$

Answer. The game starts at turn $1$ with distance $n$ and Alice to move. Bob has a winning strategy exactly when $n\in L_1$, i.e. \[2c_k\le n\le 2d_k\iff \frac{4^{k+1}+2}{3}\le n\le\frac{2\cdot4^{k+1}-2}{3}\quad\text{for some }k\ge 0,\] which gives $n=2$, $6\le n\le 10$, $22\le n\le 42$, $86\le n\le 170$, and so on. For every other $n$ Alice has a winning strategy: \[\boxed{\text{Bob wins}\iff\tfrac{4^{k+1}+2}{3}\le n\le\tfrac{2\cdot4^{k+1}-2}{3}\text{ for some }k\ge0;\ \text{otherwise Alice wins.}}\]

Problem 11

Number Theory · LPS VII, Chapter 54: Advanced Number Theory Synthesis

Let $\alpha>0$ be a fixed positive real number. Find all polynomials $P$ with integer coefficients such that \[\gcd(P(m),P(n))\ge\gcd(m,n)^{\alpha}\] for all positive integers $m,n$. (Here $\gcd(0,0)=0$.)

Show the answer

$P(x)=x^dR(x)$ with $R\in\mathbb Z[x]$, an integer $d\ge\alpha$, and $P(n)\ne0$ for all positive integers $n$

Show the 2 solutions

Solution 1 (Kill every prime except p by the Chinese remainder theorem)

We use the convention $\gcd(0,0)=0$.

These polynomials work. If $P=x^dR$ with $d\ge\alpha$, then $m^d\mid P(m)$ and $n^d\mid P(n)$, so $g^d$ divides $G=\gcd(P(m),P(n))$, where $g=\gcd(m,n)$. Since $P$ has no positive integer root, $G\ge1$ is a positive multiple of $g^d$, so $G\ge g^d\ge g^\alpha$.

Necessity. Let $P$ satisfy the condition. Then $P\ne0$ (else $\gcd(0,0)=0<1$), and $P$ has no positive integer root $r$ (else $m=n=r$ gives $0<r^\alpha$). Write $P=x^dR(x)$ with $R(0)\ne0$. We must show $d\ge\alpha$.

Let $K$ be the set of primes $q$ that divide $P(x)$ for every integer $x$. It is finite: if $q$ does not divide all coefficients of $P$ and $q>\deg P$, then $P$ modulo $q$ is a non-zero polynomial of degree less than $q$, so it does not vanish at all $q$ residues. For each $q\in K$ fix an integer $x_q$ with $P(x_q)\ne0$ and put $t_q=v_q(P(x_q))+1$. Let $C=\prod_{q\in K}q^{v_q(P(x_q))}$.

Choose a prime $p\notin K$ with $p>|R(0)|$. Let $e\ge1$ and $m=p^e$. Then $R(m)\equiv R(0)\not\equiv0\pmod p$, so $R(m)\ne0$. By the Chinese remainder theorem choose a positive integer $n$ with

  • $n\equiv p^e\pmod{p^{e+1}}$;

  • $n\equiv x_q\pmod{q^{t_q}}$ for each $q\in K$;

  • $n\equiv y_q\pmod q$ for each prime $q\notin K$, $q\ne p$, dividing $R(m)$, where $y_q$ is a residue with $q\nmid P(y_q)$ (it exists because $q\notin K$).

Then $v_p(n)=e$, so $\gcd(m,n)=p^e$. Let $G=\gcd(P(m),P(n))$; every prime factor of $G$ divides $P(m)=p^{ed}R(m)$. We bound $G$ prime by prime.

  • $v_p(G)\le v_p(P(n))=ed+v_p(R(n))=ed$, because $R(n)\equiv R(0)\not\equiv 0\pmod p$.

  • If $q\in K$: $P(n)\equiv P(x_q)\pmod{q^{t_q}}$ and $v_q(P(x_q))<t_q$, so $v_q(G)\le v_q(P(n))=v_q(P(x_q))$.

  • If $q\notin K$, $q\ne p$, $q\mid R(m)$: $q\nmid P(n)$, so $v_q(G)=0$.

Hence $G\le p^{ed}C$, and the hypothesis gives $p^{e\alpha}\le G\le p^{ed}C$ for every $e\ge1$, i.e. $p^{e(\alpha-d)}\le C$. Letting $e\to\infty$ forces $\alpha\le d$.

So the answer is \[\boxed{P(x)=x^dR(x),\ R\in\mathbb Z[x],\ d\ge\alpha\text{ an integer},\ P(n)\ne0\text{ for all }n\in\mathbb Z^+}\]

Solution 2 (A dilate of the cofactor with no common root)

We show that the answer is: all non-zero $P(x)=x^dR(x)$ with $R\in\mathbb Z[x]$ and an integer $d\ge\alpha$, such that $P(n)\ne0$ for every positive integer $n$.

These work. Let $m,n$ be positive integers and $g=\gcd(m,n)$. Both $P(m)=m^dR(m)$ and $P(n)=n^dR(n)$ are non-zero multiples of $g^d$, so $\gcd(P(m),P(n))\ge g^d\ge g^\alpha$, as $g\ge1$ and $d\ge\alpha$.

Nothing else works. Let $P$ satisfy the condition. Taking $m=n$ gives $|P(m)|=\gcd(P(m),P(m))\ge m^\alpha>0$ (with $\gcd(0,0)=0$), so $P(m)\ne0$ for every positive integer $m$; in particular $P\ne0$. Write $P(x)=x^sQ(x)$ with $Q\in\mathbb Z[x]$, $Q(0)\ne0$ and an integer $s\ge0$. It remains to show $s\ge\alpha$.

Choice of a dilation. All complex roots of $Q$ are non-zero, and there are finitely many of them, so there is an integer $k\ge2$ different from every ratio $\rho/\rho'$ of two roots. Then $Q(x)$ and $Q(kx)$ have no common complex root: if $Q(\rho)=0$ and $Q(k\rho)=0$, then $k=(k\rho)/\rho$ would be such a ratio. Hence the two polynomials are coprime in $\mathbb Q[x]$, and the Euclidean algorithm gives $U_0,V_0\in\mathbb Q[x]$ with $U_0(x)Q(x)+V_0(x)Q(kx)=1$. Multiplying by a common denominator, we get $U,V\in\mathbb Z[x]$ and an integer $B\ge1$ with \[U(x)Q(x)+V(x)Q(kx)=B .\] (If $Q$ is constant, take $B=|Q|$.) Consequently, for every positive integer $t$, the integer $\gcd(Q(t),Q(kt))$ divides $B$.

The estimate. For a positive integer $t$, $\gcd(t,kt)=t$, and \[\gcd(P(t),P(kt))=\gcd\bigl(t^sQ(t),\ k^st^sQ(kt)\bigr)=t^s\gcd\bigl(Q(t),k^sQ(kt)\bigr)\le t^sk^s\gcd\bigl(Q(t),Q(kt)\bigr)\le k^sB\,t^s,\] where we used that $\gcd(X,k^sY)$ divides $\gcd(k^sX,k^sY)=k^s\gcd(X,Y)$. The condition gives $t^\alpha\le k^sB\,t^s$ for every positive integer $t$. If $s<\alpha$, then $t^{\alpha-s}\le k^sB$ fails for large $t$. Hence $s\ge\alpha$, and $P=x^sQ$ has the stated form.

Solution (Angle-bisector feet and the foot of an altitude)

Let $T=AC\cap BD$, $\omega_1=(PI_bI_d)$ and $\omega_2=(QI_aI_c)$. Write $k=\frac{AB}{BC}=\frac{AD}{DC}$ (the hypothesis $AB\cdot CD=AD\cdot BC$).

Step 2: a description of $I_d$, $I_b$, $P$ inside triangle $QBD$. Since $Q$ lies on segment $AC$, $\angle BAC=\angle BAQ$, so the incentre $I_d$ of $ABC$ is the point where the bisector of $\angle BAQ$ meets segment $QB$. Likewise $I_b$ is the point where the bisector of $\angle DAQ$ meets segment $QD$, and $P$ is the point where the bisector of $\angle BAD$ meets segment $BD$. By the angle bisector theorem, \[\frac{QI_d}{I_dB}=\frac{AQ}{AB},\qquad \frac{QI_b}{I_bD}=\frac{AQ}{AD},\qquad \frac{BP}{PD}=\frac{AB}{AD}.\tag{1}\]

Step 3: a key relation. The length of the bisector $BQ$ of triangle $ABC$ is given by $BQ^2=AB\cdot BC-AQ\cdot QC$ (Stewart's theorem). Since $BC=AB/k$ and $QC=AQ/k$, this reads $BQ^2=\frac{AB^2-AQ^2}{k}$. The same formula for the bisector $DQ$ of triangle $ADC$ gives $DQ^2=\frac{AD^2-AQ^2}{k}$. Then \[QX=\tfrac{\alpha d}{\alpha+\beta},\ BX=\tfrac{\beta d}{\alpha+\beta},\quad QY=\tfrac{\alpha b}{\alpha+\delta},\ DY=\tfrac{\delta b}{\alpha+\delta},\quad BZ=\tfrac{\beta q}{\beta+\delta},\ DZ=\tfrac{\delta q}{\beta+\delta}.\] The points $X,Y,Z$ are interior points of the three sides, so they are not collinear; let $\omega$ be their circle. So $Z'=F$, i.e. $F\in\omega$. $\square$

Step 5: $F\in\omega_1$ and $G\in\omega_2$. By Steps 2 and 3 the Lemma applies with $X=I_d$, $Y=I_b$, $Z=P$: the foot $F$ of the perpendicular from $Q$ to $BD$ lies on $\omega_1=(PI_bI_d)$, and $\omega_1$ meets line $BD$ exactly at $P$ and $F$. The hypothesis and the whole construction are symmetric under $A\to B\to C\to D\to A$ combined with the swap of the roles of $P$ and $Q$ (the condition becomes $BC\cdot DA=BA\cdot CD$, the same condition). Hence also the foot $G$ of the perpendicular from $P$ to $AC$ lies on $\omega_2=(QI_aI_c)$, and $\omega_2$ meets line $AC$ exactly at $Q$ and $G$. (The Lemma needs a genuine triangle $QBD$. If $Q$ lies on $BD$, so that $Q=T$, or symmetrically $P=T$, the statement follows from the general case by continuity, since $X$ and $Y$ depend continuously on the quadrilateral while the circles meet in two points.)

Step 6: $T$ is on the radical axis. The points $T,P,F$ lie on line $BD$, so the power of $T$ with respect to $\omega_1$ is the signed product $\overline{TP}\cdot\overline{TF}$. As $F$ is the orthogonal projection of $Q$ on this line, $\overline{TP}\cdot\overline{TF}=\overrightarrow{TP}\cdot\overrightarrow{TQ}$ (dot product). In the same way the power of $T$ with respect to $\omega_2$ is $\overline{TQ}\cdot\overline{TG}=\overrightarrow{TQ}\cdot\overrightarrow{TP}$. The two powers are equal, so $T$ lies on the radical axis of $\omega_1$ and $\omega_2$, which is the line $XY$ through their two common points. Hence $AC$, $BD$ and $XY$ concur at $T$.

All square roots are defined: $a+1,b+1,c+1>0$ and $1-d>0$. $0$

Show the solution

Solution (The dealer keeps two groups of equal sum)

We show that the dealer can always make the payout $0$; since payouts are never negative, the answer is $\boxed{0}$.

Split $\{1,\dots,2024\}$ into the $506$ blocks $\{4j+1,4j+2,4j+3,4j+4\}$ ($0\le j\le 505$) and put $4j+1,4j+4$ into group $A$ and $4j+2,4j+3$ into group $B$; then $A$ and $B$ have equal sums. Combinatorics · LPS VII, Chapter 47: Probabilistic Method and Random Structure

There are $n$ people at a party with distinct heights; however, only their names are known – not their heights. Let $f(n)$ be the minimum number of orderings of the people you need to choose beforehand so that for every group of $3$ people, you are guaranteed to have an ordering where those three are in increasing order of height. Show that there are absolute constants $0<c_1<c_2$ such that for every $n\ge 3$ \[c_1\log_2 n\le f(n)\le c_2\log_2 n.\]

Show the 2 solutions

Solution 1 (Distinct position vectors and random orderings)

For $n\le2$ there are no groups of three, so $f(n)=0$; the statement is about $n\ge3$, which we assume. A family of orderings is good if for every three people and every possible order of their heights some ordering lists them in that order (this is what "guaranteed" means, since the heights are unknown).

Lower bound $f(n)\ge\log_2(n-1)\ge\frac12\log_2n$. Take a good family of $f$ orderings and fix one person $p$. For each other person $x$ define the vector $\chi(x)\in\{0,1\}^f$ whose $i$-th entry is $1$ if $x$ comes before $p$ in the $i$-th ordering. If $\chi(x)=\chi(y)$ for $x\ne y$, then in every ordering $x$ and $y$ are on the same side of $p$, so no ordering lists the triple in the height order $x<p<y$ — impossible for a good family. So the $n-1$ vectors are distinct and $n-1\le2^f$, i.e. $f\ge\log_2(n-1)$. Finally $\log_2(n-1)\ge\frac12\log_2 n$ because $(n-1)^2\ge n$ for $n\ge3$. So $c_1=\frac12$ works.

Upper bound. Choose $f$ orderings independently and uniformly at random. For a fixed triple and a fixed one of its $6$ orders, one random ordering lists the triple in that order with probability $\frac16$. So the probability that no chosen ordering does so is $(5/6)^f$, and the probability that the family is not good is at most \[6\binom n3\Bigl(\frac56\Bigr)^f<n^3\Bigl(\frac56\Bigr)^f .\] If $f=\bigl\lceil 3\log_{6/5}n\bigr\rceil$ this is at most $1$, so some family of $f$ orderings is good and $f(n)\le\lceil3\log_{6/5}n\rceil\le 3\log_{6/5}n+1$. Since $\log_{6/5}n=\log_2n/\log_2(6/5)<4\log_2n$ and $1\le\log_2n$ for $n\ge 3$, we get $f(n)\le 13\log_2 n$.

Thus $\frac12\log_2n\le f(n)\le13\log_2n$ for all $n\ge3$.

Solution 2 (Binary digits give an explicit family)

A family of orderings is good if for every three people and every order of their heights some ordering lists them in that order (the heights are unknown). Let $n\ge3$.

Lower bound. Fix a person $p$ and, for each other person $x$, let $\chi(x)\in\{0,1\}^f$ record in which of the $f$ orderings $x$ comes before $p$. If $\chi(x)=\chi(y)$ for $x\ne y$, then $x$ and $y$ are on the same side of $p$ in every ordering, and the order $x,p,y$ never occurs. So $n-1\le2^f$, and $f(n)\ge\log_2(n-1)\ge\frac12\log_2n$, since $(n-1)^2\ge n$.

Upper bound. Label the people $0,1,\dots,n-1$ and write the labels in binary with $L=\lceil\log_2n\rceil$ digits. For each digit position $j$, each $e\in\{0,1\}$ and each of the two directions, take the ordering that lists first everybody whose $j$-th digit is $e$ and then everybody else, each of the two groups in increasing order of labels (first direction) or decreasing order of labels (second direction). These are $4L$ orderings. Let $\alpha,\beta,\gamma$ be three people and suppose we want them in the order $\alpha,\beta,\gamma$. As $\alpha\ne\gamma$, they differ in some digit $j$, and $\beta$ agrees there with exactly one of them. Take $e$ to be the $j$-th digit of $\alpha$.

  • If $\beta$ agrees with $\gamma$, then $\alpha$ is in the first group and $\beta,\gamma$ are in the second group, so $\alpha$ comes first, and $\beta$ comes before $\gamma$ in one of the two directions.

  • If $\beta$ agrees with $\alpha$, then $\alpha,\beta$ are in the first group and $\gamma$ is in the second, so $\gamma$ comes last, and $\alpha$ comes before $\beta$ in one of the two directions.

Hence the family is good and $f(n)\le4\lceil\log_2n\rceil\le4(\log_2n+1)\le8\log_2n$.

So $\frac12\log_2n\le f(n)\le8\log_2n$ for all $n\ge3$.

So $\boxed{P(x)=c^2x^d}$ with $c\in\mathbb Z$, $d\ge0$.

Solution 2 (A two-variable polynomial identity)

Put $g(a)=\lfloor Q(a)\rfloor$ and $c=g(1)\in\mathbb Z$, so $P(ab)=g(a)g(b)$. Taking $b=1$ gives $P(a)=c\,g(a)$, and $a=b=1$ gives $P(1)=c^2$. Multiplying $P(ab)=g(a)g(b)$ by $c^2$, \[c^2P(ab)=P(a)P(b)\qquad\text{for all positive integers }a,b .\] The two-variable polynomial $D(x,y)=c^2P(xy)-P(x)P(y)$ vanishes on all pairs of positive integers; for each fixed $b$, $D(x,b)$ has infinitely many roots, so $D(x,b)=0$ identically, hence each coefficient (a polynomial in $y$) vanishes at every positive integer $b$, so $D\equiv0$. Write $P=\sum p_ix^i$. In $c^2P(xy)$ only monomials $x^iy^i$ occur, while the coefficient of $x^iy^j$ in $P(x)P(y)$ is $p_ip_j$. Hence $p_ip_j=0$ for $i\ne j$: $P$ has at most one non-zero coefficient, $P=p_dx^d$. If $P\ne0$, comparing $x^dy^d$ gives $c^2p_d=p_d^2$, so $p_d=c^2$. Hence $P=c^2x^d$ (and $P\equiv0$ is the case $c=0$). Conversely, for $P=c^2x^d$ take $Q=cx^d$; then $\lfloor Q(a)\rfloor\lfloor Q(b)\rfloor=c^2a^db^d=P(ab)$. So $\boxed{P(x)=c^2x^d}$ with $c\in\mathbb Z$, $d\ge0$.

Problem 20

Geometry · LPS VII, Chapter 45: Complex Numbers in Geometry

Let $ABC$ be a scalene triangle with circumcenter $O$ and orthocenter $H$. A point $K$ lies inside $\triangle ABC$ such that $\angle KAB=\angle KCA$ and $\angle KAC=\angle KBA$. Let $M$ be the midpoint of $BC$, and let $Z$ be the reflection of $A$ across line $OM$. Let lines $HM$ and $ZO$ meet at $P$. If points $O,H,K$ are collinear, prove that quadrilateral $KPMZ$ is cyclic.

Show the solution

Solution (Complex numbers with BC symmetric about the real axis)

Use complex numbers with the circumcircle as the unit circle, rotated so that $bc=1$. Then $u:=b+c$ is real, $M=\frac u2$ lies on the real axis, line $OM$ is the real axis, and $u\ne0$ (the perpendicular bisector of $BC$ is a line through $O$, so $O\ne M$ unless $BC$ is a diameter; in that case $u=0$, and we exclude it as degenerate). Put $t=a+\frac1a=a+\bar a$, a real number. Since the triangle is scalene, $A$ is not on the real axis, i.e. $a\ne\pm1$, $a\ne\bar a$. Then \[H=a+b+c=a+u,\qquad Z=\bar a=\frac1a .\]

The point $K$. The conditions $\angle KBA=\angle KAC$ and $\angle KAB=\angle KCA$ say that triangles $KBA$ and $KAC$ are directly similar ($K$ is inside the triangle, so both triangles have the same orientation), i.e. the spiral similarity about $K$ maps $B\mapsto A$, $A\mapsto C$: \[\frac{a-k}{b-k}=\frac{c-k}{a-k}\iff (a-k)^2=(b-k)(c-k)\iff k=\frac{a^2-bc}{2a-b-c}=\frac{a^2-1}{2a-u}.\]

The hypothesis. $O,H,K$ are collinear iff $K/H$ is real. Using $\bar a=1/a$, \[\frac KH=\frac{a^2-1}{(2a-u)(a+u)},\qquad \overline{\Bigl(\frac KH\Bigr)}=\frac{1-a^2}{(2-au)(1+au)} .\] They are equal iff $(a^2-1)\bigl[(2-au)(1+au)+(2a-u)(a+u)\bigr]=0$. As $a^2\ne1$, and the bracket equals $(a^2+1)(2-u^2)+2au$, dividing by $a$ the hypothesis becomes \[t\,(u^2-2)=2u. \tag{1}\]

The point $P$. Points of line $OZ$ are $\lambda/a$ ($\lambda$ real), points of line $HM$ are $\frac u2+\mu\bigl(a+\frac u2\bigr)$ ($\mu$ real). Equating, multiplying by $a$ and comparing with the conjugate equation gives $(a-\frac1a)\bigl(\frac u2+\mu(t+\frac u2)\bigr)=0$, so $\mu=-\frac{u}{2t+u}$ and \[P=\frac{u}{a(2t+u)} .\]

Concyclicity. $K,P,M,Z$ are concyclic iff the cross-ratio $\rho=\frac{K-M}{K-Z}\cdot\frac{P-Z}{P-M}$ is real. A direct computation gives \[\frac{P-Z}{P-M}=\frac{4t}{a\,u\,(2a+u)},\qquad \frac{K-M}{K-Z}=\frac{a\,(2a^2-2au+u^2-2)}{2\,(a^3-3a+u)},\] so $\rho=\dfrac{2t}{u}\cdot\dfrac{2a^2-2au+u^2-2}{(2a+u)(a^3-3a+u)}$. Hence $\rho$ is real iff $N_1E_0-N_0E_1=0$. Expanding, \[N_1E_0-N_0E_1=-(2t^2+tu-12)\bigl(t(u^2-2)-2u\bigr),\] which vanishes by (1). Therefore $K,P,M,Z$ are concyclic.

Problem 21

Combinatorics · LPS VII, Chapter 44: Combinatorial Games and Strategy

There are $100$ boxes on a table, each containing some number of cookies. Freddie the Frog and Toby the Toad each own a shelf that holds up to $50$ boxes. They play a game, with Freddie going first, and players alternating turns until no boxes remain on the table. On a player's turn, they choose a box on the table, and the other player places it on either shelf, provided the shelf is not yet full.

Prove that Toby can guarantee to get at least as many cookies as Freddie.

Show the solution

Solution (Partial progress: small cases and what a proof must use)

This is a partial solution: the statement is verified by computer for small games, but we have no general proof.

Model: there are $2m$ boxes ($m=50$); each turn the chooser picks a box and the other player places it on a shelf with free space; Freddie chooses on odd turns.

The case $m=1$. Freddie picks a box; Toby puts it on his own shelf if it is the larger box and on Freddie's shelf otherwise; the last box goes to the remaining shelf. Toby gets the larger box.

Observations.

  • A sufficient condition for Toby $\ge$ Freddie is the "ballot" condition: for every $j$, among the $j$ largest boxes Toby holds at least as many as Freddie (by Abel summation). However, an exhaustive search shows that Toby cannot force the ballot condition using only the ranks of the boxes when $m\ge2$; so any winning strategy must depend on the actual numbers of cookies.

  • The minimax value satisfies a capacity monotonicity found by computer: with Freddie to choose and Toby's free space at least Freddie's, the value (Toby minus Freddie) is $\ge0$; with Toby to choose, it is $\ge0$ when Toby's free space exceeds Freddie's.

A reduction (proved). For a set $R$ of boxes and capacities $a,b$, let $U(R,a,b)$ be the value (own total minus opponent's total, under optimal play) for a player $X$ with $a$ free places who chooses first against $Y$ with $b$ free places, and $W(R,a,b)$ the value for $X$ when $Y$ chooses first (so $X$ places first). Toby's value in the actual game is $W(R,50,50)$, and $U(R,50,50)=-W(R,50,50)$ (the same game seen from Freddie's side), so it suffices to show $W\ge U$ when $|R|$ is even. Two facts:

  • Lipschitz. Replacing one box $x$ by $y$ changes $U$ and $W$ by at most $|y-x|$ (copy the strategies, treating the changed box as the same box).

  • Even step. If $U(S,\cdot,\cdot)\ge W(S,\cdot,\cdot)$ for all sets $S$ of odd size, then $W(R,a,b)\ge U(R,a,b)$ for $|R|$ even. If $a=0$ or $b=0$ all placements are forced and $U=W$. Otherwise put $\varphi(x)=x+W(R\setminus x,a-1,b)$ and $\psi(x)=-x+W(R\setminus x,a,b-1)$. By the Lipschitz fact, $\varphi$ is non-decreasing and $\psi$ non-increasing in the value of the box $x$. Now $U(R,a,b)=\max_y\min(\varphi(y),\psi(y))$, and, using the hypothesis, $W(R,a,b)\ge\min_x\max(\varphi(x),\psi(x))$. For any boxes $x,y$: if $x\le y$ then $\max(\varphi(x),\psi(x))\ge\psi(x)\ge\psi(y)\ge\min(\varphi(y),\psi(y))$, and if $x\ge y$ the same holds with $\varphi$. Hence $W\ge U$.

So the problem reduces to the odd claim $U(S,a,b)\ge W(S,a,b)$ for $|S|$ odd (when an odd number of boxes remain, choosing first is at least as good as placing first). The odd claim is confirmed by exact computation but the analogous min–max argument does not prove it; it is the missing step.

What is missing. An explicit strategy for Toby (or a strategy-stealing/potential argument) valid for all $m$; the natural invariant is the pair of capacity inequalities above, but we could not find a potential function that is preserved.

Problem 22

Algebra · LPS VII, Chapter 46: Functional Equations: Iteration, Rigidity, and Deep Structure

Let $k\ge 2$ be a fixed integer. Determine all functions $f:\mathbb{N}\to\mathbb{N}$ such that, for every $n\in\mathbb{N}$, $f^k(n)$ is the number of distinct integers in the set $\{f(1),f(2),\dots,f(n)\}$.

Note: $f^k=f\circ f\circ\dots\circ f$ ($k$ times).

Show the answer

either $f$ is a permutation of $\mathbb N$ with $f^k=\mathrm{id}$, or for some $m\ge1$ $f$ permutes $\{1,\dots,m\}$ with $f^k=\mathrm{id}$ there and $f(n)=f(m)$ for all $n>m$

Show the solution

Solution (Fixed points of the counting function)

Let $D(n)=|\{f(1),\dots,f(n)\}|$, so $f^k(n)=D(n)$. Clearly $D(1)=1$, $D(n)\le n$, and $D(n+1)-D(n)\in\{0,1\}$, with $D(n+1)=D(n)+1$ exactly when $f(n+1)$ is a new value.

Key identity. $f(D(n))=f(f^k(n))=f^k(f(n))=D(f(n))$ for all $n$.

Fixed points of $D$. If $D(x)<x$ then $D(y)<y$ for all $y>x$, since $D$ grows by at most $1$ per step. So $\{x:D(x)=x\}$ is an initial segment $\{1,\dots,m\}$ with $1\le m\le\infty$.

Step 1: $f$ permutes $\{1,\dots,m\}$ and $f^k=\mathrm{id}$ there. For $n\le m$, $D(n)=n$ means $f(1),\dots,f(n)$ are distinct, so $f$ is injective on $\{1,\dots,m\}$, and $f^k(n)=D(n)=n$. The key identity gives $D(f(n))=f(D(n))=f(n)$, so $f(n)$ is a fixed point of $D$, i.e. $f(n)\le m$. Hence $f$ maps $\{1,\dots,m\}$ injectively into itself (a bijection if $m$ is finite; if $m=\infty$, $f$ is injective with $f^k=\mathrm{id}$, hence a bijection of $\mathbb N$).

Step 2: if $m<\infty$, then $D(n)=m$ for all $n\ge m$. We have $D(m+1)=m$. Suppose $D$ takes the value $m+1$, first at $p>m+1$; then $f(p)$ is new, so $f(p)\notin f(\{1,\dots,m\})=\{1,\dots,m\}$, i.e. $f(p)>m$. By the key identity $D(f(p))=f(D(p))=f(m+1)$. Since $D(m+1)=D(m)$, $f(m+1)$ is not new, so $f(m+1)\in\{1,\dots,m\}$; thus $D(f(p))\le m$, and as $D$ is non-decreasing with $D(p)=m+1$, we get $q:=f(p)<p$, $q>m$, $D(q)=m$. Then $f(q)$ is not new, so $f(q)\in\{1,\dots,m\}$, and since $f$ maps $\{1,\dots,m\}$ into itself, $f^{k}(p)=f^{k-1}(q)\in\{1,\dots,m\}$ (here $k-1\ge1$). But $f^k(p)=D(p)=m+1$. Contradiction.

Step 3: the values for $n>m$. For $n>m$, $f(n)$ is not new, so $f(n)\in\{1,\dots,m\}$, and $f^{k-1}(f(n))=D(n)=m$. On $\{1,\dots,m\}$, $f^{k-1}=f^{-1}$ (because $f^k=\mathrm{id}$), so $f(n)=f(m)$.

Verification. If $f$ is a permutation of $\mathbb N$ with $f^k=\mathrm{id}$, then $D(n)=n=f^k(n)$. In the second family, $D(n)=n=f^k(n)$ for $n\le m$, and for $n>m$, $D(n)=m$ and $f^k(n)=f^{k-1}(f(m))=f^k(m)=m$.

Answer. The solutions are exactly: (i) the permutations $f$ of $\mathbb N$ with $f^k=\mathrm{id}$, and (ii) for some $m\ge1$, the functions $f$ that permute $\{1,\dots,m\}$ with $f^k=\mathrm{id}$ there and satisfy $f(n)=f(m)$ for all $n>m$. (For example $f\equiv1$ is the case $m=1$ of (ii), and $f=\mathrm{id}$ is in (i).)

conjecture: yes

Problem 24

Algebra · LPS VII, Chapter 46: Functional Equations: Iteration, Rigidity, and Deep Structure

Find all functions $f:\mathbb{R}^+\to\mathbb{R}^+$ satisfying \[f(2x)f(y)=f(x)\bigl(f(x+y)-f(x-y)\bigr)\] for all positive real numbers $x>y$.

Show the answer

$f(x)=cx$ and $f(x)=c\sinh(kx)$ with constants $c,k>0$

Show the solution

Solution (Monotonicity gives smoothness, then an ODE)

These work. For $f=cx$: $c\cdot2x\cdot cy=cx\cdot c\,(2y)$. For $f=c\sinh kx$: $\sinh k(x+y)-\sinh k(x-y)=2\cosh kx\,\sinh ky$ and $\sinh 2kx=2\sinh kx\cosh kx$, so both sides equal $2c^2\sinh kx\cosh kx\sinh ky$.

Conversely, let $f$ be a solution and $g(x)=f(2x)/f(x)>0$, so \[f(x+y)-f(x-y)=g(x)f(y)\qquad(x>y>0). \tag{1}\]

Step 1: $f$ is increasing. For $0<v<w$ put $x=\frac{v+w}2$, $y=\frac{w-v}2$ in (1): $f(w)-f(v)=g(x)f(y)>0$.

Step 2: $f(0^+)=0$ and $f$ is continuous. By monotonicity $L=\lim_{y\to0^+}f(y)\ge0$ exists, and for each $x>0$ the one-sided limits $f(x^\pm)$ exist. Letting $y\to0^+$ in (1): $f(x^+)-f(x^-)=g(x)L$. If $L>0$, $f$ would jump at every $x>0$; but an increasing function has only countably many jumps (the jump intervals $(f(x^-),f(x^+))$ are disjoint and each contains a rational). Hence $L=0$, and then $f(x^+)=f(x^-)$, so $f$ is continuous; consequently $g$ is continuous too.

Step 3: $f$ is infinitely differentiable. Let $\Phi(t)=\int_0^tf$ (finite, since $f$ is bounded near $0$). Fix $0<a<b$ and integrate (1) over $x\in[a,b]$, for $0<y<a$: \[f(y)\int_a^bg=\Phi(b+y)-\Phi(a+y)-\Phi(b-y)+\Phi(a-y).\] Here $\int_a^bg>0$. If $f\in C^n$, then $\Phi\in C^{n+1}$ and the right side is $C^{n+1}$ in $y$, so $f\in C^{n+1}$ on $(0,a)$; as $a$ is arbitrary, $f\in C^{n+1}$. By induction $f\in C^\infty$. Similarly, integrating (1) over $y\in[0,h]$ for $0<h<x$ gives $g(x)\Phi(h)=\Phi(x+h)-2\Phi(x)+\Phi(x-h)$, so $g\in C^\infty$ as well.

Step 4: an ODE. Differentiate (1) twice with respect to $y$, and separately twice with respect to $x$: \[f''(x+y)-f''(x-y)=g(x)f''(y)=g''(x)f(y).\] So $\dfrac{f''(y)}{f(y)}=\dfrac{g''(x)}{g(x)}$ whenever $x>y$. For any $y_1,y_2$ choose $x>y_1,y_2$; then $f''(y_1)/f(y_1)=f''(y_2)/f(y_2)$. Hence $f''=\kappa f$ for a constant $\kappa$.

Step 5: solving. If $\kappa=-k^2<0$, then $f(x)=R\sin(kx+\varphi)$, which takes non-positive values; impossible. If $\kappa=0$, $f=\alpha x+\beta$ and $f(0^+)=0$ gives $\beta=0$, $f=cx$ with $c>0$. If $\kappa=k^2>0$, $f=\alpha e^{kx}+\beta e^{-kx}$ and $f(0^+)=0$ gives $\beta=-\alpha$, i.e. $f=c\sinh kx$, with $c>0$ since $f>0$.

So the solutions are $\boxed{f(x)=cx\ \text{or}\ f(x)=c\sinh(kx)}$ with constants $c,k>0$.

Problem 25

Combinatorics · LPS VII, Chapter 52: Advanced Combinatorial Structure and Hybrid Methods

Tom and Jerry are playing a game on an $n\times n$ grid. Initially, Tom colors each square with one of two colors. Jerry picks a square on the grid to start on. In each move, Jerry moves to a square sharing a side with the current square he is occupying, under the constraint that he can visit a square for the $k^{\text{th}}$ time only if he has visited every square at least $k-1$ times. Every time Jerry completes a move, Jerry reports the color of his new square to Tom.

Tom wins the game if either

  • Jerry cannot make a move, or

  • Tom can determine the square Jerry started on.

Find all $n\ge 2$ for which Tom can guarantee a win.

Note: Starting on a square counts as a visit.

Show the answer

Tom can guarantee a win exactly for odd $n$

Show the solution

Solution (Hamiltonian rounds, a four-square switch, and stripes)

Number Jerry's visits $1,2,3,\dots$ (the start is visit $1$). The rule says that a square may be visited for the $k$-th time only after every square has been visited $k-1$ times. Hence visits $1,\dots,n^2$ go to $n^2$ distinct squares: they form a Hamiltonian path of the grid starting at Jerry's square. Visits $n^2+1,\dots,2n^2$ again form a Hamiltonian path, starting at a neighbour of the end of the first one, and so on. We call these blocks of $n^2$ visits rounds. Conversely, any walk made of such rounds is allowed.

Odd $n$: Tom wins with any colouring. Colour the grid like a chessboard. The corner colour has $\frac{n^2+1}2$ squares and the other colour $\frac{n^2-1}2$. A path alternates colours, so a path through all $n^2$ squares ($n^2$ odd) starts and ends on the corner colour. If Jerry starts on the other colour, round $1$ can never be completed. Otherwise round $1$ ends on the corner colour, so round $2$ starts on a neighbour of it, which has the other colour, and round $2$ can never be completed. In both cases Jerry is stuck after finitely many moves, and Tom wins.

Even $n$: Jerry wins against every colouring. It suffices to find two different starting squares and two infinite allowed walks from them that report the same colours at every move: Jerry follows one of them, and at every moment the other one is consistent with everything Tom has seen, so Tom can never determine the start (and Jerry never gets stuck).

Write the squares as $(r,c)$, $0\le r,c\le n-1$, and call the four squares of rows $i,i+1$ and columns $j,j+1$ a block; its four sides are the four grid edges inside it.

Lemma 1 (the switch). Suppose a Hamiltonian cycle $H$ of the grid contains three sides of a block, forming the path $X\!-\!Y\!-\!Z\!-\!W$ (so $X,Z$ are opposite corners of the block, $Y,W$ the other two, and $XW$ is the fourth side). If $X$ and $Z$ have the same colour, Jerry wins.

Proof. Let $H$ be $X,Y,Z,W,v_5,\dots,v_{N},X$ with $N=n^2$. Walk 1: start at $X$ and go around $H$ in this order forever; each round is $X,Y,Z,W,v_5,\dots,v_N$ and the next round starts at $X$, a neighbour of $v_N$. Walk 2: start at $Z$, then $Y$, $X$, $W$ (all are grid neighbours; $XW$ is a side of the block), then $v_5,\dots,v_N$; this is again a Hamiltonian path, and from then on walk 2 copies walk 1. After the first round both walks are at $v_N$ with every square visited exactly once, so walk 2 is allowed. The reported colours are $Y,Z,W,v_5,\dots$ and $Y,X,W,v_5,\dots$, which agree because $X$ and $Z$ have the same colour; afterwards the walks coincide. The starts $X\ne Z$ differ. $\square$

Reading the path from the other end ($W\!-\!Z\!-\!Y\!-\!X$), the lemma also applies when $Y,W$ have the same colour. So if $H$ contains three sides of a block and some diagonal of that block is monochromatic, Jerry wins.

Lemma 2. For $n$ even and every block $Q$, the grid has a Hamiltonian cycle containing three sides of $Q$.

Proof. For $n=2$ the grid is a $4$-cycle. Let $n\ge4$. We use the merging step: if $C_1,C_2$ are disjoint cycles, $uv$ an edge of $C_1$ and $u'v'$ an edge of $C_2$ with $u u'$, $v v'$ grid edges (the four squares form a block), then deleting $uv,u'v'$ and adding $uu',vv'$ joins the paths $C_1-uv$ and $C_2-u'v'$ into one cycle through all vertices of $C_1$ and $C_2$. We split the grid into disjoint cycles, one of which carries three sides of $Q$, and merge them one by one along a tree, each step using two edges that no other step uses and that are not among the three protected sides. The boundary of a $2\times w$ rectangle of squares ($w\ge2$) is a cycle through all its squares. Let $Q$ have top-left square $(i,j)$. Transposing the grid if necessary, we may assume that $i$ is even, or that $i$ and $j$ are both odd.

  • $i,j$ odd. Take the outer ring of squares (a cycle) and the $2\times2$ blocks with odd top-left coordinates, which tile the inner $(n-2)\times(n-2)$ square; $Q$ is one of them. Merge each such block with the block directly above it, or with the ring if it is in the top inner row, using its top side and the edge just above it; but merge the blocks below $Q$ in its column downwards (the lowest one into the ring). Then $Q$ only loses its top side.

  • $i$ even. Cut the grid into the row pairs $\{2k,2k+1\}$, each a $2\times n$ rectangle, except that the pair $\{i,i+1\}$ is cut into a rectangle $R_Q$ having $Q$ at one end and at most one further rectangle $L$, all of width $\ge2$: if $j\ne1$, $R_Q$ is columns $j,\dots,n-1$ and $L$ is columns $0,\dots,j-1$ (absent if $j=0$); if $j=1$ and $n\ge6$, $R_Q$ is columns $0,1,2$ and $L$ is columns $3,\dots,n-1$. The boundary of $R_Q$ contains the three sides of $Q$ not facing the rest of $R_Q$. Merge consecutive full row pairs through their edges in columns $0,1$. Join $R_Q$ and $L$ to the row pair above (if $i\ge2$) through an edge of their top rows, using for $R_Q$ the top edge in columns $n-2,n-1$ if $j\ne1$ and in columns $0,1$ if $j=1$ (this is the end of $R_Q$ away from $Q$, or the top side of $Q$ itself if $R_Q=Q$); join the row pair below (if any) to $L$, or to $R_Q$ through its bottom edge at the end away from $Q$ if $L$ is absent; if $i=0$ join both $R_Q$ and $L$ to the row pair below in the same way. In every case $Q$ loses at most one side. Finally, for $n=4$, $j=1$, the cycle $(0,0)$, $(1,0)$, $(2,0)$, $(3,0)$, $(3,1)$, $(2,1)$, $(2,2)$, $(3,2)$, $(3,3)$, $(2,3)$, $(1,3)$, $(0,3)$, $(0,2)$, $(1,2)$, $(1,1)$, $(0,1)$ contains three sides of the block at $(0,1)$, and its mirror image in the horizontal axis handles the block at $(2,1)$. $\square$

Conclusion. If some block has a monochromatic diagonal, Lemmas 1 and 2 give Jerry a win. Otherwise for all $i,j$ \[c(i+1,j+1)\ne c(i,j)\quad\text{and}\quad c(i+1,j)\ne c(i,j+1),\] where $c$ is the colour. Applying the first relation to the block at $(i,j)$ and the second to the block at $(i,j+1)$ gives $c(i,j)=c(i,j+2)$; similarly $c(i,j)=c(i+2,j)$. So the colour depends only on $(i\bmod2,j\bmod2)$, and the two relations force either $c(i,j)$ to depend only on $i$ (horizontal stripes) or only on $j$ (vertical stripes). Then the reflection $\sigma$ of the board in its vertical axis (for horizontal stripes) or horizontal axis (for vertical stripes) preserves the colouring and, $n$ being even, moves every square. Since $n$ is even the grid has a Hamiltonian cycle (Lemma 2); let Jerry go around it forever from a square $s$. The mirror image of this walk under $\sigma$ is an allowed walk from $\sigma(s)\ne s$ reporting the same colours, so again Jerry wins.

Therefore Tom can guarantee a win if and only if $n$ is odd; the answer is $\boxed{\text{all odd } n\ge3}$.

Problem 26

Number Theory · LPS VII, Chapter 29: Valuations and Lifting the Exponent

We call a positive integer $n$ insomniac if \[\varphi(n!)+\varphi(n)!=m^2\] for some integer $m$. Prove that there exist only finitely many positive integers which are insomniac.

Note: $\varphi(n)$ is the number of positive integers less than or equal to $n$ that are coprime to $n$.

Show the solution

Solution (An odd valuation from a well-placed prime)

Let $N=\varphi(n)$, $A=\varphi(n!)$ and $B=N!$. We show that for every large $n$ there is a prime $p$ with $v_p(A)\ne v_p(B)$ and $\min(v_p(A),v_p(B))$ odd. Then $v_p(A+B)=\min(v_p(A),v_p(B))$ is odd, so $A+B$ is not a perfect square; hence only finitely many $n$ are insomniac. (For example $n=3$ is insomniac: $\varphi(6)+\varphi(3)!=4$.)

Tools. Bertrand's postulate, and the prime number theorem for arithmetic progressions: for a fixed integer $h\ge1$, the number $\pi(x;h,1)$ of primes $p\le x$ with $p\equiv1\pmod h$ satisfies $\pi(x;h,1)\sim\frac{x}{\varphi(h)\ln x}$ as $x\to\infty$. For fixed reals $0<a<b$ it gives $\pi(bn;h,1)-\pi(an;h,1)\sim\frac{(b-a)\,n}{\varphi(h)\ln n}\to\infty$, hence

  • (T) for fixed reals $0<a<b$ and a fixed integer $h\ge1$, the interval $(an,bn)$ contains a prime $p\equiv1\pmod h$ for all large $n$.

Two facts. (i) Writing $n!=\prod_{q\le n}q^{e_q}$ over the primes $q\le n$, with $e_q=v_q(n!)\ge1$, we have $\varphi(n!)=\prod_{q\le n}q^{e_q-1}(q-1)$, so for a prime $p\le n$ \[v_p(A)=e_p-1+\sum_{q\le n\text{ prime}}v_p(q-1).\tag{1}\] (ii) $N\to\infty$: for a prime power, $\varphi(p^e)^2=p^{2e-2}(p-1)^2\ge p^e$ unless $p^e=2$, where $\varphi(2)^2=1=\frac22$; by multiplicativity $\varphi(n)^2\ge\frac n2$.

Case 1: $N\le0.32\,n$. By Bertrand there is a prime $p$ with $\frac N2<p\le N$. For large $n$, $N\ge5$, so $p^2>\frac{N^2}4>N$ and $v_p(B)=\lfloor N/p\rfloor=1$. Since $3p\le3N\le0.96\,n$, $e_p\ge3$, and (1) gives $v_p(A)\ge2$. The minimum is $1$.

Case 2: $N>0.32\,n$. Note $N\le n-1<n$. Choose the row of the table below containing $N/n$, and by (T) with $h=15$ a prime $p\equiv1\pmod{15}$ with $p/n$ in the open interval of that row. In every row $p>0.18\,n$, so for large $n$ we have $p^2>n>N$; then $e_p=\lfloor n/p\rfloor$ and $v_p(B)=\lfloor N/p\rfloor$. Moreover $n/p<1/0.185<6$. A prime $q\le n$ with $p\mid q-1$ would be $q=jp+1$ with $1\le j\le5$. For odd $j$, $jp+1$ is even and larger than $2$; $2p+1$ is divisible by $3$ (as $p\equiv1\pmod3$) and larger than $3$; $4p+1$ is divisible by $5$ (as $p\equiv1\pmod5$) and larger than $5$. So the sum in (1) is empty and \[v_p(A)=\lfloor n/p\rfloor-1,\qquad v_p(B)=\lfloor N/p\rfloor .\] The bounds for $n/p$ and $N/p$ follow by dividing the bounds for $N/n$ and $p/n$: \[\begin{array}{c|c|c|c|c|c} N/n & p/n & n/p & N/p & v_p(A) & v_p(B)\\ \hline (0.32,\,0.60] & (0.305,\,0.315) & (3.17,\,3.28) & (1.01,\,1.97) & 2 & 1\\ (0.60,\,0.72] & (0.185,\,0.190) & (5.26,\,5.41) & (3.15,\,3.90) & 4 & 3\\ (0.72,\,1) & (0.340,\,0.350) & (2.85,\,2.95) & (2.05,\,2.95) & 1 & 2 \end{array}\] (For instance in the second row $n/p>1/0.19>5.26$, $n/p<1/0.185<5.41$, $N/p>0.6/0.19>3.15$ and $N/p<0.72/0.185<3.9$.) In every row the two valuations differ and the smaller one is odd.

So for all sufficiently large $n$ the number $\varphi(n!)+\varphi(n)!$ is not a square, and there are only finitely many insomniac integers.

Problem 27

Geometry · LPS VII, Chapter 48: Inversion and Circle-Preserving Transformation

Let $ABC$ be a scalene triangle with $D,E,F$ the feet of altitudes from $A$, $B$, and $C$. Let $(AEF)$ meet $(ABC)$ at $H$ and $A$, and let $AH$ meet $BC$ at $O$. Let $M$ be the midpoint of $BC$. Let $(AOM)$ meet $(AEF)$ at $L$ and $A$, and $(MEF)$ at $M$ and $P$. Let $AL$ and $(APD)$ meet $(ABC)$ at $Z$ and $R$ respectively, apart from $A$. Show that $O$, $R$ and $Z$ are collinear.

Note: $(XYZ)$ denotes the circumcircle of $\triangle XYZ$.

Show the solution

Solution (Two inversions, at O and at the orthocentre)

Notation: $\Gamma=(ABC)$; $\mathcal N=(DEF)$, the nine-point circle, which also passes through $M$; $K_0$ the orthocentre (to avoid a clash with the problem's $H$, which is the second intersection of $(AEF)$ and $\Gamma$; $(AEF)$ is the circle with diameter $AK_0$). All products of lengths along a line are signed.

Standard facts. (a) Since $\angle AHK_0=90^\circ$, the line $HK_0$ passes through the antipode $A'$ of $A$, and hence through $M$, the midpoint of $K_0A'$. So $K_0M\perp AH$. (b) $AH$, $EF$, $BC$ are the radical axes of $\Gamma$, $(AEF)$, $(BCEF)$, so they concur at $O$, and $OB\cdot OC=OA\cdot OH=OE\cdot OF$. (c) $(B,C;D,O)$ is harmonic (complete quadrilateral of the cevians through $K_0$), and with $M$ the midpoint of $BC$ this gives $OB\cdot OC=OD\cdot OM$.

Let $\Psi_O$ be the inversion with centre $O$ and power $k_O=OB\cdot OC$, and $\Psi_K$ the inversion with centre $K_0$ and power $k_K=\overline{K_0A}\cdot\overline{K_0D}$ (a signed product: $X\mapsto X'$ on line $K_0X$ with $\overline{K_0X}\cdot\overline{K_0X'}=k_K$). We use repeatedly: a circle $\omega$ with $\mathrm{pow}_Z(\omega)=k$ is mapped to itself by the inversion centred at $Z$ with power $k$, which swaps the two intersections of $\omega$ with each line through $Z$.

$\Psi_O$. By (b), (c): $\Psi_O$ swaps $B\leftrightarrow C$, $A\leftrightarrow H$, $E\leftrightarrow F$, $D\leftrightarrow M$, fixes $\Gamma$ and fixes $\mathcal N$ (it maps $D,M,E,F$ to $M,D,F,E$). The circle $(AOM)$ passes through $O$, so it goes to the line $HD$. Hence $\Psi_O(P)$, which lies on $\mathcal N$ and on line $HD$ and differs from $\Psi_O(M)=D$, is \[Z':=\text{the second intersection of line }HD\text{ with }\mathcal N .\]

$\Psi_K$. $k_K=\overline{K_0A}\cdot\overline{K_0D}=\overline{K_0B}\cdot\overline{K_0E}=\overline{K_0C}\cdot\overline{K_0F}$, so $\Psi_K$ swaps $A\leftrightarrow D$, $B\leftrightarrow E$, $C\leftrightarrow F$ and maps $\Gamma$ to $\mathcal N$. Also $\Psi_K(H)=M$: the power of $K_0$ with respect to $\Gamma$ is $\overline{K_0H}\cdot\overline{K_0A'}$, and also $2k_K$ (the altitude meets $\Gamma$ again at the reflection of $K_0$ in $BC$, at signed distance $2\overline{K_0D}$); since $\overline{K_0M}=\tfrac12\overline{K_0A'}$, we get $\overline{K_0H}\cdot\overline{K_0M}=k_K$.

Step 1: $Z$ lies on $(AK_0M)$. $L$ lies on $(AEF)$, the circle with diameter $AK_0$, so $K_0L\perp AZ$; also $A'Z\perp AZ$. Thus $K_0L\parallel A'Z$, and since $M$ is the midpoint of $K_0A'$, its projection on $AZ$ is the midpoint of $LZ$: $ML=MZ$. With directed angles, \[\angle(ZM,ZA)=\angle(LZ,LM)=\angle(LA,LM)=\angle(OA,OM)=\angle(OA,BC),\] using the isosceles triangle $MLZ$, the collinearity of $A,L,Z$, and $L\in(AOM)$. By (a), $K_0M\perp OA$, and $K_0A\perp BC$; turning both lines by $90^\circ$, $\angle(K_0M,K_0A)=\angle(OA,BC)$. Hence $\angle(ZM,ZA)=\angle(K_0M,K_0A)$ and $Z\in(AK_0M)$.

Step 2: $\Psi_K(Z)=Z'$. The circle $(AK_0M)$ passes through $K_0$, so $\Psi_K$ maps it to the line through $\Psi_K(A)=D$ and $\Psi_K(M)=H$. Since $Z\in\Gamma$, $\Psi_K(Z)\in\mathcal N\cap HD$, and $\Psi_K(Z)\ne\Psi_K(A)=D$; so $\Psi_K(Z)=Z'$.

Step 3: $\Psi_K(R)=P$. The circle $(APD)$ passes through $A$ and $D$, so the power of $K_0$ with respect to it is $k_K$ and $\Psi_K$ maps it to itself. It meets $\Gamma$ at $A,R$, so $\Psi_K$ maps these to its intersections with $\mathcal N$, which are $D$ and $P$. As $\Psi_K(A)=D$, $\Psi_K(R)=P$.

Step 4: $A,H,P,Z'$ are concyclic. The circle $(AHP)$ has power $OA\cdot OH=k_O$ with respect to $O$, so it is fixed by $\Psi_O$; it therefore contains $\Psi_O(P)=Z'$.

Step 5: $D,M,R,Z$ are concyclic. Apply $\Psi_K$ to the circle through $A,H,P,Z'$: its image passes through $\Psi_K(A)=D$, $\Psi_K(H)=M$, $\Psi_K(P)=R$, $\Psi_K(Z')=Z$. (In general position this circle does not pass through $K_0$, so the image is a circle.)

Conclusion. The power of $O$ with respect to the circle $(DMRZ)$ is $OD\cdot OM=OB\cdot OC$, the same as with respect to $\Gamma$. So $O$ lies on the radical axis of $\Gamma$ and $(DMRZ)$, which is the line $RZ$. Hence $O$, $R$, $Z$ are collinear.

Problem 28

Algebra · LPS VII, Chapter 1: Inequalities: Core Classical Methods

Call a function $f:\mathbb{R}^-\to\mathbb{R}^-$ auraic if for all $x,y,z<0$, we have \[\frac{xf(y)}{f(z)}+\frac{yf(z)}{f(x)}+\frac{zf(x)}{f(y)}\le f(x)+f(y)+f(z).\] Determine all auraic functions. (Note: $\mathbb{R}^-$ denotes the set of all negative real numbers.)

Show the answer

exactly the functions $f:\mathbb R^-\to\mathbb R^-$ with $f(x)\ge x$ for all $x<0$

Show the solution

Solution (Pass to positive variables)

Put $g(t)=-f(-t)$ for $t>0$, so $g:\mathbb R^+\to\mathbb R^+$, and write $x=-a$, $y=-b$, $z=-c$ with $a,b,c>0$. Then $\dfrac{xf(y)}{f(z)}=\dfrac{(-a)(-g(b))}{-g(c)}=-\dfrac{ag(b)}{g(c)}$, and the condition becomes \[\frac{a\,g(b)}{g(c)}+\frac{b\,g(c)}{g(a)}+\frac{c\,g(a)}{g(b)}\ \ge\ g(a)+g(b)+g(c)\qquad\text{for all }a,b,c>0. \tag{1}\]

Necessity. With $a=b=c$, (1) reads $3a\ge3g(a)$, i.e. $g(a)\le a$, i.e. $f(x)\ge x$.

Sufficiency. Let $g(t)\le t$ for all $t$. Put $u=g(a)$, $v=g(b)$, $w=g(c)$. Since $a\ge u$, $b\ge v$, $c\ge w$ and all ratios are positive, \[\frac{av}{w}+\frac{bw}{u}+\frac{cu}{v}\ \ge\ \frac{uv}{w}+\frac{vw}{u}+\frac{wu}{v}.\] Finally $\frac{uv}{w}+\frac{vw}{u}+\frac{wu}{v}\ge u+v+w$: with $X=\frac{uv}{w},Y=\frac{vw}{u},Z=\frac{wu}{v}$ we have $u=\sqrt{XZ}$, $v=\sqrt{XY}$, $w=\sqrt{YZ}$, and $X+Y+Z\ge\sqrt{XY}+\sqrt{YZ}+\sqrt{ZX}$ is $\frac12\sum(\sqrt X-\sqrt Y)^2\ge0$. So (1) holds.

Hence $f$ is auraic if and only if $f(x)\ge x$ for every $x<0$ (that is, $x\le f(x)<0$), and the auraic functions are exactly \[\boxed{f:\mathbb R^-\to\mathbb R^-\text{ with }f(x)\ge x\text{ for all }x<0}.\]

Geometry · LPS VII, Chapter 43: Locus, Transformation, and Construction Geometry

Ali draws a non-degenerate quadrilateral $COPE$ that is not cyclic. Shalin may draw the line through two drawn points, mark the intersection point of two drawn lines, mark finitely many points on a drawn line (without control over where on the line they fall), and use a tool that marks the symmedian point of any triangle whose three vertices are drawn. If Shalin can draw the $C$-Sharky point of $\triangle COE$, Ali pays him $1$ coin; otherwise Shalin pays Ali $1$ coin. If Shalin can draw the isogonal conjugate of $P$ with respect to $\triangle COE$, Ali pays him $2$ coins; otherwise Shalin pays Ali $2$ coins. Ali chooses the quadrilateral so as to make Shalin's net gain as small as possible. Find the net gain of each player.

Note: $A$-Sharky point, $S$ of $ABC$ is the point on the circumcircle of $ABC$ such that $\angle ASI=90^\circ$ where $I$ is the incenter of $ABC$.

Show the answer

Shalin can draw the isogonal conjugate but (for a suitable choice by Ali) not the Sharky point: Shalin gains $2-1=1$ coin, Ali loses $1$ coin

Show the solution

Solution (A field argument and an explicit construction)

We read the problem as follows: the drawn objects are the four vertices of $COPE$; Shalin may draw the line through two drawn points, mark intersections of drawn lines, mark arbitrary new points on drawn lines (the construction must work whatever these points are), and apply the tool that marks the symmedian point of three drawn points. Ali chooses the quadrilateral to hurt Shalin. Write $\triangle=COE$.

1. The Sharky point cannot be drawn (for a suitable quadrilateral). Let $F$ be the field generated by the coordinates of the four given points. The intersection of two lines through points with coordinates in a field $L$ has coordinates in $L$, and the symmedian point of $XYZ$ has barycentric coordinates $YZ^2:ZX^2:XY^2$, which are polynomials in the coordinates; so it also has coordinates in $L$. An arbitrary marked point on a drawn line adds one parameter $t$. Hence, if the construction uses arbitrary points with parameters $t_1,\dots,t_r$, every drawn point has coordinates in $F(t_1,\dots,t_r)$. Since the construction must work for every choice, we may take $t_1,\dots,t_r$ algebraically independent over the algebraic closure of $F$.

Ali takes $C=(0,0)$, $O=(4,0)$, $E=(1,3)$ (and $P$ any rational point such that $COPE$ is a non-degenerate, non-cyclic quadrilateral, for instance $P=(13/5,1)$, as in the figure), so $F=\mathbb Q$. The incentre of $\triangle COE$ is $I=\frac{OE\cdot C+CE\cdot O+CO\cdot E}{OE+CE+CO}$ with $OE=3\sqrt2$, $CE=\sqrt{10}$, $CO=4$, and solving for the second intersection of the circle $(COE)$ with the circle on diameter $CI$ gives the Sharky point \[S=\Bigl(\tfrac{7-5\sqrt2-\sqrt{10}+\sqrt5}{6},\ \tfrac{1+5\sqrt2-\sqrt{10}-\sqrt5}{6}\Bigr)\notin\mathbb Q^2 .\] Its coordinates are algebraic but irrational, and a purely transcendental extension $\mathbb Q(t_1,\dots,t_r)$ contains no algebraic numbers outside $\mathbb Q$. So $S$ can never be drawn, and Shalin pays Ali $1$ coin.

2. The isogonal conjugate can always be drawn. We build up a toolkit (all steps are classical straightedge constructions).

  • Harmonic conjugates. Given collinear $X,Y,Z$, the harmonic conjugate of $Z$ with respect to $X,Y$ is drawn with the straightedge (complete quadrilateral). Hence for three lines through a point $V$ we can draw the harmonic conjugate line.

  • Tangents. At a vertex, say $O$, of $\triangle$, the lines $OC,OE$, the symmedian $OK$ ($K$ the symmedian point, given by the tool) and the tangent to $(COE)$ at $O$ form a harmonic pencil: the median and the parallel to $CE$ through $O$ are harmonic with respect to $OC,OE$, and reflecting in the bisector of $\angle O$ (which preserves cross-ratios and swaps $OC,OE$) turns them into the symmedian and the tangent. So all three tangents can be drawn, hence the pole $T$ of each side (intersection of two tangents).

  • Midpoints. For side $OE$ with pole $T$, triangle $OET$ is isosceles ($TO=TE$), so its symmedian point (given by the tool) lies on its axis of symmetry, which passes through the midpoint of $OE$. So the midpoint of each side is drawable.

    If one angle of $\triangle$, say at $C$, is right, the tangents at $O$ and $E$ are parallel and the pole of $OE$ does not exist. The midpoints of $CO$ and $CE$ are still drawn as above, so (by the next item) we can draw the parallel to $CE$ through $O$ and the parallel to $CO$ through $E$; they meet at a point $D$, $CODE$ is a parallelogram, and its diagonal $CD$ meets $OE$ at the midpoint of $OE$. (At most one angle of $\triangle$ is right, so this covers every case.)

  • Parallels. If $XY$ has a drawn midpoint $M$, the parallel to $XY$ through any drawn point $Z$ is drawable: pick $S$ on line $XZ$, let $Q=SM\cap YZ$ and $R=XQ\cap SY$; then $ZR\parallel XY$. So we can draw parallels to the three sides.

  • Isogonal of a line. Let $\ell$ be a drawn line through $C$. Take any point $X\ne C$ on line $CO$; let $U$ be the intersection of $\ell$ with the parallel to $CE$ through $X$, and $Y$ the intersection of line $CE$ with the parallel to $CO$ through $U$. Then $CXUY$ is a parallelogram, so $\ell=CU$ passes through the midpoint of $XY$: $\ell$ is the $C$-median of $\triangle CXY$. The tool gives the symmedian point $K'$ of $CXY$, and $CK'$ is the isogonal of $\ell$ with respect to the angle $C$ (the angle of $CXY$ at $C$ is the angle of $\triangle$ at $C$).

Apply the last step to $\ell=CP$ at $C$ and, in the same way, to $OP$ at $O$. The two isogonal lines meet at the isogonal conjugate of $P$ (a finite point since $P$ is not on the circle $(COE)$). So Ali pays Shalin $2$ coins.

Result. Shalin receives $2$ coins and pays $1$ coin, so \[\boxed{\text{Shalin gains }1\text{ coin, Ali loses }1\text{ coin}}\]

Problem 30

Combinatorics · LPS VII, Chapter 31: Extremal Principle and Bounding Arguments

Let $n\ge 2$ be a positive integer. Apollo wants to place countesses on an $n\times(2n-2)$ chessboard. A countess can attack horizontally, vertically, or along the downright/up-left diagonal, including the cells they occupy. Determine the minimum number of countesses needed so Apollo can place them such that every cell in the board is attacked by at least one countess.

Show the answer

$n-1$ if $4\nmid n$, and $n$ if $4\mid n$

Show the solution

Solution (Sumset bound, a parity obstruction, and Skolem pairings)

Number the rows $0,\dots,n-1$ and the columns $0,\dots,m-1$, $m=2n-2$. A countess at $(i,j)$ attacks row $i$, column $j$ and the diagonal $\{(x,y):x-y=i-j\}$. One countess in each row attacks everything, so $n$ countesses always suffice.

Lower bound $k\ge n-1$. Let $k$ countesses cover the board, using $r\le k$ rows, $c\le k$ columns and a set $D$ of $|D|\le k$ diagonal values. If all rows are used, $k\ge n$. Otherwise let $R$ ($|R|=n-r\ge n-k$) be the unused rows and $C$ ($|C|=m-c$) the unused columns; if $C=\emptyset$, $k\ge m\ge n-1$. Otherwise each cell of $R\times C$ is covered only by a diagonal, so $R-C=\{x-y:x\in R,y\in C\}\subseteq D$. For non-empty finite sets of integers $|R-C|\ge|R|+|C|-1$ (if $R=\{x_1<\dots<x_p\}$, $C=\{y_1<\dots<y_q\}$, the differences $x_1-y_q<x_1-y_{q-1}<\dots<x_1-y_1<x_2-y_1<\dots<x_p-y_1$ are distinct). Hence \[k\ge|D|\ge(n-k)+(2n-2-k)-1,\qquad\text{i.e.}\qquad k\ge n-1 .\]

When $4\mid n$, $n-1$ is impossible. Suppose $k=n-1$. All inequalities above are equalities: the countesses are in distinct rows and distinct columns, exactly one row $i_0$ is unused, $|C|=n-1$, the diagonals are distinct and $D=\{i_0-y:y\in C\}$. Sum the diagonal values in two ways: \[\sum_{\text{countesses}}(i-j)=\Bigl(\sum_{i=0}^{n-1}i-i_0\Bigr)-\Bigl(\sum_{j=0}^{m-1}j-\sum_{y\in C}y\Bigr),\qquad\sum_{d\in D}d=(n-1)i_0-\sum_{y\in C}y .\] Equating, $2\sum_{y\in C}y=n\,i_0-\frac{n(n-1)}2+(n-1)(2n-3)=n\,i_0+\frac{3(n-1)(n-2)}{2}$. If $n=4q$, the right side is $4q\,i_0+3(4q-1)(2q-1)$, which is odd, while the left side is even. Contradiction; so for $4\mid n$ the answer is $n$.

Construction with $n-1$ countesses when $4\nmid n$. A Skolem pairing of order $N$ is a partition of $\{1,\dots,2N\}$ into $N$ pairs $\{x_d,y_d\}$ with $y_d-x_d=d$ for $d=1,\dots,N$. They exist for $N\equiv0,1\pmod4$: for $N=1,4,5$ use \[\{1,2\};\qquad \{7,8\},\{2,4\},\{3,6\},\{1,5\};\qquad \{9,10\},\{2,4\},\{5,8\},\{3,7\},\{1,6\},\] and for $N=4s$ ($s\ge2$), respectively $N=4s+1$ ($s\ge2$), the pairs

  • $N=4s$: $\{4s+r-1,\,8s-r+1\}$ ($1\le r\le2s$), $\{2s+1,6s\}$, $\{j,4s-1-j\}$ ($1\le j\le s-1$), $\{2s,4s-1\}$, $\{s,s+1\}$, $\{s+1+j,3s-j\}$ ($1\le j\le s-2$);

  • $N=4s+1$: $\{4s+r+1,\,8s-r+3\}$ ($1\le r\le2s$), $\{2s+1,6s+2\}$, $\{j,4s+1-j\}$ ($1\le j\le s$), $\{2s+2,4s+1\}$, $\{s+1,s+2\}$, $\{s+2+j,3s+1-j\}$ ($1\le j\le s-2$).

(For $N=4s$ the differences are the even numbers $4s,\dots,2$, then $4s-1$; $4s-3,\dots,2s+1$; $2s-1$; $1$; $2s-3,\dots,3$, and the pairs use $4s,\dots,6s-1$ and $6s+1,\dots,8s$; then $6s$; $1,\dots,s-1$ and $3s,\dots,4s-2$; $2s$, $4s-1$; $s,s+1$; $s+2,\dots,2s-1$ and $2s+2,\dots,3s-1$: every number of $1,\dots,8s$ exactly once. The case $N=4s+1$ is checked the same way.)

Case $n\equiv1,2\pmod4$. Take a Skolem pairing of order $N=n-1$ and, for each pair $\{x,y\}$ with $y-x=d$, put a countess at row $d$, column $y-1$. Rows $1,\dots,n-1$ are used once each, the columns $y-1$ are distinct, and the unused columns are the $x-1$. The countess has diagonal value $d-(y-1)=-(x-1)$. So every cell of row $0$ in an unused column $x-1$ lies on a used diagonal, and everything else is attacked by a row or a column.

Case $n\equiv3\pmod4$. Take a Skolem pairing of order $N=n-2\equiv1\pmod4$ on the columns $0,\dots,2n-5$ (shift by $1$) and place, for each pair with difference $d$, a countess at row $1+d$, column $y-1$; add one countess at row $0$, column $2n-4$. The rows used are all except row $1$. The diagonal values are $1+d-(y-1)=1-(x-1)$ for the Skolem pairs and $0-(2n-4)=1-(2n-3)$ for the extra countess, so every cell of row $1$ in an unused column ($x-1$ or $2n-3$) is attacked diagonally.

So the minimum is $\boxed{n-1}$ when $4\nmid n$ and $\boxed{n}$ when $4\mid n$.
