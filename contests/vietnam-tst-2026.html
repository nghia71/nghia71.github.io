Problem 1

Number Theory · LPS VII, Chapter 12: Exponential Congruences and Order Structure

For a positive integer $k$, a set $\mathcal{S}$ of positive integers is called $k$-Olympic if it satisfies

  • $\mathcal{S} \ne \emptyset$,

  • For all $n \in \mathcal{S}$ then all positive divisors of $(25^n - 3^n)k^n$ are also in $\mathcal{S}$.

Find all positive integers $k$ such that there exists a unique $k$-Olympic set.

Show the answer

all $k$ divisible by $15$

Show the 2 solutions

Solution 1 (Strong induction with Euler's theorem)

Answer: exactly the multiples of $15$.

For every $k$ the set $\mathbb{Z}^+$ of all positive integers is $k$-Olympic. So the $k$-Olympic set is unique if and only if every $k$-Olympic set equals $\mathbb{Z}^+$. Note that $25^n-3^n>0$ for all $n\ge1$.

If $15\nmid k$, there is a second $k$-Olympic set.

  • If $3\nmid k$, let $T$ be the set of positive integers not divisible by $3$. For $n\in T$ we have $25^n-3^n\equiv1\pmod 3$ and $3\nmid k^n$, so no divisor of $(25^n-3^n)k^n$ is divisible by $3$: all its divisors are in $T$. Thus $T$ is $k$-Olympic and $T\neq\mathbb{Z}^+$.

  • If $5\nmid k$, let $T$ be the set of positive integers not divisible by $5$. Now $25^n-3^n\equiv-3^n\not\equiv0\pmod5$ and $5\nmid k^n$, and the same argument applies.

If $15\mid k$, every $k$-Olympic set $\mathcal S$ is $\mathbb{Z}^+$. We prove $m\in\mathcal S$ by strong induction on $m$.

$m=1$: $\mathcal S$ is non-empty, and $1$ divides $(25^n-3^n)k^n$ for any $n\in\mathcal S$; so $1\in\mathcal S$.

Let $m\ge2$ and suppose $1,2,\dots,m-1\in\mathcal S$. It is enough to find an integer $n$ with \[1\le n<m\qquad\text{and}\qquad m\mid(25^n-3^n)k^n, \tag{1}\] because then $n\in\mathcal S$ and $m$ is a positive divisor of $(25^n-3^n)k^n$. Write $m=m_1m_2$, where $m_1$ is the product of the prime powers $p^{v_p(m)}$ with $p\mid k$, and $\gcd(m_2,k)=1$. Then $\gcd(m_1,m_2)=1$ and, since $15\mid k$, $\gcd(m_2,15)=1$. Let $e$ be the largest exponent of a prime in $m_1$ ($e=0$ if $m_1=1$); then $m_1\mid k^n$ whenever $n\ge e$, and $2^e\le m_1$, so $e<m_1$ when $m_1\ge2$.

  • If $m_2=1$, take $n=e$. Then $n\ge1$ (as $m=m_1\ge2$), $n=e<m_1=m$, and $m\mid k^n$.

  • If $m_2>1$, take $n=\varphi(m_2)\cdot\max(e,1)$. By Euler's theorem $25^{\varphi(m_2)}\equiv1\equiv3^{\varphi(m_2)}\pmod{m_2}$, so $m_2\mid25^n-3^n$; and $m_1\mid k^n$ because $n\ge e$. As $\gcd(m_1,m_2)=1$, $m\mid(25^n-3^n)k^n$. Moreover $\varphi(m_2)<m_2$ and $\max(e,1)\le m_1$, so $1\le n<m_1m_2=m$.

In both cases (1) holds, which completes the induction.

Hence a unique $k$-Olympic set exists exactly when $\boxed{15\mid k}$.

Solution 2 (One explicit divisibility chain)

Answer: exactly the multiples of $15$.

For every $k$ the set $\mathbb{Z}^+$ of all positive integers is $k$-Olympic, so the $k$-Olympic set is unique if and only if every $k$-Olympic set equals $\mathbb{Z}^+$. Note that $25^n-3^n>0$ for all $n\ge1$.

If $15\nmid k$, there is a second $k$-Olympic set. If $3\nmid k$, let $T$ be the set of positive integers not divisible by $3$. For $n\in T$ we have $25^n-3^n\equiv1\pmod3$ and $3\nmid k^n$, so no divisor of $(25^n-3^n)k^n$ is divisible by $3$, and $T$ is $k$-Olympic with $T\ne\mathbb{Z}^+$. If $5\nmid k$, the set of positive integers not divisible by $5$ works in the same way, because $25^n-3^n\equiv-3^n\not\equiv0\pmod5$ and $5\nmid k^n$.

If $15\mid k$, every $k$-Olympic set $\mathcal S$ is $\mathbb{Z}^+$. Since $\mathcal S$ is non-empty and $1$ divides $(25^n-3^n)k^n$ for any $n\in\mathcal S$, we have $1\in\mathcal S$. Define \[n_1=1,\qquad n_{j+1}=(25^{n_j}-3^{n_j})\,k^{n_j}\quad(j\ge1).\]

  • (a) Every $n_j$ lies in $\mathcal S$, by induction: $n_1=1\in\mathcal S$, and if $n_j\in\mathcal S$, then $n_{j+1}$ is a positive divisor of $(25^{n_j}-3^{n_j})k^{n_j}$ (namely the number itself), so $n_{j+1}\in\mathcal S$.

  • (b) $n_j\mid n_{j+1}$ for all $j$, by induction. Clearly $n_1=1\mid n_2$. If $n_{j-1}\mid n_j$, say $n_j=q\,n_{j-1}$, then with $u=25^{n_{j-1}}$ and $v=3^{n_{j-1}}$ we get $u-v\mid u^q-v^q$, i.e. $25^{n_{j-1}}-3^{n_{j-1}}\mid25^{n_j}-3^{n_j}$; also $k^{n_{j-1}}\mid k^{n_j}$. Multiplying, $n_j\mid n_{j+1}$. Consequently $n_i\mid n_j$ whenever $i\le j$.

  • (c) The sequence is strictly increasing: $n_{j+1}\ge k^{n_j}\ge2^{n_j}>n_j$.

Claim. Every positive integer $m$ divides some $n_j$.

This finishes the proof: if $m\mid n_j$, then $m\mid n_{j+1}=(25^{n_j}-3^{n_j})k^{n_j}$ by (b), and $n_j\in\mathcal S$ by (a), so $m\in\mathcal S$.

Proof of the Claim, by strong induction on $m$. For $m=1$ it is clear. Let $m\ge2$ and assume the Claim for all smaller numbers. Write $m=m_1m_2$, where $m_1$ is the product of the prime powers $p^{v_p(m)}$ with $p\mid k$, and $\gcd(m_2,k)=1$; then $\gcd(m_1,m_2)=1$ and, as $15\mid k$, $\gcd(m_2,15)=1$. Let $e$ be the largest exponent of a prime in $m_1$ ($e=0$ if $m_1=1$). If $n\ge e$, then $v_p(k^n)\ge n\ge v_p(m)$ for every prime $p\mid k$, so $m_1\mid k^n$. By (c) there is an index $J$ with $n_j\ge e$ for all $j\ge J$.

  • If $m_2=1$, then $m=m_1\mid k^{n_J}\mid n_{J+1}$.

  • If $m_2>1$, then $\varphi(m_2)<m_2\le m$, so by the induction hypothesis $\varphi(m_2)\mid n_i$ for some $i$, and by (b) $\varphi(m_2)\mid n_j$ for all $j\ge i$. Take $j=\max(i,J)$. As $\gcd(m_2,3)=\gcd(m_2,25)=1$, Euler's theorem gives $25^{\varphi(m_2)}\equiv1\equiv3^{\varphi(m_2)}\pmod{m_2}$, hence $25^{n_j}\equiv1\equiv3^{n_j}\pmod{m_2}$ and $m_2\mid25^{n_j}-3^{n_j}$. Also $m_1\mid k^{n_j}$ because $n_j\ge e$. Since $\gcd(m_1,m_2)=1$, $m\mid(25^{n_j}-3^{n_j})k^{n_j}=n_{j+1}$.

This proves the Claim. Hence a unique $k$-Olympic set exists exactly when $\boxed{15\mid k}$.

Problem 2

Combinatorics · LPS VII, Chapter 39: Graph Theory and Structural Combinatorics

Let $n$ be a positive integer. In a country, there are $8n+3$ airports. For any two airports, either there exists a direct route or not. Assume that for any two airports that do not have a direct route, the difference between the number of direct routes of the two airports is $2$. Determine the minimal number of direct routes in the country.

Show the answer

$16n^2+12n+3$

Show the solution

Solution (Pass to the complement, which is bipartite)

Let $G$ be the graph of airports and direct routes, with $N=8n+3$ vertices, and let $H$ be its complement (two airports are joined in $H$ when there is no direct route). Put $a=4n$, so $N=2a+3$. Since $d_H(v)=N-1-d_G(v)$, the condition says: \[\text{if }uv\text{ is an edge of }H,\text{ then }|d_H(u)-d_H(v)|=2. \tag{$\ast$}\] Minimising the number of edges of $G$ is the same as maximising the number $e$ of edges of $H$. We show that the maximum is $a(a+2)$. Below, $d=d_H$.

Example. Let $H$ be the complete bipartite graph $K_{a,a+2}$ together with one isolated vertex. The degrees at the ends of each edge are $a+2$ and $a$, so $(\ast)$ holds, and $e=a(a+2)$. (In terms of airports: two groups of $4n$ and $4n+2$ airports, all routes inside each group, no route between the groups, and one more airport joined to all others.)

Upper bound. Let $H$ satisfy $(\ast)$.

(1) $H$ is bipartite. Colour a vertex $v$ by the parity of $\lfloor d(v)/2\rfloor$. If $uv$ is an edge, $d(u)$ and $d(v)$ differ by $2$, so $\lfloor d(u)/2\rfloor$ and $\lfloor d(v)/2\rfloor$ differ by $1$: the ends have different colours. Let $P,Q$ be the colour classes, $|P|=x\le|Q|=y$, $x+y=2a+3$; so $x\le a+1$. Counting edges from either side, $e=\sum_{v\in P}d(v)=\sum_{v\in Q}d(v)$.

(2) Every degree is at most $a+2$. Let $v_0$ have the maximum degree $\Delta\ge1$. Each neighbour $w$ of $v_0$ has degree $\Delta-2$ (it cannot be $\Delta+2$), and $w$ has $\Delta-2$ neighbours, all in the colour class of $v_0$, while the $\Delta$ neighbours of $v_0$ are in the other class. Hence $2a+3\ge\Delta+(\Delta-2)$, i.e. $\Delta\le a+2$.

(3) If $x\le a$, then $e=\sum_{v\in P}d(v)\le x\Delta\le a(a+2)$.

(4) If $x=a+1$, then $y=a+2$, and vertices of $P$ have degree at most $a+2$.

  • If some $u\in P$ has $d(u)=a+2$, then $u$ is joined to all of $Q$, and every vertex of $Q$ has degree $a$ (not $a+4>\Delta$). So $e=\sum_{v\in Q}d(v)=a(a+2)$.

  • If some $u\in P$ has $d(u)=a+1$, then its $a+1$ neighbours in $Q$ have degree $a-1$ (not $a+3>\Delta$), and the remaining vertex of $Q$ has degree at most $x=a+1$. So $e\le(a+1)(a-1)+(a+1)=a(a+1)<a(a+2)$.

  • Otherwise all vertices of $P$ have degree at most $a$ and $e\le(a+1)a<a(a+2)$.

So always $e\le a(a+2)$.

Answer. The minimal number of direct routes is \[\binom{8n+3}{2}-4n(4n+2)=(8n+3)(4n+1)-16n^2-8n=\boxed{16n^2+12n+3}.\]

Remark. The argument uses only that the number of airports is odd: for $2a+3$ airports the minimum is $\binom{2a+3}{2}-a(a+2)$.

Problem 3

Geometry · LPS VII, Chapter 45: Complex Numbers in Geometry

Let $ABC$ be an acute, scalene triangle with altitudes $AD, BE, CF$. The projections of $A$ onto lines $EF, FD, DE$ are $X, Y, Z$ respectively. Line $BZ$ intersects the circumcircle of triangle $BDY$ at $P \ne B$, line $CY$ intersects the circumcircle of triangle $CDZ$ at $Q \ne C$. Prove that $X$ has equal power with respect to the circumcircles of triangles $YFP$, $ZEQ$.

Show the solution

Solution (P and Q lie on the circle XYZ; then complex numbers on that circle)

Angles $\angle(\ell,\ell')$ between lines are directed, modulo $180^\circ$.

Step 1: the circle $\alpha$. Since $B,C,E,F$ are concyclic and $A,C,D,F$ are concyclic, $\angle AFE=\angle ACB=\angle BFD$. So the line $AB$ bisects an angle between the lines $FE$ and $FD$, and $A$ is equidistant from them: $AX=AY$. In the same way (at $E$) $AX=AZ$. Let $\alpha$ be the circle with centre $A$ through $X,Y,Z$; it is tangent to the lines $EF,FD,DE$ at $X,Y,Z$. (It is the excircle of triangle $DEF$ opposite $D$.) Tangent segments from a point are equal: $DY=DZ$, $EX=EZ$, $FX=FY$. Hence $AD$, $AE$, $AF$ are the perpendicular bisectors of $YZ$, $ZX$, $XY$, and since $AD\perp BC$, $AE\perp BE$, $AF\perp CF$: \[YZ\parallel BC,\qquad ZX\parallel BE,\qquad XY\parallel CF. \tag{1}\]

Step 2: $P$ and $Q$ lie on $\alpha$. The line $BZ$ is not tangent to $\alpha$ (the tangent at $Z$ is $DE$, and $B\notin DE$); let $P_1\ne Z$ be its second intersection with $\alpha$. Here $P_1\ne Y$: otherwise $B$ would lie on the line $YZ$, which by (1) is parallel to $BC$ and different from it. By the tangent–chord theorem in $\alpha$ (the tangent at $Y$ is the line $DY$) and by (1), \[\angle(P_1Y,P_1B)=\angle(P_1Y,P_1Z)=\angle(YD,YZ)=\angle(DY,DB).\] So $B,D,Y,P_1$ are concyclic. Also $P_1\ne B$, because $AB>AF>AX$ shows that $B$ is outside $\alpha$. Hence $P_1$ is the second intersection of $BZ$ with the circle $BDY$, i.e. $P_1=P$. So $P\in\alpha$ and $P\ne Y$; similarly $Q\in\alpha$ and $Q\ne Z$.

Step 3: a formula for the power. Let $c_1$ be the circle $YFP$. For a point $T$ let $\pi_1(T)$ and $\pi_\alpha(T)$ be its powers with respect to $c_1$ and $\alpha$. The difference $\pi_1-\pi_\alpha$ is a polynomial of degree at most $1$ in the coordinates of $T$ (the quadratic terms cancel), and it vanishes at $Y$ and $P$, the common points of the two circles. Now $\pi_\alpha(X)=0$, $\pi_1(F)=0$ and $\pi_\alpha(F)=FX^2$. Hence, for any polynomial $g$ of degree $1$ vanishing on the line $YP$, \[\pi_1(X)=\frac{\pi_1(X)-\pi_\alpha(X)}{\pi_1(F)-\pi_\alpha(F)}\cdot\bigl(-FX^2\bigr)=-FX^2\cdot\frac{g(X)}{g(F)}. \tag{2}\] (Here $g(F)\ne0$: $F$ lies on the tangent to $\alpha$ at $Y$, which meets the chord line $YP$ only at $Y$.)

Step 4: complex coordinates. Take $A$ as the origin and $\alpha$ as the unit circle; let $x,y,z$ be the complex numbers of $X,Y,Z$ (so $\bar x=1/x$, etc.). We use two standard facts for points $u,v$ of the unit circle: the tangents at $u$ and $v$ meet at $\dfrac{2uv}{u+v}$, and a point $w$ lies on the line $uv$ iff $w+uv\,\bar w=u+v$. Thus \[f=\frac{2xy}{x+y},\qquad e=\frac{2xz}{x+z},\qquad d=\frac{2yz}{y+z},\qquad \bar f=\frac2{x+y},\quad \bar d=\frac2{y+z}.\] The point $B$. $B$ lies on the line $AF$, so $b=\tau f$ with $\tau$ real, and $BD\perp AD$ means $\operatorname{Re}\bigl((b-d)\bar d\bigr)=0$, i.e. $\tau\operatorname{Re}(f\bar d)=|d|^2$. Here \[|d|^2=d\bar d=\frac{4yz}{(y+z)^2},\qquad f\bar d+\bar fd=\frac{4xy+4yz}{(x+y)(y+z)},\qquad\text{so}\quad \operatorname{Re}(f\bar d)=\frac{2y(x+z)}{(x+y)(y+z)},\] and therefore \[\tau=\frac{2z(x+y)}{(x+z)(y+z)},\qquad b=\frac{4xyz}{(x+z)(y+z)},\qquad \bar b=\frac{4z}{(x+z)(y+z)}.\] The point $P$. $P$ is on the unit circle and $B$ lies on the line $ZP$: $b+zp\,\bar b=z+p$, so $p=\dfrac{z-b}{z\bar b-1}$. Consequently \[\frac{x-p}{y-p}=\frac{b+xz\,\bar b-x-z}{b+yz\,\bar b-y-z}.\] Now $b+xz\,\bar b=\dfrac{4xz(y+z)}{(x+z)(y+z)}=\dfrac{4xz}{x+z}$, so the numerator is $\dfrac{4xz-(x+z)^2}{x+z}=-\dfrac{(x-z)^2}{x+z}$; similarly the denominator is $-\dfrac{(y-z)^2}{y+z}$. Hence \[\frac{x-p}{y-p}=\frac{(x-z)^2\,(y+z)}{(x+z)\,(y-z)^2}. \tag{3}\] The power of $X$. In (2) take $g(t)=t+yp\,\bar t-y-p$, which vanishes exactly on the line $YP$. (It is $\sqrt{yp}$ times a real polynomial of degree $1$, so the quotient $g(X)/g(F)$ in (2) is the same.) We compute \[g(x)=x+\frac{yp}{x}-y-p=\frac{(x-y)(x-p)}{x},\qquad g(f)=\frac{2xy+2yp}{x+y}-y-p=\frac{(x-y)(y-p)}{x+y},\] \[FX^2=(f-x)(\bar f-\bar x)=\frac{x(y-x)}{x+y}\cdot\frac{x-y}{x(x+y)}=-\frac{(x-y)^2}{(x+y)^2}.\] Substituting into (2) and then using (3): \[\pi_1(X)=\frac{(x-y)^2}{(x+y)^2}\cdot\frac{(x-p)(x+y)}{x\,(y-p)}=\frac{(x-y)^2\,(x-z)^2\,(y+z)}{x\,(x+y)\,(x+z)\,(y-z)^2}. \tag{4}\]

Step 5: conclusion. The whole configuration is symmetric under the exchange $B\leftrightarrow C$, $E\leftrightarrow F$, $Y\leftrightarrow Z$, $P\leftrightarrow Q$, which exchanges the circle $c_1=YFP$ with the circle $c_2=ZEQ$ and fixes $A$, $D$, $X$. So the power of $X$ with respect to $c_2$ is given by (4) with $y$ and $z$ interchanged. But the right-hand side of (4) is symmetric in $y$ and $z$. Therefore $X$ has the same power with respect to the circles $YFP$ and $ZEQ$.

Problem 4

Geometry · LPS VII, Chapter 48: Inversion and Circle-Preserving Transformation

In triangle $ABC$, let $AE$ and $AF$ be tangents to circle $(O)$ with diameter $BC$, where $E, F \in (O)$. Let $K$ and $L$ be the intersections of $AE$ and $AF$ with $BC$, such that $B$ lies between $K$ and $C$. Suppose $KF$ and $LE$ meet $(O)$ again at $M$ and $N$. Let $D$ be the foot of the altitude from $A$; it lies on the circles $(AB)$ and $(AC)$ with diameters $AB$ and $AC$. If the circumcircle of $\triangle MON$ meets $(AB)$ and $(AC)$ at points $X\ne D$ and $Y\ne D$ respectively, prove that \[\angle XAB = \angle YAC.\]

Show the 2 solutions

Solution 1 (Pascal, a power of a point, and a lemma on circles through O and D)

Let $\rho$ be the radius of $(O)$ and let $D$ be the foot of the altitude from $A$. Since $\angle ADB=\angle ADC=90^\circ$, $D$ lies on both circles $(AB)$ and $(AC)$. We shall see that $D$ also lies on the circle $MON$; so $X$ and $Y$ are the second intersections of the circle $MON$ with $(AB)$ and $(AC)$.

If $AB=AC$, the whole figure is symmetric in the line $AO$, which exchanges $(AB)\leftrightarrow(AC)$, $M\leftrightarrow N$ and fixes $D=O$; then $X\leftrightarrow Y$ and the claim is clear. Assume $AB\ne AC$, so $D\ne O$, and $EF$ (perpendicular to $AO$) is not parallel to $BC$ (perpendicular to $AD$).

Step 1: the lines $MN$, $EF$, $BC$ are concurrent. Apply Pascal's theorem to the hexagon $E\,E\,N\,M\,F\,F$ inscribed in $(O)$, where the sides $EE$ and $FF$ are the tangents $AE$ and $AF$. The three pairs of opposite sides are \[EE\cap MF=K,\qquad EN\cap FF=L,\qquad NM\cap FE=:G,\] so $G$ lies on the line $KL=BC$. (If $NM\parallel FE$, Pascal's theorem would give $KL\parallel EF$, which we excluded.)

Step 2: $D$ lies on the circle $MON$. The line $EF$ is the polar of $A$ with respect to $(O)$: for every point $T$ of $EF$ we have $\overrightarrow{OT}\cdot\overrightarrow{OA}=\rho^2$. Let $u$ be a unit vector along $BC$; then $\overrightarrow{OG}=g\,u$ and $\overrightarrow{OD}=\delta\,u$ with $\delta=\overrightarrow{OA}\cdot u$ (as $D$ is the projection of $A$). Applying the polar relation to $T=G$: $g\,\delta=\rho^2$. So $G$ and $D$ lie on the same ray from $O$ and $OG\cdot OD=\rho^2$. The power of $G$ with respect to $(O)$ is therefore \[GM\cdot GN=GO^2-\rho^2=GO^2-GO\cdot OD=GO\cdot GD\] (as signed products on the lines $GMN$ and $GDO$). By the converse of the power-of-a-point theorem, $M,N,O,D$ are concyclic.

Step 3: a lemma. Let $\psi$ be any circle through $O$ and $D$, meeting $(AB)$ again at $X$ and $(AC)$ again at $Y$. Then $\angle XAB=\angle YAC$.

Proof. Let $W$ be the centre of $\psi$ and let $O_B$, $O_C$ be the midpoints of $AB$, $AC$, i.e. the centres of $(AB)$, $(AC)$. The segment $O_BO_C$ is parallel to $BC$ and its midpoint is the midpoint of $AO$, whose projection on $BC$ is the midpoint of $DO$. So the perpendicular bisector $s$ of $DO$ is also the perpendicular bisector of $O_BO_C$. Since $W\in s$, the lines $WO_B$ and $WO_C$ are mirror images in $s$.

The common chord $DX$ of $\psi$ and $(AB)$ is perpendicular to the line of centres $WO_B$, and $DY\perp WO_C$. (If $\psi$ is tangent to $(AB)$ at $D$, then $X=D$ and $DX$ is to be read as the common tangent; the argument is unchanged.) Therefore the lines $DX$ and $DY$ are mirror images in a line perpendicular to $s$, i.e. in the line $BC$: \[\angle(DX,BC)=\angle(BC,DY).\] Now $A,B,D,X$ are concyclic and $A,C,D,Y$ are concyclic, so \[\angle(AX,AB)=\angle(DX,DB)=\angle(DX,BC)=\angle(BC,DY)=\angle(DC,DY)=\angle(AC,AY).\] Thus the lines $AX$ and $AY$ are symmetric with respect to the bisector of angle $BAC$, so $\angle XAB$ and $\angle YAC$ are equal or supplementary. But $X$ lies on the circle with diameter $AB$, so $\angle XAB<90^\circ$ (it is an acute angle of the right triangle $AXB$, or $0^\circ$ if $X=B$), and likewise $\angle YAC<90^\circ$. Hence $\angle XAB=\angle YAC$. $\blacksquare$

By Step 2 the circle $MON$ passes through $O$ and $D$, so the Lemma applies and $\angle XAB=\angle YAC$.

Solution 2 (Complex numbers for the concurrency, inversion, and coordinates for the lemma)

Let $D$ be the foot of the altitude from $A$. Since $\angle ADB=\angle ADC=90^\circ$, $D$ lies on $(AB)$ and $(AC)$. If $AB=AC$, the reflection in the line $AO$ exchanges $(AB)$ and $(AC)$, fixes the circle $MON$ (it swaps $M$ and $N$) and fixes $D=O$, so it swaps $X$ and $Y$ and the claim is clear. So let $AB\ne AC$.

Step 1: $MN$ and $EF$ meet $BC$ at the same point. Let $(O)$ be the unit circle in the complex plane with $B=-1$, $C=1$, and let $e,f,m,n$ be the numbers of $E,F,M,N$. For $u,v$ on the unit circle, a point $w$ lies on the line $uv$ iff $w+uv\bar w=u+v$ (for $u=v$ this is the tangent at $u$). So the tangent at $E$ meets the real axis at the real number $k=\dfrac{2e}{1+e^2}$, and the line $EF$ meets it at $g'=\dfrac{e+f}{1+ef}$ (the denominators are not $0$ since these lines are not parallel to $BC$). The line $KF$ meets the circle again at $M$: $k+fm\,k=f+m$, i.e. $m=\dfrac{f-k}{kf-1}$. Consider the map $c(w)=\dfrac{1-w}{1+w}$. Then \[c(m)=\frac{(k-1)(f+1)}{(k+1)(f-1)}=\frac{c(k)}{c(f)},\qquad c(k)=\frac{1+e^2-2e}{1+e^2+2e}=c(e)^2,\qquad\text{so}\quad c(m)=\frac{c(e)^2}{c(f)} .\] By symmetry ($L$ on the tangent at $F$, $N$ on the line $LE$) $c(n)=\dfrac{c(f)^2}{c(e)}$. The line $MN$ meets the real axis at $g=\dfrac{m+n}{1+mn}$, and \[c(g)=\frac{1+mn-m-n}{1+mn+m+n}=c(m)\,c(n)=c(e)\,c(f)=c(g').\] Since $c$ is injective, $g=g'$. (If $1+mn=0$, the same computation gives $c(e)c(f)=c(m)c(n)=-1$, i.e. $1+ef=0$ and $EF\parallel BC$, which is excluded.) So $MN$, $EF$, $BC$ meet at a point $G$ with real coordinate $g=\dfrac{e+f}{1+ef}$.

Step 2: inversion in $(O)$. The tangents at $E$ and $F$ meet at $A$, so $a=\dfrac{2ef}{e+f}$, and the foot $D$ of the perpendicular from $A$ to the real axis is \[\frac{a+\bar a}{2}=\frac{ef+1}{e+f}=\frac1g .\] Thus $D$ is the image of $G$ under the inversion in the unit circle $(O)$. This inversion fixes $M$ and $N$ and maps the line $MN$ (which does not pass through $O$, since $g\ne0$) to the circle through $O$, $M$, $N$. As $G\in MN$, its image $D$ lies on the circle $MON$. Hence $X$, $Y$ are the second intersections of the circle $MON$ with $(AB)$, $(AC)$.

Step 3: the angle equality, by coordinates. Use Cartesian coordinates $O=(0,0)$, $B=(-1,0)$, $C=(1,0)$, $D=(\delta,0)$, $A=(\delta,\eta)$ with $\eta>0$. A circle through $O$ and $D$ has an equation \[\psi:\ x^2+y^2-\delta x-2wy=0,\] and the circles with diameters $AB$, $AC$ are \[(x+1)(x-\delta)+y(y-\eta)=0,\qquad (x-1)(x-\delta)+y(y-\eta)=0 .\] Subtracting the equation of $\psi$ from each of them gives the radical axes, i.e. the lines $DX$ and $DY$: \[DX:\ (x-\delta)+(2w-\eta)\,y=0,\qquad DY:\ (x-\delta)-(2w-\eta)\,y=0 .\] These two lines are mirror images of each other in the $x$-axis $BC$, so $\angle(DX,BC)=\angle(BC,DY)$ as directed angles of lines. Since $A,B,D,X$ are concyclic and $A,C,D,Y$ are concyclic, \[\angle(AX,AB)=\angle(DX,DB)=\angle(BC,DY)=\angle(DC,DY)=\angle(AC,AY).\] So the lines $AX$, $AY$ are symmetric in the bisector of angle $BAC$, and $\angle XAB$, $\angle YAC$ are equal or supplementary. Both are smaller than $90^\circ$, because $X$ lies on the circle with diameter $AB$ and $Y$ on the circle with diameter $AC$. Therefore $\angle XAB=\angle YAC$.

Problem 5

Algebra · LPS VII, Chapter 42: Polynomial Reconstruction and Interpolation

Given positive integers $k, n$ with $k < n$. Find all monic polynomials $P(x)$ of degree $kn$ such that the degree of \[Q(x) = P(x^n+1) - (P(x))^n\] is at most $kn(n-1)$.

Show the answer

$P(x)=(x^n+1)^k+c$, $c$ any constant

Show the 2 solutions

Solution 1 (Compare with the obvious solution)

Answer: $P(x)=(x^n+1)^k+c$ with an arbitrary constant $c$. Note that $n\ge2$ because $n>k\ge1$. Put $T(x)=(x^n+1)^k$.

These polynomials work. Let $P=T+c$. With $V=(x^n+1)^n$ we have $T(x^n+1)=(V+1)^k$ and $T(x)^n=V^k$, so \[P(x^n+1)-P(x)^n=\underbrace{(V+1)^k-V^k}_{(\mathrm a)}+c-\underbrace{\bigl[(T+c)^n-T^n\bigr]}_{(\mathrm b)} .\] The polynomial (a) equals $kV^{k-1}+\cdots$ and has degree $n^2(k-1)=kn^2-n^2\le kn^2-kn$, because $k\le n$. The polynomial (b) equals $ncT^{n-1}+\cdots$ and has degree at most $kn(n-1)$. Hence $\deg Q\le kn(n-1)$.

There are no others. Let $P$ be monic of degree $kn$ with $\deg Q\le kn(n-1)$, and let $D=P-T$. Since $P$ and $T$ are both monic of degree $kn$, $\deg D<kn$. Suppose that $D$ is not constant: $e=\deg D$ satisfies $1\le e\le kn-1$, with leading coefficient $\lambda\ne0$. Then \[Q(x)=P(x^n+1)-P(x)^n=D(x^n+1)+\bigl[T(x^n+1)-T(x)^n\bigr]-\sum_{i=1}^n\binom niD(x)^iT(x)^{n-i} .\] Look at the degrees of the terms on the right.

  • The term with index $i$ in the sum has degree $ie+kn(n-i)=kn^2-i(kn-e)$, which decreases with $i$. So the sum has degree exactly $e+kn(n-1)$, with leading coefficient $n\lambda\ne0$.

  • The bracket has degree $n^2(k-1)\le kn(n-1)<e+kn(n-1)$, as shown above.

  • $D(x^n+1)$ has degree $ne$.

Since $\deg Q\le kn(n-1)<e+kn(n-1)$, the term of degree $e+kn(n-1)$ of the sum must be cancelled, and only $D(x^n+1)$ can do this. Thus $ne\ge e+kn(n-1)$, i.e. $e(n-1)\ge kn(n-1)$, so $e\ge kn$. This contradicts $e\le kn-1$.

Hence $D$ is a constant $c$, and \[\boxed{P(x)=(x^n+1)^k+c}\] for some constant $c$; by the first part, every such polynomial is a solution.

Solution 2 (Symmetry under the n-th roots of unity, then the top coefficients)

We show that the solutions are exactly $P(x)=(x^n+1)^k+c$. Note $n\ge2$.

Step 1: $P$ is a polynomial in $x^n$. Let $\zeta=e^{2\pi i/n}$ and $A(x)=P(\zeta x)$; $A$ is monic of degree $kn$ since $\zeta^{kn}=1$. Because $(\zeta x)^n=x^n$, \[Q(\zeta x)=P(x^n+1)-A(x)^n,\qquad\text{so}\qquad A(x)^n-P(x)^n=Q(x)-Q(\zeta x)\] has degree at most $kn(n-1)$. On the other hand \[A^n-P^n=(A-P)\prod_{j=1}^{n-1}\bigl(A-\zeta^jP\bigr),\] and for $1\le j\le n-1$ the factor $A-\zeta^jP$ has degree exactly $kn$ (its leading coefficient is $1-\zeta^j\ne0$). So, if $A\ne P$, then $\deg(A^n-P^n)=\deg(A-P)+kn(n-1)$, and this forces $\deg(A-P)=0$: $A-P$ is a non-zero constant. But $A(0)=P(0)$. Hence $A=P$, i.e. $P(\zeta x)=P(x)$. Comparing coefficients, the coefficient of $x^i$ in $P$ vanishes unless $n\mid i$: $P(x)=R(x^n)$ for a monic polynomial $R$ of degree $k$.

Step 2: a shift. Define $S$ by $S(t)=R(t-1)$, monic of degree $k$; then $P(x)=S(x^n+1)$. With $t=x^n+1$, \[Q(x)=S\bigl((x^n+1)^n+1\bigr)-S(x^n+1)^n=W(x^n+1),\qquad W(t)=S(t^n+1)-S(t)^n .\] So $\deg Q=n\deg W$, and the condition is $\deg W\le k(n-1)=kn-k$.

Step 3: the coefficients of $S$. Write $S(t)=t^k+s_1t^{k-1}+\dots+s_k$. Suppose that $s_j\ne0$ for some $j$ with $1\le j\le k-1$, and take the smallest such $j$. Then \[S(t)^n=\bigl(t^k+s_jt^{k-j}+\cdots\bigr)^n=t^{kn}+ns_j\,t^{kn-j}+(\text{terms of lower degree}),\] while $S(t^n+1)$ contains only powers of $t$ with exponents divisible by $n$: its highest terms are $t^{kn}$ and then exponents at most $kn-n<kn-j$ (as $j\le k-1<n$). Therefore $W(t)$ contains the term $-ns_jt^{kn-j}$, and $kn-j>kn-k$. This contradicts $\deg W\le kn-k$. So $s_1=\dots=s_{k-1}=0$, i.e. $S(t)=t^k+c$ and \[P(x)=(x^n+1)^k+c .\]

Step 4: verification. For $S(t)=t^k+c$, \[W(t)=(t^n+1)^k+c-(t^k+c)^n=\bigl[(t^n+1)^k-t^{kn}\bigr]+c-\bigl[(t^k+c)^n-t^{kn}\bigr].\] The first bracket has degree $n(k-1)=kn-n<kn-k$ and the second has degree at most $k(n-1)$. So $\deg W\le k(n-1)$ and $\deg Q\le kn(n-1)$ for every constant $c$.

The answer is $\boxed{P(x)=(x^n+1)^k+c}$, where $c$ is an arbitrary constant.

Problem 6

Combinatorics · LPS VII, Chapter 10: Double Counting and Counting Identities

Let $\mathcal{H}$ be a family of subsets of $\{1, 2, 3, \ldots, 2027\}$ such that for any $A \in \mathcal{H}$ and for any subset $B \subset A$, then $B \in \mathcal{H}$. Let $l_{\mathcal{H}}, c_{\mathcal{H}}$ denote the number of sets of $\mathcal{H}$ having an even and odd number of elements respectively. Prove that \[l_{\mathcal{H}} - c_{\mathcal{H}} \le \binom{2026}{1013}.\]

Show the 2 solutions

Solution 1 (Averaging over all maximal chains)

Let $n=2027$ and $[n]=\{1,\dots,n\}$. If $\mathcal H$ is empty there is nothing to prove, so let $\mathcal H\ne\emptyset$; then $\emptyset\in\mathcal H$. We must bound \[l_{\mathcal H}-c_{\mathcal H}=\sum_{A\in\mathcal H}(-1)^{|A|}.\]

For a permutation $\pi$ of $[n]$ consider the chain $C_0(\pi)\subset C_1(\pi)\subset\dots\subset C_n(\pi)$, $C_i(\pi)=\{\pi(1),\dots,\pi(i)\}$. Since $\mathcal H$ is closed under taking subsets and contains $\emptyset$, the indices $i$ with $C_i(\pi)\in\mathcal H$ form an initial segment $\{0,1,\dots,b(\pi)\}$.

Double counting. A fixed set $A$ with $|A|=i$ equals $C_i(\pi)$ for exactly $i!\,(n-i)!$ permutations $\pi$. Give $A$ the weight $(-1)^i\binom ni$; then \[\sum_{\pi}\ \sum_{i=0}^{b(\pi)}(-1)^i\binom ni=\sum_{A\in\mathcal H}(-1)^{|A|}\binom n{|A|}\,|A|!\,(n-|A|)!=n!\sum_{A\in\mathcal H}(-1)^{|A|} .\]

An identity. For $0\le b\le n$, \[\sum_{i=0}^{b}(-1)^i\binom ni=(-1)^b\binom{n-1}b .\] Indeed, $\binom ni=\binom{n-1}i+\binom{n-1}{i-1}$, so the sum telescopes: $\sum_{i=0}^b(-1)^i\bigl[\binom{n-1}{i}+\binom{n-1}{i-1}\bigr]=(-1)^b\binom{n-1}b$. (For $b=n$ both sides are $0$.)

Conclusion. Combining, \[l_{\mathcal H}-c_{\mathcal H}=\frac1{n!}\sum_\pi(-1)^{b(\pi)}\binom{n-1}{b(\pi)}\le\max_{0\le b\le n}\binom{2026}{b}=\binom{2026}{1013}.\]

Remark. The bound in the problem is not sharp: since only even $b$ contribute positively and $1013$ is odd, in fact $l_{\mathcal H}-c_{\mathcal H}\le\binom{2026}{1012}$, with equality for the family of all sets with at most $1012$ elements. The number $\binom{2026}{1013}$ is the sharp bound for $c_{\mathcal H}-l_{\mathcal H}$, and hence for $|l_{\mathcal H}-c_{\mathcal H}|$; it is attained by the family of all sets with at most $1013$ elements. (The letters $l$ and $c$ suggest the Vietnamese words for odd and even; with that reading the stated bound is exactly sharp.)

Solution 2 (Removing one element and symmetric chains)

Let $\mathcal H\neq\emptyset$ and write $m=2026$.

Step 1: reduction to a convex family on $[m]$. Let \[\mathcal D=\{A\subseteq[m]:\ A\in\mathcal H,\ A\cup\{2027\}\notin\mathcal H\}.\] If $A\subseteq[m]$ and $A\cup\{2027\}\in\mathcal H$, then also $A\in\mathcal H$, and the two sets $A$, $A\cup\{2027\}$ contribute $(-1)^{|A|}+(-1)^{|A|+1}=0$ to $l_{\mathcal H}-c_{\mathcal H}$. The sets of $\mathcal H$ not arising in such a pair are exactly the sets of $\mathcal D$. Hence \[l_{\mathcal H}-c_{\mathcal H}=\sum_{A\in\mathcal D}(-1)^{|A|}.\] The family $\mathcal D$ is convex: if $A\subseteq B\subseteq C$ and $A,C\in\mathcal D$, then $B\in\mathcal D$. Indeed $B\subseteq C\in\mathcal H$ gives $B\in\mathcal H$; and if $B\cup\{2027\}$ were in $\mathcal H$, so would be its subset $A\cup\{2027\}$.

Step 2: symmetric chains. Lemma. The family of all subsets of $[m]$ can be partitioned into chains $A_1\subset A_2\subset\dots\subset A_r$ with $|A_{i+1}|=|A_i|+1$ for all $i$ and $|A_1|+|A_r|=m$ (symmetric chains).

Proof by induction on $m$. For $m=0$ take the single chain $\emptyset$. For the step, from each symmetric chain $A_1\subset\dots\subset A_r$ for $[m-1]$ form the two chains \[A_1\subset\dots\subset A_r\subset A_r\cup\{m\}\qquad\text{and}\qquad A_1\cup\{m\}\subset\dots\subset A_{r-1}\cup\{m\}\] (the second is omitted if $r=1$). Their sizes increase by $1$ at each step, and $|A_1|+|A_r|+1=m$, $\ (|A_1|+1)+(|A_{r-1}|+1)=|A_1|+|A_r|+1=m$, so both are symmetric for $[m]$. Every subset of $[m]$ lies in exactly one new chain. $\blacksquare$

A symmetric chain contains exactly one set of size $m/2$ ($m$ is even), so the number of chains is $\binom m{m/2}=\binom{2026}{1013}$.

Step 3: conclusion. Let $A_1\subset\dots\subset A_r$ be one of the chains. By convexity, the members of the chain that belong to $\mathcal D$ are consecutive: $A_s,A_{s+1},\dots,A_u$ (or none). Their sizes are consecutive integers, so \[\sum_{i=s}^{u}(-1)^{|A_i|}\in\{-1,0,1\}.\] Summing over the $\binom{2026}{1013}$ chains, which partition all subsets of $[m]$, \[l_{\mathcal H}-c_{\mathcal H}=\sum_{A\in\mathcal D}(-1)^{|A|}\le\binom{2026}{1013}.\]
